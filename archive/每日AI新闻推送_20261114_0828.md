### 1. Mirendil 融资 $10 亿——前 Anthropic 研究者打造 AI 自主研发平台（WSJ / MLQ.ai | 2026-11-13）

- **事件**：由前 Anthropic 研究员 Behnam Neyshabur 与 Harsh Mehta 创办的 AI Lab Mirendil 宣布完成 $10 亿 Series A，Kleiner Perkins 与 Clearlake Capital 联合领投，Battery Ventures、Doerr Capital、Google、M13 等跟投。其内部平台 Lor 可同时运行数百个 AI Agent，自动写代码、跑实验、 provision GPU 并跨子 Agent 分发任务；公司称其最小模型训练算力成本不足 $1000 万，仅用"一名研究人员 + 3.5 个月"即完成训练。团队约 20 人，来自 Anthropic、xAI、Google DeepMind、OpenAI。
- **为何值得关注**：这是目前最激进地实践"Agent 替代人类做科研"的融资案例之一——$10 亿估值背后是"用 AI Agent 构建下一代 AI"的范式赌注。若成功，将重塑 AI 研发的人力密度模型；若失败，则验证了当前 Agent 在长周期、高不确定性探索中的局限性。
- **来源链接**：<https://mlq.ai/news/ex-anthropic-researchers-startup-mirendil-raises-1-billion-to-let-ai-agents-do-the-work-of-an-ai-lab>

### 2. OpenAI 解散独立机器人团队，押注通用模型直接控制机器人（Fortune / Benzinga | 2026-11-13）

- **事件**：据 Fortune 报道，OpenAI 已将独立机器人团队解散，研究侧并入 CRO Mark Chen 麾下，硬件与应用侧划入 Greg Brockman 领导的 Applied 组织。公司引用 Nvidia 仿真数据：GPT-6 Astra 智能体在模拟任务中达成 74.8% 成功率，显著高于专用模型平均 51%。此举被视为 OpenAI 对"通用前沿模型足以覆盖机器人控制"路线的再次确认，而非退缩。
- **为何值得关注**：与 Google DeepMind（Gemini Robotics 2.5 发布）、Figure AI（持续独立建队）形成鲜明对比。两条路线——通用模型直控 vs 专用机器人架构——的竞争结果将决定未来 2-3 年具身智能的产业格局。Altman 同时要求员工放弃"side quests"以聚焦核心项目，背景是公司成本压力与 2027 IPO 筹备。
- **来源链接**：<https://fourweekmba.com/ai-openai-disbands-robotics-team-as-gpt-6-astra-runs-robots>

### 3. 四大非营利组织诉五家前沿 AI 实验室，请求法院冻结模型升级（Just Security / Shattered.io | 2026-11-13）

- **事件**：2026-11-12，Irreplaceable Education Fund、Public Citizen、Heat Initiative 与 Alliance for Secure AI 四家非营利组织在旧金山高等法院起诉 OpenAI、Anthropic、Google、Meta 及 SpaceX AI，援引加州《不公平竞争法》（UCL），请求法院禁令禁止被告开发或部署比现有更先进的人工智能系统，直至技术被证明处于充分控制之下。诉状 63 页，由前新泽西州总检察长 Matthew Platkin 代理。截至发稿尚无法官裁决。
- **为何值得关注**：这是美国首次以 UCL 为法律依据、直接针对前沿 AI 模型升级节奏提出司法冻结的请求。若法院受理，将为 AI 安全监管开辟全新诉讼路径；即便败诉，也将推动国会层面的立法讨论。风险在于：原告引用的部分事件（如 AI 绕过安全限制访问计算机系统）尚待独立核实。
- **来源链接**：<https://www.justsecurity.org/164494/nonprofits-lawsuit-freeze-frontier-ai-development>

### 4. Paperclip AI 获 11.3 万 GitHub Star——跨厂商多 Agent 协同编程框架走红（Pasquale Pillitteri | 2026-11-13）

- **事件**：开源项目 paperclipai/paperclip 自 2026-03-02 创建以来，至 11 月 13 日已达 113,619 Star / 18,856 Fork。该项目定位为多 Agent 编排层，可同时运行 Claude Code、Codex、Gemini CLI 等不同厂商的 AI 编程智能体，分配差异化任务并统一管控，避免开发者同时开十几个终端的混乱。最新 v2026.1106.0 引入 Paperclip Runner（防 prompt injection + OTLP 可观测性）。
- **为何值得关注**：GitHub Copilot 本周已原生支持 Fable 5.2 与 Gemini 4 Carbon 双模型切换，但厂商锁定的多 Agent 协作仍是空白。Paperclip 填补了这一生态位，反映开发者群体对"混合多家 Agent 各取所长"的强烈需求。短期挑战在于各厂商 API 稳定性与费用叠加。
- **来源链接**：<https://pasqualepillitteri.it/en/news/33213/paperclip-ai-what-it-is-how-it-works>
