### 2. GitHub Universe 2026 收官：Copilot Fusion 正式版上线，Code Review Max 公开预览（GitHub Blog | 2026-11-14~15 持续报道）

- **事件**：GitHub Universe 2026 大会（旧金山，11月13–14日）发布的系列功能在过去24小时内进入集中报道期。核心亮点包括：（a）**Copilot Fusion** 正式商用（GA），三个努力等级（Standard/High/Max）+ 三种执行工作流（Single / Cascade / Critique），可根据任务类型自动选择模型组合；Fusion Max 在 Artificial Analysis Coding Agent Index 上得分 60，距 Claude Code + Opus 5.5 Max 仅差2分，但成本仅为后者的一半、耗时少约40%。（b）**Copilot Projects** 公测版推出，可在多仓库间协调并行 agent 会话。（c）**Code Review Max** 公开预览，专用于高风险变更深度审查，在 ReviewBench 高严重度问题上取得最高 F1 分数。此外还推出了 Copilot Automations（支持定时/触发运行）、三端会话连续性（CLI / VS Code / Web 无缝接续）及 Cloud Sandboxes（云端沙盒作业）。

### 3. Anthropic 消息线程（Message Threads）公开测试版——降低长会话首 token 延迟（Anthropic Blog | 2026-11-02 发布，近期持续报道）

- **事件**：Anthropic 宣布消息线程（Message Threads）进入公开测试版（public beta）。该机制使编码 agent 在连续对话中只需发送与上一轮之间的增量内容，而非每次重发完整历史；对于 token 量达 50 万至 100 万的长会话，首 token 出字时间（TTFT）中位数下降约 35%。同时配套推出 Agent Studio，允许非技术用户提供自然语言指令构建自定义 agent 工作流程。
- **为何值得关注**：长上下文 agent 的首 token 延迟是目前落地应用的核心瓶颈之一。消息线程通过增量传输显著改善交互流畅度，尤其影响流水线 agent（多个 Claude Code session 串联）的实际体验。作为 Anthropic 继 Projects 之后的又一协作层优化，消息线程补全了"单 session 内部通信效率"这一环，与 Projects 的"多 session 跨仓库编排"形成功能互补。
