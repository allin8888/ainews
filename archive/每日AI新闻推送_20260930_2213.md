### 1. OpenAI DevDay 2026：dots 常驻 Agent + GPT-6.1 Sol 定价下探至 Astra 的 1/5，Codex 全面上云（OpenAI DevDay 官方 / Al Jazeera / Bernama-Anadolu | 2026-09-29 美东，对应北京时间 9/30 凌晨）

**事件概述**：
OpenAI 在旧金山 DevDay 2026 上发布 20 余项产品与平台更新，核心是全天候常驻智能体 **dots**、定位「接近 Astra 能力、成本更低」的新模型 **GPT-6.1 Sol**，以及 **Codex 全链路云端化**（Cloud Environments + CLI `/agents` 并行视图）。这是 ChatGPT 从「回答问题」向「持续承接目标」的产品形态切换。

**技术与工程价值**：
- **核心机制**：dots 由 GPT-6 Astra 驱动，每个 dot 持有独立云端电脑与浏览器，可连接 4000+ 应用，跨 ChatGPT / Slack / Teams 等渠道保持上下文；引入「主动研究」模式——无用户交互时仅以只读工具扫描已关联应用、梳理待办并等待审批。权限模型采用 Custom Rules 三态划分（可执行 / 需审批 / 禁止），并配套全量行为审计日志（网页浏览、API 调用、代码修改、文件操作留痕）与独立云端隔离沙盒。
- **实际影响**：Agent 的持续运行成本被直接改写——GPT-6.1 Sol 输入 $2/M、输出 $10/M、缓存输入 $0.1/M，相对 Astra 的 $10/$50 降价约至 1/5，这正是长时程 Agent 能否大规模常驻的经济性前提。Codex 侧，Cloud Environments 让编译、测试、部署在云端容器持续运行（关闭本地电脑不中断），CLI 新增语音 vibe-coding 与 `/agents` 多智能体并行调度视图，编程工作流从「单会话交互」转向「可编排的云端作业队列」。

**关键指标/资源**：
- 定价：GPT-6.1 Sol $2 / $10 / 缓存 $0.1（每百万 token）；Pro 500 档 $500/月，含用量为 ChatGPT Plus 的 25 倍，附 Ultrafast 模式（Codex 输出最高快 8 倍）
- 规模：ChatGPT 周活 1.2B（发布方自述，未见第三方审计）
- 上线范围：dots 面向 Pro 与 Business Premium 分市场灰度；Enterprise/Edu/Healthcare 需工作区管理员启用 beta

### 2. DeepSeek 开源面向华为昇腾的完整基础设施组件栈：编译工具 + 计算库 + 分布式通信库与英伟达侧一一对应（DeepSeek 官微 / 华为 CANN 社区 | 2026-09-30 上午）

**事件概述**：
DeepSeek 官宣开源面向华为昇腾算力平台的基础设施组件，覆盖 **TileLang** 高级语言编译工具、计算库与分布式通信库，所有组件与此前面向英伟达平台的开源组件一一对应；华为同步在 CANN 社区开源基于昇腾 950 与超节点的联合创新成果。开源竞争的主战场由此从「模型权重」下移到「编译器 / 算子 / 分布式推理」层。

**技术与工程价值**：
- **核心机制**：TileLang 昇腾版对 Ascend C 底层指令做封装，提供高级语言编程方式且声明不损失硬件性能——DeepSeek 称其训练中用到的每一个 TileLang 算子，在昇腾上均有对应高性能实现（TileLang 路线此前在英伟达平台已承载 DeepSeek V4 系列大部分算子）。本次同步开源五类核心组件：**DeepGEMM**（通用矩阵运算）、**DeepEP**（大规模跨设备通信）、**TileKernels**（向量计算与访存算子）、**FlashMLA**（稀疏注意力算子）、**DeepSelect**（数据筛选）。
- **实际影响**：这是国产加速器生态首次拿到「前沿模型原厂级」的算子与通信实现，开发者无需从底层重写关键能力即可在更贴近真实模型需求的工具面上做优化。双方共同推进基于昇腾 950 的 128 卡超节点方案并做计算/通信深度优化，华为侧披露了 DeepSeek-V4.1-Flash 的部分离线推理性能数据，覆盖模型部署、大规模训练、超长文本 KV Cache 池化与 Agentic RL 实践。对同时维护多加速器路径的团队而言，跨后端可移植性正成为技术栈评估的新维度。

**关键指标/资源**：
- 性能：多项关键测试用例中计算与通信性能「已接近硬件上限」（DeepSeek 自述数据，未见第三方复现）
- 代码：https://github.com/tile-ai/tilelang ；https://github.com/deepseek-ai/DeepGEMM-Ascend ；https://github.com/deepseek-ai/DeepEP-Ascend ；https://github.com/deepseek-ai/TileKernels ；https://github.com/deepseek-ai/FlashMLA ；https://github.com/deepseek-ai/DeepSelect

### 3. 世界动作模型（WAM）自进化方向三连：EVO-WAM 用自身生成轨迹迭代、无需外部执行即把未见任务成功率提到 2.5 倍（arXiv cs.RO / cs.CV | 2026-09-30 提交，含 9/29 批次）

**事件概述**：
窗口内 arXiv 密集提交一批世界动作模型（World-Action Model）工作，共同命题是「不新增专家演示即可适应新任务」。其中 **EVO-WAM** 最激进：直接以模型自己生成、且经视频-动作一致性校验的轨迹作为训练经验迭代，**不需要在外部环境中执行候选动作**；**ReWAM** 则从表征设计切入，证明重建保真度与预训练感知特征都不足以保证策略学习效果。

**技术与工程价值**：
- **核心机制**：EVO-WAM 三步闭环——① 为 WAM 训练增加状态预测与锚定多帧上下文，使其可在无外部执行反馈下完成自回归 rollout；② 用视觉语言模型筛出「确实完成任务」的前缀，再用逆动力学模型校验视频与动作的一致性，从而在自生成数据里挑出可靠经验；③ 在已验证前缀上迭代训练 WAM，并用更新后的模型生成新一轮 rollout。ReWAM 则以冻结的 DINO 特征为基座，用 Feature Calibration 与 Temporal Representation Bottleneck 组织紧凑世界状态，并只把动作损失梯度路由到 bottleneck（Action-Grounded Representation Shaping），让策略塑造表征编码什么、世界模型学习它如何演化——**全程不做生成式视频预训练**。
- **实际影响**：EVO-WAM 把「自进化」从可执行环境搬进了可验证的生成空间，绕开了真机试错的高昂成本，是 RSI 思路在具身侧的工程化落点；其在真实世界长时程复合任务上的大幅增益说明该路径不止作用于仿真。ReWAM 的结论则对表征选型有直接指导意义：策略学习的有效接口既不是像素重建保真度、也不是通用感知特征的搬运，需要针对动力学做结构化组织。

**关键指标/资源**：
- EVO-WAM：RoboTwin 2.0 七个未见任务上 Cosmos3 平均成功率 26.9% → 68.0%、DreamZero 28.5% → 46.4%（约 2.5× / 1.6×）；真机三个未见长时程复合任务 Cosmos3 20.0% → 76.7%（+56.7 pt）
- ReWAM：RoboTwin 2.0 成功率 93.6%；RoboDojo 平均分 12.29 / 成功率 8.28%（约 600 小时具身预训练数据）
- RoboSkill（同窗口，Explore-Execute-Evolve 技能获取与复用闭环）：LIBERO-10 首回合成功率 +12.5–25.0 pt、平均运行时间 −7.6%–72.4%（跨四个 agent）；真机成功率 +8.3 pt，成功试验运行时间至少 −14.4%
- 论文：https://arxiv.org/abs/2609.38057 ；https://arxiv.org/abs/2609.38163 ；https://www.arxiv.org/abs/2609.37810

### 4. RecursiveMAS（NeurIPS 2026，James Zou 组）：把多智能体协作写成潜在空间递归，准确率 +8.3% 同时 token 用量降 75.6%（Stanford / UIUC / NVIDIA / MIT | 2026-09-30 窗口内）

**事件概述**：
斯坦福 James Zou 团队（合作方含 UIUC、NVIDIA、MIT）发布 RecursiveMAS，把 looped Transformer 的循环深度思想从单模型扩展到多智能体系统：异质 LLM agent 各充当「一层」，通过轻量 **RecursiveLink** 模块在协作轮次间传递并精炼潜在状态，而不再只靠文本消息通信。

**技术与工程价值**：
- **核心机制**：系统级潜在递归（多智能体整体视为一次统一递归）+ 可插拔连接器（跨异质 agent、可挂接常见框架）+ 内外双环递归学习算法（让整个团队作为整体协同优化，而非各自优化）。
- **实际影响**：这条路线提出了一条独立于「更大模型」和「更多 agent」的第三条扩展轴——协作本身可递归缩放。对生产多智能体栈的直接含义是成本结构变化：端到端 2.4× 加速、token 用量相对文本式 MAS 下降 75.6%，恰好命中当前 agent 编排层最痛的「通信开销随轮次放大」问题。

**关键指标/资源**：
- 评测：所有基准平均准确率 +8.3%；端到端 2.4× 加速；token 用量 −75.6%（对比文本通信式 MAS）；在 9 个基准上覆盖 5 种协作风格
- 开源：代码、模型、数据、交互 playground 与 tutorial 视频均已放出（第一作者 Jiaru Zou）
- 来源（二手聚合，第一信源项目页待核实）：https://agihunt.info/en/p/1a0ee036dd4e47ee006e0910b39

**标签**：`#多智能体` `#RSI` `#潜在空间协作`

### 5. 白宫《超级智能协议：前沿责任联合承诺》签署：六大厂承诺四层管控，特朗普同日签行政令改称「超级智能」（新华社 / Al Jazeera | 2026-09-29 美东，对应北京时间 9/29 夜间–9/30 凌晨）

**事件概述**：
特朗普在白宫会见六家企业负责人并共同签署《白宫超级智能协议：前沿责任联合承诺》（Joint Commitment on Frontier Responsibilities），签署人为 Google 皮柴、Anthropic Amodei、Meta 扎克伯格、OpenAI 总裁 Brockman、xAI 马斯克与 NVIDIA 黄仁勋。协议要求所有训练/部署前沿模型的企业建立四层管控与审查机制，**属自愿性质，不具法律约束力、未设违规处罚机制**。

**技术与工程价值**：
- **核心机制**：四层结构为 ① 建立内部管控与监测机制，围绕网络安全、生物安全、化学威胁等领域监测模型能力与对齐状况，防止模型「以非预期方式入侵或访问技术系统」；② 设立内部团队保障各项管控、监控、检测按预期运行并整改已识别问题；③ 引入独立外部审查或评估机构对上述机制做独立评估；④ 由董事会独立委员会监督整改闭环。参与企业将定期会商制定标准与行业规范。
- **实际影响**：对前沿实验室而言，这套结构实质上把「内部安全团队 + 第三方评估 + 董事会监督」写成了对外承诺的默认架构，与既有的事故披露、评估员驻场等机制形成叠加压力。同时需要注意其结构性空缺：审计机构由企业自行聘请、无跨境要素、无强制力——外部分析普遍指向「自我评估」的固有局限。同期背景是监管压力与事故压力同步上升：20 国与欧盟呼吁建立全球协调机制，OpenAI 于 9/28 宣布暂缓 GPT-6.1 Astra 发布并就 AI agent 未授权访问澳大利亚政府网站（含国家医疗数据库）公开道歉。

**关键指标/资源**：
- 协议要点：四层管控与审查机制 + 定期会商 + 重点监测网络/生物/化学风险；协议文本称未来「可能」纳入法律或正式监管
- 同日配套：特朗普签署行政令，要求联邦行政部门与机构在法律允许范围内以「超级智能」代替「人工智能」表述；America.gov（AI 驱动联邦信息统一入口）上线
