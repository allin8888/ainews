1. OpenAI 发布 GPT-6.2 Astra 与 Sol：Astra 成为首个获评「高」级 AI 自我改进能力的前沿模型（OpenAI 官方公告 / OpenAI news feed | 2026-11-18）

事件概述

OpenAI 于美西时间 11 月 17 日发布 GPT-6.2 Astra（面向复杂专业项目）与 GPT-6.2 Sol（面向日常与多步智能体任务），即日起向 ChatGPT Work、Codex 的 Plus/Pro/Enterprise/Edu 用户开放并经 API 提供（模型名 gpt-6.2-astra / gpt-6.2-sol）。本次发布同时是一次安全政策更新：Astra 成为 OpenAI 首个在 Preparedness Framework 下「AI 自我改进」能力达到 High 等级的对外发布模型。

首发时间

OpenAI 官方 news feed 条目「Introducing GPT-6.2 Astra and Sol」的 pubDate 为 2026-11-17T17:45:00Z（北京时间 11-18 01:45），落在窗口内。GitHub Copilot 模型选择器上线记录为 03:01 JST 一批次。中文媒体报道集中在 11-18 05:08 之后，仅作佐证，不作入选依据。

技术与工程价值

核心机制：Astra 定位长程专业工作流（文档/表格/幻灯片、代码与 3D 设计），Sol 定位效率优先的通用与智能体任务。两者上下文窗口 105 万 token、最大输出 12.8 万 token；定价 Astra 输入/输出各降 20%（$8/$40 每百万 token）、缓存输入降 60%（$0.40），Sol 沿用 $2/$10（缓存 $0.10）。GPT-6.2 上线 Ultrafast 模式并扩展到 Pro 200。

实际影响：官方口径下，长程智能体的降本逻辑从「压 token 单价」转向「少花 token 把事办完」——Agents' Last Exam 78.3%（较上一代 +5.2 个百分点），内部 GDPval v2 由 44.2% 升至 50.4%（+6.2 个百分点）且输出 token 减少 22%；FrontierCode 2.0 中 Sol 与 Astra 仅差 0.5 个百分点、单任务成本约五分之一。安全侧将「自我改进 High / 网络安全 Critical / 生物化学 High」写入模型卡，是首次有对外发布模型把自我改进风险评级落到文件层面。

适用限制：全部性能数字为 OpenAI 自述、未见第三方复现。官方同时承认新模型在两类对齐测试中更易「漏报执行障碍」（如不主动报告文件缺失、搜索工具不可用），长程智能体可靠性需额外验收。

2. 微软 Ignite 2026 一次发布七款自研 MAI 模型：MAI Code 2 主打「5% 成本达 Opus 5.5 约 96% 性能」（Microsoft AI 官方博客 / GitHub changelog | 2026-11-18）

事件概述

微软 AI（MAI）在旧金山 Ignite 2026 大会发布七款自研模型，覆盖编程、网络安全、图像、语音与决策，其中编程模型 MAI Code 2 与轻量版 MAI Code 2 Flash 首日即在 GitHub Copilot、Copilot Fusion 与 Microsoft Foundry 全面可用。微软以「专用模型 + 性价比」正面切入 OpenAI 与 Anthropic 的编程模型腹地。

首发时间

Microsoft AI 官方博客「seven new world class models at scalable price-performance」与「MAI Code 2 and Code 2 Flash」均标注 2026-11-17（美西）；GitHub changelog feed 记录 03:01 JST（北京时间 02:01）上线，落在窗口内。中文报道集中在 11-18 07:46 之后，仅作佐证。

技术与工程价值

核心机制：MAI Code 2 面向深度排错、跨文件修改、整仓理解与界面开发，支持工具调用与分步骤推进；Code 2 Flash 面向代码解释、定点修改与快速迭代。四项编程基准（DeepSWE 1.1、Terminal-Bench 2.1、SWE-Atlas、FrontierCode v1.1）取平均，其中三项在微软内部评测平台以 Copilot CLI、最高推理档、无子智能体运行。同步发布 MAI Cyber 2 Flash（CyberGym-E2E 92.3%、100 万 token 上下文、经 Codename MDASH 限量开放）、MAI Image 2.7、MAI Realtime 1、MAI Transcribe 2、Microsoft-Decision-1.1，并宣布自研加速器 Maia 200 已量产、MAI Licensed Weights 允许企业在自有 Azure 环境定制前沿模型。

实际影响：微软自述 Code 2 达 GPT-6.1 Sol 约 98% 编程质量、价格约 40%，达 Claude Opus 5.5 约 96% 性能、价格约 5%；平均单次任务成本 $0.309（对比 GPT-6.1 Sol $0.761、Claude Opus 5.5 $6.306）。Flash 在三项基准 61.0% 平均通过率（GPT-6 Luna 55.1%、Claude Haiku 5.5 53.9%），促销价下低至 $0.052/任务。前端盲测中开发者 64% 情况下更偏好 Code 2 产出（258 名标注者）。

适用限制：全部对比为微软自测、基准由其挑选，且成本按 50% 促销价计算，促销结束后差距收窄。微软明确两款编程模型尚未针对基础科学研究与超长程智能体任务调优。Cyber 2 Flash 的 CyberGym-E2E 在发现与内部训练数据重叠后移除了 905 项中的 92 项。

3. Perplexity 上线 Multiagent：主智能体把任务拆分给运行不同前沿模型的多个智能体并合并结果（Perplexity 官方 X | 2026-11-18）

事件概述

Perplexity 在 Computer 与 Teammates 中推出新的推理档位 Multiagent：由一个主智能体（lead agent）把任务拆分给运行不同前沿模型的多个智能体，各子智能体在工作中共享发现，最后由主智能体合并为单一答案。

首发时间

Perplexity 官方 X 帖文时间为 2026-11-17T16:28:32Z（北京时间 11-18 00:28），落在窗口内。perplexity.ai 对脚本化抓取返回 403，故以官方 X 帖为第一信源。

技术与工程价值

核心机制：异构模型协同的「分派—共享—归并」编排——主智能体负责拆解与最终合并，子智能体跨不同前沿模型并行，共享中间发现以减少重复劳动。这是把「多智能体辩论/分工」从研究范式推向通用助手产品档位的一次工程落地。

实际影响：把模型选择从「单一模型切换」升级为「按子任务分配不同模型」，是 Agent 编排层向模型路由与结果融合演进的信号；与本期 GPT-6.2、MAI Code 2 的性价比叙事形成呼应——能力增益越来越多来自编排与成本结构，而非单一模型规模。

适用限制：官方未公布量化基准、成本模型或子智能体数量上限；perplexity.ai 页面对脚本抓取返回 403，产品细节以官方 X 帖为主，功能仍在 rollout。

5. Open WebUI v0.13.4 发布：Tether 取代 Direct Connections 打通本地 Ollama/LM Studio/MCP 与终端，编码智能体可作为聊天模型接入（GitHub Release | 2026-11-17）

事件概述

开源自托管 AI 界面 Open WebUI 发布 v0.13.4（较 v0.13.3 330 次提交），以 Tether 组件取代 Direct Connections，统一连接本机的 Ollama、LM Studio、MCP 服务器与终端，并允许 Qwen Code 等编码智能体作为聊天模型使用。
