1. vLLM v0.32.0 发布：/v1/systemone 结构化决策端点到家，NVFP4 KV cache 全架构普及 GitHub Releases | 2026-10-18

事件概述

vLLM 于北京时间 10 月 18 日 14:50 发布 v0.32.0，汇集 814 个 commit、363 位贡献者（121 位新贡献者）。本版把「结构化决策」能力下沉为推理引擎默认面，同时将低精度 KV cache 推向全硬件架构，并带来多 API worker 负载路由等面向 Agent 高并发短请求场景的系统性改进。

技术与工程价值

  • 核心机制：新增 POST /v1/systemone 端点，直接在引擎内回答 choice / noul / score 三类结构化决策问题并默认提供服务——与近期 OpenAI Decisions API、Perplexity pplx-decider 等「决策模型独立品类」浪潮形成开源基建侧呼应，编码 Agent 的工具选择/分支判断可不再经过自由文本生成。
  • 低精度 KV cache 全面铺开：NVFP4 KV cache 新支持 SM8x / SM90 / SM12x（含 SM12x XQA decode），GLM-5.x 在 SM100 默认切换 FP8 KV cache，ROCm 新增 ultraquant_4bit（约 FP8 两倍密度）。
  • 通用 hf 解析器：读取 checkpoint 自带的 response_template，新模型接入无需再写模型特定解析器，Python 与 Rust 前端双支持。
  • 多 API worker 最小负载路由：--api-server-count > 1 时按最小负载分配连接，直接优化 Agent 循环中「短请求、高频率」的请求模式。
  • 安全面：修复 3 个 GHSA（chat template 资源耗尽、tokenizer max_token_id 差一错误、P2P ZMQ socket 耗尽），CORS 默认不再放开所有源。
  • 实际影响：KV cache 低精度化直接扩大单卡可服务上下文长度与并发会话数，是自建 Agent 推理基础设施最直接的降本杠杆；/v1/systemone 与 hf 解析器分别从「决策原生支持」和「模型接入成本」两侧降低 Agent 工作流的工程摩擦。

2. VAST 开源实时世界模型 EdenLive：单卡 RTX 5090 720P 超 24FPS，「状态-渲染解耦」架构落地 VAST 官方 GitHub + 量子位 | 2026-10-18

事件概述

VAST 于 10 月 18 日正式发布并开源实时世界模型 EdenLive（Project Eden 的阶段成果，今年 6 月研究预览的延续），模型权重、推理代码、技术报告与端到端 Demo 同步上线（GitHub VAST-AI-Research/EdenLive，Apache-2.0，项目主页 vast-eden.ai），并附带开源「Prompt to Proxy Game」Skill 游戏原型。

技术与工程价值

  • 核心机制：官方称首次在实时生成前提下同时实现「任意参考输入 + 任意画风 + 长时连续运行」——给定简化场景或参考视频、目标首帧与提示词，模型沿参考的布局与运动持续生成写实、二次元等不同画风的精细画面。
  • 架构分工：延续 Project Eden 确立的「状态维护与视觉渲染解耦」——上游交互系统维护世界状态与交互规则，EdenLive 只负责把状态变化实时渲染出来，从用户输入到画面呈现的端到端延迟为百毫秒级。
  • 实际影响：交互式世界模型（游戏、仿真、虚拟内容生产）的实时性门槛从数据中心级算力降到单张消费级显卡；「物理规则由符号系统维护、视觉由生成模型渲染」的分层为「可玩性一致性」与「生成式视觉表现」的结合提供了可复用的工程范式，也回应了「AI 搭场景」能力普及之后的实时渲染缺口。

3. 西湖机器人 WR1 通用大脑：全球首创大小脑双预训练，WM+VLA+GAE 融合驱动全身协同家务任务链 西湖机器人（杭州）经新浪财经/网易报道 | 2026-10-19

事件概述

据 10 月 19 日报道，西湖机器人（杭州，官网 wlrobo.com）发布全新升级的通用大脑 WR1 并以真实家庭场景演示连贯家务任务链：人形机器人从晃动晾衣架上取下长裤、搭臂承托、抛送机械臂，转身铺展长裤并与第二台人形协同折叠，全程视觉观察、实时调整；官方称其中「人形机器人灵巧手自主折叠衣物」为全球首个演示案例，多项关键能力对标甚至超越 Figure 等海外标杆。

技术与工程价值

  • 核心机制：WR1 采用官方所称「全球首创的通用大小脑双预训练系统架构」，把多模态任务理解与全身控制深度耦合——大脑侧融合世界模型（WM）与视觉-语言-动作模型（VLA），依据视觉观察与语言指令统一输出包含身体移动、全身姿态、灵巧手操作的完整动作序列；小脑侧由自研的「全球首个通用动作大模型」GAE 完成高速稳定执行；双机协同演示中两台机器人互为观察对象、按对方动作与物体实时状态调整配合。
  • 实际影响：家务类长程任务链（柔性物体 + 外部扰动 + 多机协作）是具身智能公认最高门槛场景之一，WR1 的演示把竞争焦点从「单点技能（抓杯/叠毛巾）」推向「连贯任务执行」；其 WM+VLA 大小脑融合路线与本期 EdenLive 等「世界模型进入策略/渲染层」的进展共同强化了「世界模型作为具身系统核心组件」的趋势。
