事件
Meta AI Research 于 11 月 9 日发布 Muse Ember——其最小的开源模型系列之一，专为低成本 AI Agent 和编码任务设计。API 定价为输入 $0.10/百万 token、输出 $0.50/百万 token，同时支持 1M-token 上下文窗口。Model API 与 Google Cloud 同步上线，支持直接调用 Wonder / Spark / Ember 全系列模型。
为何值得关注
Muse Ember 填补了「高成本低效 Agent」的生态位——此前用 Claude Haiku 或 GPT-4o-mini 跑批量 Agent 时单 token 成本仍显著。$0.10/Mi input 比现有最廉价选项低一个量级，配合 Muse 系列的 Active Memory 机制（长期记忆+主动专注），有望推动企业级 Agent 批量化部署。定价策略本身也是 Meta 对抗 Anthropic/OpenAI API 溢价的明确信号。

事件
Google 将其内部 AI Agent 沙箱运行时 Agent Substrate 捐赠至 CNCF（Cloud Native Computing Foundation），与 gVisor 同属安全隔离基础设施线。初始版本尚未支持 GPU passthrough 和 live CUDA 热插拔，定位偏向 CPU-bound Agent sandbox（类似容器隔离），文档标注「first release coming soon」。
为何值得关注
这是 OpenClaw / Devin / Claude Code 等 Coding Agent 走向生产化之后必然遇到的基础设施问题——谁来保障 Agent 执行代码的沙箱？CNCF 托管意味着未来可能形成行业标准接口，且与 gVisor 兼容栈叠加能覆盖从 kernel namespace 到 container runtime 的完整隔离层次。对具身智能侧启示：仿真→真实部署的安全边界同样需要标准化沙箱，Google 此步先手值得持续跟踪。

事件
据 Interesting Engineering 报道，Anthropic Claude Fable 5.2 团队完成了一项里程碑测试——使用 1000 个并行 AI Agent 协作，在 8 天内从零构建出一个功能完整、可运行的操作系统内核原型。该项目由 Anthropic 开源技术团队主导，代码仓库已公开，后续将用于评测多 Agent 协作极限。
为何值得关注
这是一次对「AI 能否独立完成复杂系统工程」的压力测试。传统观点认为 LLM 擅长片段生成、不擅长全局架构；但 1000-Agent 并发验证了分治+一致性校验的有效性。对 AI Coding 领域直接影响：未来 IDE 内置的 Agent 编程环境可能不再局限于单轮补全，而是支持跨文件级重构与子模块并行生成。
