1. Exo：把优化循环折叠进任务执行的 agent 运行时自我改进架构——在岗学习中同时修订 harness 与策略，模型成本对 Codex 降 12–53% （arXiv 2611.00463 · Tue-03 批次 | 2026-11-03 BJ 13:00 公告）

事件概述

Krentsel、Sylvia Ratnasamy、Ion Stoica、Martin Casado、Ankur Goyal 等发布 Exo——一个支持「在岗安全学习」的 agent 运行时架构：把优化循环折叠进任务执行本身，允许 agent 在持续工作过程中同时修订自己的 harness（经可检视的代码变更）与后续策略；由最小「受保护机制层」保存执行历史并管辖策略激活，使 harness 演化不破坏安全边界。论文 v1 提交于 10-30（周末提交顺延），随 arXiv Tue-03 批次公开（公告 2026-11-03 05:00 UTC = 北京 13:00，窗口内）。本条同时补全第 124 跑待核实项：当时仅有 Arena X 转述且误归因为「Google Research」，本跑以 arXiv 元数据确证作者归属并取回全部基准数字。

技术与工程价值

  • 核心机制：与「离线跑数据集 + 代价高昂的重复执行」的自动 harness 优化路线不同，Exo 在任务执行中就地完成「发现失败 → 提议修改 → 受保护激活」闭环；受保护机制层只做两件事（保执行历史、管策略激活），把对 agent 行为的干预压缩到最小面。这把 RSI 从「模型自我改进」下沉到「运行时基础设施自我改进」——harness 以可检视代码形式演化，天然可审计。
  • 实际影响：长时程开放世界目标下，Exo 相对 Codex 与 Pi 独立运行降模型成本 12–53%、迁移运行降 45–82%，任务完成率持平；同等起始策略下若不可编辑策略则无此收益（消融对照），验证收益来自「策略可演化」而非单纯调度。

2. NorthCUA 技术报告：经验飞轮 + 递归自我改进 + 桌面/网页联合 RL，开源 CUA 模型家族 Nano/Mini/Pro/Ultrafast （arXiv 2611.02102 · Tue-03 批次 | 2026-11-03 BJ 13:00 公告）

事件概述

NorthCUA 发布集成系统技术报告：Experience Flywheel 供给多样可执行任务 → NorthCUA Harness 维持长程交互、记录决策并核验任务结果 → 从记录中策展已验证轨迹；未解决任务走递归自我改进——演化可复用技能并保留已验证里程碑，使后续尝试在先前进度上继续。Staged Learning 将经验与 grounding 数据结合做 mid-training 与长程 SFT，策略再经桌面/网页联合强化学习在同一 Harness 内从新尝试中学习。模型 v1 提交于 11-01（周末顺延），随 Tue-03 批次公开（北京 11-03 13:00，窗口内）。

技术与工程价值

  • 核心机制：把「经验生产」与「策略改进」闭环在同一 harness 内打通：harness 同时是执行环境、记录器与结果核验器，使 RL 训练信号（任务是否真完成）与部署时分布一致；递归自我改进以「技能库 + 里程碑保留」形式组织，避免每次从零试探。产出 Nano/Mini/Pro/Ultrafast 四档——Ultrafast 在 pre-RL Nano 上配对直选动作与开放式生成，给出实测质量-延迟折衷。

3. 小米汽车发布 Auto World Model 2.0：统一流式因果世界模型覆盖真实驾驶与具身智能，VTA+多视角 RoPE+WorldRec 2.0 前向重建 （arXiv 2611.01677 · Tue-03 批次 | 2026-11-03 BJ 13:00 公告）

事件概述

小米汽车团队（22 人署名）发布 Auto World Model 2.0——面向 Physical AI 的统一流式因果世界模型：建模并生成真实世界的因果物理演化，统一异构条件输入实现视角一致生成。架构以 View-Temporal Attention（VTA）捕获跨视角空间依赖与时序动态，以多视角旋转位置编码（RoPE）编码跨视角/跨时位置关系；WorldRec 2.0 从多视角、多时刻观测单次前向重建静态与动态 3D 高斯，以其渲染作为显式场景上下文保障长时程生成的几何与外观；VTA 时序层引入门控线性注意力（GLA）降低多视角 rollout 的计算与 KV-cache 开销。v1 提交于 11-01，随 Tue-03 批次公开（北京 11-03 13:00，窗口内）。

技术与工程价值

  • 核心机制：一个模型同时服务「驾驶世界模型」与「具身智能」两条线——预训练混合大规模视频与异构视觉模态学视觉/几何/动态先验，mid-train 跨视角配置训练「动作与物体状态如何塑造后续场景演化」，蒸馏式 post-train 后进入闭环仿真评估；配套物理交互数据管线覆盖多样交互与长尾事件。WorldRec 2.0 的「单次前向 → 3D 高斯 → 显式场景上下文」是把重建结果直接当作生成的几何锚，缓解长时程漂移。

4. Archon Robotics 发布 Anchor 1：人形全身操作控制器 + 分级基准，真实世界追踪误差较全基线降 30–80% （arXiv 2611.00193 · Tue-03 批次 | 2026-11-03 BJ 13:00 公告）

事件概述

Archon Robotics（25 人署名，含 Yu Qiao、Hongyang Li 等）发布 Anchor 1——面向「精准且稳定的人形全身操作」的全身控制器，并配套覆盖多样协调需求的基准。方法三件套：① 校准稀疏运动参考——保留任务相关的人体运动结构、免在线关节空间重定向，为精准控制留出运动学自由度；② 离线策展「机器人运动 × 校准稀疏参考」配对分布，把训练分布塑形至稳定、物理合理的全身协调；③ 显式误差反馈与运动编码解耦——提升控制精度的同时支持灵活指令接口。v1 提交于 10-30，随 Tue-03 批次公开（北京 11-03 13:00，窗口内）。

技术与工程价值

  • 核心机制：抓住全身操作的独特难点——执行偏差敏感（小误差或意外迈步即失败）。与「全身跟踪优先」路线不同，Anchor 1 把「任务相关的稀疏参考」与「自由度」分离：参考只锚定任务所需结构，其余关节留给优化器，再以解耦的误差反馈通道约束漂移。基准沿精准度、持续执行稳定性、可达性三轨评估。
  • 实际影响：最严苛真实世界全局评分设置下，追踪误差较全部既有基线降 30–80%，且前瞻输入更少、免重定向；仿真与真机双验证。人形从「运动技能展示」转向「操作可用性」的控制器层竞品开始出现。

5. Auriga 技术报告：任务无关具身 agent harness 零样本关闭 RoboDojo 68.3% 规划-执行鸿沟 （arXiv 2611.01112 · Tue-03 批次 | 2026-11-03 BJ 13:00 公告）

事件概述

Auriga 团队（21 人署名，Chang Xu 组）量化了具身 VLM 的规划-执行鸿沟：在 RoboDojo 上，GPT-6 Astra 在参考控制接口下操作成功率仅 22.5%，移除手臂执行环节即升至 76.2%——差距不在「会不会想」而在「能不能动」。Auriga 作为任务无关 harness 零样本（无目标任务试跑、无重置）关闭该鸿沟的 68.3%：模型在显式任务信念上做全部任务决策，经直接工具调用或合成多步 Python 程序行动；harness 提供校准 3D 测量、指端参考双臂控制与通往机器人的单一准入网关；运动前模型在仿真暂停态检视视觉轨迹预览。v1 提交于 10-31，随 Tue-03 批次公开（北京 11-03 13:00，窗口内）。

技术与工程价值

  • 核心机制：与 NorthCUA「经验飞轮喂 RL」不同，Auriga 不训练模型，纯靠 harness 工程弥合鸿沟：校准测量替代 VLM 的几何瞎猜、指端参考替代关节空间抽象、单一准入网关收口安全、轨迹预览把「执行后才发现错」提前到「执行前」。这是「harness 即产品」路线在具身方向的对照实验。
  • 实际影响：给「VLM 直接当机器人策略」这一流行叙事给出量化反驳（22.5% vs 76.2%），并证明零样本 harness 可回收近七成差距；对 agent harness 设计（信念状态、准入网关、预览门控）给出可迁移组件。

6. WorldSketch：VLM 不再生成动作、转而「搭建世界模型」——自改进运动学世界模型实现零样本移动操作 （arXiv 2611.00513 · Tue-03 批次 | 2026-11-03 BJ 13:00 公告）

事件概述

WorldSketch（Jiaming Wang）提出 agentic robotics 新范式：VLM 不编排预定义技能、也不直接生成动作，而是作为 agent 主动查询感知工具，搭建并可视化校验一个「最小运动学世界模型」——只捕获任务相关物体、交互几何与可能运动；几何规划器随后在该模型上联合优化接触与全身运动。世界模型本身可自改进：执行反馈核验结果、更新不确定假设，使 agent 能力随部署累积。随 Tue-03 批次公开（北京 11-03 13:00，窗口内）。

技术与工程价值

  • 核心机制：在「技能编排（受技能库限制）」与「VLM 直出动作（要求 VLM 精通几何与接触）」两难之外开出第三条路：VLM 出「世界模型 + 约束」，几何规划器出「动作」——分工使 VLM 回避其最弱项（精确几何/接触推理），并把错误面收窄到可校验的显式模型上。
  • 实际影响：零样本移动操作（无需目标场景演示）+ 世界模型随执行自改进，与 Exo（运行时自我改进）、NorthCUA（技能递归演化）同日构成「自改进」在 harness/世界模型/技能库三个层面的完整样本；单作者工作，工程可复现性待第三方验证。
