1. 百度开源 ERNIE 5.5 Flash Base：280B/14B 激活 MoE 预训练终点权重，混合稀疏注意力与 Multi-Router Latent MoE

百度文心官方技术博客 | 2026-11-05

事件概述

百度文心于 11 月 5 日发布并开放 ERNIE-5.5-Flash-Base 权重——一个总参数 280B、每 token 激活 14B 的稀疏 MoE 基座语言模型，在 33.5T tokens 上从零完成预训练，训练上下文最长 128K、微调与推理支持 1M tokens。本次开放的是预训练终点 checkpoint（未经中训练与后训练），FP8 与 BF16 两套 safetensors 已上架 Hugging Face，并同步提供 vLLM / SGLang 部署示例与 NVIDIA Megatron-Bridge 微调示例。

技术与工程价值

  • 核心机制：43 层 Transformer，围绕「单位激活参数、单位 KV cache 字节的效果」逐组件重构。① Latent-Gated Sparse Attention：37 层采用 HCA 重度压缩注意力（每 128 个 token 压成 1 条缓存），仅 6 层用 MLA+DSA 逐 token 稀疏访问全上下文；低秩门控改用各层本就生成的 query latent 计算输出门，门投影权重参数减少 75%；另有 VHA 跨头低秩混合。② Multi-Router Latent MoE：多个独立初始化的 sigmoid 路由器共同打分，针对「单一路由器打分与专家实际效用仅弱相关、落选专家拿不到梯度致错误自强化」；512 个路由专家选 10 外加 1 共享专家，专家在 2048 维隐空间计算，dispatch/combine 通信量与专家 FLOPs 约减半。③ ECHO：复用主干最后一层做多步预测、取代独立 MTP 模块，多步损失直接作用于生成下一 token 的参数，作投机解码草稿模型时涌现外推特性。另有 MultiMax 输出头、mHC（4 条并行残差流）与 R2L 数字分词（词表约 200K）。训练侧用分布式 Muon + FP8，Dense/MoE 同号卡通信融合为单次集合通信；FlashMask-4 基于 CuTe-DSL 支持 SM90/SM100、head dim 最高 576/512，SM100 上相对 FlashAttention-4 MaskMod 前向最高提升 175%、反向 74%。
  • 实际影响：把「Base 权重」作为阶段明确、可对照的公共研究基线开放，配合统一 checkpoint 让不同后训练方法的增益可直接比较，降低领域适配、指令微调、强化学习与 Agent 行为塑造的起步成本。预训练语料特别加强仓库级代码与软件演化数据（commit、issue、pull request、代码评审、需求→PR 与多 commit 轨迹、自动生成测试、经 CI 验证的修复），明确面向仓库级推理与 Agent 软件工程能力。

2. 月之暗面发布 Kimi Hosted Agents：把 Agent Harness 做成云端服务（Harness as a Service）

Kimi 开放平台官方发布 / 官方文档 | 2026-11-05

事件概述

月之暗面于 11 月 5 日正式发布 Kimi Hosted Agents（托管智能体），把支撑 Agent 运行的 Harness 作为云端服务提供给企业与开发者，提供 7×24 小时托管环境，支持长程任务执行与多智能体高效协作，企业无需自行搭建和维护运行框架。官方同步上线快速开始、定价、API 参考文档及首批 8 个金融 Agent 模板。

技术与工程价值

  • 核心机制：Kimi Durable Harness Core 把会话历史、工具执行、沙箱、失败恢复、超时重试五层由「应用方自建」转为「平台托管」——事件溯源 + 断点续跑（平台故障后自动接管并恢复到中断前状态）、可定制 Agent Loop（Ralph loop、planner-executor-verifier、coordinator agent team 等编排范式）、上下文工程（工具按需加载、长任务压缩、追求 token 效率与 cache rate）、隔离云沙箱与网络访问控制、项目级凭证库与预算限制、执行留痕可审计导出。安全侧提供 Kimi Inference Hook：在每次模型推理前由企业自建/自采安全服务器对初始提示词与工具返回内容做 allow/deny 裁决，平台不留存提示与响应、仅记录裁决与时间戳（当前仅对企业认证用户定向开放）。
  • 实际影响：把 Agent 从原型验证到生产上线的工程门槛压缩为「定义任务 + 接入工具」，底层运行环境的维护与升级由平台承担；配套 140+ Skills 与 30+ 插件，覆盖联网检索、专业数据查询、办公文档处理、内容生成，并已接入 Wind、iFinD、东方财富、S&P Global、SEC EDGAR 等金融数据源，企业亦可挂接自有工具、数据源与内部 MCP。这标志 B 端商业化从「卖模型推理 API」向「卖智能体运行时」延伸，与本期 ERNIE Base 权重开放共同构成「基座—运行时」两层的分工。

3. Compounding Physical RSI：把执行失败转成可继承能力的自进化策略，RoboDojo-Sim 42 任务登顶

arXiv 2611.06654 · cs.RO Thu-05 公告批次 | 2026-11-05

事件概述

提出「复利式物理 RSI（Compounding Physical RSI）」自进化策略框架，把策略执行中的失败转化为可遗传给下一代的能力；在 RoboDojo-Sim 基准全部 42 个任务上，CSU-AI-07 以三 seed 均值 Overall Score 26.15、Success Rate 20.70% 位列榜首。

技术与工程价值

  • 核心机制：论文先指出物理环境中阻断「复利」的三个瓶颈——终局执行反馈很少能定位是哪个阶段导致失败、失败轨迹本身不提供纠正动作、更新共享参数会退化已掌握技能；由于任务完成率近似各阶段通过率的乘积，代际增益本可相乘放大。对应设计三阶段闭环：① 自动化能力缺口评估把失败 rollout 追溯到进度中断的任务阶段，并生成结构化改进目标；② remedy 阶段按该目标筛选已验证的阶段相关经验，用行为正则化离线强化学习精炼策略，无需在每个优化步做昂贵的在线 rollout；③ retention 阶段在「继承的参考策略」与「精炼后策略」之间构造权重空间候选，跨任务集评估后把最佳候选晋升为下一代参考状态，以守护既有技能。
  • 实际影响：把「执行 → 诊断 → 自我更新」的物理 RSI 从概念推进到可计量、可离线运行的闭环，并显式处理「学新不忘旧」这一持续训练的核心工程难点；对长时序分阶段操作任务的策略迭代与部署给出可复用流程，也与本期 PyRUA-REAL 的「技能资产沉淀」路线形成互补。

4. PyRUA-REAL：真实世界具身递归自我改进，coding agent 把交互经验沉淀为持久记忆与可复用技能

arXiv 2611.06768 · cs.RO Thu-05 公告批次 | 2026-11-05

事件概述

以 GPT-6-Astra 级 coding agent 为驱动，研究真实世界中的具身递归自我改进：PyRUA-REAL 让编码智能体把物理交互经验保留为持久记忆与可复用的可执行技能，用于指导后续探索与代码精炼；在 8 个真实世界任务上平均成功率 91.1%，在 RoboDojo 基准 42 个任务上平均成功率 84.4%。

技术与工程价值

  • 核心机制：不同于「每轮从零开始」的在线 agent 循环，框架把探索、执行反馈、代码精炼、部署四步产出的经验固化为两类可继承资产——持久记忆与可执行技能（程序），后续轮次的探索、改进与任务迁移可直接调用。研究系统考察了智能体如何协作、哪类执行反馈真正支撑有效的代码精炼、任务规格与既有技能如何影响鲁棒性与任务迁移；并额外评估「脱离在线 agent 决策、只部署最终程序」时产出程序的效率与能力，即把自我改进成果固化为可独立运行的交付物。
  • 实际影响：把 RSI 从「参数或策略自更新」扩展到「程序与技能资产自沉淀」，且验证沉淀结果可离线部署，降低真实机器人持续运行对在线大模型的依赖；为「物理探索 → 可复用机器人技能」提供实证指导，是本期 AI Coding 与具身智能、RSI 三条主线的交汇点。

5. Calibrated Relational World Models：用校准关系世界模型检测「静默动作接口失配」

arXiv 2611.06653 · cs.RO Thu-05 公告批次 | 2026-11-05

事件概述

把学到的「状态—动作—效果」关系当作离线契约，用于检测机器人动作在形状与量程都合规、但语义错误（坐标轴置换、符号反转、旋转重标定、夹爪极性反接）的「静默动作接口失配」，并对最可能出错的字段排序。论文被 CoRL 2026「机器人世界模型不确定性建模」Workshop 收录。

技术与工程价值

  • 核心机制：用干净留出的转移样本校准告警阈值，配合固定逆词汇表做闭集定位；在 10 个 LIBERO Spatial 任务、432 条源 episode 上做容量受控对比，于 2.5% 经验干净误报率下比较三种打分：ridge 前向残差、四分量联合高斯混合、以及同一混合的精确条件分布。结果显示条件分布召回最高，而联合打分在定位上更优，呈现明确的「检测—定位权衡」。
  • 实际影响：为机器人部署前与运行中的接口语义校验提供不依赖在线试错的离线诊断手段，把「世界模型」用于可审计的安全校验而非仅用于生成画面。更值得关注的是评测纪律：作者明确声明这些是回顾性诊断、不是部署校准保证，且 DROID、HYDRA 全部三个任务、短时故障、小偏移、精确修复与模拟缓解均未通过各自 gate，xArm 仅贡献 1 个任务——结论仅支持「有界离线诊断 + 检测定位权衡」，不构成联合密度方法优越或跨机器人安全性的证据。这种完整披露负面边界的写法，对世界模型落地讨论比又一组 SOTA 数字更有参考价值。
