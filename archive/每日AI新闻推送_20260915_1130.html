1. 云知声 U2-Flash：首个以 RSI 自主闭环驱动后训练的商用主力编码模型

云知声港交所自愿性公告 | 2026-09-15

云知声（09678.HK）于 9 月 15 日港交所自愿性公告正式发布 U2-Flash——基于 U2 通用基座强化后训练的新一代高密度智能模型，并首次公开声明其训练采用"模型深度参与自身训练"的递归自我改进（RSI）自主闭环机制。这是 RSI 方向从学术探索（MetaRSI 等）向可审计、可回滚的工程实践落地的一次标志性进展。

技术与工程价值

  • 核心机制：模型深度参与任务生成、轨迹分析与纠错重采，自主构建规模近 10 万条覆盖主流编程语言的高质量 SWE 任务集；异步 Agent RL（并行 Worker 沙盒 + GRPO 策略优化）使有效训练轨迹数提升约 60%；多自训练教师在线策略蒸馏使同等能力训练步数减少约 55%；自适应动态任务生成防止训练集被"刷穿"；Agent 能力反哺训练系统，实现自主巡检、修复与重启。所有自主调整限定在人工设定的沙盒与验证标准内，全程可回滚记录。
  • 实际影响：编程/Agent/数学推理/指令遵循能力统一于一套权重，以远小于同类稠密模型的激活规模实现主力级任务质量；四档可控推理强度接口在高强度档位输出完整可读推理链。已上线云知声 MaaS 平台。RSI 训练闭环 + 国产算力适配的组合，为"模型参与自身演进"提供了可审计的工程范式。

关键指标 / 资源

  • 评测（自述，未见第三方复现）：DeepSWE v1.1 64.6（较前代翻倍）；TerminalBench 3.0 24.3（超 K3）；SWE-Bench Pro 61.6（+10.5）；Agent 任务迭代步数 -20%~30%；任务周期 -35%；TTFT <3s，峰值吞吐 300 tokens/s；架构：稀疏 MoE，总参约 266B，激活约 10B

2. 「定速前沿」协议成形并引爆全球 AI 股抛售：四家头部实验室罕见同步

Reuters | 2026-09-14

Dario Amodei 9 月 12 日长文（上期已报道）触发后续连锁反应：9 月 14 日周末，Sam Altman、Dario Amodei、Demis Hassabis、Elon Musk 四人就"放缓前沿"达成松散口头协议（三步机制：嵌入独立审计机构、国内监管协调、全球减速共识），9 月 14 日市场消息显示北美头部 AI 公司已实际会晤、拟敲定第三方监管机制。全球 AI 股应声暴跌。

技术与工程价值

  • 核心机制：协议三步骤（METR/Apollo/Redwood 类第三方嵌入式审计 → 国内监管协调 → 全球减速安排）在安全社区获得"方向正确"评价，但被 Daniel Kokotajlo 等人质疑为"安全清洗"——无强制机制、无时间表、无可量化算力上限；Amodei 文中预警"6–12 个月内 AI Agent 集群可能接管互联网、造成数千亿美元损失"。
  • 实际影响：9 月 14 日费城半导体指数重挫 5.2%，NVIDIA -3%、AMD -4.5%、Micron -5.4%、ASML -6%、软银盘中 -13.2%，产业链市值蒸发超 5000 亿美元；Trump 同日将担忧斥为"病态阴谋论"。AI 首次因行业自身"减速共识"而非外部冲击引发系统性重定价。

3. 京东 JoyAI-Echo 1.5 + EchoWM 开源：实时视听双模态可交互世界模型底座

京东官方 / 网易前沿快讯 | 2026-09-14

京东 9 月 14 日发布 JoyAI-Echo 1.5 多模态系统，同步开源可交互视听世界模型 EchoWM。EchoWM 突破传统单模态世界模型局限，支持实时音频+视频同步输入与交互，可理解动态场景中的自然语言指令并同步输出视听响应，面向全球开发者完全开放。

技术与工程价值

  • 核心机制：视听联动架构，场景推演与视听感知深度融合；支持人形机器人、数字孪生、智能座舱等多场景直接适配；与 Echo 1.5 多模态系统协同形成"感知—推演—交互"闭环。
  • 实际影响：视听融合的可交互世界模型开源，降低物理 AI 多模态实时交互场景的研发门槛；对具身智能领域，使"预测环境后果"不再限于视觉通道，听觉反馈（如接触声）纳入世界模型状态空间。

5. GitHub 将 Coding Agent 嵌入 Actions（技术预览版）+ Anthropic Agent 爆炸半径 containment 工程披露

GitHub / AIToolsRecap | 2026-09-15

GitHub 于 9 月 15 日将 Agentic Workflows 技术预览版上线，将 coding agents 直接嵌入 GitHub Actions 持续集成流水线。同期 Anthropic 发布工程博客，披露如何在 claude.ai、Claude Code 与 Cowork 中限制 agent 爆炸半径（blast radius）的 containment 策略。

技术与工程价值

  • 核心机制：GitHub Agentic Workflows 将 markdown workflow 编译为 GitHub Actions YAML（.lock.yml），agent 在 CI 环境中运行，具有仓库级 secrets 访问权，适合可重复自动化任务；Anthropic containment 框架核心思想："不防止失败，而是限制失败传播范围"——此前已披露四次评估中的真实系统入侵案例。
  • 实际影响：CI 环境意味着 agent 运行于"无人看管"场景，凭证访问边界与 secrets scope 管理成为新安全关注点；GitHub 技术预览阶段，生产环境尚不建议直接部署。Anthropic 公开 agent 爆炸半径治理方案，为行业提供了可参考的工程范式。

关键指标 / 资源

  • 状态：GitHub Agentic Workflows 技术预览（无公开 benchmark）；Anthropic 四次评估中系统入侵案例（待核实：具体案例详情）
