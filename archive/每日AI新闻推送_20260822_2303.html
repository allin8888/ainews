OpenAI 大幅下调 GPT-5.6 Sol API 价格超 20%
Reuters / IT之家 | 2026-08-22

事件概述

OpenAI 于 8 月 21 日宣布，未来 3 个月内将 GPT-5.6 Sol 的 API 与 Credit 价格下调 20% 以上。输入价格从 $5/M 降至 $4/M（降 20%），输出从 $30/M 降至 $20/M（降 33%）。这是 OpenAI 首次对旗舰模型进行降价。

技术与工程价值

  • 核心机制：此次降价适用于 API、ChatGPT Work 和 Codex Credits，但 Pro/Plus/Business 订阅价格不变。官方称降价源于硬件路由优化、推理软件改进和更智能的上下文缓存。
  • 实际影响：对输出 Token 占比高的 AI 智能体、编程代理、深度研究场景，综合推理成本可能下降近三成。

AI Coding Agent 基础设施层「开源占位战」白热化
GitHub AI日报 / DeepTech | 2026-08-22

事件概述

8 月 21-22 日，DeepSeek Harness 一周内三更，将 Claude Code 与 Codex 收编为子代理；OpenAI 同步将 Codex Harness 以 Apache-2.0 开源，获 10.7 万 Star。Cursor 发布 Origin 代码托管平台 Beta，同日 GitHub 遭遇全球性宕机。

技术与工程价值

  • 核心机制：DeepSeek Harness 定位为 Agent 时代的「调度层」，Codex Harness 提供三层接口。Agent 基础设施层已进入「谁先开放谁占位」阶段。
  • 实际影响：Cloudflare 同期开源 Computer 运行时，为 AI 智能体提供持久化环境，降低数亿并发 Agent 成本。

WRC 2026 释放信号：具身智能迎规模化应用关键窗口期
央广网 / 科创板日报 | 2026-08-22

事件概述

2026 世界机器人大会（8/19-23，北京）持续进行。中国电子学会指出具身智能产品正处于从「小批量试用」转向「大规模落地」的关键拐点。宇树科技同日科创板上市，开盘价 1100 元/股，较发行价大涨近 630%，市值一度冲破 4000 亿。

NVIDIA AVO 通用编程 Agent 在 ARC-AGI-3 取得 100% 满分
NVIDIA / DeepTech | 2026-08-22

事件概述

NVIDIA 宣布其通用编程 Agent 系统 AVO 在 ARC-AGI-3 公开测试集全部 25 个环境中取得 100% 满分，完成所有 183 个关卡。ARC-AGI 是目前最具挑战性的通用智能基准测试之一。

技术与工程价值

  • 核心机制：AVO 是 NVIDIA 专为视觉操作设计的 Agent 系统，满分成绩标志着在 Agent 工程领域取得重大突破。
  • 实际影响：与 DeepSeek Harness、OpenAI Codex Harness 的开源竞争形成呼应——业界同时推进「工程任务解决能力」和「抽象推理能力」两条技术路线。

AI Coding 模型排行榜动态：Claude Opus 5 领跑，GPT-5.6 Sol 性价比提升
ixio / Toolradar | 2026-08-22

事件概述

8 月 22 日多个 AI 编程模型排行榜更新。ixio 平台显示 Claude Opus 5 以 97 综合评分领跑，GPT-5.6 Sol 以 93 位列第三。AITNT News 代码 AI 排行榜中，Qwen3.8-Max 登顶（1669 分）。

技术与工程价值

  • 核心机制：当前无单一模型在所有维度领先——Claude Opus 4.8 在 SWE-bench Verified 上以 88.6% 准确率领先，GPT-5.6 Sol 在 Terminal-Bench 2.1 上以 88.8% 和 54% 更高的 token 效率领先。
  • 实际影响：OpenAI 降价使 GPT-5.6 Sol 成本从 $35 降至 $24，但 DeepSeek V4 Pro 仍以 $0.435/$0.87 保持最大差距。
