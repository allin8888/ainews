英伟达 Q2 财报超预期：营收 962 亿美元同比 +106%，Q3 指引 1080 亿美元；Vera Rubin 平台全面量产
NVIDIA / Nasdaq | 2026-08-26
事件概述

英伟达 8 月 26 日美股盘后发布 FY2027 Q2 财报：总营收 962.21 亿美元（同比 +106%），非 GAAP 净利润 698 亿美元（同比 +126%）；数据中心营收 890 亿美元（同比 +117%），占收入 93%。CFO 给出 Q3 指引 1080 亿美元（±2%），远超市场 970 亿预期，并预估 FY2028 全年增长约 70%。

技术与工程价值
  • 核心机制：Vera Rubin 平台（含 Rubin GPU + Vera CPU + Groq 3 LPX 推理加速器 + NVLink Fusion 互联）进入全面量产阶段，首批机架已在 CoreWeave/Google Cloud/Microsoft Azure/Nebius 运行；Groq 3 LPX 单 rack 256 颗 LPU，Artificial Analysis 基准测试下运行 Gemma 4 31B（100K 上下文）达 3400 token/s，为竞品 4 倍。
  • 实际影响：AI 算力需求从训练侧向推理侧迁移的趋势进一步确认——黄仁勋明确"推理是 AI 的增长引擎"；云行业积压订单超 2 万亿美元，前五大超大规模云厂商 2026 年资本支出预计近 8000 亿美元，2027 年达 1.3 万亿美元；AWS 宣布 2027–2029 财年新增部署 200 万颗 GPU。
关键指标/资源

Q2 数据中心 $89B（+117% YoY）；Q3 指引 $108B（+12% QoQ，+57% YoY）；库存增至 320 亿美元（为 Rubin 批量销售备货）；中国收入占比低于 1%（Hopper 架构数据中心产品）

来源：NVIDIA FY2027 Q2 财报（nvidianews.nvidia.com，8/26）；Hot Chips 2026 主题演讲（Igor Arsovski 发布 Groq 3 LPX 架构）

阿里发布全新 Qoder 智能体工作台：自然语言驱动编程，内置 Harness + Qwen3.8-Max
阿里巴巴 / IT之家 | 2026-08-27
事件概述

8 月 27 日，阿里巴巴正式发布全新 Qoder，定位从"AI 编程工具"升级为"面向所有人的智能体工作台"。该产品以 Coding 为核心底座，用户无需编写代码，仅用自然语言描述目标即可完成开发、原型制作、数据处理等任务。自 2025 年 8 月全球发布以来，Qoder 累计服务超 600 万用户和超 10 万家企业客户。

技术与工程价值
  • 核心机制：采用 Harness 技术作为编排层——"读—改—验证—迭代"的长链路自治：自行检索代码库、跨文件编辑、运行测试，并根据真实结果自我纠错；分级权限模式 + 工具白名单机制，敏感操作必须显式授权；内置 Qwen3.8-Max 等多款前沿模型，Auto 智能调度按任务特点在效果/速度/成本间自动匹配；支持跨会话长期记忆，周期性自我提炼技能。
  • 实际影响：Qoder 提供编程与通用两种模式，通用模式面向不懂代码的用户（原型制作、数据处理）；40+ 连接器、70+ 插件、2 万+ 技能覆盖代码仓库/项目管理/云服务/内部工具；引入 Plan/Goal/侧边任务三件套处理长程复杂任务，Browser Use 和 Computer Use 让 Agent 操作网页和桌面应用。
关键指标/资源

用户基数 600 万+ / 企业客户 10 万+；插件生态 70+ / 连接器 40+ / 技能库 2 万+

来源：国际版 qoder.com / 中国版 qoder.cn；IT之家报道（8/27）

阿里云下调 Qwen3.8-Flash API 价格 20%：输入 ¥0.80/M、输出 ¥2.70/M
阿里云百炼公告 | 2026-08-27
事件概述

阿里云 8 月 27 日 11:18 发布公告，北京时间当日 12:00 起对 Qwen3.8-Flash 模型计费单价进行下调调整：输入从 ¥1.00/M 降至 ¥0.80/M，输出从 ¥3.00/M 降至 ¥2.70/M，降幅约 20%。

技术与工程价值
  • 核心机制：Qwen3.8-Flash 是基于 Qwen4 架构的 MoE 多模态模型，125B 总参 / 6B 激活，原生支持百万级上下文窗口，兼容 OpenAI 与 Anthropic 接口协议，可直接配合 Claude Code、Codex 等工具使用。
  • 实际影响：调整后定价约 DeepSeek-V4-Flash 的 1/3，持续强化"性价比战"策略；阿里云以 Flash 作为流量入口构建开发者生态飞轮，降低高频 API 调用和轻量 Agent 任务的成本障碍；同期已上线的"千问办公"产品与 QwenWork 国际版（已登顶杰富瑞 Agent 综合得分第一）形成协同。
关键指标/资源

输入 ¥0.80/M（降 20%）、输出 ¥2.70/M（降 10%）；低于 DeepSeek-V4-Flash 同档位定价

来源：阿里云百炼官方公告（aliyun.com/notice/118600，8/27）

华尔街日报 / Anthropic | 2026-08-26
事件概述
