XPENG Turing World Model WorldGPT：跨六类载体的物理 AI 世界动作模型（XPENG Blog | 2026-11-24）

事件概述

小鹏汽车于 11 月 24 日发布 Turing World Model 家族新成员 WorldGPT——一个云侧"教师"世界动作模型，可在学习了人形机器人、汽车、无人机、船艇、单机械臂和双机械臂共六类载体后，根据历史视觉观察与自然语言指令预测场景演变并规划动作，且将大模型蒸馏到各载体端侧小模型。小鹏称截至 11 月 12 日其在 12 项公开基准上排名第一（公司宣称，未经独立测试）。

技术与工程价值

  • 核心机制：以"单一世界模型 → 多载体蒸馏"替代此前"为每种载体从头训练"的做法；云端教师模型负责共享的物理世界常识，端侧学生模型承担低延迟执行。
  • 实际影响：机器人操作在 50 项单臂任务基准上取得 95.2% 平均成功率（官方宣称最高），对未见过任务/环境扰动展现出强泛化；同时覆盖自驾场景，意味着同一套世界模型可打通车–机–空–水多个产品线。

iFood 将 Codex 编码 Agent 规模化至 15,000 仓库——OpenAI 客户案例（OpenAI Blog / iFood | 2026-11-24）

事件概述

OpenAI 于 11 月 24 日更新其客户故事库，介绍巴西外卖平台 iFood 如何将 Codex 编码 Agent 部署到旗下约 15,000 个代码仓库中，贯穿从代码审查到文档维护的全链路工程流程。这是目前公开披露的最大规模企业级单体 Codex 部署之一。

技术与工程价值

  • 核心机制：通过 AGENTS.md、分支保护策略与 CI 门禁形成"上下文→可见性→护栏"三重闭环，让 Agent 自主运行测试并在 PR 级别接受人工审查，避免直接触碰生产。
  • 实际影响：将重复性高、范围明确的工程任务（重构、重命名、补测）外包给 Agent，工程师转做监督与架构决策；企业级复制路径明确（选健康测试套件仓库起步 + 按需放行 PR），为同类组织提供参考蓝图。

SoftBank 收购 Marc Raibert 创办的 Robotics & AI Institute（RAI）（The Robot Report | 2026-11-24）

事件概述

据 The Robot Report 报道，软银已正式完成对 Marc Raibert 从现代汽车集团 acquired 的 Robotics and AI Institute (RAI) 的收购。RAI 由波士顿动力创始人 Raibert 于 2022 年创立，初始资金超 4 亿美元，总部设在剑桥（MA），专注移动性、操作、感知与智能等机器人基础难题，目前有 24 个开放岗位（含实习），分布在剑桥与苏黎世两地。财务条款未披露。

技术与工程价值

  • 核心机制：此次并购延续了软银近年来持续扩充机器人资产组合的策略（此前已控股 Boston Dynamics 等），并将 RAI 的基础研究能力并入其投资生态。
  • 实际影响：Raibert 出走 Hydra 后首次落地商业实体；RAI 的学术型定位与软银的产业化资源结合可能加速多项基础成果的工程化；开招 24 个岗位信号明显，团队扩张在即。

OpenAI × Cisco 联合发布 Shirudo：基于 Codex 生成 eBPF 盾牌的实时 Linux 漏洞防护工具（Indian Express / OpenAI Blog | 2026-11-24）

事件概述

OpenAI 与思科联合宣布 Shirudo——一款面向 Linux 系统的 AI 驱动即时防御工具。该工具调用 Codex 编码 Agent 针对已知漏洞（如 Java4Shell）生成针对性输入校验补丁，并通过 eBPF 机制将其附着到正在运行的进程（如 Elasticsearch）上，实现无需重启的热修复；内部测试显示成功拦截针对 Java4Shell 的攻击并保持服务在线。

技术与工程价值

  • 核心机制：AI Agent 编写补丁 → 安全团队审阅 → eBPF 加载 → 流量镜像验证有效性 → 可选切换至生产态，全程可观测、可回滚。
  • 实际影响：填补"找到漏洞 → 写补丁 → 测试 → 部署"之间的高危窗口期；为运维/AI Agent 协作提供可复用范式（Agent 生成、人类审核、eBPF 执行）；对大规模 Elasticsearch/Kubernetes 环境有即战力。
