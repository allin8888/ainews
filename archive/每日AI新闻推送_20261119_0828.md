### 1. Google DeepMind Genie 4：可编辑交互式世界模型，已面向 Google AI Ultra 订阅用户开放（Google DeepMind Blog | 2026-11-18）

**事件概述**：Google DeepMind 宣布 Genie 4（Project Genie 新一代交互世界模型）正式向 Google AI Ultra 订阅用户开放。Genie 4 支持在会话进行中通过自然语言提示实时修改场景——切换天气、添加角色或重定向剧情，并首次将视觉与原生实时音频同步生成。

**技术与工程价值**：
- 核心机制：Genie 4 是首个支持「mid-session 文本编辑 + 实时原生音频」的世界模型；配合新的 Project Genie Agent，可通过对话协作构建世界并自动生成背景配乐
- 实际影响：突破 Genie 3 固定时长限制（新 Genie 3 支持 3 分钟会话、360°全景、可链接多世界）；标志着交互世界模型从「单次生成」走向「持续编辑+声音同步」的下一代形态，对训练仿真和物理 AI 有直接复用价值

### 2. Postman 2026 API 报告：AI Agent 已进入生产环境，但大多数 API 未就绪（Postman Blog | 2026-11-18）

**事件概述**：Postman 发布《2026 State of the API Report》，核心发现是 AI Agent 正在大规模投入生产使用，但企业 API 在身份认证、短效凭证和流量治理层面远未准备好承接 Agent 流量。

**技术与工程价值**：
- 核心机制：Postman 平台数据显示其 MCP Server 的 AI Agent 请求量从 5 月到 10 月增长 3.3 倍（月均 200 万+），调用人数增 2.2 倍至近 3.3 万人；其中超过一半的工具调用是写操作（创建/修改集合和请求），而非只读
- 实际影响：Agent 不再只是「查看」API，而是主动改变状态；仅 19.1% 的组织将 Agent/MCP 流量路由到网关；报告指出修复方案并不复杂——身份隔离、短效凭证和前置控制点即可显著降低风险

**关键指标/资源**：
- 代码/论文：[Postman Blog](https://blog.postman.com/the-2026-state-of-the-api-report-agents-are-in-production-and-most-apis-arent-ready)
- Agent 在 Postman MCP 中写操作占比：51% vs 读操作 46%

### 3. Humyn Labs 融资 4700 万美元：为物理 AI 机器人采集真实世界训练数据（TechCrunch | 2026-11-18）

**事件概述**：印度创业公司 Humyn Labs 完成 4700 万美元 Series A 融资（含 2100 万美元风债），用于建设覆盖新兴市场的行为数据采集网络，帮助美国 AI 与机器人公司获取训练Physical AI 所需的真实世界人类行为数据。
