### 1. OpenAI Jalapeño 自研推理芯片首次实测：每瓦吞吐超英伟达 GB300 最高 1.9 倍（OpenAI Blog / SemiAnalysis | 2026-08-25）

**事件概述**：
OpenAI 在 Hot Chips 2026 大会上公布首款定制推理 ASIC「Jalapeño」的首批实测数据，由 OpenAI 与博通联合开发、台积电 3nm 制程，标称 TDP 700W（实测 ≤550W），在 SemiAnalysis InferenceX 基准上击败所有可测英伟达/AMD/谷歌同代芯片。

**技术与工程价值**：
- **核心机制**：专为语言模型推理设计，将 KV 缓存等模型状态尽量贴近计算单元，减少跨芯片搬运；采用 GMP（Gluon Modeling Protocol）自研编程语言，Codex 参与内核编写——部分 AI 生成内核比人类专家版本快 1.5–1.8 倍。从组队到流片仅用 16 个月（行业常规 ≥3 年）。
- **实际影响**：推理成本正在从"峰值算力竞赛"转向"每瓦 token 产出竞赛"；OpenAI 在推理端首次展示摆脱 GPU 供应商依赖的可行路径，继 Google TPU、Amazon Trainium 后又一个超大规模厂商自研推理 ASIC 落地。

**关键指标/资源**：
- 每瓦吞吐：GB200/GB300 的 1.5–1.9 倍；端到端延迟低 1.7–3.6 倍；交互场景最高快 2.1–4.1 倍
- 测试模型：GPT-OSS 120B、DeepSeek R1 670B、Kimi K2.5 1T（单 token 预测模式，未使用多 token 预测优化）
- 对等配置下（GB300 开启 MTP），领先幅度收窄至约 1.5 倍
- 链接：[OpenAI Blog](https://openai.com/blog) / [SemiAnalysis 现场验证报告](https://semianalysis.com)
- **待核实**：SemiAnalysis 仅验证了 InferenceX 部分运行，未跑完整套件；未与 Vera Rubin 正面比较；大规模生产部署尚未开始（计划 2026 年底小规模、2027 年扩产）

### 2. Meta Muse Code Beta 发布：面向大规模代码库的自主软件工程 Agent（Meta Tech Blog | 2026-08-25）

**事件概述**：
Meta 正式发布 Muse Code beta，基于 Muse Spark 1.2 驱动，针对大型仓库规划、编码、测试、PR 全流程的自主编码 Agent，内部工程团队试用后常规 bug 解决时间减少 40%。

**技术与工程价值**：
- **核心机制**：双循环规划架构（Monte Carlo 树搜索 + 回归测试验证），在隔离 ephemeral Docker 沙箱内动态验证代码改动，再提交 PR；多子代理拆分复杂工程任务，避免单模型幻觉扩散。
- **实际影响**：标志着 Coding Agent 竞争从"单文件补全"全面进入"整仓维护"阶段；终端形式（macOS/Linux CLI）与 Claude Code/Codex 直接竞争，定价策略颠覆（Contributor 版输出 token 仅 $0.2/M，标准版 $4.25/M，但数据用于训练下一代模型）。

**关键指标/资源**：
- Terminal-Bench 2.1 得分 82.9%（对比 Claude Opus 5 的 86.7%）
- 链接：[Meta Tech Blog](https://meta.tech) / GitHub（待公开）
- **待核实**：大规模仓库真实场景复现数据待补充；贡献者版数据使用权条款需仔细审阅
