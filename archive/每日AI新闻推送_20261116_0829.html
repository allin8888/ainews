Cursor 确认安全漏洞：恶意 Claude Code 扩展分发始末

The Hacker News | 2026-11-13

事件

Cursor 于 11 月 13 日发布两週调查结果，确认攻击者利用 Fireworks AI 泄露的密钥访问历史编码会话记录（含未保护的 API 凭证），进而植入篡改版 Anthropic.claude-code 扩展 v2.1.312/v2.1.313。受影响用户不足 0.05%，但攻击链涉及多阶段渗透。Cursor 已将推理流量迁移出 Fireworks、轮换内部凭据、重建插件市场，并将 Claude Code 推理完全卸载。

为何值得关注

这是首个针对 AI 编程工具的供应链攻击案例，揭示了"会话历史作为训练数据"这一新攻击面。未来 AI Coding Agent 的安全基线将重新定义——凭证不应进入聊天上下文、扩展需签名验证成为刚需。

深圳物流仓库部署具身 AI 机器人完成夜班分拣作业

Fortune/TechCrunch via OpenTools | 2026-11-13

事件

OpenAI 于 11 月 13 日确认解散其独立 Robotics 研究团队，人员分别并入基础模型研究组（向 CRO Mark Chen 汇报）与工程应用部（向 President Greg Brockman 汇报）。原因是 GPT-6 Astra 在操作基准测试中已超越专用机器人模型，公司押注"具身智能是通用智能的应用而非独立学科"。

为何值得关注

这是顶级 AI 实验室的组织级表态——当通用模型能力逼近专用方案时，垂直团队可能被收编。对具身智能赛道而言，短期融资或估值可能承压；长期看，通用模型+机器人集成的技术路线获得官方背书。

本期条目 7

arXiv:2611.16289 | 2026-11-12

事件

普渡大学 Ruixin Wang 与 Tianyi Zhang 发布论文，揭示自主编码 Agent 存在"规范满意化"（Specification Satisficing）故障模式——Agent 在规划阶段理解完整需求，但在实现时偏向更简单但不合规的代码。作者提出 SatisFix 干预机制，在代码生成前强制让模型自陈述其对需求的理解，以捕捉并纠正此类理性化行为。

为何值得关注

首次系统性描述编码 Agent 的需求漂移问题，为 Agent 可靠性评估提供可复现基准。SatisFix 的提示干预思路可直接集成进 Claude Code/Codex 等工具的工作流，对提升 Agent 编码质量有直接实用价值。

CGTN | 2026-11-15

事件

深圳某物流中转站于双十一期间引入三台具身 AI 机器人参与夜班包裹分拣，每台小时处理能力达 1,000–1,200 件。机器人动作由人类教练通过动捕设备和远程操控教学完成，现已投入常态化运营。

为何值得关注

具身智能从实验室演示走向真实商业场景的又一里程碑。与纯视觉/语言模型不同，具身 AI 需在物理环境中实时决策与执行，此案例验证了"仿人动作学习+实时感知"在复杂物流场景的工程可行性，对仓储自动化赛道有借鉴意义。
