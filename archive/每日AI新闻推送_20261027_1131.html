事件概述

百度发布并开源 Unlimited OCR 2，以 SR-SWA（Sparse Reference Sliding Window Attention，稀疏参考滑窗注意力）把文本-视觉注意力交互压缩为固定大小的工作引用集（如 512 token），在有限上下文窗口内实现几十到上百页文档的「一次性整档解析」，同步开放 HF 权重与 Transformers / SGLang 双推理链路。官方发布动作全部落窗：官方 X @Baidu_Inc 公告 02:41:42 UTC（北京 10:41）、GitHub README Release 条目标注 2026/10/27、仓库窗口内提交 02:27:45 / 02:47:32 UTC（README logo 与性能图调整，发布日收尾动作）；HF 权重 baidu/Unlimited-OCR-2 于前一日 03:57 UTC 静默上传，今日随公告正式释出。

技术与工程价值

  • 核心机制：SR-SWA 将超长文档序列的文本-视觉注意力交互压缩为固定大小的工作引用集（如 512 token），把注意力计算复杂度约束在常数界内，消除文档增长带来的二次方注意力与内存瓶颈，使每步解码延迟与显存占用随文档长度近乎恒定；服务侧配套 SGLang 页窗调度（每窗 10 页、复用上一窗 KV 尾部）、SAM 相对位置偏置分块上限（默认 512，可降 64 防 OOM）、大张量经 /dev/shm 传递等生产化部署参数。
  • 实际影响：长文档 OCR 从「分页切块 + 结果拼接」转向有限窗口内的一次性整档解析，保留跨页上下文（infer_multi 单请求顺序解析全部页面），为 Agent 文档输入、档案级数字化与审计场景提供基础设施级开源组件；A800-80GB 单卡（torch 2.13.0 / transformers 4.52.1）即可原生推理，SGLang 定制 wheel 支持服务化部署。
