### 1. NVIDIA Isaac Lab 3.0 GA 与 Agile ONE SN 参考人形机（NVIDIA Blog / Robotics & Automation News | 2026-11-23）

**事件概述**：NVIDIA 于 GTC Berlin 正式发布 Isaac Lab 3.0 通用可用性版本，并同步推出基于 Agile Robots Agile ONE SN 的参考人形机器人平台。Agile ONE SN 身高 1.4m、重 40kg，全身 31 DoF，双手各 20 DoF 带触觉传感与力控，搭载 Isaac GR00T 基础模型与 Jetson Thor 计算系统，预计 2027 年初出货。Isaac OS Runtime 为开源运行时框架，连接传感器、AI 模型、控制系统与硬件；SimReady Central Library 收录 2000+ 仿真就绪资产；Human 1M 数据集提供人类活动录制与 3D 手部追踪数据。

**技术与工程价值**：
- **核心机制**：NVIDIA 首次将仿真训练工具（Lab）、运行时（OS）与参考硬件（ONE SN）打包为全栈开放方案，竞争壁垒从工具层转移至硬件质量与专有训练数据。Toyota Material Handling Europe 报告采用 Omniverse 仿真工作流可将调试时间缩短约 50%，是该方案首个公开企业基准数据。
- **实际影响**：OEM 和开发者可获得经认证的硬件蓝图而非仅软件，对具身智能产业化路径中"训练—部署—运维"闭环具有标志性意义；黄仁勋将其定义为"机器人领域的 ChatGPT 时刻"。

**关键指标/资源**：
- 评测/性能：Toyota Material Handling Europe 调试时间缩减 **50%**（NVIDIA 披露的唯一客户绩效数字）
- 代码/论文：Isaac Lab 3.0 GA 开源 / Isaac OS 运行时开源；SimReady Central Library 2000+ 资产；Human 1M 数据集
- 硬件规格：Agile ONE SN，1.4m/40kg，31 DoF + 双手各 20 DoF，GR00T + Jetson Thor（2,070 FP4 TFLOPS / 128 GB 统一内存）

### 2. X Square Robot 发布 WALL-OSS-1.0 VLA 原生预训练基础模型（X Square Robot / GlobeNewsWire | 2026-11-23）

**事件概述**：深圳自变量机器人今日发布 WALL-OSS-1.0，其视觉-语言-动作（VLA）基础模型采用原生预训练方法，将视觉、语言与物理动作在统一学习框架内联合训练，而非先在预训练 VL 模型上叠加动作训练头。在开放真实机器人评估中，WALL-OSS-1.0 以 55.1% 零样本成功率完成 312 项由评估者自由选取的真实任务（覆盖未知物体、工具使用、双操作手协调和多步操控），无需任务特定演示或微调。同期发布 XR Harness 智能体多步规划框架与 WALL-API-1.0 开发者接口；代码与权重即将开源。

**技术与工程价值**：
- **核心机制**：基于 Qwen3.5 底座，语言/视觉语言/机器人动作三类数据在同一训练流程中联合注入，改进型 Action Tokenizer 将连续运动转为紧凑离散 token 序列，结合 Uni-CoT 指令→推理→子任务→动作链路，实现端到端具身推理。
- **实际影响**：零样本真实机器人成功率较前代大幅跃升（上一代 WALL-OSS-0.5 未见同类公开基线对比）；X2Real 仿真基准得分 67.55，显著领先最强开源基线 Lingbot-VLA-2.0 的 40.94。代码/模型权重开源将进一步降低具身 VLA 研究门槛。

**关键指标/资源**：
- 评测/性能：零样本真实机器人成功率 **55.1%**（312 项开放任务）；X2Real 仿真基准 **67.55/100** vs Lingbot-VLA-2.0 **40.94**
- 代码/论文：`wall-x` 仓库（Apache-2.0，即将开源完整权重）；XR Harness 智能体规划框架；WALL-API-1.0 工业接口

### 3. OYMotion 完成数亿元 D 轮融资，加速灵巧手供应链布局（Dealroom / BigGo Finance / 36Kr | 2026-11-23）

**事件概述**：上海奥羲（OYMotion Technologies）今日宣布完成数亿元人民币 D 轮，中兵顺景、长江资本、光谷产业投资等机构联合领投，这是公司 2026 年内第二轮融资（3 月刚完成 2060 万美元 C 轮）。创始人张琦透露资金将用于具身智能商业化加速与 IPO 筹备。公司成立于 2015 年，产品涵盖五类系列约 20 个 SKU 的多指夹爪与灵巧手，服务近 200 家人形机器人及具身智能企业，出口逾 100 国；珠海自建工厂年产能数万台。

**技术与工程价值**：
- **核心机制**：产品线已形成清晰梯度——AP001 聚焦负载与压力感知，AP002 强化响应速度，AP003 增加 3D 磁触觉传感，对应下游需求从"能抓"到"抓得稳、抓得准"的演进。公司已拆分研发体系：机器手末端执行器部门与脑科学部门并行，后者延续仿生手与神经康复外骨骼路线。
- **实际影响**：投资方阵容含央企背景的中兵顺景（中国兵器工业集团投资臂），标志国资产业资本开始密集涌入灵巧手赛道；价格战加剧下规模化制造与渠道扩张成为下一竞争焦点，D 轮资金直接指向量产能力兑现与盈利拐点验证。

**关键指标/资源**：
- 评测/性能：营收过去 4–5 年每年翻倍（张琦自述）；累计融资超 8000 万美元（Tavily Crunchbase 数据，截至 2026-03 D 轮前）

### 4. 蚂蚁集团低调开源 LingSante-3.1-flash 560B 医疗 MoE 模型（Ant Ling / Artificial Analysis / Emergent.sh | 2026-11-22）

**事件概述**：蚂蚁集团旗下 Ant Ling 团队于 11 月 22 日通过 X 账号官宣并发布 Hugging Face 仓库（inclusionAI org），开源 LingSante-3.1-flash——560B 总参数、25B 每 token 活跃参数的混合线性 MoE 医疗大模型，1M token 上下文，MIT 许可。架构基于 Ling-3.1-flash 通用底座，训练流程含医疗混训、SFT、医疗强化学习与多教师 on-policy 蒸馏。同日 Afu 健康 App 启动 LingSante 模型家族发布，同批次含 124B 多模态轻量版 LingSante-3.1-air-VL。无官方博客公告，Hugging Face 仓库初期下载量仅为 0。

**技术与工程价值**：
- **核心机制**：MoE 路由采用 512 experts 选 8 active/token 配置，配合 MLA（Multi-head Latent Attention）层，适合长上下文临床文档处理；SGLang day-0 镜像推荐 8×H200 TP8+EP8 部署，vLLM 亦支持，另提供 MXFP4 量化变体以降低推理成本。
- **实际影响**：若官方宣称分数得到独立复现，将对医疗垂直领域 Open-Weights 模型格局形成显著冲击；但目前外部唯一独立评测（Artificial Analysis MLCR-AA）仅给出 23.3% 长上下文医疗推理分，远低于厂商自述 HealthBench Professional 65.72/HLE-with-tools 72.22/BrowseComp 94.10。开源节奏"静默发布"暗示技术成熟度与合规审查之间的张力。

**关键指标/资源**：
- 评测/性能：**HealthBench Professional 65.72 / HLE-with-tools 72.22 / BrowseComp 94.10**（厂商自报，待第三方验证）；MLCR-AA 长上下文医疗推理 **23.3%**（Artificial Analysis 独立）
- 代码/论文：Hugging Face inclusionAI/LingSante-3.1-flash；MXFP4 量化权重；无单独技术论文
