1.Anthropic 推出 Claude Duet：主动式智能体研究预览，Opus 5.5 驱动云端 VM 常驻执行

第一来源：Anthropic 官方博客 / @claudeai ｜ 2026-10-21

事件概述

Anthropic 发布独立应用 Claude Duet 研究预览版（候补制，面向美国 Pro/Max 订阅者）：一款基于 Opus 5.5 的「主动式智能体」，运行在带独立浏览器的云端虚拟机上，每隔几小时巡检用户已连接的应用，主动推送晨间简报与待办事项；用户关掉手机电脑后任务仍在后台继续，发送消息、付款、签文件、删内容等敏感动作须经用户批准。

技术与工程价值

  • 核心机制：① 云端 VM + 浏览器隔离执行环境，本地设备关机不影响任务连续性；② 继承 Claude 账号既有记忆、技能与应用连接，通过 Claude Marketplace 6,000+ 连接器零配置接入 Gmail、Slack、QuickBooks、Stripe、Shopify 等；③ 凭据处理沿用 Claude Managed Agents 设计——Agent 从不直接看到密码与登录令牌；④ 新增专用分类器 + 安全系统提示词逐条检查外发消息，拒绝分享信用卡号、政府证件等最高敏感级信息，健康与个人财务信息仅在用户明确指示时放行；⑤ 动作由 auto mode 分类器审批，证券交易与账户间转账即使用户同意也一律禁止；⑥ 支付经 Stripe Link / Shop Pay 虚拟卡完成，形成「用户批准 + 钱包端确认」双重闸门。红队、外部机构渗透测试与公开漏洞赏金覆盖。
  • 实际影响：继 Meta Muse（上线后登顶美区 App Store）与 OpenAI Dots 之后，个人 Agent 赛道形成三强格局；竞争壁垒从模型能力扩展到记忆、工具连接与安全架构三层。官方坦言预览版仍可能误判信息紧急程度、个人事务（如订票）能力偏弱，暂不支持 Microsoft 365，语音模式仅转写。

2.GitHub Next × Microsoft Research 发布 PDD Kit：Verus 形式化验证门控智能体生成的 Rust 代码

第一来源：@GitHubNext 官方 X / automater.ai ｜ 2026-10-21

事件概述

GitHub Next 与 Microsoft Research 联合发布 Proof-Driven Development Kit（PDD Kit）研究预览版：把「人逐行读 diff」的评审模式反转为「人批规格、机器证代码」——智能体生成的 Rust 代码必须通过 Verus 定理证明器验证其对全部输入满足形式化规格，方可合入，产出「已验证 PR」。

技术与工程价值

  • 核心机制：五步流水线——① 团队在 Chopin（GitHub Next 的多人实时智能体规划工具，2026-09 研究原型）中共同规划功能；② PDD Kit 与代码对话、推断意图并生成 Verus 形式化规格；③ 人工批准的是规格而非代码；④ Verus 证明器自动验证智能体代码对每个输入满足规格；⑤ 无法完全证明时回退到测试 + 计算机使用智能体（CUA）实证检查；⑥ 输出已验证 PR。GitHub 官方定位为「verified software factory，工程师评审规格而非代码」，并称其「让团队无需逐行评审即可交付 AI 生成代码，保障强于单纯代码评审与测试」（厂商表述）。
  • 实际影响：Microsoft Research verus-proof-synthesis 仓库（AutoVerus 150 项 / VeruSAGE 849 项验证任务）的证明合成研究线首次被包装进「规划→PR」产品工作流，形式化验证从专门技术变为智能体工作流中的按钮式环节。边界清晰：仅支持 Rust，且仅覆盖可形式化表达的属性（I/O 契约、不变量、状态机转换）；UI 行为与多数 I/O 密集型逻辑仍走回退路径。GitHub Universe（10-28/29）将首次对真实代码公开演示。

3.讯飞星火 X2.6 发布：293B-A30B MoE 全国产算力训练，SWE Pro 77.3

第一来源：科大讯飞 1024 开发者节主论坛 ｜ 2026-10-22

事件概述

科大讯飞在 2026 全球 1024 开发者节（北京）发布端云一体大模型星火 X2.6：293B 总参 / 30B 激活 MoE、1M tokens 上下文，官方称其为首个完全基于全国产算力训练、并同步突破代码与智能体能力的主流大模型；同步开源端侧模型 X2.6-4B，并发布星火语音基座 SparkAudio 1.0。

技术与工程价值

  • 核心机制：针对国产芯片显存与带宽受限，训练侧采用长程任务动态并行训练（按任务长度自适应分配计算资源，官方称超长上下文训练效率提升约 4 倍）；推理侧采用国产异构算力分布式推理 + 首个基于全国产设备的四层 KV Cache + 中间结果复用（官方称整体推理效率提升约 4.5 倍）。端云协同分工：约 60% 常规任务端侧完成（数据不出域、零 Token 成本）、30% 端云协同、10% 交云端大模型。
  • 实际影响：把「国产算力能否训出有竞争力的大模型」变成公开可检验的命题——训练效率、推理缓存、端侧小模型与定价一次性落地；对信创与国产替代需求的企业新增一个可自行基准测试的选项。代码与智能体基准（SWE Pro 77.3 / SWE Multilingual 95.0 / SWE Verified 95.4）均为厂商自述，未见第三方复现；SWE Verified 上略低于 DeepSeek-V4.1-Flash（95.4 vs 95.6）。

4.LIBERO-10 基准报告：GPT-6 Astra 以 44% 成功率领先，前沿推理模型零训练直控机器人

第一来源：arXiv:2610.30051 ｜ UT Dallas ｜ 2026-10-21 v1

事件概述

UT Dallas 团队发布统一闭环操作框架，在 LIBERO-10 基准上系统评测 6 个前沿 AI 模型（GPT-6 Astra / GPT-6.1 Sol / GPT-6 Luna / Claude Opus 5 / Claude Opus 5.5 / Gemini-4 Argon）× 3 档推理强度共 18 种配置、累计 1,800 个评测回合：模型仅凭视觉观测、机器人本体感与结构化工具调用（指定目标末端位姿与夹爪指令）直接控制机器人，无任何任务特定微调或预训练操作技能。GPT-6 Astra 成功率 44% 居首，Gemini-4 Argon 以 43% 紧随。

技术与工程价值

  • 核心机制：闭环框架把机器人控制建模为工具调用——模型输出目标末端执行器位姿与夹爪命令而非连续动作 token；每回合执行后有测试/判定反馈。实验发现提高推理强度普遍提升操作表现但增加推理成本；任务间差异显著——模型在物体放置类任务表现较好，在精确空间排布与复杂多步交互上明显挣扎；单轮成绩不足以刻画交互式操作能力（不同交互预算下排名会变化）。
  • 实际影响：首次在标准化机器人基准上给出「前沿通用模型零样本直控」的系统对照数据：44% 距实用尚远，但证明了纯推理路线可行性；评测框架与全部实验结果开源，为「推理能力→物理动作」转化提供可复现基线。与本期 AW-0（世界动作模型输出技能程序）形成路线对照：端到端直控 vs 代码即技能。

5.AW-0 智能体世界动作模型：代码-视频-动作三流统一 MoT，把「技能」变成可复用程序

第一来源：arXiv:2610.30136 ｜ NVIDIA / UC Berkeley 等 ｜ 2026-10-21 v1

事件概述

由 NVIDIA、UC Berkeley、Georgia Tech 等机构研究者（含 Ken Goldberg、Danfei Xu、Yuke Zhu、Linxi "Jim" Fan、Trevor Darrell、Renrui Zhang 等）提出 AW-0：在统一 mixture-of-transformers 架构中把代码、未来视频、机器人动作建模为三个耦合生成流——代码专家生成参数化技能例程与控制逻辑，视频与动作专家生成未来视觉状态与低层电机命令；配套自动 curation 流水线把机器人与人类视频轨迹标注为对齐程序，并把 recurring 例程固化为可复用技能库。RoboTwin 2.0 与物理双臂操作任务上超越 VLA 与 WAM 基线，语言跟随、语义推理与鲁棒性同步提升。

技术与工程价值

  • 核心机制：代码在模型中承担双重角色——既结构化世界模型内部的多步预测与控制，又把技能表示为可供后续智能体执行复用的程序；这弥合了「代码规划 + 技能复用」的智能体路线与「视觉预见 + 物理动态」的世界模型路线之间的断层。自动 curation 流水线（视频轨迹→对齐程序→技能库）解决了技能复用的数据来源问题。
  • 实际影响：为世界动作模型（WAM）开辟「智能体化」演进方向——WAM 不止预测未来，还输出可执行技能程序；与本期 LIBERO-10（纯 VLM 零样本直控 44%）形成路线对照。作者群横跨 NVIDIA 机器人与伯克利自动化实验室，工程落地信号强。

关键指标/资源

  • 评测：RoboTwin 2.0 + 物理双臂操作，较 VLA/WAM 基线提升（摘要未披露具体数值，待论文全文核实）
