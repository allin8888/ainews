### 1. arXiv Wed-28 批次·自进化 harness 论文群：RuHarness 评分共进化、GEPA-Curator 策展学习、Evolving Agent Teams 攻破 FlashInfer 生产内核（arXiv cs.AI/cs.CL | 2026-10-28）

**事件概述**：
arXiv Wed-28 批次同日公告 4 篇互为呼应的「agent 自我改进基础设施」论文，主题收敛为：**监督信号本身需要被治理**——RuHarness 让评分标准随 harness 共进化，GEPA-Curator 先筛选哪些经验配得上进入优化循环，Evolving Agent Teams 用多智能体团队重组逃出真实生产内核的局部最优，GEPA 并行批处理把反思优化循环本身变成可并行负载。

**技术与工程价值**：
- **核心机制**：① **RuHarness**（2610.36826, cs.AI）rubric–harness 共进化框架：从执行轨迹持续发现并重估行为标准、优先处理最相关的未解决弱点、以之引导针对性 harness 更新（任务目标保持固定）；静态评分标准跟不上跨轮次行为弱点漂移的问题被显式建模。② **GEPA-Curator**（2610.37651, cs.CL）给反思式提示优化器加「策展层」：任务策展过滤高噪声/不可靠学习信号的任务 + 先验成功检索把历史成功轨迹作为优化上下文——失败 rollout 不总是有用信号，甚至有害。③ **Evolving Agent Teams**（2610.36848, cs.AI）中央 supervisor 诊断每个局部最优并重组 agent 团队 + 持久文件系统（学习文档/进化历史/团队工件）为重组提供经验 grounding。④ **Batching GEPA**（2610.36774）把开源 GEPA 优化器改为每步提议-评估一批候选而非单个，并给出有限 worker 池下的运行时模型。
- **实际影响**：递归自我改进（焦点四）从「让 agent 自己跑」推进到「治理自我改进的监督信号」——rubric 漂移、经验噪声、局部最优三类失效模式同日各有对应方案；EAT 证明多智能体自进化能在**真实生产级 CUDA 内核**上兑现，而非玩具基准。

**关键指标/资源**（论文自述，未见第三方复现）：
- 评测/性能：EAT 匹配 token 预算下从零生成 CUDA 内核较 FlashInfer MLA paged decode **生产内核平均 1.2x 加速**，FlashInfer-Bench 47 个生产负载赢 36 个（其余 11 个 0.86–0.99x）；KDA prefill AMD MI350X 较 vLLM 3.01x、NVIDIA B200 较 FlashKDA 3.44x；Apple silicon MoE 专家卸载 30.3 tok/s decode（Qwen3.8-Flash-Next MLX 4-bit / 48GB M4 Pro）；RoboDojo held-out seeds 62.1 vs 最佳榜单 55.3。GEPA-Curator 在 GoBrowse/ALFWorld/AppWorld/τ-bench（Gemini 3.1 Pro 与 Claude Opus 5 作优化器）较 GEPA 最高 **+20.7%**、较 ACE 最高 +21.2%。Batching GEPA：多数批式运行墙钟 ≤1/2、最快 1/4–1/3；LiveBench-Math 68.9%→72.1%（2×2）、HoVer 49.0%→60.0%（8×1）。RuHarness 在多任务/多骨干上超越强 harness 进化基线，held-out 任务增益最大。

### 2. arXiv Wed-28 批次·世界动作模型集群：ThinkWorld 链-动力学推理、Trace-WAM 3D 运动监督、RynnWorld-Latent 跨本体潜在动作、Best-of-N 可选余量测量（arXiv cs.RO | 2026-10-28）

**事件概述**：
同批次 cs.RO 收录一整组世界动作模型（WAM）论文，恰好覆盖 WAM 的四个前沿问题：**推理时怎么想**（ThinkWorld）、**监督什么**（Trace-WAM）、**跨本体怎么做**（RynnWorld-Latent）、**测试时选择有多少真实收益**（Best-of-N WAM）。

**技术与工程价值**：
- **核心机制**：① **ThinkWorld**（2610.37666）把动作思维表示为 Chain-of-Dynamics（CoD）——连接当前世界与未来状态的离散运动 token 序列；先以动作标注演示初始化 CoD，再对每个 CoD 预测其诱导的未来、按预测与观测结果的匹配度做 RL 强化——**无动作标注的人类视频因此可直接从观测状态转移提供监督**，人类与机器人经验精炼同一推理空间，实现人-机迁移。② **Trace-WAM**（2610.36840）为视频-动作学习加「未来 3D 运动预测」辅助目标（时序点对应+像素位移+深度变化），三支路 Mixture-of-Transformer（Tri-MoT）联合学习视频预测/运动预测/动作生成；运动监督塑造动作生成所用的表征，但动作专家推理时不消费预测轨迹——保持单次视觉前向+动作去噪的推理路径。③ **RynnWorld-Latent**（2610.36791）以 RynnLAM 的 3D-grounded 通用潜在动作为共享条件接口，人类交互视频/机器人演示/仿真 rollout 无需统一原生动作空间即可联合预训练（23 数据集约 5.535 亿帧），支持数字遥操作与潜在动作合成两条数据生成路线。④ **Best-of-N WAM**（2610.37196）提出去噪反事实协议（位级可复现分支、重复续跑、held-out oracle、共同随机数）测量测试时选择的真实「可选余量」，并构建 fail-gate 选择器——只在 WAM 读出预测失败时偏离策略块。
- **实际影响**：WAM（焦点三）与具身策略（焦点二）交叉推进：ThinkWorld 打通人类视频→机器人动作推理的监督通道；Best-of-N 的预注册检验（4 个 WAM、2 基准、10 万+ branched rollouts）给「测试时计算」在机器人控制上的收益边界给出首个去噪测量，纠正标准估计的系统性高估。

**关键指标/资源**（论文自述，未见第三方复现）：
- 评测/性能：Best-of-N 协议下，17 次续跑/候选测得三个 WAM 的可选份额仅 **24%–66%**（标准估计高估）；结构化动作扰动最多创造 **+16 个百分点**可选余量；两个动作条件想象 WAM 中，想象未来携带与真实未来无差异的候选-结果信息（Cosmos Policy 的 value head 未利用）。ThinkWorld 仿真+真机验证人-机迁移与未见任务泛化。Trace-WAM 在 RoboCasa-GR1/LIBERO/LIBERO-Plus 少演示与分布偏移下对 Fast-WAM 增益明显。RynnWorld-Latent 公开基准+两个真机平台视频预测提升，合成 mid-training 提升 LIBERO/LIBERO-Plus 策略成功率。
- 代码/论文：ThinkWorld https://arxiv.org/abs/2610.37666 ；Trace-WAM https://arxiv.org/abs/2610.36840 ；RynnWorld-Latent https://arxiv.org/abs/2610.36791 ；Best-of-N WAM https://arxiv.org/abs/2610.37196
- 同批另见（未单列）：World Dreamer v5-lite（2610.37518，多机器人共享世界状态）、GAWM（2610.37091，冻结 DINOv3 潜在预测紧凑 WAM）、Rollback（2610.36068，世界模型经验回溯）、E0.5（2610.36011，未来预测型 3D 基础）。

### 3. TAPESTRY：把预训练视频扩散 Transformer 直接复用为机器人策略——动作即 patch token，84ms 单步出动作块（arXiv 2610.36823 | 2026-10-28）

**事件概述**：
「视频生成先验→机器人控制」的第三条路线：不付测试时视频生成的成本、也不从零训练动作头——TAPESTRY 把预训练视频扩散 Transformer 原地变成世界动作模型，机器人动作被当作视频 latent 空间里的**单 patch token** 处理。

**技术与工程价值**：
- **核心机制**：动作时间步经轻量线性投影映射到预训练 VAE 的 patch 维度，走与视频完全相同的 patchify 层和 Transformer 骨干；每个 minibatch 元素采样三种扩散目标——视频扩散（机器人+人类视频建立动力学先验）、视频+动作联合扩散（耦合扩散时间步+非对称注意力掩码）、动作-only 扩散（干净图像 latent 条件下去噪动作）；测试时从纯噪声**单步 DDIM** 生成紧凑动作 token 序列，免整段视频生成。
- **实际影响**：世界模型（焦点三）的先验以近乎零额外结构复用到控制（焦点二）：消费级硬件 84 ms 出一个平滑动作块，视频先验与动作执行共享同一骨干权重——为「预训练视频模型直接驱动真机」给出当前最廉价的耦合方案之一。

**关键指标/资源**（论文自述，未见第三方复现）：
- 评测/性能：动作块推理 84 ms/块（消费级硬件）；测试时视频生成调用 0 次（单步 DDIM）。
- 代码/论文：https://arxiv.org/abs/2610.36823

### 4. Dwell：VLM 在自身潜在世界里学世界模型兼做策略——免重构未来的 model-based RL（arXiv 2610.36925 | 2026-10-28）

**事件概述**：
VLM 的世界知识第一次被系统性用于驱动**在线交互中的策略自我改进**：Dwell 把 VLM 重构为「循环潜在转移算子」，在自身表征空间里预测、调整、行动——世界模型与策略两个角色由同一组预训练权重承担。

**技术与工程价值**：
- **核心机制**：model-based RL 框架：agent 从真实交互中学会预判与评估动作结果，从潜在想象中改进行为；策略更新移动交互分布时，作为世界模型的表征同步适应；全程在 latent 空间完成想象，避开「持续更新大模型+视频重构」的双重算力开销。论文核心论断：**对 VLM agent 有效的世界模型不必重构未来，只需预测对行动有用的未来**。
- **实际影响**：世界模型（焦点三）×自进化 agent（焦点四）交叉：五个交互视觉环境中可训练方法综合最强，同时把想象所需的计算大幅压缩，为「经验驱动持续学习」给出可负担的实现路径。

**关键指标/资源**（论文自述，未见第三方复现）：
- 评测/性能：五个交互视觉环境可训练方法中综合最强；想象计算开销较视频重构方案大幅降低（论文未给统一绝对值口径）。

### 5. From 12 to 200 Demonstrations：ACT/π0.5/SmolVLA/Diffusion Policy 在低成本臂上的 1,340 回合数据缩放实证（arXiv 2610.37170 | 2026-10-28）

**事件概述**：
四个主流模仿学习策略在**同一低成本臂（SO-101）、同一任务（带干扰物抓放）、同一评测集**上按 12/25/50/100/200 演示嵌套子集、每策略单一固定配方训练实测：1,340 个评分回合、126 个 block——罕见的公开同条件具身数据缩放曲线。

**技术与工程价值**：
- **核心机制/发现**：ACT（从零训练）：12 演示 1/40 → 100 演示 37/40，自 100 演示起领先（领先幅度研究未完全归因）；π0.5（微调动作专家）在数据稀缺档位最优：12 演示 16/40、25 演示 28/40，此后稳定在约 70%；SmolVLA 与 Diffusion Policy 峰值约 50%，且各自暴露「不起动」失效——**SmolVLA 47% 回合手臂从未移动**、Diffusion Policy 在修剪演示中的空闲引导段前几乎不起动。
- **实际影响**：具身智能（焦点二）数据预算的工程参照系——「选哪个策略」的答案取决于演示预算档位（稀缺选 π0.5、充足选 ACT）；「不起动」类失效提示具身评测协议必须覆盖启动行为，否则成功率被系统性误读。

**关键指标/资源**（论文自述，未见第三方复现）：
- 评测/性能：ACT @100 演示 37/40（92.5%）；π0.5 @12 演示 16/40（40%）、@25 演示 28/40（70%）；SmolVLA 未起动率 47% 回合；总评测 1,340 评分回合。
