Google DeepMind 发布 Gemini 3.7 Flash：主打编程与智能体的「最强工作模型」，价格减半

事件 8/13，Google DeepMind 发布 Gemini 3.7 Flash（距 3.6 Flash 仅三周），定位「coding and agents 的最强 workhorse 模型」。介绍价 $0.75/1M 输入、$3.75/1M 输出，为 3.6 Flash 的一半，年底前维持该价。编码与智能体基准明显提升：FrontierCode 1.1 Main 43.6% vs 34.4%、DeepSWE v1.1 65.3% vs 49.0%、WebDev Arena Elo 1588 vs 1538、AutomationBench 30.4% vs 17.0%、GDP.pdf 34.0% vs 22.0%。
为何值得关注 在 Grok 4.6 / DeepSeek V4 Pro / Qwen3.8 开源同一周，Google 选择用「降价 + 编码/智能体专项增强」而非冲榜来抢开发者心智，印证本系列「性价比模型冲击前沿」主线。对 AI Coding 而言，Flash 档把生产级 agent 的边际成本进一步压低，利于在 CI/长程任务中大规模铺开。
来源：Google DeepMind 官方博客

Claude Code v2.1.232 发布：默认启用 Subagent forking，集中修补 Windows 权限绕过

事件 8/13 晚，Claude Code 发布 v2.1.232。默认启用 subagent forking（subagent_type: "fork" 子代理继承完整对话与提示缓存，交互会话中非队友代理默认后台运行）；新增 GitLab token 系列密钥脱敏与插件市场 GitLab 仓库克隆支持；修复 PowerShell 权限绕过（变量写参可静默覆盖 $PSDefaultParameterValues 重定向后续命令文件访问）、Windows 权限绕过（Git Bash 跟随 Cygwin 风格符号链接绕过路径校验）、嵌套 git 仓库继承父目录信任等漏洞（据 GitHub Releases）。
为何值得关注 subagent forking 把「长程任务拆给子代理并行且共享 prompt cache」做成默认，直接呼应 8/13 NDC 演讲「2026 重心从信息输入模型转向从模型输出」的编排思路；本轮集中修补 Windows 权限绕过类漏洞，延续本系列长期警示——Coding Agent 能力增长必须与权限收敛同步。
来源：Claude Code GitHub Releases

Cursor 推出 builds + 通过 AIUC-1 安全认证：云智能体启动快 3 倍、环境更韧性

事件 8/13，Cursor 发布 builds——后台持续准备就绪的开发环境副本，云智能体启动快至 3 倍（内部环境启动快 10 倍、首 token 快 3 倍），智能体始终从最近一次成功 build 启动，依赖/安装脚本出错不影响运行；8/17 起所有环境默认启用、不额外收费。同日 Cursor 宣布获得 AIUC-1 认证（智能体安全与可靠性独立审查），并披露 Firetiger 团队加入。
为何值得关注 builds 把「环境预热 + 失败隔离」做成托管能力，是 Agent 运行时标准化的又一落点（延续 8/8「运行时标准化」主线）；AIUC-1 独立认证则把「框架即中间件却缺威胁模型」的隐患（8/6 Langflow 入 KEV）推向可审计的第三方背书，工具厂竞争从模型能力下沉到运行时与合规层。
来源：Cursor Blog

Boris Cherny：让 Claude 接管应用日常维护，数周开出 388 个 PR

事件 8/13，Anthropic 的 Boris Cherny 分享实践：通过 Slack 频道让 Claude 运行崩溃模糊测试、重复代码统一、死代码移除等日常任务，数周内自动开出 388 个 PR，其中 180 个经 Claude Code Review + 人工审核后合并；Claude 通常一次改对，出错时调整例程次日改进。
为何值得关注 这是 Coding Agent 从「写功能」走向「长期运维自有代码库」的强实证——维护类工作（模糊测试/去重/清理）恰好是长尾、低创意、高重复的工程负担。与 #2/#3 的运行时/编排能力叠乘，预示「agent 接管 repo 卫生」将成为标配而非噱头。
来源：X @bcherny

AWS Strands Robots 用 Hugging Face Storage Buckets 打通「记录—训练—部署」机器人数据闭环

事件 8/13，AWS 开源的 Strands Robots（Apache 2.0）发布实践：通过单一智能体循环，将机器人演示记录、基于 Hub 数据流的策略训练、硬件部署整合在一起，全程保持 LeRobot 磁盘格式不变，数据借助 Hugging Face Storage Buckets 在记录/训练/部署间流转。
为何值得关注 具身智能的工程瓶颈长期在「数据格式/存储/训练/部署各自为政」。Strands 把这条链路统一到 LeRobot 格式 + HF Hub 存储，降低跨团队复现与部署成本，是 NVIDIA（GR00T/LeRobot 工作流）、腾讯/小米开源之后的又一项「开放工程链路」信号，印证本系列「开放的是工程链路而非参数规模」判断。
来源：Hugging Face Blog（AWS）
