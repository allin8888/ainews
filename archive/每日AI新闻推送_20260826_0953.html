OpenAI Jalapeño 自研推理芯片首次实测：每瓦吞吐超英伟达 GB300 最高 1.9 倍
OpenAI Blog / SemiAnalysis | 2026-08-25

事件概述

OpenAI 在 Hot Chips 2026 大会上公布首款定制推理 ASIC「Jalapeño」的首批实测数据，由 OpenAI 与博通联合开发、台积电 3nm 制程，标称 TDP 700W（实测 ≤550W），在 SemiAnalysis InferenceX 基准上击败所有可测英伟达/AMD/谷歌同代芯片。

技术与工程价值

  • 核心机制：专为语言模型推理设计，将 KV 缓存等模型状态尽量贴近计算单元，减少跨芯片搬运；采用 GMP（Gluon Modeling Protocol）自研编程语言，Codex 参与内核编写——部分 AI 生成内核比人类专家版本快 1.5–1.8 倍。从组队到流片仅用 16 个月（行业常规 ≥3 年）。
  • 实际影响：推理成本正在从「峰值算力竞赛」转向「每瓦 token 产出竞赛」；OpenAI 在推理端首次展示摆脱 GPU 供应商依赖的可行路径，继 Google TPU、Amazon Trainium 后又一个超大规模厂商自研推理 ASIC 落地。

关键指标 / 资源

  • 每瓦吞吐：GB200/GB300 的 1.5–1.9 倍；端到端延迟低 1.7–3.6 倍；交互场景最高快 2.1–4.1 倍
  • 测试模型：GPT-OSS 120B、DeepSeek R1 670B、Kimi K2.5 1T（单 token 预测模式）
  • 对等配置下（GB300 开启 MTP），领先幅度收窄至约 1.5 倍
⚠️ 待核实：SemiAnalysis 仅验证了 InferenceX 部分运行；未与 Vera Rubin 正面比较；大规模生产部署尚未开始（计划 2026 年底小规模、2027 年扩产）

Meta Muse Code Beta 发布：面向大规模代码库的自主软件工程 Agent
Meta Tech Blog | 2026-08-25

事件概述

Meta 正式发布 Muse Code beta，基于 Muse Spark 1.2 驱动，针对大型仓库规划、编码、测试、PR 全流程的自主编码 Agent，内部工程团队试用后常规 bug 解决时间减少 40%。

技术与工程价值

  • 核心机制：双循环规划架构（Monte Carlo 树搜索 + 回归测试验证），在隔离 ephemeral Docker 沙箱内动态验证代码改动，再提交 PR；多子代理拆分复杂工程任务，避免单模型幻觉扩散。
  • 实际影响：标志着 Coding Agent 竞争从「单文件补全」全面进入「整仓维护」阶段；定价策略颠覆（Contributor 版输出 token 仅 $0.2/M，标准版 $4.25/M），但数据用于训练下一代模型。

关键指标 / 资源

  • Terminal-Bench 2.1 得分 82.9%（对比 Claude Opus 5 的 86.7%）
⚠️ 待核实：大规模仓库真实场景复现数据待补充；贡献者版数据使用权条款需仔细审阅

第二届世界人形机器人运动会闭幕：百米纪录刷新至 8.86 秒，具身智能从「炫技」转向「上岗」
环球时报 / 河南日报 | 2026-08-25/26

事件概述

第二届世界人形机器人运动会 8 月 25 日在北京国家速滑馆「冰丝带」闭幕，汇聚 16 国 666 支队伍 2056 台机器人。北京人形机器人创新中心天工机器人在 100 米复赛跑出 8.86 秒，刷新此前 9.39 秒纪录；擎仓×越疆同步首发美妆日化行业具身智能规模化落地方案。

技术与工程价值

  • 核心机制：具身智能竞争焦点从「身体性能」（跑跳登高）转向「大脑能力」（世界模型+泛化决策）；蚂蚁灵波、智澄 AI、大晓机器人等集中发布自研世界模型方案；雄安新区具身智能训练场常态化运营，每日产出高质量真机数据。
  • 实际影响：人形机器人从技术验证全面进入 PMF（产品市场契合）验证期；上下料/分拣等标准化场景成为首个规模化落地突破口，行业共识「成功率至少 99% 才能规模化」。

关键指标 / 资源

  • 百米纪录：8.86 秒（超越博尔特 9.58 秒人类纪录）；跳高 2.88 米
  • 2026 H1 人形出货量：4 万+ 台，中国占 97%+
  • 宇树科技科创板首日市值破 4000 亿，涨幅 630%
⚠️ 待核实：冲线后多台机器人摔倒暴露自主运动控制稳定性短板；宇树上市后股价较首日高点已跌 45%、市值缩水 300 亿美元，泡沫警示声起

小鹏机器人首轮融资超 9 亿美元，刷新中国具身智能单轮私募纪录
小鹏汽车 / 新浪科技 | 2026-08-25

事件概述

小鹏旗下人形机器人业务完成首轮超 9 亿美元融资，投后估值超 63 亿美元（约 430 亿元），由 IDG 资本领投、高榕创投参投，腾讯与阿里战略跟投，小鹏保持控股。IRON 人形机器人全身 76 自由度，计划 2026 年底量产、2027 年零售服务销售。

技术与工程价值

  • 核心机制：首款落地场景选门店而非工厂，瞄准高复杂度人机交互环境；63 亿美元估值刷新中国具身智能单轮私募纪录，反映资本对人形机器人商业化窗口加速打开的预期。
  • 实际影响：车企跨界具身智能进入资本兑现期——自动驾驶技术栈（感知/规划/控制）与人形机器人高度同构，小鹏以「第一个场景是门店」差异化避开与宇树/智元在工厂场景的直接竞争。

关键指标 / 资源

  • 融资金额：超 9 亿美元（单轮私募中国具身智能最高）
  • IRON 机器人：76 自由度，2026 年底量产，2027 年零售服务
⚠️ 待核实：63 亿美元估值为投后口径；门店场景规模化落地时间线待观察
