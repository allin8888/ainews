### 2. datasette-llm 0.1a11 发布：新增 OpenAI 兼容端点，本地模型一行命令驱动 Datasette Agent（Simon Willison 官方博客 + GitHub Release | 2026-11-14）

**事件概述**：
Simon Willison 发布 datasette-llm 0.1a11：Datasette 的中间层插件（供其他插件依赖以统一配置 LLM），本次新增 OpenAI 兼容端点支持——任何实现 OpenAI 伪标准协议的模型服务均可作为后端，覆盖 LM Studio、Ollama、llama.cpp（刚发布 v1.0.0）等本地运行时。作者给出一条 uvx 命令演示：以本地 LM Studio 运行的 qwen3.8-27b 经 datasette-agent 启动一个完整 Datasette Agent 实例。

**首发时间**：
GitHub Release published_at 2026-11-14T23:59:28Z（仓库 datasette/datasette-llm，Datasette 官方 org），与作者博客文章发布时刻（2026-11-14 23:59 UTC）一致；落入窗内。

**技术与工程价值**：
- **核心机制**：datasette-llm 定位为「intermediate plugin」——不直接面向用户，而是为其他 Datasette 插件提供统一的 LLM 配置面；0.1a11 增加 api_base 配置使 OpenAI 兼容端点（本地或远程）成为一等公民，插件生态无需各自适配即可共享模型配置。
- **实际影响**：把「私有数据 + 本地模型 + Agent」的启动成本压缩到一条命令（wget 数据库 → uvx --with datasette-agent datasette --root --secret ... -s plugins.datasette-llm.default_model），对数据不出域的分析场景有直接工程价值。
- **适用限制**：仍为 0.1 alpha 第 11 个迭代（a11），API 稳定性未承诺；演示为作者自测口径，未见第三方复现；依赖的 datasette-agent 包同处 alpha（0.5a0）。

**关键指标/资源**：
- 评测/性能：未披露可比量化指标。
- 代码/权重/许可：Apache-2.0 开源，仓库 datasette/datasette-llm（Datasette 官方 org，20 stars，2026-11-15 GitHub API 查询）；依赖 PyPI 包 datasette-agent 0.5a0（作者同生态）。
- 论文/官方来源：Release https://github.com/datasette/datasette-llm/releases/tag/0.1a11 ｜ 官方博客 https://simonwillison.net/2026/Nov/14/datasette-llm/
