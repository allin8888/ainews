## 1. Flue 2：用 React 风格 Hooks 重写 Agent「元 Harness」
- **事件**：Astro 作者 Fred Schott 发布 Flue 2 首个稳定版，把 React 的 hooks 心智模型引入 Agent 框架——`useModel` / `useTool` / `useSkill` / `useSandbox` 等 16 个内置 hook，每次模型调用前重跑，使工具与资源可随对话/工作流条件式挂载。框架建立在开源 harness 底座 Pi 之上，沙箱为一等公民（just-bash 虚拟沙箱 / local / cf-shell / Daytona 容器）。
- **为何值得关注**：延续本期「增量在模型之外」主线（7/18→8/6→8/8→8/16 七周脉络）。Flue 的核心命题「agent 由 harness 定义而非模型」与 Claude Code / Codex 的工程实践同构，把"运行架"从各框架的边角能力推到一等抽象；其 headless-first 设计与可移植沙箱，对编码 Agent 的跨环境部署有直接参考价值。
- **来源链接**：[latent.space：React for Agents](https://latent.space/p/flue-2) ｜ Flue 仓库（withastro/flue，Apache 2.0）

## 2. Cloudflare Agents 推出 Agent Tracing，10/1 起按 span 计费
- **事件**：在 Workers tracing 之上新增 agent / model / tool / approval 四类 span，可逐 turn 回放 Agent 调用链；首批支持 Think、Flue v2、AI SDK（wrapAISDK 适配器），自定义 harness 走 OpenTelemetry GenAI 语义约定。beta 期免费，2026-10-01 起纳入 Workers Observability 计费（Free 20 万事件/天，Paid 2000 万/月，$0.60 / 百万超额）。
- **为何值得关注**：Agent 可观测性正成为"标配"，但两条 caveat 直击本期成本主线——① trace 非无损，长消息/推理/工具参数可能被截断，debug 与合规留存需显式配置；② 每 span 计费使高扇出 Agent（每 turn 大量工具调用）成本不可忽略，验证/可观测性本身变成成本优化问题。
- **来源链接**：[Cloudflare 官方博客](https://blog.cloudflare.com/agents-on-cloudflare/) ｜ [Tracing 文档](https://developers.cloudflare.com/agents/runtime/operations/observability/tracing/)

## 4. 七鲜咖啡全球首家 24h 无人店，机器人 1 小时出杯 202 杯获吉尼斯
- **事件**：京东旗下七鲜咖啡北京银河 SOHO 店开业，研磨、萃取、调饮到出杯全程由机器人完成，单杯约 20–30 秒；现场以"1 小时机器人咖啡店供应最多杯"挑战吉尼斯成功（202 杯，门槛 130 杯）。核心系统为橡鹿机器人"鲜咖方舟"AI 全自动饮品工作站，依托京东 AI 大模型与具身智能融合。
