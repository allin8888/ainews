### 2. LangChain 公开 Deep Agents 浏览器工具优化复盘：七套工具对比选定 Stagehand，WebVoyager 90% 通过仅 $1.98（LangChain 官方博客 | 2026-11-03）

**事件概述**：
LangChain 发布工程复盘，对比七套浏览器工具集后为 Deep Agents 选定 Stagehand（Browserbase）并重建浏览器工具层：代码模式 `run`（Playwright 式链式调用，中间上下文不进模型窗口）、以 accessibility tree 快照替代截图、`settle wait`（固定 sleep 改为页面静默 500ms 即返回）、结构化 JSON 输出与单往返批处理，并公布三套基准的完整对比数据。

**技术与工程价值**：
- **核心机制**：Agent 浏览器瓶颈不在模型而在工具层往返开销——快照中位 117 字符 vs 托管工具 ~17,000 字符、单任务模型轮次 10 vs 26、8 秒固定等待压缩到 0.6 秒；把「浏览器动作」编译成代码块批量执行是 token 成本下降一个数量级的关键。
- **实际影响**：为 Agent 浏览器工具选型提供了可复用的评测方法学（WebVoyager/HardBench/WebTailBench 三基准 + 成本口径），Playwright MCP 与代码模式工具的 13 倍成本差是 Agent 工程选型的直接参考。

**关键指标/资源**：
- 评测/性能：WebVoyager 100 任务（Claude Sonnet 5.5）：Stagehand **90% 通过 / $1.98 总成本 / 中位 17.4s 每任务**，对比 Playwright MCP 78% / $26.71（约 13× 成本、3× 单任务耗时）；HardBench 38 核心任务：`run` 代码模式 30/38 vs CLI 21/38（自述数据，未见第三方复现；Browserbase「Stagehand v4 token 效率 +80%」为厂商口径）
- 代码/论文：https://www.langchain.com/blog/how-we-optimized-browser-use-for-deep-agents
