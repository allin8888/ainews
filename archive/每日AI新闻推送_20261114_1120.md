### 1. Google Gemini 4 Hydrogen 发布：面向日常编码与智能体工作流的高速执行模型（Google DeepMind 官方博客 / Google 开发者博客 | 2026-11-13）

**事件概述**：
Google 发布 Gemini 4 系列的「高速执行档」模型 Gemini 4 Hydrogen，定位为日常编码与智能体任务中的低成本、高吞吐执行层，并同步在 Antigravity 中推出多模型编排功能 Orchestrator。

**技术与工程价值**：
- **核心机制**：Hydrogen 设 low / medium / high（默认）/ xhigh 四档思考深度，可在单一上下文内按需权衡推理深度、延迟与成本；原生支持 100 万 token 输入与 100 万 token 输出。配套的 Orchestrator 在单次会话内于规划模型（Carbon / Argon）与执行模型（Hydrogen）间自动交接控制权——规划模型先探查代码库、识别依赖、产出方案，Hydrogen 负责改文件、写代码、跑构建与测试，遇阻再交还规划模型修订；并行智能体场景下 Carbon 协调、Hydrogen 驱动 worker / verifier 在隔离工作区并行构建与验证。
- **实际影响**：对 AI Coding 工作流，Hydrogen 把「轻量执行 + 重规划」分层落地为可一键启用的产品形态；Orchestrator 在 Terminal-Bench 4.0 上接近 Carbon 的任务成功率，同时平均配额消耗降 24%、完成速度提升 19%，为大型工程团队压降 AI 编码成本提供可预测路径（也带来模型级审计 / 归因的新治理问题）。

**关键指标/资源**：
- 评测/性能：Artificial Analysis 智能指数默认 high 档 51（xhigh 54），高于 Argon 的 50（第三方口径）；官方称相对 Gemini 3.8 Flash 默认 high 档任务完成速度提升 2.5×，Terminal-Bench 4.1 得分 18.2% → 57%（自述数据，未见第三方复现）；原生支持并行读文件 / 搜索以处理大型代码库。

### 2. 西湖大学 Awomo-0.5「概念世界模型」：4B 参数登顶 6 项物理推理与机器人操作评测（西湖大学世界模型研究中心 / 雷峰网 | 2026-11-13）

**事件概述**：
西湖大学成立世界模型研究中心（施一公揭牌），同步发布首版基础模型 Awomo-0.5——一款仅 40 亿参数的「通用物理世界模型」，在 6 项国际公开评测的不同榜单中同时登顶，覆盖物理推理、机器人操作与泛化。

**技术与工程价值**：
- **核心机制**：采用「概念世界模型（Concept World Model）」路线——不把逐帧生成画面作为核心目标，而是在隐空间构建可组合、可复用的物理概念（物体属性、空间关系、材质、接触状态），每个概念同时对应语言描述与物理现象，再基于概念推演后续状态。该路线与 LeCun 推动的 JEPA 同属隐空间家族，但把潜空间内容显式定义为可组合物理概念。
- **实际影响**：以极小参数量在物理推理与零样本机器人操作上证明「结构化概念表征优于堆参数」，为具身 / 世界模型在真实机器人迁移提供低成本路径；两项关键泛化测试——RoboTwin-c2r（50 项双臂任务、布局打乱）成功率 80.6%，MolmoSpaces（AI2 零样本操作硬核基准，23 万+ 场景、13 万+ 物体）73.4%。

**关键指标/资源**：
- 评测/性能：4B 参数；RoboTwin-c2r 80.6%、MolmoSpaces 73.4% 零样本（团队自报，未见第三方复现）；6 项国际公开评测登顶（物理推理 / 机器人操作 / 泛化）。
- 代码/论文：西湖大学世界模型研究中心（AutoLab 自主智能实验室）；雷峰网报道《40 亿参数模型拿下 6 个评测第一》（2026-11-13 18:10，链接 https://www.leiphone.com/category/academic/nhzldlwI6rJVyXIl.html）；截至发稿未检索到公开权重或 arXiv 论文，模型卡 / 论文链接待核实。

### 3. RSI-PDEbench 与 RSI-PDE：递归自改进智能体在 PDE 求解上的基准与 Harness（arXiv 2611.14949 | 2026-11-13）

**事件概述**：
一篇 11 月 13 日提交 arXiv 的论文提出 RSI-PDEbench——面向偏微分方程（PDE）求解的递归自改进（RSI）智能体基准，以及配套 Harness RSI-PDE，验证「带验证门的递归自改进」可显著提升科学计算智能体的效率。

**技术与工程价值**：
- **核心机制**：RSI-PDE 先以残差损失初筛候选方程，再用相对 L2 反馈精化系数与数值求解器，并以 validation gate 约束策略与记忆更新；在三大设置（Full 无噪 / Noisy 高斯噪声 RMS=50% / Hard-OOD 未见模板与偏移系数）下闭环自改进。基准含 1,001 个案例、42 个方程模板，跨 4 个前沿模型对比。
- **实际影响**：在科学计算这一「结果可验证」的高价值领域，为 RSI 闭环提供量化证据：相对单次运行基线，pass rate 平均提升 106.5%–181.9%；相对原生 Harness（Claude Code / Codex）提升 3.0%–19.6%，同时总模型调用减少 46.9%（12 个模型-设置对），指向「更少调用、更稳收敛」的自改进范式。

**关键指标/资源**：
- 评测/性能：pass rate 相对单次基线 +106.5%~+181.9%、相对原生 Harness +3.0%~+19.6%、模型调用 −46.9%（论文自报，未见独立复现）；1,001 cases / 42 templates。
- 代码/论文：arXiv:2611.14949（2026-11-13 提交，论文链接 https://arxiv.org/abs/2611.14949）；基准与 RSI-PDE Harness（论文未附公开仓库链接，待核实）。

### 4. DeepSeek 开放「全家桶」应用 API：深度思考搜索、文件输入与 OCR/ASR/TTS 独立接口（DeepSeek 官方 / 澎湃新闻 | 2026-11-13）

**事件概述**：
DeepSeek 宣布在原有 API 中开启对应参数即可获得深度思考搜索、文件输入等对话功能，并将语音及相关底层能力开放为独立接口（OCR / ASR / TTS），开发者可近乎 1:1 复刻完整 DeepSeek App。

**技术与工程价值**：
- **核心机制**：在 Messages、Responses 与 Chat Completions 三大接口下，基于 V4.1-Flash（deepseek-flash）支持：① 非思考模式联网搜索（deepseek_web_search）自动搜网页 / 图片并附引用；② 思考模式深度思考搜索（多步推理中自主联网并阅读链接）；③ 文件输入（PDF / Office / 图片，文本提取或图文混排解析后拼入上下文）；④ 阅读链接（deepseek_read_url 自动抓网页）；⑤ 模型安全（开启安全校验参数，命中风险返回拒答）；上述能力及语音经服务端自动完成工具调用与上下文拼接。OCR / ASR / TTS 可作为独立端点单独或组合调用。
- **实际影响**：将 DeepSeek App 背后的交互能力整体商品化为可调用的工具层，把「应用外壳」与「模型推理」解耦，降低开发者复刻复杂对话产品的门槛，延续 10 月 Search / Fetch API 之后的工具接口开放节奏——属「AI 应用层进一步商品化」信号（自述）。

**关键指标/资源**：

### 5. 无界前沿开源 Fx-Bio-1031：125B MoE 生信模型把 RSI 带进生命科学（无界前沿 / Hugging Face 模型卡 | 2026-11-13）

**事件概述**：
无界前沿（Endless Frontier，中科院院士发起、上海交大 / 上海算法创新研究院 / 深势科技联合孵化）于 11 月 13 日官宣开源生物信息大模型 Fx-Bio-1031 完整权重，基于 Qwen3.8-Flash-Next 做 RSI 后训练，在 Anthropic BioMysteryBench 困难子集上超越 GPT-6-Astra 与 Opus-5。

**技术与工程价值**：
- **核心机制**：125B MoE（每 token 激活约 6B）、原生 512K 上下文、Qwen Community License 1.0；核心为自演进体系 RSI-OS 三层飞轮——评估层（联合深势 BioMaster 团队，114 内部任务 × 3 轮 = 342 题次、2 万+ 模型请求独立验证）、数据层（AI 针对短板自主造题 / 求解 / 审查）、环境层（AI 编写修复生信脚本、打磨 Harness）。模型被直接置入真实 Linux 工具环境与数百万行原始数据，自主写代码、调数据库、做交叉验证。
- **实际影响**：高难盲测中，模型在乳腺癌队列任务主动加做 14 项敏感性分析与阴性对照并划出结论失效边界；在 ATAC-seq 盲测中跨库推理还原 9 份无标签样本分组；在突变签名任务连跑 76 步抓出乳腺癌头号元凶，并在细菌测序质检中揪出底层坏记录后连续 258 步交付可追溯报告——为「垂域 RSI + 可审计智能体」提供开源底座。

**关键指标/资源**：
- 评测/性能：BioMysteryBench Difficult Pass@5 70.59%（对比 GPT-6-Astra 47.06%、Opus-5 52.94%）、BiomniBench Pass@3 89.50%（均为厂商自报、内部评测框架、未见第三方复现）；BixBench3 45.76% 落后于 GPT-6-Astra 48.70（厂商自曝短板）。
- 代码/论文：Hugging Face 模型卡 endless-frontier/Fx-Bio-1031（https://huggingface.co/endless-frontier/Fx-Bio-1031）；量子位授权刊载发布稿、TPS Report 英文报道（2026-11-13）。
