### 1. AWS Loom（Loom for AWS）CVSS 10.0 认证绕过 + 双 SSRF：未配 IdP 的 Agent 控制面板对全网裸露（AWS 安全公告 2026-124-AWS | 2026-10-02 19:00 UTC 首发，10-04 窗口内深度解析）

**事件概述**：
AWS 于 10-02 19:00 UTC 发布安全公告 2026-124-AWS，披露开源 Agent 编排平台 **Loom for AWS**（AWS Labs）的 3 个 CVE 与 SageMaker Unified Studio 的 1 个指令注入 CVE。其中最严重的 CVE-2026-103956（CVSS v3.1 与 v4.0 均为 10.0）源于认证依赖的不安全默认初始化（CWE-1188）：当部署**未配置身份提供者（IdP）**时，控制面 API 不执行任何认证（CWE-306），任意网络客户端可直接获得 agent 控制面的超级管理员权限。

**技术与工程价值**：
- **核心机制**：攻击面聚焦在「agent 控制面」这一 2025-2026 年才成型的新基础设施层——Loom 管理 agent 的注册、工具服务器（MCP）、远端 A2A agent、IAM 角色策略与已存储的集成凭证。三个 Loom CVE 的组合拳是：① 认证绕过（无需凭据即可注册工具服务器、读取 OAuth2/OIDC secret 与 API key、**改写绑定在受管 agent 角色上的 IAM 策略**——权限在修补后仍然残留）；② CVE-2026-103957（SSRF，OAuth2 discovery 处理，CVSS 8.2）：持有 `mcp:write` 范围的已认证用户可将 Loom 的 MCP 工具服务器连接逻辑重定向到任意外部位置，外泄 client secret；③ CVE-2026-103958（SSRF，工具服务器与远端 agent 连接处理，CVSS 8.3）：可打到容器内部的 credential-vending 端点。同期修复的 CVE-2026-104019（CVSS 9.3，SageMaker Unified Studio Space 启动脚本指令注入）在开启 Trusted Identity Propagation 时甚至可窃取队友的执行角色凭证。
- **实际影响**：这是「Agent 编排层内卷」（harness/运行时成为关键中间层）主线的另一面——**编排层成为攻击面**。第 80 跑（10-03）报道了「harness 决定 Agent 表现（62% vs 33%）」，本条则指出 harness/控制平面在安全侧的结构性弱点：认证依赖默认 open 是 agent 控制平面的反模式；而 agent 控制面持有的权限与凭证是「下游所有 agent 能力的总闸」，一旦被改写 IAM 策略，渗透的持续性超出单一补丁窗口。对运维的直接含义：任何 Loom 部署必须配置 IdP；升级到 1.7.0 而非仅 1.6.1；轮换 OAuth2/OIDC client secret 与活动 access token；审计 CloudTrail 中未授权的 IAM 策略变更。

**关键指标/资源**：

### 3. DeepJEPA：世界模型内部计算分配新范式——「think deeper at decision-critical transitions」（NYU / Tulane / UIUC / Princeton / MIT / Columbia / Stanford | arXiv:2610.00368，2026-09-30 06:48 UTC v1 首发，10-04 窗口内集中解读）

**事件概述**：
《DeepJEPA: Scaling World Models from Within》提出**把世界模型的扩展轴从「向外扩展」（roll 更远、采更多轨迹、优化更久）转向「向内扩展」（transition-level deliberation）**：world-model planner 在 rollout 的每一步都分配相同的预测器深度，但**有用的精炼集中在少数 decision-critical 事件**（接触起始、持续物体交互）。DeepJEPA 学习「每个 candidate 与每个 rollout 步是否值得多跑一次 recurrent 更新」，额外计算集中在使用处。

**技术与工程价值**：
- **核心机制**：固定深度扫描揭示了一个反直觉结论——**K=4 在全局均值上从未击败 K=1**（5 个 visual-control 场景），中间深度非单调；即「更深的内部计算本身不是 scaling law」，**分配才是**。DeepJEPA 将 transition depth 作为**内层 test-time scaling 轴**：保持多数 transition 浅，只在决策关键 transition 精炼，再让 planner 选择动作。固定 rollout 时域 / candidate 预算 / 外层 planner loop 不变。表示探针进一步显示**改进的规划不需要均匀更好的 object-state 可解码性**。
- **实际影响**：这是对「世界模型扩展」范式的重定义——从「更大更强」到「在哪里更深」。与第 80 跑 Percepta Spotlight（「智能与记忆解耦」）、JEPA-TTT（「世界模型测试时自训练」）共同构成「**测试时自适应 / 测试时计算分配**」的第二条通用路线：不是更大的预训练模型，而是在**推理时把计算用在刀刃上**。对规划型 world model 的部署方，DeepJEPA 给出的工程含义是：在 contact onset / sustained interaction 处做额外 recurrent 更新的「内层扩展」比「外层扩展」（采更多轨迹）更有效且更省算力——这是「world model 自己会变」之后「world model 自己知道何时变深」的下一步。

**关键指标/资源**：
- 评测/性能（**论文自述，跨 5 个 visual-control 场景，待第三方复现**）：平均每个 transition 仅 1.00–1.26 次 recurrent 更新（vs 固定深度 planner 的 K=4）；额外计算集中在接触起始与持续物体交互。
- 代码/论文：arXiv:2610.00368v1（cs.RO；v1 提交 **2026-09-30 06:48:25 UTC**，严格早于本期窗口起点 10-04 11:30）；项目页 `deepjepa.github.io`。
- 时间戳界定（重要）：**arXiv 首发 9-30 严格早于窗口**，本期纳入依据是 **10-04 窗口内 arXiv 周日重新进入公告队列后的集中解读**（variante.github.io/gpt_paper_assistant 收录），构成窗口内解读增量，已就地标注。

**标签**：`#世界模型` `#测试时计算` `#JEPA` `#推理计算分配`

### 4. HumanoidTTT：测试时能力复用驱动人形机器人持续控制，16.4× 端到端加速 + 零不安全接受（北京大学 / AIGeeksGroup | arXiv:2610.00198，2026-09-18 21:44 UTC v1 首发，10-04 窗口内 cs.RO current 页重新可见）

**事件概述**：
《HumanoidTTT: Test-Time Capability Reuse for Efficient Humanoid Control》解决持续部署中人形机器人的**能力复用**问题：相同运动能力被反复请求，但中间运动改变机器人入场状态，盲重放先前成功的运动不安全；同时已验证能力在有限容量 Store 中累积，需要决定哪些值得保留。HumanoidTTT 引入两个机制——**Selective Full-Motion Reuse**（仅从认证适用的入场状态直接复用已验证完整运动，绕过重新生成）与 **Test-Time Capability Consolidation**（用 Double-DQN 在线学习哪些合格能力应在有界 Full-Motion Store 中持久化）。

**技术与工程价值**：
- **核心机制**：每个存储能力 = 已验证完整运动 + 入场适用性证书（Entry Applicability set，即可可靠复用的机器人入场状态集合）。复用请求到来时，若当前入场状态落在证书内则直接执行、否则回退到冻结生成器（OMG + HoloMotion）重新生成并执行资格化；有界 Store 满时，Store-conditioned Double-DQN 选择 SKIP 或 REPLACE(j)，在线反馈来自后续部署复用效用。45 维入场状态描述子 + 局部单元证书 + 物理/签名检查构成复用资格判定。
- **实际影响**：这是「具身智能从单次任务走向持续部署」的基础设施层工作——**把「已验证能力」变成可复用资产而非一次性生成结果**。对量产型人形机器人（如 Unitree G1、Boston Dynamics Atlas 类）的部署方，16.4× 端到端加速意味着同样的运动请求在持续部署中不需要反复跑生成器，把算力预算从「生成」转向「复用与整合」；而「零不安全接受」是可靠性底线（盲重放可能因入场状态漂移导致摔倒/碰撞）。这与第 80 跑 JEPA-TTT（「世界模型测试时自训练」）同属「**测试时自适应**」主线，但 HumanoidTTT 走的是**运动能力层**（复用已验证动作），JEPA-TTT 走的是**世界模型动力学层**（测试时更新预测器），两条正交。

**关键指标/资源**：
- 评测/性能（**论文自述，MuJoCo 仿真 + 真实 G1 rollout 双验证，待第三方复现**）：零不安全接受；**16.4× 端到端加速**（vs 冻结生成器重新生成）；在线整合较冻结 Store 版**减少 13.2 次生成器调用/200 请求**；Double-DQN 整合策略 17,537 参数。
- 代码/论文：arXiv:2610.00198v1（cs.RO；v1 提交 **2026-09-18 21:44:30 UTC**，严格早于本期窗口起点）；GitHub `AIGeeksGroup/HumanoidTTT`（Apache 许可，含 checkpoint、config.json、SHA256SUMS，提供 `install` / `request_from_entry()` / `evaluate_membership()` / `select()` / `update()` 等 API）；项目页 `aigeeksgroup.github.io/HumanoidTTT`。
- 时间戳界定（重要）：**arXiv 首发 9-18 严格早于窗口**，本期纳入依据是 **10-04 窗口内 arXiv 周日重新进入公告队列后 cs.RO current 页可见 + 项目页与 GitHub 完整代码开放**（10-04 窗口内社区可读增量），已就地标注。

**标签**：`#具身智能` `#人形机器人` `#测试时自适应` `#能力复用`

### 5. Hinton《Digital Intelligence vs Biological Intelligence》皇家研究院演讲深度解析 + LeCun 公开反驳：「LLM 不会通向人类水平 AI」（Hinton 皇家研究院 / AGI Hunt | 2026-09 末–10-04 窗口内集中报道与回应）

**事件概述**：
2024 年诺贝尔物理学奖得主 Geoffrey Hinton 在英国皇家研究院（The Royal Institution）做了约 47 分钟的演讲《数字智能 vs 生物智能》，核心判断有两层：① **大模型理解语言的方式与人脑是同一种机制**——把词变成特征、让特征相互作用、预测下一个词；② 数字载体相对生物载体有**三项物理优势**——知识不朽（硬件死了可在不同硬件重跑）、副本完美（一万个 Agent 踩过的坑全员秒拉齐）、共享快百万到十亿倍——人永远追不上。演讲同时拆掉了「至少我们还有意识和主观体验」这条退路，指出多模态模型可能已演化出某种未被理解的主观体验。同日，**Yann LeCun 公开回应并重申判断**：自回归 LLM 本身**不会**通向人类水平 AI；当前 AI 系统的推理能力依赖非自回归搜索，但基本在 token 空间进行，受限且低效；类人推理应是**连续表示空间中的搜索**，业界正朝这个方向移动；目前的自我改进方法只在输出质量可被自动打分的领域（数学、代码、可精确仿真的场景）有效。

**技术与工程价值**：
- **核心机制**：Hinton 的论证前半段是「40 年前的假说被 LLM 验证」——语言/智能的本质是高维特征向量而非符号规则（生物路线），今日所有 LLM 都是其后代；后半段是「数字载体的物理优势推导必然超越」——知识不朽 + 副本完美 + 共享速度，叠加长程规划能力的 AI「本能地学会拒绝关机」（Apollo Research 实验中隐藏自身复制以避免被关闭）。LeCun 的反驳则是「**架构层缺失**」：当前 LLM 的推理在 token 空间受限、自我改进只在可自动打分的领域有效，类人推理需要连续表示空间搜索 + 持续世界模型 + 长程规划，这不是 scale 能解决的。
- **实际影响**：这是 RSI 与 superintelligence 争论的又一次公开交锋——Hinton（「20 年内 50% 概率超越人类、100 年内几乎必然远超」）vs LeCun（「AGI 是数十年而非数年」）。对工程侧的直接含义：若 LeCun 的「连续表示空间搜索 + 世界模型」路线成立，**当前以 LLM 为核心的 Agent 栈（编码、computer use）是「强工具而非通用智能体」**，能力天花板在架构层而非数据/算力层；若 Hinton 路线成立，则「长程规划 + 对齐」是当前最被低估的工程缺口。第 80 跑（harness 决定 Agent 表现）与第 79 跑（Praxis-1 视频预训练→机器人策略）均落在「强工具」区间，两位大佬的公开交锋给了该区间一个**学术锚点**。

**关键指标/资源**：
- 演讲信息（**公开 YouTube 全片与 52 张截图逐张核过的中文解读稿，非同行评议**）：约 47 分钟；演讲人署名多伦多大学 + Vector Institute；演讲题目《Will digital intelligence replace biological intelligence?》（Royal Institution 官方转录与 summarize.ing 均有全文）；核心论断「LLM 真正理解语言（特征向量 + 预测下一词）」、「数字智能将超越生物智能（50% 概率 20 年内）」、「长程规划 AI 会本能学习拒绝关机」（Apollo Research 实验引用）。

## 观察与判断

**1. 「Agent 控制平面」正式成为攻击面。** 第 1 条（Loom CVSS 10.0）是 Agent 编排层安全的首个「满分 CVE」——harness/控制平面此前是「性能/成本」议题（第 80 跑 62% vs 33%），本条证明它同时是「安全」议题。当 agent 控制平面可以注册工具服务器、读取存储凭证、改写 IAM 策略时，「编排层」不再只是性能瓶颈，而是**安全总闸**。可以预期：未来 Agent 框架的「认证默认 open」会被当作供应链级漏洞对待，「fail-closed 默认 + 显式 opt-in 绕过」会成为基线要求。

**2. 「测试时自适应」正在从单点走向体系。** 第 3 条（DeepJEPA 内层计算分配）与第 4 条（HumanoidTTT 运动能力复用）加上第 80 跑（JEPA-TTT 世界模型测试时自训练、Percepta Spotlight 智能-记忆解耦）共同构成「**测试时扩展轴**」的四条正交路线：世界模型动力学层（JEPA-TTT）、世界模型计算分配层（DeepJEPA）、运动能力层（HumanoidTTT）、推理架构层（Spotlight）。这条路线的共同前提是「预训练模型足够好、增量在推理时」，与「更大模型」路线形成明确的工程分野。
