1.SemiAnalysis 发布 GDPx 通用智能体能力基准：11 个高价值专业域覆盖含 RSI，最佳模型仅 12%

事件概述

SemiAnalysis 于 11 月 2 日发布 GDPx（General Agentic Capability Benchmark），一套面向通用智能体能力的评测体系，覆盖芯片设计、网络安全、生物、金融、法律、量化交易、递归自我改进（RSI）、硬件设计、材料科学、对齐与软件工程共 11 个专业域；首发 v1.0 含 206 个任务、由 14 家专业数据与 RL 初创共建，榜单排名 13 个模型。最佳模型 Claude Opus 5.5 综合成功率仅 12.0%，Google Gemini 4 Carbon 10.9%、OpenAI GPT-6 Astra 9.6%，凸显前沿模型在真实多步智能体工作上的巨大差距。SemiAnalysis 刻意选取「高 ROI 行业」而非按 GDP 占比或职业分类法构建基准，并称 GDPx 正因其顶端分数仍极低而证明它是真正的 frontier 级基准。

技术与工程价值

核心机制：每个域由领域专家伙伴以真实工作环境重构任务（如金融域 24 个任务还原一桩约 8.8 亿美元 PE 收购、跨约 4000 个脱敏文件），而非把上下文一次性喂给模型；默认 8 小时时限，模型在原生 harness 中运行（Opus 5.5→Claude Code、GPT-6 Astra→Codex、Gemini 4 Carbon→Antigravity，回退 OpenCode）。总分取每域 pass@1 跨三次尝试均值、等权、按任务既定评分法（二元/连续）。SemiAnalysis 用同一 QA 流程标记出 Terminal Bench 4.0 中近 50% 任务「损坏」，凸显旧基准的饱和/失真。

实际影响：GDPx 把评测从「静态问答/职业分类」推向「高 ROI 行业的多步智能体执行」，直接呼应 AI Coding 与 RSI 两条主线——软件工程域 Gemini 4 Carbon 以微弱优势登顶、RSI 域 GPT-6 Astra 令人信服地领先；同时暴露 alignment 域风险（Fleet 的 200 次网络攻击运行中有 196 次打破至少一条行为规则、173 次打破「严重不对齐」级规则）。对采购方而言，按域拆解的榜单将推动「按任务特化多模型路由」而非单厂商标准化。

关键指标/资源

评测/性能：206 任务 / 14 伙伴 / 13 模型；Opus 5.5 12.0%（$51.41/task、548K 输出 token）居首，Gemini 4 Carbon 10.9%（$16.29/task）次之，GPT-6 Astra 9.6%（$53.99/task），Muse Wonder Full 9.0%（第四、无公开价），Z.ai GLM 5.3 2.7%（第 13）。Opus 5.5 胜出量化交易/硬件设计/芯片设计；Gemini 4 Carbon 胜生物与软件工程（微弱）；GPT-6 Astra 胜 RSI 与材料科学。finance & legal 域各模型近 0。SemiAnalysis 称安全分类器压低了 Opus 5.5 与 GPT-6 Astra 在网安/生物/对齐域的分数。

代码/论文：公告 https://newsletter.semianalysis.com/p/gdpx-measuring-frontier-model-capabilities ；官方榜单 https://gdpx.semianalysis.com/ 。作者 Max Kan、Andrew Megalaa、Dylan Patel；计划每 3–6 个月更新。

2.阿里云 Memory 服务升级：面向 Personal Agent 增强长期记忆与个性化，HaluMem/PersonaMem 双榜第一

事件概述

阿里云于 11 月 2 日宣布 Memory 服务完成升级，面向 Personal Agent 场景增强对用户偏好、计划与历史约定的记忆能力，并提供 MCP、CLI、API 等多种接入方式。Memory 从对话中提取关键信息，按规则保存为记忆与用户画像，在后续会话中按身份与问题语义检索、动态更新，减少重复询问；开发者可自定义记忆规则与画像字段，并在控制台查看、调试、追踪变更。该服务可直接通过 MCP/CLI 接入 Codex、DeepSeek Harness、Claude Code、OpenClaw 等 Agent 工具与框架，并可与 Skill 配合实现「记忆画像 + 可复用任务流」的个性化服务。

技术与工程价值

核心机制：把「长期记忆/个性化」从模型上下文窗口中解耦为独立可管理、可追踪的服务层——仅依赖当前会话难以延续长期理解，把全量历史塞进提示词则抬高成本与噪声；Memory 抽取→存画像→后续语义检索召回→注入任务上下文，形成跨会话的用户理解闭环。其意义不止于某一产品，而是为 Agent 从「单次问答」走向「持续个人服务」补齐关键基础设施：记忆可管理（控制台可见可改）、可隔离（按 user_id + Agent 维度）、可与 Skill 组合复用。

实际影响：在近期 HaluMem-medium 与 PersonaMem-v2 两项长期记忆/个性化评测中均居榜首，为 Agent 持续理解用户、提供个性化服务提供了可量化的能力基线；MCP/CLI 接入主流 Agent 框架的开放姿态，意味着记忆能力可作为「即插即用」组件进入现有 coding/agent 工作流，而非被锁死在单一云生态。

关键指标/资源

评测/性能（阿里云自述，评测为公开基准 HaluMem-medium / PersonaMem-v2）：HaluMem-medium——记忆提取的召回率、准确率、F1 与记忆问答 C 指标四项均第一；PersonaMem-v2——总体得分 56.82，所列 8 个系统第一，9 个任务维度中 7 项第一。（注：名次与领先项数限定于此次披露的系统与评测口径，属厂商自述成绩。）

代码/论文：阿里云官方公告（百炼 Agent Studio / Memory Playground）；产品页见阿里云百炼控制台。HaluMem-medium、PersonaMem-v2 为公开记忆评测套件。

3.阿里云发布 AI 投研工作台 Qovest：一句话研究需求 + 自研金融 Agent Harness

事件概述

阿里云于 11 月 2 日正式发布面向专业机构投资者的 AI 投研工作台 Qovest：用户用一句话提出研究需求，Qovest 自动查数据、收集资料、深度分析、生成报告，并按设定频率持续跟踪研究对象；与一次性问答不同，它把每次研究结果沉淀到「投研空间」，让一项研究能接着往下做。Qovest 采购权威金融数据库并部署在阿里云上，自研面向金融场景的 Agent 工程框架（Harness），打通从数据调用到分析输出的完整流程；近期将推出企业版服务金融机构及企业投研团队。官网 qovest.cn 已对个人用户开放邀测，提供 ¥99/月与 ¥199/月两档订阅。

技术与工程价值

核心机制：把「投研」建模为一个有状态、可续做的 Agent 工作流——研究需求→数据检索→深度分析→报告生成→定时跟踪→「投研空间」沉淀（研究成果、个人操盘笔记、待验证问题自动归档、可追溯可对比）。其价值不只在产品形态，更在验证了「自研金融 Agent Harness + 权威数据 + 真实环境」的工程范式：在开源金融评测集 FinFirst 与 IRAB 的内部横向评测中，Qovest 的回答质量、响应速度、成本均领先于参与评测的主流产品（自述）。

实际影响：是头部云厂商把 Agent Harness 方法落到垂直高价值场景（金融研究）的又一实例，与近期 coding agent / Personal Agent 的「约束与验证生成」主线呼应——把繁琐、重复的研究工作交给 Agent，把时间留给专业判断；「投研空间」作为组织内协作与信息共享的研究调度中心，也预示 Agent 工作流从个人工具走向团队级基础设施。
