### 1. Nasiko 发布 TokenOps——AI Agent 花费追踪与预算控制工具（Crypto Briefing | 2026-11-13）

- **事件概述**：Nasiko 推出 TokenOps，一款面向多 Agent 场景的花费追踪平台，可按 Agent、团队、模型三个维度实时统计 token 消耗。系统在花费达到预算 80% 时自动告警，到达上限则暂停对应 Agent 执行。
- **技术与工程价值**：

- **关键指标/资源**：
  - 追踪维度：按 Agent / 团队 / 模型三级隔离
  - 告警阈值：80%（可配置）；熔断阈值：100%

### 2. SlashVibe 开源 AI Agent 桌面控制器——带独立屏幕与语音控制的物理交互层（The Gadgeteer | 2026-11-15）

- **事件概述**：SlashVibe 是一个开源 AI Agent 桌面工作站控制器，配备独立小屏（显示 Agent 状态/进度）及可拆卸语音控制器，内置 Node.js 与 Python SDK，支持开发者自定义 Agent 工作流。Kickstarter 早鸟价 $189（零售价 $249），预计 2027 年 3 月发货。
- **技术与工程价值**：
  - **核心机制**：为多 Agent 并行工作的场景提供"物理可见层"——通过专属屏幕与语音交互，让 Agent 执行状态从「黑盒进程」变为「可视化仪表盘」。
  - **实际影响**：与 Vercel agent-desktop（纯软件方案）形成硬件互补，适合希望本地优先、离线可用的 AI 开发者和团队；开源 SDK 降低了自定义集成门槛。
- **关键指标/资源**：
  - SDK：Node.js + Python 双栈
  - 硬件形态：桌面控制器 + 可拆卸语音模块
  - 发布时间：Kickstarter 上线于 2026-11-15
  - 来源链接：<https://the-gadgeteer.com/2026/11/15/slashvibe-open-source-ai-agent-desk-controller/>
