### 1. XPENG Turing World Model WorldGPT：跨六类载体的物理 AI 世界动作模型（XPENG Blog | 2026-11-24）

**事件概述**：小鹏汽车于 11 月 24 日发布 Turing World Model 家族新成员 WorldGPT——一个云侧"教师"世界动作模型，可在学习了人形机器人、汽车、无人机、船艇、单机械臂和双机械臂共六类载体后，根据历史视觉观察与自然语言指令预测场景演变并规划动作，且将大模型蒸馏到各载体端侧小模型。小鹏称截至 11 月 12 日其在 12 项公开基准上排名第一（公司宣称，未经独立测试）。

- **实际影响**：机器人操作在 50 项单臂任务基准上取得 95.2% 平均成功率（官方宣称最高），对未见过任务/环境扰动展现出强泛化；同时覆盖自驾场景，意味着同一套世界模型可打通车–机–空–水多个产品线。
- **关键指标/资源**：
  - 评测表现：单臂操作成功率 95.2%（官方发布数据，待第三方复核）

### 2. iFood 将 Codex 编码 Agent 规模化至 15,000 仓库——OpenAI 客户案例（OpenAI Blog / iFood | 2026-11-24）

**事件概述**：OpenAI 于 11 月 24 日更新其客户故事库，介绍巴西外卖平台 iFood 如何将 Codex 编码 Agent 部署到旗下约 15,000 个代码仓库中，贯穿从代码审查到文档维护的全链路工程流程。这是目前公开披露的最大规模企业级单体 Codex 部署之一。

**技术与工程价值**：
- **核心机制**：通过 AGENTS.md、分支保护策略与 CI 门禁形成"上下文→可见性→护栏"三重闭环，让 Agent 自主运行测试并在 PR 级别接受人工审查，避免直接触碰生产。
- **实际影响**：将重复性高、范围明确的工程任务（重构、重命名、补测）外包给 Agent，工程师转做监督与架构决策；企业级复制路径明确（选健康测试套件仓库起步 + 按需放行 PR），为同类组织提供参考蓝图。
- **关键指标/资源**：
  - 覆盖规模：~15,000 仓库
  - 参考实践：[OpenAI 客户故事 iFood](https://openai.com/business/customer-stories/ifood)｜[OnWave-AI 部署指南](https://www.onewave-ai.com/blog/how-to-deploy-openai-codex-for-your-engineering-team)

### 4. OpenAI × Cisco 联合发布 Shirudo：基于 Codex 生成 eBPF 盾牌的实时 Linux 漏洞防护工具（Indian Express / OpenAI Blog | 2026-11-24）

**事件概述**：OpenAI 与思科联合宣布 Shirudo——一款面向 Linux 系统的 AI 驱动即时防御工具。该工具调用 Codex 编码 Agent 针对已知漏洞（如 Java4Shell）生成针对性输入校验补丁，并通过 eBPF 机制将其附着到正在运行的进程（如 Elasticsearch）上，实现无需重启的热修复；内部测试显示成功拦截针对 Java4Shell 的攻击并保持服务在线。

**技术与工程价值**：
- **核心机制**：AI Agent 编写补丁 → 安全团队审阅 → eBPF 加载 → 流量镜像验证有效性 → 可选切换至生产态，全程可观测、可回滚。
- **实际影响**：填补"找到漏洞 → 写补丁 → 测试 → 部署"之间的高危窗口期；为运维/AI Agent 协作提供可复用范式（Agent 生成、人类审核、eBPF 执行）；对大规模 Elasticsearch/Kubernetes 环境有即战力。
- **关键指标/资源**：
  - 实测用例：Java4Shell 热修补、Elasticsearch 不停机
  - 来源链接：[Indian Express 报道](https://indianexpress.com/article/technology/tech-news-technology/openai-cisco-launch-shirudo-linux-systems-security-threats-10976255)
