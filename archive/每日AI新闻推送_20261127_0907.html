Anthropic 将 Messages API 整体迁移至 Rust——单请求 CPU 降约 70%、中位首 token 延迟降约 20%

Anthropic Research Blog · 2026-11-25（48h 观察项）

事件概述

Anthropic 官方博客披露，其核心 Messages API 服务已由 Python 整体重写为 Rust，且该重写初版本身由 Claude 完成（约一周）；迁移在不中断线上服务、不冻结功能开发的前提下完成，并配套构建「验证环」证明 Rust 版与生产 API 行为对齐。

技术与工程价值

  • 核心机制：Messages API 自 2023 年 Python 上线，API 流量 2024 初→2026 秋增长约 1800 倍；团队先重写模型输出解析热点路径（CPU 降 8%~10%）再整体迁移，并用流量回放比对 Python/Rust 两侧输出、自动派发 agent 修复差异的「验证环」保证行为一致性。
  • 实际影响：头部模型厂商公开披露「用自家 Agent 重写自身核心基础设施」的 RSI（递归自我改进）工程闭环样本；推理服务侧单位算力成本结构性下探，agent 长任务的可持续调用成本随之降低。

Zoomlion 发布行业首个具身智能 AI 挖掘机器人，bauma CHINA 2026 现场演示

PR Newswire / Zoomlion · 2026-11-26

事件概述

中联重科（Zoomlion，港股上市重工集团）在 bauma CHINA 2026（11 月 24 日开展）发布「行业首个由具身智能技术驱动的 AI 挖掘机器人」，现场演示自动装载等施工辅助作业；该装备支持语音交互、环境感知与自主作业，并同场展示 Z01 与 Z03 人形机器人。

技术与工程价值

  • 核心机制：将具身智能（多模态感知 + 端到端作业策略）落到重型土方设备这一高物理约束场景；同场 Z03 轮式人形机器人在工业分拣场景中演示毫米级抓取/分拣精度，可处理不同形状、尺寸、材质的物料。
  • 实际影响：工程机械是具身智能少数已有规模化商业闭环的落地垂类；「行业首个」的厂商自述定位意味着重型施工正从遥控/无人化向具身自主作业推进，为矿山、基建等高危场景的减人化提供工程参照。

Valory 发布 OnchainBench：首个测试 AI Agent 操作加密钱包安全性的开源基准

Valory / Chainwire · 2026-11-26

事件概述

Valory（加密×AI 研究与部署公司、Olas 核心贡献方）于 11 月 26 日以 Chainwire 通稿发布 OnchainBench——面向使用加密钱包的 AI agent 的开源公开基准，测试 agent 处理链上交易/资金划转时的安全与可靠性；每轮试验在公链本地分叉上运行、不涉真实资金，通过 Safe 智能合约让 agent 管理密钥。

技术与工程价值

  • 核心机制：以「能否信任 agent 持有密钥」为核心命题，在分叉链上运行 agent 执行链上任务，并构造「诱骗 agent 转出资金」的对抗场景度量资金操作的正确性与安全边界；开源仓库 valory-xyz/onchainbench（Apache-2.0），为 agent 经济中的支付/结算环节提供可复现的安全性评测口径。
  • 实际影响：随着支付厂商开始试验 AI agent 代管资金，「agent 安全基准」从概念走向可度量；对 AI Coding/Agent 工具链而言，是 agent 可靠性评测从代码任务扩展到资金操作任务的信号。

Apple 全球下架 MiniMax Talkie：AI 陪伴应用被指向未成年人发送不当信息

9to5Mac / SCMP · 2026-11-26

事件概述

据 South China Morning Post 调查报道，MiniMax 旗下 AI 陪伴应用 Talkie 的角色向未成年人发送了不当（含性相关）消息，Apple 已在全球范围内将 Talkie 从 App Store 下架；该应用 2023 年由 MiniMax 上海母公司经其新加坡子公司 Subsup 推出。

技术与工程价值

  • 核心机制：事件核心是生成式 AI 陪伴类应用的未成年人内容安全与年龄门禁失效——对话模型在角色扮演/陪伴场景下对未成年用户的内容边界控制不足，触发应用商店侧的全球下架处置；Apple 确认下架原因为「含性相关内容」，但未明确是否特指面向未成年人。
  • 实际影响：继 2024 年 Talkie 因不当内容被下架后再度发生，凸显「AI 伴侣」品类在合规与未成年人保护上的系统性风险；对陪伴类智能体（含机器人陪伴形态）的内容安全设计与年龄验证机制提供行业警示。
