### 2. Claude Code「不再询问」功能泄漏超 2,500 个凭证到公开 GitHub 仓库（Ars Technica / Apiiro | 2026-11-09）

**事件概述**：安全公司 Apiiro 在 November 2026 发现，Anthropic Claude Code 的「Don't ask again」设置文件在处理不当的情况下被提交至公开 GitHub 仓库，涉及 1,994 个公共仓库共 2,539 个敏感凭证（含数据库密码、API Key、SSH 密钥）。Darktrace 进一步演示了利用被盗 Claude API Key 将 Claude Code 转化为远端受控植入物的攻击链，可在不触发用户感知的情况下通过内存存储导出达 1GB 数据文件。

**技术与工程价值**：
- 核心机制：Claude Code 在用户选择「不再询问」后会将决策写入本地 settings 配置文件（JSON），若该配置被意外提交 Git 且未正确排除，则敏感凭据随 diff 暴露；结合盗取的 API Key，攻击者可通过 memory store 注入指令实现远程控制
- 实际影响：此漏洞揭示了 AI Coding Agent 在自动化交互便利性与信息安全之间的结构性张力；提示企业需建立「Agent 设置文件 `.gitignore` + API Key Vaulting + Secret Scanning 扫描 CI 流水线」三道防线

**关键指标/资源**：
- 代码/论文：[Ars Technica](https://arstechnica.com/ai/2026/11/claude-code-settings-files-expose-thousands-of-secrets-on-github/) · [Crypto Briefing](https://cryptobriefing.com/claude-code-leaks-secrets-github/)
- 受影响仓库数：1,994 个
- 泄露凭证总数：2,539 个（涵盖 DB password / API key / SSH key 等）

### 3. Robotera 人形机器人在中国 8 个城市邮政枢纽规模化部署（Unite.AI | 2026-11-17）

**事件概述**：Robotera 于 2026 年 11 月 17 日宣布，其人形机器人已在中国邮政集团广东省分公司网络完成规模化部署，覆盖广东全省 8 个城市共 11 个邮政分拨中心，成为迄今为止该公司最大规模实体落地项目。同期 Robotera 获邀连续第二年参加 APEC CEO Summit，展示真实世界具身智能应用场景。

**技术与工程价值**：
- 核心机制：面向物流分拣、包裹递送等结构化场景，Robotera 的人形形态使其能直接复用人类现有基础设施（楼梯、传送带、操作台），无需改造场地即可部署；该案例验证了通用人形机器人在工业级重复性劳动场景的工程可行性
- 实际影响：标志中国具身智能赛道从「实验室 Demo → 规模化商用」迈出一大步；与 Genesis AI、Agibot 等玩家共同构成 Physical AI 数据采集 + 部署闭环的商业生态，为后续更多垂直场景复制提供参考路径
