1️⃣ Apple AMP1：用通用 AI 模型通过 Python 代码控制机械臂，无需微调

具身智能 Apple CoRL 2026

事件

Apple 发布 AMP1（AI Model Protocol v1），允许通用大语言模型通过 Python 代码直接控制机器人手臂，无需针对特定硬件进行微调。测试结果显示，通用 AI 模型的机械臂操控表现甚至优于专门为机器人设计的专业模型。该技术已在 CoRL 2026 会议上展示。

为何值得关注

AMP1 的核心突破在于「通用模型 + 代码接口」范式——不再需要为每种机器人硬件训练专用策略网络，而是让通用 LLM 通过编写和执行 Python 代码来驱动物理动作。这对具身智能的工程落地路径有重大影响：降低了多模态感知到运动控制的适配成本，使小型团队也能快速原型化机器人应用。此前 NVIDIA GR00T 2 走的是世界模型路线（从视频学习），Apple 则走了代码中介路线，两条路径正在收敛。

AI安全 Anthropic 企业AI
