Together AI 开源 Hurdle：面向 Claude Code / Codex 的 API 任务 Agent 测试与护栏框架

Together AI 官方公告 / eWeek · 2026-11-25（48h 观察项）

事件概述

Together AI 于 11-25 发布开源 npm 库 Hurdle，用于度量 Claude Code 与 OpenAI Codex 等编码 Agent 在真实 API 任务上的表现；开发者自定任务后，Hurdle 运行、记录 Agent 行为并评估结果，可对比不同指令/技能/MCP 连接条件下复现同一任务，输出通过率、执行时长、成本与可回放会话。

技术与工程价值

  • 核心机制：区别于通用编码基准，Hurdle 面向「企业自有客户可能发起的任务」做可复现评测；沙箱化运行经本地代理 Guardian 路由并校验 Agent 的 API 请求、拦截越界/危险调用并把真实凭证替换为临时占位；本地直跑模式便捷但可访问用户真实文件与凭证，官方明确提示风险。
  • 实际影响：为 AI Coding 工具的「能力 + 安全」双重验收提供可落地的工程口径——既能量化 Agent 调 API 的正确率，又能把护栏（guard）做成一等公民；对 Agent 评测与治理是「评测即验收」的又一开源样本。

Microsoft Research 实证研究：编码 Agent 的补丁为何更大——额外行主要是测试而非冗余代码

arXiv 2611.34875 · 2026-11-25（48h 观察项）

事件概述

Microsoft Research 预印本《How Much Do Coding Agents Over-Edit, and Why?》提出 DRA（Delta Residue Attribution）方法：重放 Agent 轨迹、把最终补丁的每个代码块回溯到写入它的步骤、逐块回退并重跑测试以判定该块是否必要；在 7,660 条已解决的 GitHub Copilot CLI 轨迹（覆盖 18 个前沿模型，SWE-bench Verified 6,728 + DeepSWE 932）上，用同一口径同时评估 Agent 与开发者补丁。

技术与工程价值

  • 核心机制：DRA 用「可执行测试」而非人工判定来归因补丁必要性，直接回答「Agent 多写的行到底是过度编辑还是必要补充」这一评测盲区。
  • 实际影响：结果修正了「Agent 补丁更大=过度编辑」的直觉——SWE-bench Verified 上额外行的 61% 是测试、13% 是文档，Agent 代码块必要率 88.7% 甚至高于开发者的 86.4%；对 AI Coding 评测与代码评审工具设计提供「补丁构成 + 必要性」的可复现口径。

Einsia AI 开源 RoboUniverse-10K：首个 10K 级可交互物理仿真 RL 环境套件

PRNewswire / Einsia · 2026-11-25（48h 观察项）

事件概述

Einsia AI 于 11-25 以新加坡 PRNewswire 通稿发布 RoboUniverse-10K——面向具身/Agent 机器人训练的开源 10,807 个可交互物理仿真环境（单臂 Franka 与双臂 AgileX 抓取），由真实操作视频构建、在 Isaac Sim 内以自动化检查对齐物理现实，并配套 500 任务验证基准；项目同时开源 RoboUniverse-35B-A3B SFT 模型与论文/代码，与清华、北大等研究者合作。

技术与工程价值

  • 核心机制：把「可验证 + 物理对齐」作为一等公民，将大规模 RL 训练环境从「手工搭场景」变成「可批量生成、可自动验收」的工程资产；held-out 评估与「具身 coding-agent post-training」定位，把 RL 环境与 Agent 后训练打通。
  • 实际影响：对具身智能（世界模型/RL 环境规模化）是基础设施级开源样本——RoboUniverse-35B-A3B 在 RoboUniverse-Verified 零样本成功率从 0.8% 提升到 21.2% 的自述数据，给出「环境规模→成功率」的可复现参照。

Volvo Cars 在 Ghent 工厂训练 Hexagon Aeon 人形机器人，瞄准 2027 投产

Volvo / Automotive World · 2026-11-26（48h 观察项）

事件概述

Volvo Cars 已在比利时 Ghent 整车工厂开始训练与测试 Hexagon Robotics 的 Aeon 人形机器人；Ghent 为 Volvo 集团内首个引入人形机器人试验的工厂，计划 2027 年中期投入真实生产岗位，员工正以「示范-教学」方式让机器人学习任务。

技术与工程价值

  • 核心机制：把「人形机器人进整车总装线」从概念推向有明确投产时间表的工厂部署；Aeon 10kg 有效载荷的物理约束直接决定其只能承接较轻的装配/搬运任务，是「形态决定岗位」的典型工程取舍。
  • 实际影响：整车制造是具身智能少数有明确量产与排期的高约束场景，为「机器人替代/协同一线岗位」提供可对标的时间线（2027 投产），也是检验 sim-to-real 与长时程任务可靠性的工业试金石。
