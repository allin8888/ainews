### 1. Can LLMs Debug Robots by Editing Their Weights? GPT-6 Astra 仅编辑 65 行 embedding 修复 π0.5 指令跟随（arXiv 2611.09376 | 2026-11-09 arXiv 公告）

**事件概述**：
论文把 weight-space programming 引入机器人基础策略：GPT-6 Astra 读取 π0.5 策略权重，仅编辑 65 行 token embedding 即修复其词汇指令接地错误——无梯度更新、无新演示，只靠 CPU 工作区与预算内仿真器反馈。

**技术与工程价值**：
- **核心机制**：LLM 定位指令接地失败对应的 embedding 行并直接改写权重值；三次独立会话在 765 条 held-out 释义上全部提升成功率，最佳一次 86.3% → 92.0%（48 次修复、4 次回归，exact paired p=1.31×10⁻¹⁰）；335 条含被编辑 token 的指令子集提升幅度更大。
- **实际影响**：机器人策略的「调试」语义从改提示词/工具延伸到直接改策略权重——修复成本从重训练降到分钟级权重编辑；同时反证 VLA 的行为错误高度集中在极少数 embedding 行。
- **适用限制**：单一 π0.5 策略、仿真器反馈预算约束；成功率与 p 值均为作者自测口径，未见第三方复现。

**关键指标/资源**：
- 评测/性能：65 embedding 行；765 条释义 86.3% → 92.0%（自述数据，未见第三方复现）
- 代码/论文：https://arxiv.org/abs/2611.09376
