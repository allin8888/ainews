### 1. [微软 Agent Lightning v1.0 正式发布："Agent 训练 Agent"走向工程化](https://juejin.cn/post/7677434290662228022) (2026-08-25 | 稀土掘金)

**事件概述**：
微软开源的 Agent Lightning 框架发布 v1.0 正式版，已获 1.76 万 Star。核心能力是用部署时的真实 Agent Harness 做强化学习训练——Agent 通过框架代理与模型交互，工具、上下文、控制流和环境全部保持在环内，且无需修改任何代码。仅用 6000 条训练样本，端到端将 Qwen3.5-9B 编程工作流的 SWE-bench Verified 成绩从 41.8% 提升到 56.4%（+14.6 个百分点）。v1.0.1 还推出 Agent Lightning Skill，让 Claude Code、Codex、GitHub Copilot 等编程智能体能够系统性优化其他 AI Agent 的提示词、工具与工作流。

**技术与工程价值**：
- **核心机制**：用"真实 Harness 在环"抹平训练环境与部署环境的鸿沟，Agent 强化学习从论文走向工程化
- **实际影响**：这是"Agent 训练 Agent"的标志性一步——此前 Agent 强化学习最大的痛点是"训练环境与部署环境不一致"，6000 条样本换 14.6 个点的跳跃说明数据效率极高

**关键指标/资源**：
- GitHub Star：1.76 万
- 训练样本：6000 条
- SWE-bench Verified：41.8% → 56.4%（+14.6pp）
- 代码仓库：https://github.com/microsoft/agent-lightning
