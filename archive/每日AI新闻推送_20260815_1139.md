## 主选（5 条，按重要性排序）

**1. DeepSeek 开源 Harness 的开发记录显示其大量使用 OpenAI Codex**（云头条 / 163.com，8/15 01:10）
- **事件**：开发者 Elie Bakouch 统计 DeepSeek Harness 公开 GitHub 历史——984 个已合并 PR 中 209 个来自 `codex/*` 分支（21.2%），相关提交约 2807 次（占总提交 22.8%）；而 `claude/*` 分支仅 3 个合并 PR（0.3%），提交 71 次。OpenAI 开发者体验团队成员 VB Srivastav 公开喊话「有问题随时找我，希望你们和我一样喜欢 Codex」。
- **为何值得关注**：开源编程 Agent 框架的「去模型化」主张在现实中被讽刺性印证——DeepSeek 用竞争对手的 Codex 造出了对标 Claude Code 的 Harness；说明模型无关（model-agnostic）的 harness 设计已成共识，工具层与模型层正在解耦，与前几期「增量在模型之外」主线一致。
- **来源链接**：https://www.163.com/dy/article/L4B8ETI90511D6RL.html （统计为第三方基于公开 GitHub 历史得出，精确占比待核实）

**2. ICML 2026 Open Reproductions：1200+ 志愿者 + 编码 Agent 复现 2226 篇论文**（Hugging Face / abidlabs，8/13 发布，8/15 持续讨论）
- **事件**：7/15–8/2 的复现挑战赛共产出 6816 份 Trackio logbook，覆盖 ICML 2026 约 1/3 论文（2226 篇），35908 条 claim 由自动化 Logbook Judge（开源权重 GLM-5.2）逐条裁决；参与者自带 Claude Code / Codex / Cursor / Pi 等 agent，部分 logbook 公开上传完整 agent 执行轨迹。
- **为何值得关注**：编码 Agent 首次在会议尺度承担「可复现性审计」这一科研基础设施角色；agent trace 公开化把「验证 / 审计」这一模型之外的层推到大规模实证，为 AI Coding 在科研中的定位提供了 landmark 案例。
- **来源链接**：https://worldthatgrows.com/news/what-we-learned-by-reproducing-2200-papers-from-icml ；挑战页 https://huggingface.co/spaces/ICML-2026-agent-repro/challenge

**3. Anthropic 详解 Claude 文本水印机制（SynthID-Text），为欧盟 AI 法案合规**（Anthropic Newsroom，8/14 19:22）
- **事件**：未来 Claude 生成文本将内嵌基于 Google DeepMind SynthID-Text 的水印，用于判定文本由 Claude 撰写的概率；仅改变等概率候选词的随机来源，不影响生成质量 / 可读性，不增加 token 或成本，读者无法区分水印文本与正常文本。
- **为何值得关注**：在 AI 生成代码与文档泛滥的背景下，非侵入式内容溯源成为信任 / 合规层的新基础设施；对「agent 产出如何归因与审计」这一 AI Coding 治理问题给出了可落地的工程答案。
- **来源链接**：https://www.anthropic.com/news/claude-text-watermark

**4. 2026 上半年具身智能融资 935 亿元（同比 +5 倍），机器人「进厂打工」跑出 ROI 实证**（北青网 / 今日头条，8/15 07:11）
- **事件**：国内具身智能赛道 H1 融资破 935 亿元（同比约 5 倍）；广州邮区中心分拣流水线机器人供件效率从 300 提升至 1200 件/小时、准确率 >95%、7×24 运行；单一汽车工厂工站成功率 98%。工信部 + 国资委 6 月已启动实景实训专项行动，目标年底百个高价值场景 + 万台级落地。
- **为何值得关注**：具身从「炫技」转入「算清 ROI」的实干期；「数据飞轮」（真实场景→数据→更强能力→更多场景）成为头部企业竞争核心，直接决定能否跨过量产鸿沟与核心零部件国产化临界点。
- **来源链接**：https://www.toutiao.com/article/7674028766510744083/
