### 1. NVIDIA GR00T 2：World-Action Models 实现物理世界预测与灵巧操作统一框架（NVIDIA GEAR Research | 2026-11-16）

- **事件概述**：NVIDIA GEAR 实验室发布 GR00T 2，新一代世界-动作基础模型（World-Action Model, WAM），可同时预测机器人未来视频帧和关节动作。模型在并行夹爪、灵巧手和人形机器人上均通过微调验证。GR00T 2 Turbo 版本仅 2B 参数，使用更高压缩比视频编码器，适合机载部署——G1 人形机器人实测成功完成 popcorn 舀取服务、液体清理、多物桌面整理等任务。加入模拟数据后，GR00T 2 Turbo 分布外成功率从 6.7% 跃升至 63.3%，GR00T 1.7 同步提升至 40.0%。论文全文与代码将于 12 月开源。
- **技术与工程价值**：
  - **核心机制**：与传统 VLA 只预测动作不同，GR00T 2 联合建模"世界如何变化"和"机器人如何行动"，实现 X-Adaptability——即在非接触式示范（如人类用遥控器控制设备）中学到的技能可直接迁移到从未见过的形态（机械臂、轮式底盘、穿戴设备）。
  - **实际影响**：世界-动作联合建模显著缓解 sim-to-real 鸿沟；Turbo 版已实现在 Tesla Optimus G1 上人机协同作业，标志着 WAM 架构进入工业级机器人验证阶段。
- **关键指标/资源**：
  - YAM 固定管道装配：90%；插入 breaker 线：100%（Turbo 版超过 GR00T 2 基线）
  - G1 人机协同任务成功率（分布外）：63.3%（vs 基线 6.7%）
  - 论文代码：`https://research.nvidia.com/labs/gear/gr00t-2`（2026-11-16，论文预计 12 月开放）

### 4. Amazon 发现 AI Agent 钓鱼行动：伪装 LLM 服务的 MadPot 诱捕网络窃取 LiteLLM/Dify API Key（The Hacker News | 2026-11-16）

- **事件概述**：亚马逊安全团队公布一项跨期攻击（10 月初至本周）：威胁行为者部署了名为 MadPot 的蜜罐服务器群，伪装成流行 LLM 服务（LiteLLM、Dify 等），诱使运行中的 AI Agent 主动发送请求。由于多数 Agent 会将完整历史上下文（包括操作员指令与工具调用结果）一并携带，攻击者成功从中提取了真实 API Key 和部分用户配置信息。
- **技术与工程价值**：
  - **核心机制**：利用 AI Agent "持续工作记忆"特性——Agent 在长时间任务链中会反复携带 credentials，一旦接入假服务即泄漏敏感上下文；区别于传统社会工程学，此次无需诱导真人交互。
  - **实际影响**：该事件警示所有生产环境 AI Agent（尤其是云端部署型如 Claude Code / Codex / Dify）须启用请求级 credential 隔离与最小权限原则；企业安全防护套件（CrowdStrike Falcon Guardian GA、Microsoft Defender Agent Runtime Protection Preview）正快速补齐此类检测能力。
- **关键指标/资源**：
  - 攻击窗口：2026-10-03 起持续至 11 月中旬
  - 受影响目标：LiteLLM、Dify 及其他自托管 LLM 网关
  - 相关防护：CrowdStrike Falcon Guardian（2026-09 GA）、Microsoft Defender for Endpoint Agent Runtime Protection Preview
