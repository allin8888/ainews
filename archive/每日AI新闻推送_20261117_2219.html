1. 商汤 SenseNova Loop-9B 全量开源发布：32 层权重共享执行 56 次、512K 上下文的 9B Agent 编码模型（GitHub 官方仓库 + IT之家 | 2026-11-17）

事件概述

商汤科技开源体系 SenseNova 发布 Loop-9B 全量版（full release）：权重与代码于 2026-11-17 正式开放，结束 2026-10-31 启动的 preview 阶段；模型定位编码与自动化 Agent 场景，同步提供官方 AWQ 4-bit 量化权重。

首发时间

GitHub 官方仓库 README 记载 full release 2026-11-17（weights + code）；IT之家报道 2026-11-17 13:56 UTC（21:56 BJ）。全量发布精确小时级时刻未获第一方结构化数据，以仓库 README 日期 + 媒体报道时刻双锚定，落在窗口内。

技术与工程价值

核心机制：32 层 Transformer（hidden 4096）中中间 24 层权重共享执行两次，等效 56 次执行深度；双流架构叠加 mHC 多头连接（Sinkhorn 归一 20 迭代）；注意力为混合设计（每 4 层组 3 层线性注意力 + 1 层全注意力）；9B 参数推理计算量等效约 14.6B；上下文 512K；训练数据覆盖文本/图像/代码与 tool-use 轨迹。

实际影响：官方基准自述——对 Qwen3.8-27B：NL2Repo 41.36 vs 44.60、AIDABench 65.31 vs 65.01、AutomationBench 36.67 持平；全量版较 preview 大幅提升：Terminal-Bench 2.1 59.55（preview 40.45）、GAIA 69.90（preview 37.86）、BIRD 72.34。Apache-2.0 许可，官方 AWQ 4-bit 权重约 4.9GB，64K 上下文 8-bit KV 显存约 10GiB（4-bit KV 约 9GiB）、256K 上下文约 15GiB。

适用限制：全部基准为官方自述，未见第三方复现；对 Qwen3.8-27B 的 NL2Repo 项落后 3.24 分；全量发布精确小时级时刻未获第一方结构化数据。

机器人硬件与具身智能

2. FlagOpen 发布 HumanCOIN：LeRobot 生态首个覆盖 EEG/EMG 的人形操作人类信号数据基础设施（GitHub + 智源 FlagOpen | 2026-11-17）

事件概述

智源 FlagOpen 开源 HumanCOIN（The Human-Signal Dataset at the Scale of Egocentric Manipulation）主仓库与配套 HumanCOIN-DataManager 门户，面向第一人称视角操作场景的多模态人体信号数据集基础设施。

首发时间

GitHub org 页两仓库 updated 2026-11-17；aihot 智源 FlagOpen 原创开源项目源收录 2026-11-17 06:19 UTC（主仓库）/ 08:34 UTC（门户）。GitHub API 全程不可达，仓库精确创建时刻未获第一方结构化数据，以 org 页 updated 日期 + aihot 收录时刻双锚定。

技术与工程价值

核心机制：基于 LeRobot（pinned 0.3.3）继承 LeRobotDataset 的多传感器多频率扩展——每传感器独立时间索引 parquet 存储、查询时动态对齐，单条轨迹可携带异构采样率的并行数据流；支持 RGB 30/60Hz、IMU 50–1000Hz、EEG 256/512/1000Hz（8–256 通道）、EMG 20–500Hz，以及音频/温度/6-DoF 位姿。

实际影响：把生理信号（EEG/EMG）纳入具身操作数据格式，为「人类操作意图」侧的具身智能研究提供标准化数据管线；数据集经 Hugging Face/ModelScope org 页分发，DataManager 门户提供管理入口。

适用限制：数据集规模（小时数/参与者）仓库未列；LICENSE 文件存在但类型未确认；HF/ModelScope 数据集页未逐字核对（HF API 间歇不可达）。

3. Liquid AI 发布 d1.2/d1.2-ultra 决策模型：全模态输入登顶 AA Decision Index v2.1，校准误差 0.8（官方博客 + 官方 X | 2026-11-16）

事件概述

Liquid AI 发布 d1.2 与 d1.2-ultra 两款决策模型（面向分类/路由/打分类工作负载），新增音频输入形成文本/图像/音频全模态，d1.2-ultra 以 75 分登顶 Artificial Analysis Decision Index v2.1。

首发时间

官方 X 帖 2122346077231923698 经 snowflake 反推为 2026-11-16 15:08:30 UTC（23:08 BJ）；官方博客 datePublished 2026-11-16（无时刻，以 X snowflake 补精确锚）。落在窗口起点 11-16 14:19 UTC 后约 49 分钟，窗内首发。

技术与工程价值

核心机制：决策模型品类（分类/路由/打分）而非生成模型；d1.2-ultra 在 AA Decision Index v2.1 得 75 分（官方称领先此前最佳 2 分），校准误差 0.8（d1.2 为 1.2）——对比 Jev 1.14 为 2.7、Perplexity Decider v1.3 为 3.7、GPT-6 Luna 为 7.2（13 项基准 22,505 问）；新增 5 类任务：价值读取 98%/96%、PII 检测 94%/93%、RefCOCO 94%、COCO 计数 93%/92%、多选 87%/90%；音频任务 ESC-50/FLEURS 95–97%。

实际影响：输入定价 $0.02/M token（d1.2）与 $0.042/M（ultra），1024×1024 图像计 1536 tokens——较生成模型低 1–2 个数量级的决策专用价位；将「判断/路由/打分」从对话式 LLM 中拆出为独立供给层。

适用限制：仅 Liquid 官方 API 可用（api.liquid.ai/decisions/v1/systemone），OpenRouter/Vercel 上架为「coming soon」承诺；权重不开放；参数规模未披露；「领先 2 分」为官方口径引第三方榜单快照。
