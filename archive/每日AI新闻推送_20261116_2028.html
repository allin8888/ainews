NVIDIA GR00T 2：World-Action Models 实现物理世界预测与灵巧操作统一框架（NVIDIA GEAR Research | 2026-11-16）

自述 · EmbodiedAI · Robotics · WorldModel · NVIDIA

事件概述

NVIDIA GEAR 实验室发布 GR00T 2，新一代世界-动作基础模型（World-Action Model, WAM），可同时预测机器人未来视频帧和关节动作。模型在并行夹爪、灵巧手和人形机器人上均通过微调验证。GR00T 2 Turbo 版本仅 2B 参数，使用更高压缩比视频编码器，适合机载部署——G1 人形机器人实测成功完成 popcorn 舀取服务、液体清理、多物桌面整理等任务。加入模拟数据后，GR00T 2 Turbo 分布外成功率从 6.7% 跃升至 63.3%，GR00T 1.7 同步提升至 40.0%。论文全文与代码将于 12 月开源。

技术与工程价值

  • 核心机制：与传统 VLA 只预测动作不同，GR00T 2 联合建模"世界如何变化"和"机器人如何行动"，实现 X-Adaptability——在非接触式示范（如人类用遥控器控制设备）中学到的技能可直接迁移到从未见过的形态（机械臂、轮式底盘、穿戴设备）。
  • 实际影响：世界-动作联合建模显著缓解 sim-to-real 鸿沟；Turbo 版已实现在 Tesla Optimus G1 上人机协同作业，标志着 WAM 架构进入工业级机器人验证阶段。

Embodied AI 发布 AIR 肌腱驱动工厂人形机器人，工业线缆操作可靠度达 98%（Humanoid Europe 2026 | roboticsandautomationnews.com | 2026-11-16）

第三方 · EmbodiedAI · HumanoidRobot · IndustrialAutomation

事件概述

瑞士洛桑初创 Embodied AI（创始人含 MIT/EPFL/ETH Zurich 前研究员 Francesco Stella、Kai Junge）在慕尼黑 Humanoid Europe 2026 发布 AIR——双臂轮式人形机器人，采用肌腱驱动手臂结构。在工业线缆处理测试中达成 98% 可靠度（目标值 90%），能从录制演示视频约一个月内学会新任务，设计符合 ISO/TS 15066:2016 安全标准，计划 2027 年取得 CE 认证量产。

技术与工程价值

  • 核心机制：肌腱驱动架构模仿人类手部精密运动，兼顾力控柔顺性与高带宽响应；双 Arm + 轮式底盘组合适合工厂狭窄通道场景。
  • 实际影响：AIR 将人形机器人可靠性指标推向工业生产可用门槛（90%+），为汽车线束、电子制造等重复精度要求高的场景提供新选项。

UiPath 正式发布 AI 编码 Agent，集成 Claude Code 与 OpenAI Codex（BigGo Finance | 2026-11-16）

自述 · AICoding · AgenticDevelopment · RPA · UiPath

事件概述

企业 RPA 龙头 UiPath 于 11 月 16 日正式推出 AI 编码 Agent，将其整合 Anthropic Claude Code 与 OpenAI Codex CLI 作为底层引擎，面向开发自动化流程设计与维护场景。产品附带 AI 开发工作流、数据连接管理、安全管控三大模块，定位为"低代码向全代码过渡的桥梁"。

技术与工程价值

  • 核心机制：Agent 以自然语言描述业务逻辑，自动编排 RPA 流程并生成可执行 Python/C# 代码；内置安全审查层对生成的脚本进行合规扫描。
  • 实际影响：RPA 市场主流厂商首次全面拥抱 Agentic Coding 范式，意味着大量存量企业流程可借助 LLM 完成从"录播回放"到"意图驱动"的代际升级，同时也打开了 Cursor / Windsurf 等独立编码 Agent 向企业 B2B 渗透的新路径。

Amazon 发现 AI Agent 钓鱼行动：伪装 LLM 服务的 MadPot 诱捕网络窃取 LiteLLM/Dify API Key（The Hacker News | 2026-11-16）

第三方 · AISecurity · AgentSecurity · ThreatIntel

事件概述

亚马逊安全团队公布一项跨期攻击（10 月初至本周）：威胁行为者部署了名为 MadPot 的蜜罐服务器群，伪装成流行 LLM 服务（LiteLLM、Dify 等），诱使运行中的 AI Agent 主动发送请求。由于多数 Agent 会将完整历史上下文（包括操作员指令与工具调用结果）一并携带，攻击者成功从中提取了真实 API Key 和部分用户配置信息。

技术与工程价值

  • 核心机制：利用 AI Agent "持续工作记忆"特性——Agent 在长时间任务链中会反复携带 credentials，一旦接入假服务即泄漏敏感上下文；区别于传统社会工程学，此次无需诱导真人交互。
  • 实际影响：该事件警示所有生产环境 AI Agent（尤其是云端部署型如 Claude Code / Codex / Dify）须启用请求级 credential 隔离与最小权限原则；企业安全防护套件（CrowdStrike Falcon Guardian GA、Microsoft Defender Agent Runtime Protection Preview）正快速补齐此类检测能力。
