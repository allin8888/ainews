OpenAI 重组机器人团队——GPT-6.2 Astra 能力飞跃促使独立 Robotics 部门拆分并入研究架构

事件概述

OpenAI 于 2026 年 11 月 13 日确认将其独立的机器人研发团队拆分重组：基础研究人员并入 Chief Research Officer Mark Chen 领导的统一研究组织，应用机器人与硬件团队则移交给 President Greg Brockman 的 Applied 部门。公司官方理由是 GPT-6.2 Astra 等通用模型已展现出直接控制机器人的能力，无需专门构建 VLA（视觉-语言-动作）模型。员工 David Schnurr 在 X 上反驳"解散"说法，指出职位页面仍有 15 个开放机器人岗位。一周后 Google 采取类似行动，将 Gemini 4 Hydrogen 通用模型替代专用 Gemini Robotics ER 2。

技术与工程价值
  • 核心机制：frontier labs 正在经历从「专用机器人模型」到「通用模型编程式控制机器人」的技术路线转换。GPT-6.2 Astra 在 AA-Robotics v0.1 基准测试中以 41.2% 得分超越前代 GPT-6 Astra 的 19.6%，显示涌现能力的跃迁幅度超出预期。
  • 实际影响：对 AI Coding Agent 赛道的信号是——如果通用 LLM 已通过 tool calling 模式有效控制物理机器人，那么 Agentic Coding 的基础设施可直接复用于具身智能场景，降低开发门槛。

CoRL 2026 会后反思：世界模型厂商收购与「通用模型是否真能取代机器人学」之争

事件概述

CoRL 2026 会议（Austin, TX）期间，多位研究者对 frontier labs 主导的机器人技术路线展开深度反思。关键争议点包括：(1) Fei-Fei Li 的世界模型 Atlas（World Labs，2026 年被 AMD 以 82 亿美元收购）能否真正帮助机器人减少真实数据采集依赖；(2) Aiden Swann (Goodfire) 声称发现 GPT-6.2 Astra 的训练数据中包含机器人仿真数据，质疑其"涌现能力"的真实性；(3) 多位研究生与会者反映，OpenAI 原定参展 booth 临时取消，被解读为模型能力展示已足够。

技术与工程价值
  • 核心机制：世界模型（如 Atlas）试图通过学习物理世界的视频生成来替代真实环境中的 trial-and-error 数据采集，但如果训练数据本身包含大量仿真数据，则说明「纯通用模型的涌现能力」论调可能存在选择性披露。
  • 实际影响：评估模型是否适合机器人控制任务时，需关注其训练数据构成和评测基准的真实来源，而非仅看 benchmark score。

GitHub Supply Chain Attack 波及 4,837 账户与 61,000+ 仓库——恶意 Action 窃取凭证

事件概述

本周安全周报报道了一起大规模 GitHub Actions 供应链攻击事件：攻击者在 4,837 个账户中植入了恶意工作流，目标覆盖超过 61,000 个仓库。恶意 Actions 主要尝试窃取 access tokens、云凭证和 API keys。与此同时，Microsoft Threat Intelligence 报告称攻击者正使用名为 ARTEX 的 agentic AI 工具自动搜索公开 GitHub 代码库中的密码和应用凭证。

技术与工程价值
  • 核心机制：GitHub Actions 作为 AI Coding Agent 生态的核心基础设施，供应链攻击直接影响整个 Agent 开发链的安全信任基础。攻击者利用 Agentic AI 自动化凭证扫描，标志着威胁行为体从「手动挖掘」转向「AI 驱动的大规模情报收集」。
  • 实际影响：使用 Claude Code、Cursor、Devin 等 AI Coding 工具的开发者，必须重新审视 CI/CD 流程中的凭证管理策略——包括 pre-commit secret scanning、short-lived credentials、以及 agent 专属的受限凭据体系。
