Together AI 发布 Agent Evals Playbook——文档与 Skill 优化将编码完成率从 75% 提升至 97%

explainx.ai · 2026-11-16

事件概述

Together AI 于 11 月 16 日发布一篇详细的 Agent 评测实战笔记，展示在真实平台任务上，通过修复文档陷阱、Skills 配置和 API 错误提示，Claude Code 和 Codex 的编码完成率从 75% 跃升至 97%。文章将此类实践定义为「Agent Experience（AX）」——继 DX 之后开发者体验的新维度。

技术与工程价值

  • 核心机制：揭示了当前编码 Agent 失败的主要原因并非模型能力不足，而是环境交互层面的信息不对称（API 错误语义不清、文档缺失或过时）。Skill 系统可将人类专家的工作流沉淀为机器可执行模板，直接桥接这一鸿沟。
  • 实际影响：对追求生产级可靠性的企业而言，该 playbook 提供了一套可复用的评估方法论；同时佐证了「模型之外，基础设施质量决定 Agent 可用性」的判断。相关讨论可见同日的 ffmpeg-skill（42 个本地 FFmpeg MCP 工具，GitHub 6,000+ Star）。

Jasjeet Sekhon 离任 Google DeepMind 加入 Anthropic，负责 Claude 认知严谨性

explainx.ai / BigGo Finance · 2026-11-16

事件概述

Google DeepMind 首席战略官 Jasjeet Sekhon 于 11 月 16 日官方宣布离职，加入 Anthropic，负责 Claude 模型的「认知严谨性」（epistemic rigor）方向——即模型如何建立知识、量化不确定性。Sekhon 曾于 2026 年 3 月才从 OpenRouter CPO 职位加盟 DeepMind，任职约 8 个月。此前，Gemini 联合负责人 Noam Shazeer 已于 6 月转投 OpenAI，AlphaFold 共同发明人 John Jumper 亦已加入 Anthropic。

技术与工程价值

  • 核心机制：「认知严谨性」直接关联 Agent 的可靠性问题——当 Claude Code 或 Codex 面对不确定信息时，如何准确表达置信度而非幻觉出一个看似合理的错误答案。这对多 Agent 协作场景尤为关键：一个不能量化自身不确定性的 Agent 可能在错误的假设上继续执行任务链。
  • 实际影响：此次人事变动叠加 Anthropic 预计本周启动的大规模 IPO，向资本市场传递了明确信号——Anthropic 正加速补强研究与管理核心团队。据 Zecki 数据，过去 12 个月离开 DeepMind 的员工中 25% 流向 Anthropic，14% 流向 OpenAI，「实验室人才争夺战」进入白热化。

Star Plus Legend × Galaxy 签署战略合作——拓展机器人娱乐与具身智能消费场景

Yonhap News / PRNewswire · 2026-11-17

事件概述

Star Plus Legend Holdings（港交所 6683.HK）与 Galaxy Corporation 于 11 月 16 日在香港签署战略合作备忘录（MOU），双方将在机器人乐园、机器人导览及全球机器人娱乐领域深化合作。此举建立在两者既有演唱会、展览及 IP 衍生品合作基础之上，进一步将具身智能技术引入大众消费市场。Star Plus Legend 已于 2026 年 11 月在香港尖沙咀开设全球首家 Pandabot Cafe，融合具身 AI、AIGC 与知名 IP，为消费者提供实体互动体验。

技术与工程价值

  • 核心机制：该合作标志着具身智能商业化路径的进一步拓宽——从工业制造（如 Mercedes-Benz 工厂的 Gemini Robotics 2.5 测试）延伸至休闲娱乐消费场景。Pandabot Cafe 模式验证了「IP + 具身机器人 + 实体空间」的可操作性，为后续规模化复制提供了商业样板。
  • 实际影响：消费级具身智能的市场潜力持续得到验证；小米雷军在近期访谈中亦表示，具身智能机器人是「巨大的产业机会」。结合 11 月 16 日 Gemini Robotics 2.5 在奔驰工厂达 96% 成功率的工业侧进展，具身智能正在双向渗透——高端制造与大众消费两端同步推进。
