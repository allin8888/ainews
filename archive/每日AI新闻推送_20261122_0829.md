### 3. Parallel Code 发布：多 AI 编码 Agent 并行编排工具，支持 Claude Code / Codex / Copilot

- **事件概述**：Parallel Code 于 2026 年 11 月 21 日正式发布，是一款开源多 Agent CLI 编排工具，可在隔离的 Git worktree 中同时运行多个 AI 编码助手（Claude Code、GitHub Codex、GitHub Copilot Agent）。通过 YAML 清单定义任务与合并策略，支持同步对比模式（等待所有 Agent 完成）和异步流式模式（逐个审查输出）。
- **技术与工程价值**：- **核心机制**：利用 Git worktree 实现各 Agent 任务的完全隔离与独立版本控制，避免并发修改冲突；- **实际影响**：为团队评估多种 AI 编码工具的性能差异提供了标准化基准测试平台，也支持「投票式」融合多个 Agent 输出的实用场景，降低单一 Agent 偏差风险。
- **关键指标/资源**：- 代码/下载：[parallelcode.app](https://parallelcode.app)，npm / Homebrew / 二进制安装，支持 macOS/Linux/Windows；- 信源：[emergent.sh 报道](https://emergent.sh/news/parallel-code-launches-multi-agent-cli-claude)。

### 4. Slack 新功能：让 Claude Code 与 Codex 接入团队历史对话上下文

- **事件概述**：2026 年 11 月 19 日，Forbes 报道 Slack 推出新功能，允许 AI 编码 Agent（如 Anthropic Claude Code、OpenAI Codex）访问团队在 Slack 中的过往讨论记录，从而理解团队的编码决策背景与设计意图。
- **技术与工程价值**：- **核心机制**：通过 MCP-compatible 集成或 Slack API 权限扩展，将频道历史消息作为 Agent 可读取的上下文注入，而非仅依赖本地仓库代码；- **实际影响**：解决当前 AI 编码 Agent 最大的痛点之一——脱离组织知识孤岛，显著提升大模型代码建议的相关性与正确性。这一方向也预示了 Agent-to-Agent 协作将成为下一波工作流改造的重点。
