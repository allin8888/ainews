### 2. 微软 Ignite 2026 一次发布七款自研 MAI 模型：MAI Code 2 主打「5% 成本达 Opus 5.5 约 96% 性能」（Microsoft AI 官方博客 / GitHub changelog | 2026-11-18）

**事件概述**：
微软 AI（MAI）在旧金山 Ignite 2026 大会发布七款自研模型，覆盖编程、网络安全、图像、语音与决策，其中编程模型 MAI Code 2 与轻量版 MAI Code 2 Flash 首日即在 GitHub Copilot、Copilot Fusion 与 Microsoft Foundry 全面可用。微软以「专用模型 + 性价比」正面切入 OpenAI 与 Anthropic 的编程模型腹地。

**首发时间**（第一信源）：
Microsoft AI 官方博客「seven new world class models at scalable price-performance」与「MAI Code 2 and Code 2 Flash」均标注 2026-11-17（美西）；GitHub changelog feed 记录 03:01 JST（北京时间 02:01）上线，落在窗口内。中文报道集中在 11-18 07:46 之后，仅作佐证。

### 3. Perplexity 上线 Multiagent：主智能体把任务拆分给运行不同前沿模型的多个智能体并合并结果（Perplexity 官方 X | 2026-11-18）

**事件概述**：
Perplexity 在 Computer 与 Teammates 中推出新的推理档位 Multiagent：由一个主智能体（lead agent）把任务拆分给运行不同前沿模型的多个智能体，各子智能体在工作中共享发现，最后由主智能体合并为单一答案。

**首发时间**（第一信源）：
Perplexity 官方 X 帖文时间为 2026-11-17T16:28:32Z（北京时间 11-18 00:28），落在窗口内。perplexity.ai 对脚本化抓取返回 403，故以官方 X 帖为第一信源。

**技术与工程价值**：
- **核心机制**：异构模型协同的「分派—共享—归并」编排——主智能体负责拆解与最终合并，子智能体跨不同前沿模型并行，共享中间发现以减少重复劳动。这是把「多智能体辩论/分工」从研究范式推向通用助手产品档位的一次工程落地。
- **实际影响**：把模型选择从「单一模型切换」升级为「按子任务分配不同模型」，是 Agent 编排层向模型路由与结果融合演进的信号；与本期 GPT-6.2、MAI Code 2 的性价比叙事形成呼应——能力增益越来越多来自编排与成本结构，而非单一模型规模。
- **适用限制**：官方未公布量化基准、成本模型或子智能体数量上限；perplexity.ai 页面对脚本抓取返回 403，产品细节以官方 X 帖为主，功能仍在 rollout。

**关键指标/资源**：
- 评测/性能：无公开量化基准（产品功能发布）；编排形态为主智能体分派 + 异构前沿模型子智能体并行 + 结果归并（官方描述，未见第三方复现）。
- 代码/资源：面向 Perplexity Computer 与 Teammates 用户逐步开放；首发 2026-11-17T16:28:32Z。
