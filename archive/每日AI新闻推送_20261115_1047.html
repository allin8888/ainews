1. datasette-vega 0.7 发布：Datasette 图表插件时隔八年四个月首次更新（Simon Willison 官方博客 + GitHub Release | 2026-11-14）

事件概述：Simon Willison 发布 Datasette 图表渲染插件 datasette-vega 0.7：为 Datasette 的数据表与自定义 SQL 查询结果渲染 Vega-Lite 图表。该插件上一个版本 0.6.1 停留于 2018 年 7 月 10 日，本次时隔八年四个月重启维护，作者称之为「Datasette 最久未动的插件」。本次更新适配最新 Datasette alpha 版本，并随 Datasette Lite（浏览器 Pyodide/WASM 形态）新获得的 JavaScript 插件加载能力提供在线实机演示。

首发时间：GitHub Release published_at 2026-11-14T17:09:09Z（官方仓库 simonw/datasette-vega），与作者博客文章发布时刻（2026-11-14 17:09 UTC）一致；窗口为 UTC 2026-11-14 15:24 → 11-15 02:47，落入窗内。

技术与工程价值

  • 核心机制：0.7 版本完成对最新 Datasette alpha 的兼容性重建，并利用 Datasette Lite 新增的 JS 插件机制实现浏览器端渲染——README 实机演示直接链接到 Datasette Lite 在线实例，无需本地安装即可体验。
  • 实际影响：Datasette 生态的可视化能力重新接上主线；「浏览器内跑插件」路径有了首个官方演示用例，为数据工具的零安装分享场景（教学、报告、公开数据集探索）提供参照。
  • 适用限制：目标运行环境为 Datasette alpha 版本，API 尚未冻结；本条为维护性更新，未披露可比量化指标。

2. datasette-llm 0.1a11 发布：新增 OpenAI 兼容端点，本地模型一行命令驱动 Datasette Agent（Simon Willison 官方博客 + GitHub Release | 2026-11-14）

事件概述：Simon Willison 发布 datasette-llm 0.1a11：Datasette 的中间层插件（供其他插件依赖以统一配置 LLM），本次新增 OpenAI 兼容端点支持——任何实现 OpenAI 伪标准协议的模型服务均可作为后端，覆盖 LM Studio、Ollama、llama.cpp（刚发布 v1.0.0）等本地运行时。作者给出一条 uvx 命令演示：以本地 LM Studio 运行的 qwen3.8-27b 经 datasette-agent 启动一个完整 Datasette Agent 实例。

首发时间：GitHub Release published_at 2026-11-14T23:59:28Z（仓库 datasette/datasette-llm，Datasette 官方 org），与作者博客文章发布时刻（2026-11-14 23:59 UTC）一致；落入窗内。

技术与工程价值

  • 核心机制：datasette-llm 定位为「intermediate plugin」——不直接面向用户，而是为其他 Datasette 插件提供统一的 LLM 配置面；0.1a11 增加 api_base 配置使 OpenAI 兼容端点（本地或远程）成为一等公民，插件生态无需各自适配即可共享模型配置。
  • 实际影响：把「私有数据 + 本地模型 + Agent」的启动成本压缩到一条命令（wget 数据库 → uvx --with datasette-agent datasette --root --secret ... -s plugins.datasette-llm.default_model），对数据不出域的分析场景有直接工程价值。
  • 适用限制：仍为 0.1 alpha 第 11 个迭代（a11），API 稳定性未承诺；演示为作者自测口径，未见第三方复现；依赖的 datasette-agent 包同处 alpha（0.5a0）。
