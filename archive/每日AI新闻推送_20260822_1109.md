### 1. OpenAI 全面开源 Codex Harness，Agent 运行时成为新战场（格隆汇/OpenAI官方博客 | 2026-08-21）

**事件概述**：
OpenAI 宣布将驱动 Codex App、CLI 与 IDE 扩展的底层执行框架 Codex Harness 以 Apache-2.0 协议全面开源，仓库 github.com/openai/codex 截至当日已累计约 10.7 万 Star、1.6 万 Fork。

**技术与工程价值**：
- **核心机制**：开源内容包含三层集成接口——用于脚本与 CI 的 `codex exec`、提供 TypeScript/Python 编程式调用的 Codex SDK、以及支持持久会话/事件流/任务中断/人工审批的 app-server（基于双向 JSON-RPC 协议）。Harness 不做推理，只负责上下文维护、工具调用、沙箱执行、权限审批等"脏活"。
- **实际影响**：仅通过保留推理与上下文压缩两项 Harness 侧调整，GPT-5.6 Sol 在 ARC-AGI-3 上的得分就从 13.3% 升至 38.3%，输出 Token 减少约六倍。落地案例包括 Thrive Holdings 搭建税务申报流程（试点处理 7000 份申报表，准备时间缩短约三分之一）、思科用 Codex SDK 在云控制平台内构建自然语言 App Builder。
- **关键指标/资源**：10.7 万 GitHub Star / 1.6 万 Fork；ARC-AGI-3 得分 13.3% → 38.3%（仅 Harness 调整）；codex 仓库：github.com/openai/codex

**标签**：`#AI Coding` `#开源` `#Agent基础设施`

### 2. DeepSeek Harness 一周三更，把 Claude Code 与 Codex 收编为子代理（新京报/数据猿 | 2026-08-19–21）

**事件概述**：
DeepSeek Harness 于 8 月 13 日开放 MIT 协议开发者预览后，一周内完成三次版本迭代（RC.7 → RC.8 → 0.1.0），将 Claude Code 和 Codex 正式纳入插件式子代理体系，试图成为 Agent 时代的"调度层"。

**技术与工程价值**：
- **核心机制**：v0.1.0-rc.8 版本新增 DeepSeek-V4-Flash-Vision-Exp 多模态选项，支持原生图片请求与图文混合输入；子代理体系通过 Profile Bundle 机制加载，Codex 子代理支持非交互权限模式及多实例并行；reportDelivery 唤醒机制使子代理完成任务后主动回传并唤醒父任务，不再依赖轮询或超时检测。
- **实际影响**：开发者可在单一框架内灵活切换不同模型和工具链，根据任务类型自动选择最优 Agent 执行。对无视觉能力的模型，系统通过 OCR、颜色统计、像素扫描等技术将图片转成结构化信息，形成"工具层视觉"方案。
- **关键指标/资源**：v0.1.0-rc.8 发布 24 小时内收获超 200 颗 GitHub Star；支持 MCP/ACP 图片附件持久化；harness 仓库：github.com/deepseek-ai/deepseek-harness

**标签**：`#AI Coding` `#开源` `#多模态` `#Agent编排`

### 3. Generalist AI 发布 GEN-1.5 机器人基础模型，被类比为"具身智能的 GPT-3 时刻"（新智元/东方财富 | 2026-08-20）

**事件概述**：
硅谷 Generalist AI 于 8 月 20 日凌晨（北京时间）发布新一代机器人基础模型 GEN-1.5，仅需看 3-12 秒人类演示即可零代码执行新任务，10 项操作 one-shot 平均成功率 59%（少样本微调后提升至 83%），李飞飞、英伟达等参投。

**技术与工程价值**：
- **核心机制**：模型采用"物理提示（Physical Prompting）"范式——将感知运动示例放入上下文窗口，类比大语言模型的 Prompt Engineering。核心能力包括：单次示范学习（3-12 秒演示→几秒内学会）、物理提示串联（将不同示范串联为更长行为序列）、梯度下降少样本自适应（1-5 分钟数据/10-50 次演示→1-10 个梯度步骤微调）、行为策略层面泛化（使用训练数据中从未出现的新工具）。
- **实际影响**：展示了训练数据中从未出现过的"策略涌现"——用簸箕代替刷子把积木铲进碗里、自发切换双手拧瓶盖、用另一只手拨掉粘在指尖的乐高积木。研究者将其类比为 2020 年 GPT-3 发布，认为具身智能走到 Scaling Law 拐点。
- **关键指标/资源**：one-shot 平均成功率 59% / few-shot 83%；30 秒记忆窗口；100Hz 动作轨迹生成频率；模型架构：多模态+本体感知+传感器融合

**标签**：`#具身智能` `#机器人` `#世界模型` `#多模态`

**事件概述**：
英伟达同意支付 60 亿美元获得 Poolside AI 模型使用许可，并向其 100 多名员工发出聘用邀请，另以 120 亿美元估值追加 10 亿美元战略投资。Poolside 将继续独立运营，交易结构与英伟达此前收购 Groq 的模式相似。

**技术与工程价值**：
- **核心机制**：交易呈"许可费 + 股权投资 + 人才引进"复合结构，规避传统并购审查。Poolside 专注于开发面向计算机编程自动化的 AI 模型，尤其针对政府及国防软件领域，技术方向与英伟达拓展 AI 应用场景的战略高度契合。
- **实际影响**：反映英伟达从芯片供应商向 AI 全栈生态的加速转型，通过资本手段锁定上游模型能力。此类"许可替代收购"模式已引发立法者质疑，认为实质上绕过了反垄断审查机制。
- **关键指标/资源**：许可费 60 亿美元 / 股权投资 10 亿美元 / 投前估值 120 亿美元；Poolside 在美国和巴黎均设有办公室
