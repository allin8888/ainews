1. Meta 全量部署 Catching JiTTests：LLM 在代码合入前按需锻造「一次性捕获测试」，H1 拦截 74 个严重隐私 bug、隐私 SEV 总量降 20% （Meta 官方工程博客 | 2026-10-29 UTC 16:00）

事件概述

Meta 工程博客发布《Catching Bugs Before They Land》，首次系统披露 Catching JiTTests（即时捕获测试）从研究原型进入全量生产基础设施：每次 PR 提交时由 LLM 按需生成专攻「本次 diff 引入的行为差异」的一次性测试——默认不入库、用完即弃，工程师只回答「这个行为变化是否预期」的是非题。概念与论文（arXiv:2601.22832）于 2026 年 2 月公开，本条事件为 10-29 官方博客的生产规模部署详解（RSS pubDate 2026-10-29 16:00:12 GMT = 北京 10-30 00:00，落窗）。

技术与工程价值

  • 核心机制：双管线并行——dodgy diff 把 diff 直接当「嫌疑变异体」生成能区分 parent/diff 行为的测试（铺量、覆盖广、误报多）；intent-aware 先读 diff 标题/描述/代码推断变更意图与风险点（空值、边界、状态机），在 parent 上注入变异后生成「parent 过、mutant 挂」的测试再打真实 diff（精准）。parent 过而 diff 挂记为 weak catch，经 RubFake 确定性规则评估器（布尔翻转、mock 错误、反射断裂等误报模式 + 风险标记）与多模型 LLM-as-Judge 集成（-1~+1 语义分、等级、理由聚合排序）过滤假阳性，仅高分候选推给人审；passing 池经评审有选择地「收割」为长期加固测试，形成「临时探针 + 永久资产」双轨。
  • 实际影响：直接回应 AI Coding 时代的结构性矛盾——agent 生成代码的速度已超过人类写/维护测试的速度，传统测试「守未来、不抓当下」且脆断维护成本爆炸。把测试变成按 diff 定制、阅后即焚的动态防线，人审被压到「一句是非题」量级，是头部机构把 LLM 测试生成推进到全量 CI 基础设施的标杆样本；RubFake 规则层 + judge 集成 + human-on-the-loop 的分层降噪设计对自建 agent 编码工作流可直接借鉴。

2. Figma 公开自研画布编辑模型训练方法：25 万合成样本 SFT 起步、确定性校验器 + 视觉评委做奖励，转向 RL 后内部评测 77.8% （Figma 官方博客 | 2026-10-29）

事件概述

Figma 官方博客发布《How we're training a Figma-fluent editing model》，详解为 Figma Agent 训练专用画布编辑模型的完整配方：任务不是从零生成设计，而是对既有画布做「调间距、换颜色、按反馈重排」的小步编辑；先用 25 万+ 合成样本做 SFT（起始设计 + 合成编辑请求 + 成功改动三元组，以 Figma 原生文件格式表示、输出可直接落回画布），教师模型先尝试编辑、再由确定性校验器与视觉模型评委检查有效性并反馈自我修正；早期基于 Llama 3.3 70B 的版本在 25 万样本训练后编辑任务表现已与当时顶级模型竞争。官方渠道条目发布时刻 2026-10-29T21:00:02Z（北京 10-30 05:00，落窗；博客页仅日期级 10-29，已列待核实）。

技术与工程价值

  • 核心机制：SFT 上限被明确承认——模型倾向复现训练见过的设计、泛化变弱、样本覆盖成本高，因此转向 RL：贴近设计领域的强化学习环境、样本多样性扩充、奖励模型打磨与「专家撰写的评判标准」；评测不把「设计质量」当笼统分数，拆为对齐度、对比度、请求满足度、组件用法正确性等维度，结构检查 + 视觉评委 + 专家设计师三层校准；基座随时代际更新（官方提及已使用更新的 Qwen 等模型）。
  • 实际影响：「垂直领域 Agent 专用后训练模型」的罕见完整工程样本——LLM-as-Judge 与确定性校验器混合成可训练奖励、评委反馈进入数据闭环（与 arXiv 近期 rubric-harness 共进化方向同频），并以产品指标验证收益：Figma Agent 已向全部用户推出，典型任务从测试版到正式版提速约 20%；与专家设计师对照测试 62% 情形不输上一代、评分 +33%、撤销操作 -60%。为设计-代码一体化工作流提供「专用小模型 + 混合奖励」路线参照。

4. Pika 开源 Pika-H3-Flex：MiniMax H3 后训练六步采样视频模型，LoRA 适配器 + Apache-2 推理包落地 （Hugging Face 官方仓库 | 2026-10-29 UTC 17:08）

事件概述

Pika Labs 发布并开源 Pika-H3-Flex——对 MiniMax H3（2026-07-31 开源的 33B 全模态音视频生成基座）做后训练的成果：HF 仓库创建于 2026-10-29T17:08:44Z（北京 10-30 01:08，落窗），官方博客/X 同日发布。核心卖点是把采样从 50 步蒸馏到 6 步、原生输出带 32kHz 立体声的 480p/768p 视频，官方称 15 秒 768p 片段仅需约 7 秒 DiT 计算（受控基准口径）。

技术与工程价值

  • 核心机制：三阶段后训练——①自建美学筛选音视频语料 SFT（仍 50 步教师档）；②PDMD（Projected Distribution Matching Distillation）把采样 50→6 步（官方称标准 DMD 在其实验不稳定）；③蒸馏后奖励学习：ReFL（美学/清晰度）与 DPO（指令遵循/真实感）分别训练 LoRA 再合并为单一适配器、不增推理步数。交付为 FL2VA（文本+首/尾帧）与 Ref2VA（多模态引用：最多 9 图 + 3 视频 + 3 音频共 12 个引用文件，支持运动迁移、角色替换、引用引导编辑）两个 LoRA（各 ~2.77GB FP32），叠加 H3 基座（组件合计约 210GB）；推理代码 Apache 2.0；ComfyUI 当日提供三个官方模板（ManualSigmas 1000/750/500/250/100/40/0、video shift 12 / audio shift 3、CFG 1.0）。8×B300 上经 fused kernels / FlashAttention-4 / 块稀疏注意力优化，5 秒 768p 完整推理 3.409s→2.129s（1.60×）。
  • 实际影响：继 fal H3 Max（09-01，闭源 API 路线）后第二个 MiniMax H3 后训练产品，但选择开源分发——把视频模型迭代成本压到 LoRA 级，创作者可本地以 6 步调度做草稿级快速迭代（单卡实测 5 秒 1344×768 约 1 分钟，与官方 7 秒口径的差距须注意：后者为受控基准 DiT 计算、非端到端延迟）；「开源适配层 + 闭源高级能力（4K 上采样器、五条可编辑音轨留云端）」的分层开源模式，与 Mistral MaaS 商用墙（上期）同属最新开放策略样本。

5. Unsloth 发布 Mistral Large 4「Dynamic 1-bit」GGUF：约 233GB 本地跑 1T 参数多模态模型，保留 91% top-1；AA 同日第三方确认 1.05T-A52B/1M 上下文 （X @UnslothAI 官方账号 | 2026-10-29 UTC 14:27）

事件概述

Unsloth 为上期报道的 Mistral Large 4「Le Chonk」开放权重释出 Dynamic 1-bit GGUF 量化家族（unsloth/Mistral-Large-4-1T-A52B-GGUF）：1-bit 档需 256–270GB 内存、最小 UD-IQ1_S 约 233GB 磁盘，较 FP8 约 1.1TB 缩小 80%，称在 Mac Studio 一类大内存单机即可本地运行，保留 91% top-1 准确率，支持文本+图像输入、1M 上下文与 160+ 语言。官方宣布帖 2026-10-29T14:27:32Z——距窗口起点约 2.5 分钟；仓库 createdAt 11:24:56Z（窗口前，建库/上传开始）、权重落定 lastModified 15:58:11Z（窗口内），本条按「官方账号宣布 + 权重落盘均在窗内」入选并做边缘披露。

技术与工程价值

  • 核心机制：延续 Unsloth Dynamic 量化路线——按层/张量敏感度非均匀分配位宽，把 1T MoE（52B 激活）压进 1-bit 档 GGUF；MoE 稀疏激活使低比特总预算内每 token 实际计算量远小于稠密档位，配合 llama.cpp / vLLM / SGLang 生态与多模态输入保留。
  • 实际影响：昨日 Large 4 权重开放回答「有没有」，1-bit GGUF 回答「跑不跑得起」——把前沿开源旗舰的硬件门槛从机架级降到单机工作站/Studio 级，私有化与离线场景（含 agent 编码）获得可用的 1T 档选项；量化以牺牲部分精度换可达性，91% top-1 保留为 Unsloth 自给口径（待第三方复现）。同日 Artificial Analysis 官方账号（14:58:23Z，窗口内）发布对 Large 4 的评估：总参数 1.05T、激活 52B、上下文 1M tokens——上期待核实的架构与上下文参数获第三方口径确认。
