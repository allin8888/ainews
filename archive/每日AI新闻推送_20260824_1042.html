Jeff Dean 离开谷歌后创业首秀：Discovery Loop 以多 Agent 驱动科研方法论全自动闭环

Discovery Loop · 2026-08-22
前谷歌首席科学家 Jeff Dean 在斯坦福 Frontier & Pioneer Symposium 首次公开新创业项目 Discovery Loop。公司以公共利益公司（PBC）架构运营，核心使命是用多 Agent 系统将科学研究全流程（拆解子问题→提出假设→执行实验→评估结果→迭代反馈）自动化，瞄准递归自我改进（RSI）与 AI for Science。

核心机制

  • 构建具备跨 20 个领域博士级专业知识的多智能体系统，将 RSI 从"模型改自身权重"拓展到"整个科学方法论自动化"
  • 约 10 人小团队依托云与 MaaS 生态绕过大厂硬件壁垒，以极致人效比推进特定赛道

实际影响

若成功，将把 AI 从"辅助人类做研究"升级为"自主完成科学研究"，对药物发现、材料科学、基础物理等领域的研发效率产生结构性跃升；为递归自我改进提供了不同于"模型权重自我修改"的务实路径。

关键指标 / 资源

  • 目标覆盖 20 个学科领域博士级专业知识（目标指标，尚未发布基准）
  • Jeff Dean 缔造 MapReduce、TensorFlow、操盘 Gemini；联合 Sanjay Ghemawat、Oriol Vinyals 等老搭档创立
#递归自我改进 #AI for Science #Jeff Dean #基础设施

Cloudflare 为 AI Agent 量身打造 Web 基础设施：无 Chromium 浏览器 + 可编程钱包 + x402 支付协议三件套齐发

Cloudflare · 2026-08-06 / 8 月中旬
Cloudflare 在过去三周内连续发布三项产品——Kitesurf（从零编写、无 Chromium 的浏览器）、Wallets（Account Wallet + Virtual Wallet）、Monetization Gateway（基于 x402 协议的边缘结算），三者共同构成面向 Agent 的完整 Web 基础设施栈。

核心机制

  • Kitesurf：Rust 编写、WASM 编译、V8 Isolates 运行，通过 235,000+ Web Platform Test；CPU/内存仅为 Chromium 的 1/3–1/7，支持 Chrome DevTools 协议
  • Wallets：按会话/ merchant 白名单/最大交易额度控制 Agent 消费
  • x402 协议：Agent 按次付费，稳定币边缘结算，无需注册或跳转

实际影响

彻底改变 Agent fleets 的 per-session 基础设施成本结构；Agent 付费能力从"需要人工介入"变为"可治理的自动化支出"，为大规模 Agent 自主完成 web 交互、API 调用、付费订阅开通打开大门。

关键指标 / 资源

  • Kitesurf 通过 235,000+ Web Platform Test 子项；CPU/内存降低 3–7 倍
  • x402 协议开放，已有 20+ 公司接入支付流
  • 链接：cloudflare.com（产品页）

Matt Pocock "Skills" 仓库一周内斩获 23 万 Star，"Prompt as Code"进入可版本化管理时代

GitHub Trending · 2026-08-24
TypeScript 教育者 Matt Pocock 将个人 .agents 目录中的"Skills"集合开源为 mattpocock/skills，短短数日内达到 233,815 Star。每个 Skill 是针对特定工程任务的结构化多步协议，含检查清单、错误处理流程、"禁止操作"约束，Claude Code、Codex、Cursor 等 Harness 可直接导入消费。

核心机制

  • 将"高级工程师的判断力"显式编码为可版本化、可分享、可组合的 Markdown 文件
  • Skills 之间可嵌套、组合、优先级排序，形成可追溯的"工程知识 Git 历史"

实际影响

标志着 AI Coding 竞争重心从"基座模型能力对比"进一步下沉到"编排层与知识层"——配置精良的 Skill 库可以让中档模型达到比未经调优的顶级模型更高的输出质量；预测 6 个月内将出现"Skill 注册表"（类似 npm/PyPI）。

关键指标 / 资源

  • 233,815 Star（截至 2026-08-24 GitHub Trending）
  • github.com/mattpocock/skills

世界机器人大会闭幕：具身智能从"炫技"全面转向"上岗打工"，世界模型专家委员会成立

WRC 2026 / 中国电子学会 · 2026-08-19–23
2026 世界机器人大会 8 月 19–23 日在北京闭幕，373 家企业、3000+ 展品、150+ 首发新品。主题从"能走能跳"正式转向"能干活、能交付、能成交"。会同期，中国电子学会正式成立"世界模型专家委员会"，跨维智能 CEO 贾奎受聘首届委员并首提"Physical Token 经济学"。

核心机制

  • 大晓机器人"晓满"（即时零售履约，1N 力控，合作商户包括烧卖购、快客达、中石油便利店）、"晓新"（酒店洗衣全流程）、"晓途"（户外巡检，已落地上海漕河泾/滨江）
  • 银河通用"银河星脑"驱动 Galbot ET-1 网球对抗（延迟≤5ms）；蚂蚁灵波"一脑多机"已在国大药房上线
  • 自变量机器人提出数据质量优先于规模，反对"千万小时数据决定论"

实际影响

行业共识从"谁的数据多"转向"数据来自什么环境、覆盖哪些任务、是否包含失败样本"；贾奎提出的 Physical Token 经济学主张从产业早期系统思考数据基础设施、模型架构与场景协同，形成数据飞轮。

关键指标 / 资源

  • 2026 H1 中国人形机器人出货量 4 万+ 台（全球占比 97%+）
  • 银河通用 Galbot ET-1 网球交互延迟≤5ms；自变量估值超 200 亿元
  • wrc2026.org；中国电子学会世界模型专家委员会公告

NVIDIA Nemotron 3.5 Lightning 开源：30B MoE 单卡可跑，任务完成成本降至 Opus 4.8 的 1/3

NVIDIA · 2026-08-22
NVIDIA 发布开源模型 Nemotron 3.5 Lightning（30B 参数 MoE）及配套推理路由框架 NeMo Switchyard，支持单 GPU（RTX PC / DGX Spark / Jetson）运行，无需授权费。NeMo Switchyard 智能路由将简单任务分配给 Lightning、复杂决策路由至前沿模型，综合 AI 支出降低 50–67%。

核心机制

  • MoE 架构，推理速度较竞品快 4 倍，Agent 任务完成率提升 30%
  • HuggingFace、ModelScope、build.nvidia.com 三方均可免费下载
  • NeMo Switchyard 通过任务分类器动态选择最优模型，实现成本-性能帕累托前沿最优 trade-off

实际影响

将前沿级 AI 能力从"必须付费 API"变为"本地可部署、零许可费"，直接冲击 Claude Opus 4.8 / GPT-5.6 等企业客户定价体系；500+ SKU 中腰部卖家可在 30–60 天内收回 GPU 基础设施成本。

关键指标 / 资源

  • 推理加速 1.98–2.40×；任务成本降至 Opus 4.8 的 ~1/3
  • huggingface.co/nvidia / modelscope.cn / build.nvidia.com（Nemotron 3.5 Lightning）
  • 后续：Nemotron 4（1T+ 参数，2026 年末）已在规划中
