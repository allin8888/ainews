1. Anthropic 发布 Claude Haiku 5.5：运行成本较上代降约 75%，首款可调推理强度的 Haiku

第一来源：Anthropic 官方博文 / Reuters ｜ 2026-10-07
事件概述

Anthropic 于 10-07 发布 Claude Haiku 5.5，系 Haiku 家族第三款 5.5 模型（继 Opus 5.5、Sonnet 5.5 后），官方称其为迄今最快、最便宜、能力最强的 Haiku 系列小型模型；平均运行成本较 Haiku 4.5 低约 75%。这是首款支持可调节推理强度（effort）的 Haiku，并可作为 Opus 5.5 / Sonnet 5.5 的「子智能体」用于编码、computer use、知识工作等高频任务。

技术与工程价值
  • 核心机制：引入 effort 旋钮（成本/智能权衡）；首款带窄范围高危网络安全请求内置防护的 Haiku；定价分层——提示词 ≤100k token 时输入/输出 $0.10/$0.50 per M，>100k 时升至 $0.50/$2.50。同步将 Sonnet 5.5 缓存读取价减半至 $0.10/M，使多数 agentic 任务成本再降约 20%。
  • 实际影响：把「高频、低成本、低延迟子智能体」路线正式产品化——用 Haiku 5.5 承担分类/摘要/提取/子任务，Opus/Sonnet 承担重活。OSWorld 15.7%→72.4%、Terminal-Bench 4.0 0→39.2% 显示小模型 coding / computer-use 能力跃升，直接压低长链路 agent 的 token 经济学。
评测/性能（Anthropic 官方自述，缺第三方复现，待核实）：OSWorld 72.4%（vs 4.5 的 15.7%）；Terminal-Bench 4.0 39.2%（vs 0）；GDPval-AA 1620（上代 2 倍+）。
定价：$0.10/$0.50 per M（≤100k token）；Sonnet 5.5 缓存读取降至 $0.10/M。
资源：Anthropic 官方博文与 Haiku 5.5 System Card；Release Notes。

2. 微软将 MAI Code 1.1 Flash 引入 Windows 11，GitHub Copilot 本月底支持本地/云端混合推理

第一来源：微软旧金山发布会 / IT之家 ｜ 2026-10-07 PT = 北京 2026-10-08 01:00
事件概述

微软在旧金山活动宣布 GitHub Copilot 将在本月底前支持本地 AI 模型推理，开发者可在云端模型与设备端模型间自动或手动切换；本地模型可选 MAI Code 1.1 Flash（经 Windows ML）或任意 OpenAI 兼容本地端点。MAI Code 1.1 Flash 是 6 月 MAI-Code-1-Flash 的升级版，已集成进 Copilot / VS Code。

技术与工程价值
  • 核心机制：MAI Code 1.1 Flash 为 MoE，总参 1370 亿 / 活跃 68 亿，3-bit 量化使体积缩小约 80%，上下文 256K；Surface Laptop Ultra（128GB 统一内存）实测解码吞吐 40–63 token/s（提示 2K→256K）。新增多模态「看图写代码」——读截图/架构图/UI 草图生成代码并补 OAuth 回调与前端埋点。Copilot 协调器据性能/成本/准确性路由请求到云或本地。
  • 实际影响：把「端侧本地优先编码」从概念推到产品——断网（飞行模式）即可跑编码 agent；高隐私/低延迟场景可强制本地；OpenAI 兼容端点开放使第三方本地模型也能接入 Copilot。相较 6 月版 Terminal-Bench 2.1 +22%、.NET +15%、流速 +25%、token -25%，标志编码模型竞争从「云端能力」下沉到「端云协同与部署成本」。
评测/性能（微软自述，缺独立基准，待核实）：1370 亿总/68 亿激活；3-bit 量化；256K 上下文；解码吞吐 40–63 tok/s；相对 1.0 版 Terminal-Bench 2.1 +22% / .NET +15% / 流速 +25% / token -25%。
资源：IT之家（10-08 06:21）、微软发布会；推荐 120GB+ 内存方能流畅本地运行。

3. OpenAI 在 GitHub 发布 openai/math：722 份由内部模型生成的数学手稿

第一来源：OpenAI GitHub / 上海证券报·网易 ｜ 2026-10-07
事件概述

OpenAI 于 10-07 在 GitHub 发布 722 份数学手稿（组织为 372 个「成果族」），覆盖数论、代数几何、实分析、组合、理论计算机、数学物理、PDE 等方向，含米尔恩理性猜想与代数特化、准黎曼假设、希尔伯特第十问题等，全部由一个尚未发布的内部前沿模型生成。

技术与工程价值
  • 核心机制：流程为向模型提出约 4000 个问题，平均每个结果耗费约 3 小时 ChatGPT Pro 思维计算；输出汇总为成果族与论文并设显著性水平，仅保留 judged significant 的 372 族公开。OpenAI 披露：绝大多数结果来自「单一提示词交给单一 AI agent」（部分需多次尝试），即一次性批量生成数百个证明族。仓库附 10 个结果推理摘要、基于 Pro 时长估算的计算量、尝试问题数统计。
  • 实际影响：RSI / 自主研究主线最新坐标——AI 直接产出成体系数学成果；与 MetaRSI-v1 / AIDE² / RRSI 等「改进研发流程」路线互补，本次是「AI 作为研究产出主体」的极端样本。但学界质疑强：仅 162/722（约 22%）有 Lean 形式化主结果，OpenAI 自承「部分未形式化结果可能有问题」；MIT Andrew Sutherland 称模型发布前「单提示词单 agent」说法无法验证。
评测/性能（OpenAI 自述 + 社区核验缺口，待核实）：722 手稿 / 372 成果族 / ~4000 问题 / 平均 3 小时 Pro 思维 / 162 份 Lean 形式化（约 22%）。
资源：GitHub openai/math；AGMAI（普林斯顿高等研究院）咨询组声明（仅作咨询角色，不代表对结果影响的评判）。

4. Nous Research 完成 $90M B 轮（$1.5B 估值），扩容开源自改进智能体 Hermes Agent

第一来源：Nous Research CEO 公告 / CryptoCortex ｜ 2026-10-07
事件概述

开源 AI 实验室 Nous Research 于 10-07 宣布完成 9000 万美元 B 轮融资，估值 15 亿美元，由 Robot Ventures 领投，NVIDIA、微软 M12、三星、Y Combinator、USV、Menlo 等跟投；资金用于扩容开源自主智能体 Hermes Agent 及其企业版与移动 App。

技术与工程价值
  • 核心机制：Hermes Agent 2026-02 以 MIT 许可发布，定位自主、自改进——跨会话持久记忆 + 自动生成可复用技能（skills）；可本地或托管运行；累计下载/克隆超 2400 万次，约占全球 AI token 推理量 2.5%。本次资金主打「Hermes for Businesses」：SSO、审计能力、工作区管控，同时保持开源。
  • 实际影响：开源自改进 Agent 基础设施化的资本侧确认——继第 80 跑 HF×Liquid 多 Harness RL、第 79 跑 Marathoner 长时程编码 Agent 后，开源 Agent 从研究玩具走向企业级产品；与本地 Hermes Agent 技术栈（VPS 托管、MCP 集成）高度相关，标志该路线获主流资本背书。
指标（公司自述，缺第三方审计，待核实）：$90M B 轮 / $1.5B 估值 / 累计融资约 $160M / 2400 万+ 下载 / 全球 AI token 推理 ~2.5%。
资源：Nous Research 公告；Hermes Agent（MIT 许可）。

5. Mecka 完成 $60M B 轮（红杉领投，NVIDIA/M12 跟投），主攻机器人数据基础设施

第一来源：Mecka 公告 / TechCrunch / Unite.AI ｜ 2026-10-07
事件概述

机器人学习数据基础设施公司 Mecka 于 10-07 宣布完成 6000 万美元 B 轮，红杉资本领投，NVIDIA、高通创投、三星、微软 M12 等跟投，天使含 DoorDash CEO Tony Xu、前 Tesla Optimus 负责人 Milan Kovac 等；资金用于扩展数据采集基础设施、内部研究实验室与商业机器人部署。

技术与工程价值
  • 核心机制：Mecka 自研多传感器采集硬件 + 重建模型 + 质检基础设施，全球采集队记录人在家庭/工业环境中的演示；内部 CV/多模态模型把原始噪声现实转为结构化信号（运动追踪、3D 重建、触觉力、声、速度、点云等）；EgoVerse 数据集（2026-04 首投、07 修）含 1362 小时人类演示 / 80k episodes / 1965 任务 / 240 场景 / 2087 演示者，并做跨实验室人→机器人迁移研究。公司称机器人缺的是「经验」——「运动、接触、力、几何不在互联网上，无法 scrape/license/buy」。
  • 实际影响：具身智能「数据瓶颈」催生专属基础设施层——继第 78 跑 Rho 5B VLA、第 77 跑 DeepSeek 昇腾、第 76 跑具身触觉三连后，本条目指向「数据/部署层」这一被忽视的具身栈环节；与 Scale AI/Mercor 之于 LLM 类比，标志具身进入「数据标注工业化」阶段，为 Sim2Real 与跨本体迁移提供规模化真实信号。
指标（公司自述，待核实）：$60M B 轮 / 红杉领投 / NVIDIA+M12+高通+三星跟投 / EgoVerse 1362h / 80k episodes / 1965 tasks；$100M run-rate（2026-06）、年底目标 $300M 为公司自述。
资源：Mecka 公告；EgoVerse 论文（arXiv 2026-04-08 首投、07-07 修）。
