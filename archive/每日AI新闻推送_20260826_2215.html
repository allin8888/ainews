JetBrains 2026 开发者调查：Claude Code 反超 GitHub Copilot 登顶第一，90% 开发者已用上 AI 编程 Agent
JetBrains Research | 2026-08-26

JetBrains Research 发布《2026 年开发者生态系统调查报告》，覆盖全球超 1.5 万名专业开发者。Claude Code 工作场景使用率从 2026 年 1 月的 18% 飙升至 5–7 月的 39%，半年翻倍，直接反超 GitHub Copilot（降至 21%）。全球约 90% 专业开发者已每周至少使用一次 AI 编程 Agent，其中 68% 每天使用。

技术与工程价值

  • 核心机制：竞争重心从"谁的 AI IDE 更好用"转向"谁的 Agent 能真正接手开发工作"
  • 实际影响：Claude Code 崛起、Cursor 下滑（18%→12%），终端 IDE 形态正被云端 Agent 形态取代

关键指标

  • Claude Code 使用率 39% vs GitHub Copilot 21%（半年翻倍）
  • AI 编程 Agent 周使用率 90% / 日使用率 68%
  • OpenAI Codex 使用率从 3% 增至 16%，认知度从 27% 升至 65%

OpenAI 首款自研推理芯片 Jalapeño 首测：每瓦吞吐 1.9 倍于 GB300，年底极小规模部署
Hot Chips 2026 | 2026-08-25

在 Hot Chips 2026 大会上，OpenAI 硬件负责人 Richard Ho 首次披露与博通联合开发的推理芯片 Jalapeño 实测数据。采用 3nm 工艺，标称功耗 700W（仅为 GB300 的一半），在 SemiAnalysis InferenceX 基准测试中，三款公开模型（GPT-OSS 120B、DeepSeek R1 670B、Kimi K2.5 1T）每瓦峰值吞吐量达对比系统的 1.5–1.9 倍，端到端延迟降低 1.7–3.6 倍。

技术与工程价值

  • 核心机制：配备 6 颗 HBM4 内存（216GB 总容量），单一架构同时优化高吞吐和低延迟；二代芯片已接近流片，三代启动设计
  • 实际影响：自研芯片从 PPT 走向实测对标，每瓦性能优势直接拉低推理成本曲线；OpenAI 强调"补位"而非"脱钩"英伟达

关键指标

  • 每瓦吞吐 1.5–1.9x vs GB300；端到端延迟低 1.7–3.6x
  • DeepSeek R1 单用户生成速度最高约 700 token/s（vs GB300 约 169 token/s）
  • 极小规模部署 2026 年底，全面上量 2027 年

阿里千问 Qwen3.8-Flash 发布并开源：千亿总参仅激活 6B，训练成本降近 90%
阿里千问 | 2026-08-26

8 月 26 日晚，阿里发布并同步开源千问最新模型 Qwen3.8-Flash。采用全新下一代架构，千亿总参数仅激活 60 亿（6B）即可获得超越 Claude Opus 4.6 的前沿性能。训练成本较 Qwen3.7-Plus 骤降近 90%，推理成本每百万 Tokens 输入仅 1 元、输出 3 元，价格最低至 DeepSeek-V4-Flash 的 1/3。同日预告 23:00 开源 Qwen3.8-Flash-Next（基于下一代 Qwen4 架构的多模态 MoE）。

技术与工程价值

  • 核心机制：MoE 架构进一步优化，FP8 量化版本同步发布，适配本地部署需求
  • 实际影响：将全球模型性价比推至极致新水平，生产环境部署门槛大幅降低

关键指标

  • 训练成本降近 90%；推理成本：输入 1 元/M token，输出 3 元/M token
  • 超越 Claude Opus 4.6 性能，MoE 千亿总参 / 6B 激活
  • 魔搭社区开源，千问 AI 平台同步上线 API

光象科技发布物理原生世界模型 Phi-WM 1.0 ActEffect：让机器人学会"动作会带来什么后果"
光象科技 × 清华大学李升波教授课题组 | 2026-08-25

8 月 25 日，光象科技联合清华大学发布第一代物理原生世界模型 Phi-WM 1.0 ActEffect。有别于传统 VLA 模型（模仿学习）与生成式世界模型（统计预测），ActEffect 将世界模型转变为"训练时反馈器"，使机器人实质建立起"动作与物理后果"间的时序因果关系。三项技术创新：①从 MIP 获得可比较的完整动作提案；②依次优化避免虚假改进；③结果预测仅引入物理观测，不依赖语言任务目标。

技术与工程价值

  • 核心机制：训练期完成因果规律学习，推理阶段无需保留世界模型进行显式循环预测，实现轻量化推理，降低算力成本
  • 实际影响：具身智能从"模仿动作"走向"理解后果"，解决 Sim2Real 因果学习瓶颈；工业级 Phi-Bot X1 已完成 5 天连续 36 小时焊接上下料自主循环作业验证

关键指标

  • LIBERO 98.8% / LIBERO-PLUS 80.3% / RoboCasa-GR1 67.5% 平均成功率
  • 已在汽车制造真实场景完成验证，与多家头部汽车企业达成商业合作
#具身智能 #世界模型
