### 1. Claude Code 推出实验性 Code Mode——智能体可用 JavaScript 调用自有工具（Anthropic Blog | 2026-11-14）

- **事件**：Anthropic 为 Claude Code 上线了实验性 Code Mode，默认关闭。开启后，Claude Code 可编写 JavaScript 脚本来调用自身工具链（文件读写、shell 执行、浏览器操作等），实现"用程序驱动工具调用"而非逐次交互。Anthropic 称此举旨在降低多步复杂任务的 tool-calling 开销，但同时也承认"程序化工具调用比单次调用更难在运行前审查"，因此暂未默认开启。
- **为何值得关注**：这是编码 Agent 从"对话式单轮工具调用"向"可编程工作流"演进的关键一步。Code Mode 本质上让 Claude Code 具备了自编排能力，与 n8n Nod 等本地自动化 Agent 形成竞争又互补的格局。对开发者而言，复杂重构或多文件批改场景的效率有望显著提升；风险在于脚本级 tool-calling 的可解释性和安全性需要新的审计范式。
- **来源链接**：<https://www.anthropic.com/news/claude-code-code-mode>

### 2. n8n 发布 Nod——开源本地自动化 Agent，Apache 2.0 授权（n8n Blog | 2026-11-14）

- **事件**：n8n 发布了 Nod，一款可在 Mac、Windows 或私有服务器上运行的本地自动化 Agent，采用 Apache 2.0 开源协议，用户自主选择底层模型。Nod 在沙箱化浏览器环境中运行，数据完全保留在本地，成本仅为基础模型 API 调用费用，无订阅席位费。
- **为何值得关注**：在 AGI 叙事热捧 hosted Agent 的同时，Nod 代表了一条务实路线：自托管 + 自建模型选择权。对于重视数据隐私（金融、医疗、法务领域）和企业内部自动化场景，Nod 提供了一个低门槛的本地 Agent 入口。与 Anthropic Code Mode 相比，Nod 面向更广泛的自动化场景（非仅限编程），但深度和灵活性可能不及专用编码 Agent。
- **来源链接**：<https://n8n.io/blog/nod-local-automation-agent>

### 3. llama.cpp 发布 v1.0.0——正式启用语义化版本控制（Hugging Face / ggml-org | 2026-11-13）

- **事件**：Hugging Face 旗下的 ggml-org 团队于 11 月 13 日正式发布 llama.cpp v1.0.0 及 ggml v1.0.0，标志着该项目在诞生约 3.5 年后进入稳定期。新版本的重大变化是引入了语义化版本控制（Semver）：未来 API/ABI 破坏性变更将仅在主版本号升级时发生，为集成方提供明确的兼容性保证。
- **为何值得关注**：llama.cpp 是开源本地推理的事实标准栈，v1.0.0 的发布意味着生态将从"快速迭代期"进入"稳定维护期"。对部署者而言，Semver 大幅降低了依赖管理的不确定性；对商业产品（如 Ollama、LM Studio）来说，稳定的 ABI 保障也减少了适配成本。此举进一步巩固了开源本地 LLM 推理基础设施的行业地位。
- **来源链接**：<https://github.com/ggml-org/llama.cpp/releases/tag/v1.0.0>

### 4. Cloudflare 开源 Kitesurf——无状态浏览器引擎专为 AI Agent 设计（Cloudflare Blog | 2026-11-14）

- **事件**：Cloudflare 将 Kitesurf 浏览器引擎以 Apache 2.0 许可证开源。Kitesurf 运行于 Cloudflare Workers 之上，专为 AI Agent 的网页交互场景设计，具备无状态特性，允许开发者和社区直接检查、定制和部署。
- **为何值得关注**：AI Agent 浏览网页的能力一直依赖 Puppeteer/Playwright 等通用自动化工具，这些工具资源开销大且不适合大规模分布式部署。Kitesurf 的无状态架构使 Agent 浏览器操作可以水平扩展到 Cloudflare 的全球边缘网络，显著降低延迟与成本。这对需要大量网页抓取、表单填写、信息提取的 Agent 应用（如财经数据采集、竞品监控）具有实质性价值。
- **来源链接**：<https://developers.cloudflare.com/kitesurf>
