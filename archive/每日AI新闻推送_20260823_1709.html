#1

OpenAI Codex 周活突破 2000 万，增速超越 Claude Code 四倍

来源：OpenAI | 2026-08-22

事件概述

OpenAI Codex 负责人确认，Codex 本周活跃用户突破 2000 万，四周增速达 20.8%，约为 Claude Code（5.2%）的四倍。同日 OpenAI 宣布收购实时数据库 InstantDB 团队，强化 Agent 基础设施；并澄清 sub2api 用量扣减问题，承诺为受影响用户返还额度。

技术与工程价值

  • 核心机制：Codex 作为轻量级 Rust 终端编码代理，启动速度提升约 25 倍，支持文件读写、命令执行、代码审查等全链路工作流；v0.149.0 引入 Agents Dashboard，可在终端内搜索/管理后台任务。
  • 实际影响：AI 编程从"补全工具"演变为"自主执行工作流"，Codex 与 ChatGPT Work 双向打通，OpenAI 在开发者入口的领先优势进一步扩大。

关键指标/资源

  • 评测/性能：周活 2000 万，四周增速 20.8%（Claude Code 5.2%）
  • 代码/论文：github.com/openai/codex（11.3 万 Star）

#2

小红书开源 dots3-note 280B 大模型，华为昇腾当日完成零日适配

来源：小红书 dots 实验室 | 2026-08-23

事件概述

小红书 dots 实验室在海外发布 MoE 架构开源大模型 dots3-note preview，总参数 280B、激活参数 16B，支持 512K 上下文及文本、视觉、语音多模态理解。发布当天，华为昇腾 Atlas 800A3 与 900A3 SuperPoD 即通过 vLLM Ascend 完成 0 Day 适配部署。

技术与工程价值

  • 核心机制：采用 MoE（混合专家）架构，16B 激活参数可支持高效推理，同时保持 280B 总参数的丰富知识储备；推理、Agent 与多模态性能接近更大尺寸密集模型。
  • 实际影响：作为中国月活超 3 亿的内容平台，小红书自研并开源模型，标志着其 AI 能力从搜索/推荐升级为支撑整套产品体验的底层基座，充实中国开源大模型生态。

关键指标/资源

  • 评测/性能：总参数 280B / 激活 16B，512K 上下文，多模态（文本+视觉+语音）
  • 代码/论文：github.com/xiaohongshu/dots（Apache 2.0）
#开源模型 #MoE #国产算力

第二届世界人形机器人运动会开幕，9.39 秒百米超越博尔特纪录

来源：世界人形机器人运动会组委会 | 2026-08-22

事件概述

第二届世界人形机器人运动会在北京国家速滑馆"冰丝带"开幕，666 支队伍、2056 台机器人参与 51 个赛项 1301 场比赛。天卓队机器人以 9.39 秒打破博尔特 9.58 秒的男子百米世界纪录，天工 Ultra 跳出 2.88 米超越人类跳高纪录。本届赛事多项竞技取消人工遥控，全程全自主运行。

技术与工程价值

  • 核心机制：从"遥控"到"自主"的代际跃迁——模型需实时感知环境、独立决策、协调全身关节完成复杂运动，考验端到端感知-控制一体化能力与鲁棒性。
  • 实际影响：赛场表现直接映射产业水平：2026 上半年中国人形机器人出货量超 4 万台（全球占比 97%），行业从 POC 试点进入 PMF（产品市场契合）验证阶段，商业化窗口开启。

关键指标/资源

  • 评测/性能：百米 9.39 秒（超越人类纪录）、跳高 2.88 米、666 支队伍 / 2056 台机器人
  • 代码/论文：wrc2026.org（赛事官方信息）

#4

NVIDIA AVO 智能体在 ARC-AGI-3 取得 100% 满分

来源：NVIDIA Research | 2026-08-21

事件概述

NVIDIA 发布 AVO 通用编程 Agent 架构，在抽象推理与视觉理解基准 ARC-AGI-3 上取得 100% 满分（25/25 环境，183/183 关卡），而 Claude Opus 5 裸跑仅 30%。该成果通过持久记忆与监督器架构实现 3 倍性能跃升，补足 SWE-bench 难以覆盖的抽象推理能力评估。

技术与工程价值

  • 核心机制：AVO 将世界模型嵌入实时决策回路，通过持久记忆维持长程任务状态，监督器模块进行中间验证与纠错，6,624 次环境动作完成全部关卡。
  • 实际影响：证明架构创新可显著放大模型能力——仅 Harness 层面的优化（推理状态保留 + 上下文压缩）即让 GPT-5.6 Sol 在 ARC-AGI-3 上得分从 13.3% 升至 38.3%，输出 Token 压缩至六分之一。

关键指标/资源

  • 评测/性能：ARC-AGI-3 满分（100%），183/183 关卡通过
  • 代码/论文：github.com/NVIDIA/AVO-agent
#ARC-AGI #Agent架构 #推理基准

OpenAI 大幅下调 GPT-5.6 Sol API 价格超 20%，优惠期至 11/21

来源：OpenAI | 2026-08-21

事件概述

OpenAI 宣布 GPT-5.6 Sol 基准价格下调超 20%（输入 $5→$4，输出 $30→$20），优惠期三个月至 11/21。这是 OpenAI 首次对旗舰模型降价，美媒称系中国开源模型定价压力所致。同期 OpenAI 还收购 InstantDB 团队以强化开发者工具链。

技术与工程价值

  • 核心机制：API 定价策略调整反映 AI 基础设施层竞争加剧——中国开源模型（DeepSeek、Qwen、GLM）以极低价格抢占企业客户，倒逼头部厂商调整定价策略。
  • 实际影响：降低企业 Agent 项目运行成本，预计带动大量 AI 编程、自动化工作流应用门槛进一步下降；但也可能引发"价格战"导致高质量模型服务利润压缩。

关键指标/资源

  • 评测/性能：输入 $4/M token，输出 $20/M token（原价 $5/$30）
  • 代码/论文：openai.com/api/pricing/
#定价策略 #API竞争 #中国模型压力
