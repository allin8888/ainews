01Anthropic 发布 Claude Fable 5.2 与 Claude Mythos 5.2：同底模双品牌、降价 20%，agentic coding 与机器人仿真基准跃升

Anthropic 官方 ｜ 2026-11-09（官方 X 18:57:59 UTC，窗内）

事件概述：Fable 5.2 与 Mythos 5.2 为同一底层模型的两个发行版——Mythos 5.2 去除部分网络安全/生物防护、面向合格机构开放，Fable 5.2 保留防护面向全体用户。主打 agentic coding、推理与视觉，输出提速至多 30%，价格降至 $8/$40 每百万 token（fast mode 2.5x 提速档 $16/$80）。

技术与工程价值
  • 核心机制：同底模双品牌安全分级发行；preserved thinking 防蒸馏覆盖全部账号（阻止编辑先前上下文提取推理链）；Effort 分档默认 Medium；官方披露 Orchestrator 模式可将简单任务委派给更小模型。
  • 实际影响：官方自测 FrontierCode 2.0 49.1%（Xhigh，5.1 为 32.4%）、FrontierSWE v2 69.9%、Terminal-Bench-Science 0.1 74.6%；机器人仿真 RoboDojo Sim 64.9%（5.1 为 27.6%、Opus 5.5 为 39.4%）；费马大定理 Lean 形式化 30 小时完成（研究版旧纪录 11 天，Opus 5.5 完成 26–27%）；CVE 2026-10 批次 1,829 例全档位超 5.1 与 Opus 5.5；误报拦截约 -55%（网络安全 -60%、生物 -40%）。
  • 适用限制：官方自测口径（自述数据，未见第三方复现，第三方项另行标注）；RoboDojo Sim 为仿真评测，非真机；OSWorld 2.1 为 offline partial 子集。
  • 第三方核验：Artificial Analysis Intelligence Index v5 65 分登顶（AA 专文称「首个公开的 Mythos 级模型」）；ARC Prize 官方 ARC-AGI-2 93.8%；Arena Code Arena WebDev 1832 分登顶；官方页转引 Perplexity WANDR——Medium effort 约 40% 单任务成本匹配 Opus 5.5 最高分。
  • 生态：Claude Code v2.1.321 将 Fable 5.2 设为默认（GitHub Release 11-09）；上线 Cursor（CursorBench 默认档 56.9%）、Devin、OpenRouter（上架信息列 1M 上下文，待核实）、Perplexity、Google Cloud、Microsoft Foundry。

03蚂蚁灵波开源触觉基础模型 LingBot-Touch：JEPA 统一异构触觉表征，跨传感器/灵巧手零训练迁移

Robbyant 官方 X @robbyant_brain ｜ 2026-11-09 19:11:40 UTC（雪花解码复核一致）

事件概述：基于近 5,000 小时真实触觉数据预训练的 JEPA 触觉表征模型，统一磁传感器、压阻阵列与视触觉三类异构信号，支持跨传感器、跨灵巧手、跨任务与跨动作模型迁移。代码 Apache-2.0，Tiny/Small 权重发布于 Hugging Face 与 ModelScope。

技术与工程价值
  • 核心机制：模态专属 tokenizer（磁/压阻/视触觉）+ 共享 Haptic Transformer（5D RoPE 时空地址）+ EMA target encoder，潜空间掩码预测；token 携带时间/手指/空间地址，官方推荐 attention-based querying 读取而非逐 token 池化。
  • 实际影响：触觉信号首次进入「基础模型化」开源轨道。官方四性质：统一（多源异构互增强）、可迁移（预训练与下游传感器/真机手完全不同仍零训练迁移）、高效（最小 ViT 高频推理）、可扩展（数据增益持续）。
  • 适用限制：推理发布（frozen target encoder），未放训练代码；权重需账号权限下载；「近 5,000 小时」为官方 X 口径；GitHub 仓库 created_at 为公告前约 10 小时静默创建，首发以官方公告计。

05DeepX 二代边缘 AI 芯片 DX-M2 流片：LPDDR5X-PIM 协同，5W 内运行至多 100B 参数模型

EE Times 专访 ｜ 2026-11-09（HN 提交 18:33 UTC，136 分；官网新闻页暂无对应条目）

事件概述：韩国边缘 AI 芯片公司 DeepX 完成二代加速器 DX-M2 流片，搭配三星定制 LPDDR5x-PIM：在一代 DX-M1 相同的 5W 功耗预算内运行 20B–100B 参数模型（约 3B–20B 激活）达 10–30 tokens/s，并将机器人库 Newton 定位为 Nvidia Isaac 的 API 兼容替换。

技术与工程价值
  • 核心机制：内存带宽 50→150 GB/s；NPU 效率经设计改进与 2nm 制程各翻倍；GEMV 卸载至 PIM 仿真下 Llama3.1-8B tokens/s 6.7x（需 2.7x 总功耗，同功耗内预计 2x）；支持投机解码与 TurboQuant，80 TOPS。
  • 实际影响：官方称 5W 可进入无人机与一切电池供电设备；Isaac 管线 API 切换至 Newton 官方称续航约 20x、切换 <1 秒；PIM 将成 LPDDR6 JEDEC 标准，DX-M3（2028，chiplet）原生支持。
  • 适用限制：全部指标为 DeepX 仿真/自述（自述数据，未见第三方复现）；PIM 编译器未完成（现需大量手工优化，原型编译器仅运行于仿真）；6.7x 附带功耗条件，不得与同功耗方案直接排名；样品 2027-03、量产 2027 秋均为计划口径。
