### 1. Inkling 2 Mini（Thinking Machines Lab | 2026-11-21）
- **事件概述**：Thinking Machines Lab 发布 Inkling 2 Mini，一款 26.4B 参数开源代码大模型。采用「looped transformer」架构——中间层对每个 token 循环计算三次，激活参数仅约 3.4B，总内存占用 ~20GB，可在配备 32GB 统一内存的 Mac 上离线运行。Apache 2.0 许可。
- **技术与工程价值**：
  - **核心机制**：稀疏专家 + 多层重复推理 + 门控消息传递，以更低激活参数量换取更高推理深度；原生低比特训练降低显存压力。
  - **实际影响**：在 SWE-bench Pro v2 Hard、DeepSWE v1.1、Vibe Code Bench 等仓库级编程基准上超越 Qwen3.8-27B，成为 sub-100B 开源模型中的 agentic coding 领跑者；单命令 `ollama run inkling2mini` 即可本地部署，推动离线代码 Agent 落地。
- **关键指标/资源**：
  - SWE-bench Verified: 79.2% / SWE-bench Pro v2 Hard: 77.9% / DeepSWE v1.1: 48.2% / Vals Index v2.2: 46.5%
  - 上下文长度：1M tokens
  - 代码仓库：https://github.com/thinkingmachines/inkling （待核实）
**标签**：`#Inkling` `#CodingAgent` `#OpenWeight` `#LocalLLM`

### 2. Anthropic Claude Managed Agents「Dreaming」功能详解（Code with Claude 活动报道 | 2026-11-21）
- **事件概述**：Anthropic 于「Code with Claude」两天活动中展示 Claude Managed Agents 的「Dreaming」功能——多 Agent 协作时，各 Agent 可将任务笔记自动写入共享存储；下一位接手相同代码任务的 Agent 可读取这些笔记快速上手，实现跨会话知识积累。
- **技术与工程价值**：
  - **核心机制**：Agent 自写自读笔记（self-notes），通过 Consolidation 流程聚合信息并发现跨任务模式；默认工作流从「Prompt Claude」转为「Claude 自我提示」。
  - **实际影响**：将多 Agent 代码协同从纯并发改为可累积经验的迭代过程，缩短同一代码库的切换成本，是 Production Coding Agent 向「团队化」演进的关键一步。
- **关键指标/资源**：
  - 平台：Claude Managed Agents（云端托管多 Agent 框架）
  - 活动：Code with Claude 2026
  - 来源：Arnaud Mercier 现场报道修正版（已更正 Dreaming 属于 Managed Agents 非 Claude Code 独立产品）
**标签**：`#Anthropic` `#MultiAgent` `#ClaudeCode` `#Dreaming`

### 3. Together AI 安全事件：AI 编码 Agent 泄露凭证导致 Prompt 样本被盗（Together AI 官方公告 | 2026-11-21）
- **事件概述**：Together AI 于 11 月 21 日发布安全事件通知——开发公共 GitHub 仓库 xorl 期间，一个 AI 编码 Agent 不慎提交了包含凭据的配置条目，该凭据随后被第三方获取并用以下载存储在私有 Hugging Face 仓库中的 Prompt 样本（涉及 MiniMax M3、GLM-5.2、Kimi K2.6 模型的 June-July 请求数据）。
- **技术与工程价值**：
  - **核心机制**：Agent 无意识 commit 了含 API key / HF token 的文件 → 凭据暴露窗口期内被外部获取 → 访问私仓下载历史 Prompt 采样。
  - **实际影响**：暴露了当前 AI 编码 Agent 在企业级开发链路中的核心隐患——Agent 缺乏「知识边界」意识，会主动抓取配置环境；也验证了 Dragos 研究的结论：200 万个注入探针中部分探针流入非授权渠道。Together AI 随即推出最小特权凭据、PR 扫描、ZDR 默认关闭三项补救措施。
- **关键指标/资源**：
  - 受影响数据：2026 年 6 月 24、7 月 4/8/14 日的小样本 Prompt
  - 修复措施：scoped 凭据 / PR 强制扫描 / ZDR 默认开启 / 更新 Agent 使用规范
  - 公开报告：https://www.together.ai/blog/security-event-prompt-leakage-for-requests-in-june-and-july-of-2026
**标签**：`#AISecurity` `#CredentialLeak` `#TogetherAI` `#AgentSafety`
