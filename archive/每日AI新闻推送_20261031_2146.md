### 1. DeepSeek 发布 Super-agent 架构并开源 dsh-superagent-prototype：Router 常驻分派 + Worker 隔离并发，任务完成 P95 15.7 分钟对单 Session 29.5 分钟（GitHub deepseek-ai/dsh-superagent-prototype + DeepSeek Harness 团队文章 | 2026-10-31 BJ 17:32 建仓 / 20:05 首发提交）

**事件概述**：
DeepSeek Harness 团队发布《Super-agent 设计探索：迈向更自主的 Agent 系统》（英文题名 *Exploring Super-agent Design: Towards a More Autonomous Agent System*），把 Agent 从「用户手动开的单次会话」中解绑，定义为跨信道常驻、可并行推进多任务的连续实体：上层 Router 承接人类交互、维护全局上下文并分派任务，下层 Worker 在相互隔离的会话中并发执行，只向 Router 汇报、不直接对用户说话。同步以 MIT 协议开源研究原型 **dsh-superagent-prototype**——面向单个 GitHub 仓库的 proactive coding agent，监听 GitHub（可选飞书），在独立会话与工作目录中干活并以 Pull Request 交付。一手时点取证：仓库 `created_at = 2026-10-31T09:32:46Z`（北京 **17:32:46**），首发提交 `feat: add the dsh-superagent research prototype` 于 `2026-10-31T12:05:39Z`（北京 **20:05:39**），均落在窗口内；检查时 star 325。

**技术与工程价值**：
- **核心机制**：五模块撑起「连续 / 高效 / 主动 / 持久」四个特征——① 双层架构：Router 只做序点（Sequence Point）、协调与记忆，可用轻量模型甚至省掉 Bash 工具；Worker 决定结果与代码质量，配最强模型 + 全套工具，内部可再开 Subagent 或本身就是一个 Agent Team，对上层透明。② 事件驱动：群聊消息、邮件日程、代码评审评论、CI 结果统称 **Trigger**，先经程序层 Fast Path（来源/群组/白名单准入）过滤，再交语义层 Slow Path（模型按提示词策略判断）；同一话题或同一 PR 的连续事件构成 **Thread**，Worker 直接订阅 Thread，后续事件绕开 Router 直达（订阅关系多对多，两个 Worker 改同一 PR 时互见提交、自行解冲突）。③ 上下文侧把窗口当 Cache 管：**Inline & Spill**（近期信息内联、超预算内容留窗口外只留引用/摘要，长内容先给前 50 字并留「续读」入口）+ **链式召回 Chain of Recall**（Trigger/Thread/Worker Session 各配唯一 ID，沿引用图逐跳找回旧任务上下文）。④ 提前行动：借**投机执行**——群里讨论 Bug 时后台先复现、找修复，只有确认问题且找到简单修法才交付，否则全程安静；交互侧把耗时工具调用改成异步 `start()`/`stop()` 构成全双工异步 ReAct Loop（已在 DeepSeek Harness 实现但未默认开启），IM 信道单次回复限 100 词以内、PR/邮件信道写结构化交付。⑤ 长期在线：借鉴**存算分离**，Agent Loop 计算放云端无状态容器、会话状态进数据库，执行环境留在原地由端侧轻量 daemon 承接命令，支持 BYOM（把日常开发机接给云端 Agent）、也支持接云端托管机或按需环境，设备重新上线后自动续跑等它的任务；另设独立 **Watchdog Session** 作外部控制回路，既查接口报错/状态恢复失败，也用模型判断 Worker 是否取得实质进展、是否偏离目标并可在线改主系统提示词与触发规则。
- **实际影响**：把「一个人同时能跟几个 Agent」从用户注意力问题（官方观察：一个人通常只能同时跟进 3–5 个活跃 Session）转为系统调度问题；同一套骨架同时覆盖研发协作（问题复现、PR 评审、新功能并行）与个人助手（一个聊天框里按话题各派 Worker）。官方自列未解问题：Router 层水平切分粒度与层内协作拓扑、跨月长程记忆、脱离 Session 后的人机中途接管、实例间 A2A 通信，以及安全隐私——云端 Agent Loop 一旦因服务端入侵或提示词注入失守，连着的端侧设备（未提交改动、私有凭据、内网服务）都有被控制风险。团队同时坦言思路来自计算机系统经典工程思想（Fast Path、缓存、局部性、投机执行、存算分离）而非全新理论。
- **工程提示（读代码前须知）**：README 明示「研究原型、参考用途，非 DeepSeek 正式产品；大量工程由 coding agent 完成，可能含 bug、代码风格与工程实践不一致」，且已为公开做改编、与内部版本及文章描述的实现并不等同，文中部分设计属未来方向未实现；安装流程本身设计为交给编码 Agent 执行（`Read SETUP.md in this repository and set up dsh-superagent with me.`）；文档为编号体系 docs/000-philosophy → 008-cookbook。
