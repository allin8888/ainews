02LangChain 公开 Deep Agents 浏览器工具优化复盘：七套工具对比选定 Stagehand，WebVoyager 90% 通过仅 $1.98

LangChain 官方博客 ｜ 2026-11-03

事件概述

LangChain 发布工程复盘，对比七套浏览器工具集后为 Deep Agents 选定 Stagehand（Browserbase）并重建浏览器工具层：代码模式 run（Playwright 式链式调用，中间上下文不进模型窗口）、以 accessibility tree 快照替代截图、settle wait（固定 sleep 改为页面静默 500ms 即返回）、结构化 JSON 输出与单往返批处理，并公布三套基准的完整对比数据。

技术与工程价值

  • 核心机制：Agent 浏览器瓶颈不在模型而在工具层往返开销——快照中位 117 字符 vs 托管工具 ~17,000 字符、单任务模型轮次 10 vs 26、8 秒固定等待压缩到 0.6 秒；把浏览器动作编译成代码块批量执行是 token 成本下降一个数量级的关键。
  • 实际影响：为 Agent 浏览器工具选型提供可复用的评测方法学（WebVoyager / HardBench / WebTailBench 三基准 + 成本口径），Playwright MCP 与代码模式工具的 13 倍成本差是 Agent 工程选型的直接参考。
