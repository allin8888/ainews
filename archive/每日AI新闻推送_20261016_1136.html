1. Meta 开源 Muse Spark Open：816B MoE 智能体编码模型，NVFP4 权重上线 Hugging Face

NVIDIA 技术博客 / Hugging Face·2026-10-15
事件概述

10 月 15 日，Meta 发布 Muse Spark Open——面向智能体编码（agentic coding）的 816B 总参 MoE 模型（每 token 激活 42B，256 专家 top-8 路由），权重以 NVFP4 格式上线 Hugging Face；NVIDIA 同步发布 GB300 NVL72 平台部署技术博客。这是 Muse 系列继 8 月 30B dense 模型 Muse Glimmer 之后第二个开源 release。

技术与工程价值
  • 核心机制：稀疏 MoE 以约 1/20 的激活参数提供前沿级智能体能力，规避同规模 dense 模型的 serving 成本；1M token 上下文可整体装入含依赖与遗留代码的完整代码库；1.8B 感知编码器单趟处理交叠文本/图像/视频帧/音频；goal-conditioning 机制维持长会话方向，context compaction 在长运行会话中保留关键信息；支持多模态网页浏览、派生并协调子代理、跨桌面/移动/浏览器环境操作计算机，且每个动作前生成解说文本。
  • 实际影响：首次将 Muse 开源线从单卡 dense 小模型扩展到前沿规模稀疏架构；NVIDIA 提供 SGLang / vLLM / TensorRT-LLM 部署、NIM 生产容器与 NeMo AutoModel 后训练（SFT/LoRA）全栈路径，Megatron Bridge 支持大规模生产训练格式转换。
关键指标/资源
  • 评测/性能：SemiAnalysis AgentX 基准 >50,000 tokens/GPU/s、>600 tokens/user/s（4×Blackwell + 投机解码，NVIDIA 自述数据，未见第三方复现）；官方未披露标准软件工程基准对比数据
  • 代码/论文：huggingface.co/meta-models/Muse-Spark-Open-816B-A42B-NVFP4；NVIDIA 博客 developer.nvidia.com/blog/scale-agentic-coding-workflows-with-metas-muse-spark-open-on-nvidia-gb300-nvl72/">developer.nvidia.com/blog/scale-agentic-coding-workflows-with-metas-muse-spark-open-on-nvidia-gb300-nvl72/

2. 阶跃星辰开放 Step 5 Preview 权重：600B/27B 激活 MoE，92 层窄深架构技术博客同步上线

阶跃星辰官方公告 / Hugging Face & ModelScope·2026-10-15
事件概述

10 月 15 日，阶跃星辰正式释放 Step 5 Preview 的 BF16 与 FP8 权重、技术博客与配套开源开发工具，兑现 9 月模型发布时承诺的开源时间表。该模型面向长程 Agent 任务设计，权重已上线 Hugging Face 与 ModelScope。

技术与工程价值
  • 核心机制：600B 总参 / 27B 激活稀疏 MoE，原生支持文本与视觉输入，1M token 上下文；92 层「窄而深」架构为隐式多跳推理提供更多计算步，同时压低参数与计算量；Sparse GQA 以 8 token 分块索引将索引与 top-k 选择开销降至 1/8；FP32 key states + 细粒度梯度裁剪保障深网训练稳定；在约 100 万个可验证环境（软件工程、科学推理、ML 研究、专业知识工作）上做长程任务 RL；上下文压缩纳入端到端策略训练，Agent 学会整理任务状态并继续执行，并配长轨迹细粒度奖励归因。
  • 实际影响：截至 10 月 15 日列 OpenRouter token 用量周榜与日榜全球第二（发布方引用平台数据）；FP8 checkpoint 单节点 4×B300 或 8×H200 可部署，BF16 需 8×B300 或双 8 卡 H200 节点；开发者可以 vLLM / SGLang 部署 OpenAI 兼容 API，或以 Transformers 离线推理接入自有数据与工具链。
关键指标/资源
  • 评测/性能：OpenRouter 周/日调用量榜全球第二（截至 2026-10-15，OpenRouter 平台数据，发布方引用）；「AI 编程、软件工程、专业知识工作、金融场景表现突出」为发布方自述

3. Perplexity 开源 SPACE：生产级 Firecracker microVM Agent 沙箱，108 次红队攻击零逃逸

Perplexity 官方公告 / GitHub·2026-10-15
事件概述

10 月 15 日，Perplexity 宣布以 Apache 2.0 开源 SPACE（Sandboxed Platform for Agentic Code Execution）——支撑 Perplexity Computer 全部会话的 Agent 代码执行沙箱平台，代码与托管文档上线 GitHub。

技术与工程价值
  • 核心机制：每个沙箱独立运行于 Firecracker microVM，隔离边界落在 hypervisor 层而非容器命名空间；「模板→沙箱→命令会话」三层模型中，命令输出经独立数据平面连接以会话级 attachment token 传输，生命周期操作异步化（返回 operation id 轮询）；凭证支持 BYOK，仅在使用瞬间注入且从不落入沙箱；快照/检查点以增量变更存储，支持暂停/恢复/分支，滚动快照保留一周；Rust 实现、HTTP/SSE 对外接口，附 E2B 兼容封装。
  • 实际影响：继 Chainguard Workspaces（10-14）与微软 Execution Containers GA（10-09）之后，「编码 Agent 运行环境安全化」主线再添一个经过生产规模验证的参考实现；红队测试专门覆盖 OpenAI/Hugging Face 事件同类的网络绕过技术；CoreWeave 与 Akamai 已上架运行，Crusoe 合作接入托管 AI 服务。
关键指标/资源
  • 评测/性能：沙箱创建中位延迟约 60ms（此前 185ms，降幅约 2/3，Perplexity 自述）；2026 年 9 月红队 108 次利用尝试无一实现 VM 逃逸（发现少量网络策略绕过并已修复、复测未再成功——自述安全评估，未经第三方独立复现）；投产以来数百万次沙箱创建、数千万次重连事件（自述）
  • 代码/论文：github.com/perplexityai/SPACE">github.com/perplexityai/SPACE

4. NVIDIA 开源 Nemotron 3.5 Super VL 与 Bolt 边缘模型：120B MoE 智能体多模态，权重数据集配方全开

NVIDIA 官方博客·2026-10-15
事件概述

10 月 15 日，NVIDIA 发布开源 Nemotron 3.5 Super VL——120B 总参 / 12B 激活的 MoE 多模态智能体模型，同时发布面向边缘与本地硬件的 Nemotron 3.5 Bolt 74B-A9B 24GB；更小的 Bolt E4B 4GB 定档 10 月 23 日。

技术与工程价值
  • 核心机制：Super VL 从 Nemotron 3 Ultra 蒸馏（SkewReverse loss 用于提升编码精度），后训练采用多教师 on-policy 蒸馏；推理、指令遵循、工具使用与文本/图像/文档/视频理解合为单一系统，视觉训练面向 OCR、表格、图表及网页/PDF 等结构化文档；提供 base / post-trained / NVFP4 三种 checkpoint，NVFP4 采用 4-bit 权重激活 + 量化感知蒸馏；LiLiCorr 开放投机解码在 DGX Spark 上最高 2.3x 加速；multi-token prediction 内置 drafter；context-reuse serving 跨重复 Agent 调用保留 attention cache 与 Mamba 循环状态。
  • 实际影响：权重、数据集与训练配方全开，含与 IIT Madras / AI4Bharat 共建的 22 种印度语言约 2.8T token 数据集；Bolt 74B 以原生 2-bit 量化塞入 24GB 显存，配合 10 月 16 日到货的 RTX Spark 笔记本；生态侧 Scale AI 为 Skydance 供应商金融 Agent 与 EY 并购尽调 Agent 后训练（推理成本降 40x、延迟降 5x，自述），Mercor 在 APEX-SWE 编码基准上后训练编码 Agent，Atlassian / CrowdStrike / Perplexity / Dassault Systèmes 等集成。
关键指标/资源
  • 评测/性能：Hermes Bench 63.44%（Nemotron 3 Ultra 为 56.33%）、LangChain 行为评测 87.05%（84.3%）、CharXiv 80.8%（Nano Omni 63%，启用代码解释 84%）——均为 NVIDIA 自述；EXO Labs 独立评测称其位于 DGX Spark 准确率-任务完成时间 Pareto 前沿

5. Figma Code Layers 开放公测 + Specs 画布：把 AI 编码代理接进设计工作流

Figma 官方公告 / Config India·2026-10-15
事件概述

10 月 15 日，Figma 在首届 Config India 大会宣布 Code Layers 从私测转入全账号层级公测，同步推出 Markdown 画布编辑器 Specs（公测）与 Guidelines（公测），并为 AI 代理提供设计系统上下文。

技术与工程价值
  • 核心机制：Code Layers 把可运行软件组件直接嵌入设计画布，支持从 GitHub 仓库导入项目、视觉设计与功能代码并排比较，并指挥 AI 代理生成或修改执行代码；Specs 作为画布上的协作文档面，集中定义设计系统规范、实现规则与项目上下文，供人类协作者与已连接 AI 代理共同消费，可直接引用画布框架并嵌入 FigJam 图与实时代码组件；MCP 支持扩展至 20+ 外部工具（含 Open Code、Grok Bot 等），Specs 与 code layers 可经 MCP 导出或通过自动化 GitHub PR 回流开发环境。
  • 实际影响：设计到前端代码的翻译损耗被显式工程化；与 Payload（headless CMS）集成为 Figma Make 原型提供托管后端（管理界面、数据库、认证）；标志 Figma 从图形设计工具向 AI 驱动软件开发基础设施转型。
