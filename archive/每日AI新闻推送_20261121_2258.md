### 1. Thinking Machines 开源 Inkling 2 Mini：26.4B 循环 MoE、约 20GB 可在 32GB Mac 本地跑，SWE-bench Verified 79.2%（官方博客 / Hugging Face | 2026-11-21）

**事件概述**：
Thinking Machines Lab 于北京时间 11 月 21 日 04:10 通过官方账号发布 Inkling 2 Mini——一个开放权重的循环 Transformer（looped transformer）MoE 模型，把中间层每 token 复用 3 次以增加「每 token 推理量」而不增加参数存储。模型总参数 26.4B、激活 3.4B（含循环约 5.4B 权重激活），权重约 20GB，可在 32GB 内存 Mac 或单台 NVIDIA DGX Spark 上运行，Apache 2.0 许可同步开放，主打本地 Agent 编码与工具调用。

**技术与工程价值**：
- **核心机制**：24 个存储层分为 4 组各 6 层，首尾各 1 组只运行 1 次，中间 2 组（12 层）共享权重运行 3 次，形成每 token 48 次层应用；每次循环通过「Attention Residuals + 学习门控」接收上一轮消息。MoE 每 token 从 128 专家中选 8 个。训练从每层 384 专家起步，中期剪枝保留 128 个再用 1T token 蒸馏修复；大部分权重原生 NVFP4、末 4 层 MXFP8，省去量化转换损失。同步发布可变循环研究模型 TML-d24-varloop-research，用于可监控性（monitorability）实验。
- **实际影响**：把「推理时计算（inference-time compute）」从提示/采样层面下沉到架构层面——用权重复用换深度，而不增加 checkpoint 体积。官方称循环中间层在 27/28 项评测优于循环末层；可变循环模型的「无 CoT 时间跨度」从 1 pass 的 16 秒提升到 3 pass 的 37 秒，且 CoT 随循环变短仍可读、未出现 agentic sabotage 上升，为「推理可见性与可控性」提供首批可研究的循环架构模型。对本地化 Agent 编码而言，20GB checkpoint + Apache 2.0 显著降低自托管门槛。

**关键指标/资源**：
- 评测/性能（均为官方自述，未见完整第三方复现）：SWE-bench Verified 79.2%（bash only）、SWE-bench Pro v2 Hard 77.9%、DeepSWE v1.1 48.2%（Qwen3.8-27B 自报 42.2%）、Terminal-Bench v2.1 71.6%、BrowseComp 79.0%、MCP Atlas 82.7%、GPQA Diamond 86.6%；AA Intelligence Index 20.1（与 Qwen3.8-27B 并列）；Stanford Intelligence-per-Watt 在 DGX Spark 上 0.703（对比 Qwen3.6-35B-A3B 0.430、Gemma-4-26B-A4B 0.159）。短板：HLE-Diamond 15.2%、MultiChallenge 50.0%、AA-Omniscience -8.6。
- 代码/论文：官方博客 https://thinkingmachines.ai/news/inkling-2-mini/ ；权重 https://huggingface.co/thinkingmachines/Inkling-2-Mini ；模型卡 https://thinkingmachines.ai/model-card/inkling-2-mini/ ；Attention Residuals 论文 arXiv:2603.15031
- 适用边界：官方所列 32GB 为 Mac 内存下限、Ollama 构建为 0.40.17 预发布；跨厂商基准的 harness 与设置不同，差距仅为方向性参考；中文输出可能截断或混英、agent 可能未询问即删改文件。

### 2. Anthropic 数学家称与 Claude 合作证明广义黎曼猜想，同日出现纯人类竞争草稿且两份证明均被指出问题（alpo.ge 声明 / The Decoder | 2026-11-21）

**事件概述**：
Anthropic 数学家 Levent Alpöge 于 11 月 20 日（美东周五）宣布，其与 Claude 合作得到黎曼猜想（RH）及广义黎曼猜想（GRH）的证明，证明仅以 Lean 语言发布、分 14 个数据包，打印将超 25 万页。数小时后，斯坦福数学教授、AMS 主席 Ravi Vakil 转发数学家 Alessandro Masullo 的独立「全人类、无 AI」GRH 竞争草稿。事件在窗口内持续发酵（AI HOT 首波 11-20 22:40Z，跟进 11-21 05:02Z / 11:19Z）。

**技术与工程价值**：
- **核心机制**：Alpöge 与 Claude 扩展数学家 Stepanov 的方法，用串联特殊数学变换模拟「对整数求导」的效应；关键洞察由语言模型给出——长度为 X 的数列需串联恰好 √X 个变换。证明以 Lean 形式化，由「数字裁判」逐步校验逻辑推导，但初始问题是否被正确编码为人类易错点。
- **实际影响**：若任一证明成立，将使数百篇以 RH 为前提的论文转为定理，并波及密码学、随机矩阵与物理。更重要的信号是 AI 在「自主攻克百年开放难题」上的角色跃迁：Alpöge 称在复杂子领域 Claude 已远超其本人；同时事件暴露「AI 证明的可验证性瓶颈」——证明体量超出人类可阅读范围，只能依赖形式化校验与社区长时间梳理。

**关键指标/资源**：
- 评测/性能：证明规模 >250,000 页（打印口径），Lean 形式化分 14 个数据包；原始声明 https://alpo.ge/remark.pdf ；跟进报道 https://the-decoder.com/hours-after-anthropic-claims-a-claude-proof-of-the-riemann-hypothesis-stanford-releases-an-all-human-competing-draft/

### 3. Baseten 开源 bison-1 / groundhog-1 决策模型：基于 Gemma 4、登顶 AA Decision Index v2.1，Brier 0.14（官方博客 / Hugging Face | 2026-11-20）

**事件概述**：
Baseten（Base Labs）于 11 月 20 日发布并开源两款决策模型 bison-1 与 groundhog-1，首次改用 Google Gemma 4 作为「美国本土骨干」。决策模型不生成文本，而是在单次 prefill 内对 yes/no、选项、打分类问题返回校准概率，用于路由、分诊、护栏与欺诈检测等工程管线。bison-1 以 76 分位列 Artificial Analysis Decision Index v2.1 第 1（共 19 款），开放 BF16 权重。

**技术与工程价值**：
- **核心机制**：bison-1 为 31B dense（Gemma 4 31B 后训练），groundhog-1 为 26B MoE、约 4B 激活（Gemma 4 26B-A4B）；上下文从上一代 16k 提升 8 倍至 128k 并支持图像输入。校准提升主要来自训练数据中扩大「软标签」占比（教模型输出「83% 选 A、17% 选 B」而非硬 100%），配合 Gemma 底座，把 Brier 分数压到 0.14（d1.2-ultra 为 0.15）。
- **实际影响**：把「决策/路由」从大模型的自然语言输出中解耦为专用小模型，是 Agent 基础设施层的工程化细分——128k 上下文意味着完整策略与历史可单次入参，无需截断或摘要；bison-1、mammoth-1、elephant-1 共同占据 AA 准确率-时延 Pareto 前沿。权重 MIT + Apache 2.0 开放，便于自托管路由/护栏管线。

**关键指标/资源**：
- 评测/性能（AA 与官方自述，未见独立复现）：bison-1 Decision Index v2.1 76 分（第 1/19，领先 d1.2-ultra 的 75、mammoth-1 的 71）；六项子榜中四项第 1（When2Call 98、EvalSafe-O*NET 93、AA-Symmetry 89、HLE-MultiChoice 51）；Brier 0.14；LongMemEval M(128k) 84.8；定价 $0.10 / 百万输入 token，groundhog-1 $0.035。训练用 192 / 128 张 B200。
- 代码/论文：官方博客 https://www.baseten.co/blog/meet-bison-1-and-groundhog-1/ ；权重 https://huggingface.co/baselabs/bison-1 与 https://huggingface.co/baselabs/groundhog-1
- 适用边界：groundhog-1 尚无官方 Index 分数（官方预计与 mammoth-1 相当）；所有数字为厂商自述；知识密集型决策为弱项（AA-Omniscience-Decision 60，第 11）。

### 4. 近 200 万条诱饵请求揭开 AI 供应链隐私漏洞：三家服务商现入侵迹象，「零数据保留」亦失效（Dragos 官方博客 / Ars Technica | 2026-11-21）

**事件概述**：
安全公司 Dragos 首席研究官 HD Moore 向多家 AI 服务商发送近 200 万条带可追踪「金丝雀（canary）诱饵」的请求，用于观察测试秘密是否被后续程序或人用于访问系统。Ars Technica 于 11 月 21 日报道该研究，发现 AI 服务链存在提示词被窃、转售商外传数据与隐私设置未被执行三类问题。

**技术与工程价值**：
- **核心机制**：以「人工投放的可追踪测试秘密（非真实用户数据）」作为探针，追踪其是否在服务商链路中被滥用——攻击者是否用窃取的密钥发起云 API 调用、是否有中间商记录并外传请求、标记「零数据保留/禁止收集」的请求其私密 URL 是否仍被抓取。
- **实际影响**：把「AI 供应链安全」从推测变为可测量问题——数据经多层中间商转手、在各环节解密，使「零数据保留」承诺形同虚设；至少三家服务商出现遭入侵迹象，部分诱饵密钥提交后数小时即被使用，甚至有请求在模型运行前被拒绝、其中密钥仍被盗。对使用 AI Agent 处理敏感业务的企业，结论直指「本地部署或直连可信服务商并显式指定上游」的必要性，与本期「Agent 能力增长快于安全治理」的主线呼应。

**关键指标/资源**：
- 关键发现：近 200 万条诱饵请求；至少 3 家服务商出现入侵迹象；被盗密钥发起数万次云服务接口调用；部分「零数据保留」请求的私密 URL 数日后仍被抓取。
- 来源：Dragos 官方博客 https://www.dragos.com/blog/ai-supply-chain-security-canary-tokens ；Ars Technica 报道（经 IT之家 11-21 转述 https://www.ithome.com/1/030/322.htm ）
- 适用边界：研究为厂商自述，未点名具体服务商；诱饵为人工投放，反映的是链路泄漏可能性而非真实用户数据泄露规模。
