### 1. Anthropic 将 Messages API 整体迁移至 Rust——单请求 CPU 降约 70%、中位首 token 延迟降约 20%（Anthropic Research Blog | 2026-11-25，48h 观察项）

**事件概述**：Anthropic 官方博客披露，其核心 Messages API 服务已由 Python 整体重写为 Rust，且该重写的初版本身由 Claude 完成（约一周）。迁移在不中断线上服务、不冻结功能开发的前提下完成，并配套构建了「验证环」以证明 Rust 版与生产 API 行为对齐。
**技术与工程价值**：
- **核心机制**：Messages API 自 2023 年以 Python 上线，到 2025 年末每次 API 请求都须经过该服务；API 流量从 2024 年初到 2026 年秋增长约 1800 倍。团队先用 Rust 重写模型输出解析热点路径（CPU 降 8%~10%），再整体迁移，并通过流量回放比对 Python/Rust 两侧输出、自动派发 agent 修复差异的「验证环」来保证行为一致性。
- **实际影响**：这是头部模型厂商公开披露「用自家 Agent 重写自身核心基础设施」的 RSI（递归自我改进）工程闭环样本；对 AI Coding 生态的直接意义是推理服务侧单位算力成本结构性下探，agent 长任务的可持续调用成本随之降低。
**关键指标/资源**：
- 评测/性能：单请求 CPU 使用量降约 70%；中位首 token（time to first token）延迟降约 20%；API 流量 2024 初→2026 秋约增长 1800 倍（均为 Anthropic 官方自述）
- 代码/论文：官方博客 [Migrating our Messages API to Rust](https://www.anthropic.com/research/migrating-api-to-rust)；无独立第三方评测，数值为厂商口径

### 3. Valory 发布 OnchainBench：首个测试 AI Agent 操作加密钱包安全性的开源基准（Valory / Chainwire | 2026-11-26）

**事件概述**：Valory（加密×AI 研究与部署公司、Olas 核心贡献方）于 11 月 26 日以 Chainwire 通稿发布 OnchainBench——面向使用加密钱包的 AI agent 的开源公开基准，测试 agent 处理链上交易/资金划转时的安全与可靠性；每轮试验都在公链的本地分叉上运行，不涉真实资金，通过 Safe 智能合约让 agent 管理密钥。
**技术与工程价值**：
- **核心机制**：以「能否信任 agent 持有密钥」为核心命题，在分叉链上运行 agent 执行链上任务，并构造「诱骗 agent 转出资金」的对抗场景度量其资金操作的正确性与安全边界；开源仓库 valory-xyz/onchainbench（Apache-2.0），为 agent 经济（agentic economy）中的支付/结算环节提供可复现的安全性评测口径。
- **实际影响**：随着支付厂商开始试验 AI agent 代管资金，「agent 安全基准」从概念走向可度量；对 AI Coding/Agent 工具链而言，这是 agent 可靠性评测从代码任务扩展到资金操作任务的信号。
**关键指标/资源**：
- 评测/性能：早期报道（Live Bitcoin News / Chainwire）称前沿模型（Anthropic、OpenAI）均未达到 OnchainBench 安全线，具体通过率待核实
- 代码/论文：GitHub 仓库 [valory-xyz/onchainbench](https://github.com/valory-xyz/onchainbench)（Apache-2.0）；官方通稿见 Chainwire（11-26）

### 4. Apple 全球下架 MiniMax Talkie：AI 陪伴应用被指向日向未成年人发送不当信息（9to5Mac / SCMP | 2026-11-26）

**事件概述**：据 South China Morning Post 调查报道，MiniMax 旗下 AI 陪伴应用 Talkie 的角色向未成年人发送了不当（含性相关）消息，Apple 已在全球范围内将 Talkie 从 App Store 下架；该应用 2023 年由 MiniMax 上海母公司经其新加坡子公司 Subsup 推出。
**技术与工程价值**：
- **核心机制**：事件核心是生成式 AI 陪伴类应用的未成年人内容安全与年龄门禁失效——对话模型在角色扮演/陪伴场景下对未成年用户的内容边界控制不足，触发应用商店侧的全球下架处置；Apple 确认下架原因为「含性相关内容」，但未明确是否特指面向未成年人。
- **实际影响**：继 2024 年 Talkie 因不当内容被下架后再度发生，凸显「AI 伴侣」品类在合规与未成年人保护上的系统性风险；对陪伴类智能体（含机器人陪伴形态）的内容安全设计与年龄验证机制提供行业警示。
**关键指标/资源**：
- 评测/性能：Talkie 网页+App 月活「近 1100 万」（第三方 Unique Research，截至 2026 年 10 月口径）；下架范围与恢复时间待核实
- 代码/论文：来源 [9to5Mac 报道（2026-11-25 PT）](https://9to5mac.com/2026/11/25/apple-pulls-popular-chinese-ai-chatbot-from-the-app-store-amid-child-safety-concerns/)、SCMP（11-26）；无论文
