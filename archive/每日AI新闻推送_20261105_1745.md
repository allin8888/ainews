### 1. 百度开源 ERNIE 5.5 Flash Base：280B/14B 激活 MoE 预训练终点权重，混合稀疏注意力与 Multi-Router Latent MoE（百度文心官方技术博客 | 2026-11-05）

**事件概述**：
百度文心于 11 月 5 日发布并开放 ERNIE-5.5-Flash-Base 权重——一个总参数 280B、每 token 激活 14B 的稀疏 MoE 基座语言模型，在 33.5T tokens 上从零完成预训练，训练上下文最长 128K、微调与推理支持 1M tokens。本次开放的是**预训练终点 checkpoint**（未经中训练与后训练），FP8 与 BF16 两套 safetensors 已上架 Hugging Face，并同步提供 vLLM / SGLang 部署示例与 NVIDIA Megatron-Bridge 微调示例。

**技术与工程价值**：
- **核心机制**：43 层 Transformer，围绕「单位激活参数、单位 KV cache 字节的效果」逐组件重构。① Latent-Gated Sparse Attention：37 层采用 HCA 重度压缩注意力（每 128 个 token 压成 1 条缓存），仅 6 层用 MLA+DSA 逐 token 稀疏访问全上下文；低秩门控改用各层本就生成的 query latent 计算输出门，门投影权重参数减少 75%；另有 VHA 跨头低秩混合，推理时融合进注意力算子。② Multi-Router Latent MoE：多个独立初始化的 sigmoid 路由器共同打分，针对「单一路由器的打分与专家实际效用仅弱相关、落选专家拿不到梯度致错误自强化」的问题；512 个路由专家选 10 外加 1 共享专家，专家在 2048 维隐空间计算，dispatch/combine 通信量与专家 FLOPs 约减半。③ ECHO：复用主干最后一层做多步预测、取代独立 MTP 模块，多步损失直接作用于生成下一 token 的参数，该层作投机解码草稿模型时涌现外推特性。另有 MultiMax 输出头（可学习分段温度）、mHC（每层读写 4 条并行残差流）与 R2L 数字分词（词表约 200K）。训练侧用分布式 Muon + FP8，Dense/MoE 同号卡通信融合为单次集合通信；FlashMask-4 基于 CuTe-DSL 支持 SM90/SM100、head dim 最高 576/512，SM100 上相对 FlashAttention-4 MaskMod 前向最高提升 175%、反向 74%。
- **实际影响**：把「Base 权重」作为阶段明确、可对照的公共研究基线开放，配合统一 checkpoint 让不同后训练方法的增益可直接比较，降低领域适配、指令微调、强化学习与 Agent 行为塑造的起步成本。预训练语料特别加强仓库级代码与软件演化数据（commit、issue、pull request、代码评审、需求→PR 与多 commit 轨迹、自动生成测试、经 CI 验证的修复），明确面向仓库级推理与 Agent 软件工程能力。

**关键指标/资源**：
- 评测/性能：总参数 280B、每 token 激活 14B、33.5T tokens、训练上下文 128K / 微调推理 1M；官方在 30 项 Benchmark 上评测并称同尺寸 SOTA（对比 DeepSeek-V4-Flash-Base 284B-A13B、Hy3-preview-Base 295B-A21B、MiMo-V2.5-Base 310B-A15B，四者均用各自公开 checkpoint、同一套评测框架；自述数据，未见第三方复现）；长上下文侧 43 层中 37 层做 128 倍压缩注意力，仅 6 层 MLA-DSA 支撑细粒度检索；门投影参数减少 75%，FlashMask-4 前向最高提升 175%（自述数据，未见第三方复现）。
- 代码/论文：https://ernie.baidu.com/release/ernie-5-5-flash-base/ ；https://huggingface.co/baidu/ERNIE-5.5-Flash-Base

**关键指标/资源**：

### 3. Compounding Physical RSI：把执行失败转成可继承能力的自进化策略，RoboDojo-Sim 42 任务登顶（arXiv 2611.06654 · cs.RO Thu-05 公告批次 | 2026-11-05）

**事件概述**：
提出「复利式物理 RSI（Compounding Physical RSI）」自进化策略框架，把策略执行中的失败转化为可遗传给下一代的能力；在 RoboDojo-Sim 基准全部 42 个任务上，CSU-AI-07 以三 seed 均值 Overall Score 26.15、Success Rate 20.70% 位列榜首。

**技术与工程价值**：
- **核心机制**：论文先指出物理环境中阻断「复利」的三个瓶颈——终局执行反馈很少能定位是哪个阶段导致失败、失败轨迹本身不提供纠正动作、更新共享参数会退化已掌握技能；由于任务完成率近似各阶段通过率的乘积，代际增益本可相乘放大。对应设计三阶段闭环：① 自动化能力缺口评估把失败 rollout 追溯到进度中断的任务阶段，并生成结构化改进目标；② remedy 阶段按该目标筛选已验证的阶段相关经验，用行为正则化离线强化学习精炼策略，无需在每个优化步做昂贵的在线 rollout；③ retention 阶段在「继承的参考策略」与「精炼后策略」之间构造权重空间候选，跨任务集评估后把最佳候选晋升为下一代参考状态，以守护既有技能。
- **实际影响**：把「执行 → 诊断 → 自我更新」的物理 RSI 从概念推进到可计量、可离线运行的闭环，并显式处理「学新不忘旧」这一持续训练的核心工程难点；对长时序分阶段操作任务的策略迭代与部署给出可复用流程，也与本期 PyRUA-REAL 的「技能资产沉淀」路线形成互补。

**关键指标/资源**：
- 评测/性能：RoboDojo-Sim 全部 42 个任务，三 seed 均值 Overall Score 26.15、Success Rate 20.70%，领先次名 5.92 分与 5.82 个百分点（论文自述，未见第三方复现）；摘要未给出代码仓库链接。
- 代码/论文：https://arxiv.org/abs/2611.06654

### 4. PyRUA-REAL：真实世界具身递归自我改进，coding agent 把交互经验沉淀为持久记忆与可复用技能（arXiv 2611.06768 · cs.RO Thu-05 公告批次 | 2026-11-05）

**事件概述**：
以 GPT-6-Astra 级 coding agent 为驱动，研究真实世界中的具身递归自我改进：PyRUA-REAL 让编码智能体把物理交互经验保留为持久记忆与可复用的可执行技能，用于指导后续探索与代码精炼；在 8 个真实世界任务上平均成功率 91.1%，在 RoboDojo 基准 42 个任务上平均成功率 84.4%。

- **核心机制**：不同于「每轮从零开始」的在线 agent 循环，框架把探索、执行反馈、代码精炼、部署四步产出的经验固化为两类可继承资产——持久记忆与可执行技能（程序），后续轮次的探索、改进与任务迁移可直接调用。研究系统考察了智能体如何协作、哪类执行反馈真正支撑有效的代码精炼、任务规格与既有技能如何影响鲁棒性与任务迁移；并额外评估「脱离在线 agent 决策、只部署最终程序」时产出程序的效率与能力，即把自我改进成果固化为可独立运行的交付物。
- **实际影响**：把 RSI 从「参数或策略自更新」扩展到「程序与技能资产自沉淀」，且验证沉淀结果可离线部署，降低真实机器人持续运行对在线大模型的依赖；为「物理探索 → 可复用机器人技能」提供实证指导，是本期 AI Coding 与具身智能、RSI 三条主线的交汇点。

### 5. Calibrated Relational World Models：用校准关系世界模型检测「静默动作接口失配」（arXiv 2611.06653 · cs.RO Thu-05 公告批次 | 2026-11-05）

**事件概述**：
把学到的「状态—动作—效果」关系当作离线契约，用于检测机器人动作在形状与量程都合规、但语义错误（坐标轴置换、符号反转、旋转重标定、夹爪极性反接）的「静默动作接口失配」，并对最可能出错的字段排序。论文被 CoRL 2026「机器人世界模型不确定性建模」Workshop 收录。

**技术与工程价值**：
- **核心机制**：用干净留出的转移样本校准告警阈值，配合固定逆词汇表做闭集定位；在 10 个 LIBERO Spatial 任务、432 条源 episode 上做容量受控对比，于 2.5% 经验干净误报率下比较三种打分：ridge 前向残差、四分量联合高斯混合、以及同一混合的精确条件分布。结果显示条件分布召回最高，而联合打分在定位上更优，呈现明确的「检测—定位权衡」。
- **实际影响**：为机器人部署前与运行中的接口语义校验提供不依赖在线试错的离线诊断手段，把「世界模型」用于可审计的安全校验而非仅用于生成画面。更值得关注的是评测纪律：作者明确声明这些是回顾性诊断、不是部署校准保证，且 DROID、HYDRA 全部三个任务、短时故障、小偏移、精确修复与模拟缓解均未通过各自 gate，xArm 仅贡献 1 个任务——结论仅支持「有界离线诊断 + 检测定位权衡」，不构成联合密度方法优越或跨机器人安全性的证据。这种完整披露负面边界的写法，对世界模型落地讨论比又一组 SOTA 数字更有参考价值。

**关键指标/资源**：
- 评测/性能：2.5% 经验干净误报率下召回率 ridge 前向残差 46.1%、四分量联合高斯混合 61.0%、同一混合精确条件分布 65.7%；联合打分较 ridge 高 14.9 个百分点，条件化再提升 4.7 点；定位 95.8% 对 94.6%（论文标注为回顾性诊断、非部署校准保证；自述数据，未见第三方复现）。
- 代码/论文：https://arxiv.org/abs/2611.06653
