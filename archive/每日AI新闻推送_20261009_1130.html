1. IQuest-Q1 开源：320B/15B MoE 面向 Agentic 长程编码的基座模型

PRNewswire / IQuestLab · 2026-10-08 · iquestlab.github.io · GitHub
事件概述

IQuest Research（至知创新研究院）发布 IQuest-Q1，一款总参 320B、每 token 激活约 15B 的稀疏 MoE 智能体基座模型，把「读仓库—驱动终端—调用工具—保持长上下文」作为训练目标原生内建，而非事后适配。

技术与工程价值
  • 核心机制：decoder-only Transformer + 稀疏 MoE；三阶段训练（预训练→中训→后训），后训以 SFT + RL 覆盖软件工程、长程 agentic 任务与通用推理；顶部叠加多教师在线策略蒸馏（MOPD）整合多专家能力、避免继承单一教师偏差；上下文 524,288 token。
  • 实际影响：可自托管的 320B 级 Agent 基座，能一次性从自然语言生成可运行 3D 游戏/应用，并「进入已有代码库定位 RL 训练跑挂的根因」，补足小模型在长程多步任务上的上下文与耐力短板。
关键指标 / 资源
  • 评测/性能：公布 NL2Repo、CyberGym、Terminal-Bench 2.1、DeepSWE v1.1、JobBench 五项基准结果；「NL2Repo 仅次于 Claude Opus 5」为社区转述（自述数据，未见第三方复现）
  • 代码/论文：GitHub — IQuestLab/IQuest-Q1；Hugging Face — IQuestLab/IQuest-Q1；Blog — iquestlab.github.io

2. Aether AI CRIS-0：因果驱动的具身机器人系统首次家庭场景实机演示

Business Wire · 2026-10-08 · aetherlabs.ai · 通稿 20261008233217
事件概述

因果智能公司 Aether AI 公布 CRIS-0（Causal Robotic Intelligence System）首次公开实机演示，让「因果引导机器人智能体 + 因果世界模型」在家庭场景中作为一套集成的具身 AI 系统协同运行。

技术与工程价值
  • 核心机制：把每个任务组织成显式因果表示（环境变量 + 因果结构），任务推进中持续更新表示、预测动作后果、选择工具、用执行结果校验预测并据此续/重试/重规划；每阶段拆成「可原子校验的子目标」，用可执行校验脚本在运行时核验「动作执行完」与「预期结果达成」之别。
  • 实际影响：突破端到端 VLA「会做动作但不会管理任务状态」的瓶颈，让机器人在条件变化（被挪物、伸手挡门）后仍能把长程任务做完，且安全拦截响应极快。
关键指标 / 资源
  • 评测/性能：微波炉门危险场景平均 0.2s 内拦截/改道（公司称，另有一口径记 0.5s，待核实）；个性化取放任务复杂模糊指令下成功率 90%；抗扰咖啡倾倒任务平均 2s 内重规划；「数小时微调数据 / 约 20000h 预训练」均为公司自述；世界模型 CausalWM 称列 TriWorldBench 第一、PAI-Bench 机器人赛道第一（自述，PAI-Bench 分据论文为作者自测而非官方榜）
  • 代码/论文：Business Wire 通稿（20261008233217）+ aetherlabs.ai 技术说明
#具身智能#因果世界模型#Sim2Real

3. Memento 3：冻结 LLM 的基于模型递归自我改进 + 反思规则库

arXiv:2610.11794 · 2026-10-08 12:06 UTC · arxiv.org/abs/2610.11794
事件概述

Memento 系列新作 Memento 3 让「冻结」的 LLM 智能体通过外部记忆持续学习显式世界模型，走通一条 model-based RSI 路线——底层 LLM 权重不动，靠「反思规则库 + 可执行代码」持续自我改进。

技术与工程价值
  • 核心机制：智能体把可修正的环境动力学假设写入自然语言「规则库」作持久语义记忆，编译成可执行代码用于预测与规划；通过「观测→反思→修规则→编译→校验」闭环，用预测误差同时打磨规则库与代码；代码更新仅当 LLM 判定其忠实于规则库、且逐格精确重放能复现观测转移时才被接受。扩展版并行维护多个世界模型、共享交互证据指导探索。
  • 实际影响：把 RSI 从「改模型权重」转到「改外部可控的世界模型」，使冻结前沿模型也能在陌生环境持续改进，且每个改进可审计、可回滚。
关键指标 / 资源
  • 评测/性能：ARC-AGI-3 上单模型智能体通过全部 25 个公开游戏的所有关卡，平均相对人类动作效率（RHAE）100.0、仅用 44% 的人类动作数；Atari 乒乓球 3 组不同开局 21:0 全胜且不再调用 LLM
  • 代码/论文：arXiv:2610.11794（v1 2026-10-08 12:06 UTC）
#递归自我改进#世界模型#RSI

4. Embodied Turing Machines / COAP：机器人递归自我改进的「无模型在环」范式

arXiv:2610.12369 · 2026-10-08 17:29 UTC · arxiv.org/abs/2610.12369
事件概述

Kairui Hu 等提出「具身图灵机」观点：把具身世界看作一台图灵机，磁带是机器人+环境状态、规则是策略——若状态能被精确表示，决策可全部写成代码。据此提出 COAP（Code-Only-as-Policy），在控制回路中彻底不放 VLM/VLA。

技术与工程价值
  • 核心机制：用代码从相机图像与本体感知测量/追踪机器人、环境与任务状态，并据此做出所有决策；同一套代码跨 episode 复用，不同任务共享一个可继承/扩展的库。相对 VLA 与 Agent Harness，代码态策略具备显式状态、可恢复执行的在线控制、可跨任务累积能力三点优势。
  • 实际影响：给「编码智能体闭环改造具身策略库」提供了 RSI 的理想载体——每次改动显式、可控、可继承，且该库可同时作为 VLA/Harness 的高效数据引擎。
关键指标 / 资源
  • 评测/性能：RoboDojo 42 个双臂任务上，测试时无任何模型，策略库成功率达 70.24%
  • 代码/论文：arXiv:2610.12369（v1 2026-10-08 17:29 UTC）
#具身智能#递归自我改进#无模型策略

5. PlanWAM：规划塑形未来表示，端到端自动驾驶世界动作模型

arXiv:2610.11382 · 2026-10-08 07:13 UTC · arxiv.org/abs/2610.11382
事件概述

Jinchang Xu 等提出 PlanWAM（Planning-Shaped World Action Model），核心问题是「哪种未来表示对规划真正有用」——让规划任务去塑形未来状态表示，只保留对轨迹规划最有用的信息。

技术与工程价值
  • 核心机制：用时序寄存器金字塔以近因感知方式压缩多帧历史；引入「特权未来后验分支」直接观测真值未来帧，用轨迹规划目标塑形出「规划塑形未来隐表示」；再用 hindsight-to-foresight 蒸馏训练一个只看历史的先验分支来预测该表示，作为规划上下文指导轨迹生成与筛选。
  • 实际影响：在世界动作模型（WAM）范式里首次把「对未来表示的塑形」作为一等公民，兼顾开环与闭环评测的领先规划性能，给端到端自动驾驶世界模型提供了可部署的前瞻形式。
关键指标 / 资源
  • 评测/性能：NAVSIM-v1/v2 navtest 93.8 / 90.9 PDMS；闭环 HUGSIM 零样本 38.7 HD-Score
  • 代码/论文：arXiv:2610.11382（v1 2026-10-08 07:13 UTC）
#世界模型#自动驾驶#端到端
