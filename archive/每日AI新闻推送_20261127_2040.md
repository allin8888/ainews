### 1. Together AI 开源 Hurdle：面向 Claude Code / Codex 的 API 任务 Agent 测试与护栏框架（Together AI 官方公告 / eWeek | 2026-11-25，48h 观察项）

**事件概述**：Together AI 于 11-25 发布开源 npm 库 Hurdle，用于度量 Claude Code 与 OpenAI Codex 等编码 Agent 在真实 API 任务上的表现；开发者自定任务后，Hurdle 运行、记录 Agent 行为并评估结果，可在对比不同指令/技能/MCP 连接条件下复现同一任务，输出通过率、执行时长、成本与可回放会话。
**技术与工程价值**：
- **核心机制**：区别于通用编码基准，Hurdle 面向「企业自有客户可能发起的任务」做可复现评测；沙箱化运行经本地代理 Guardian 路由并校验 Agent 的 API 请求，可拦截越界/危险调用，并将真实凭证替换为临时占位；本地直跑模式虽便捷但可访问用户真实文件与凭证，官方明确提示风险。
- **实际影响**：为 AI Coding 工具的「能力 + 安全」双重验收提供可落地的工程口径——既能量化 Agent 调 API 的正确率，又能把护栏（guard）做成一等公民；对 Agent 评测与治理是「评测即验收」的又一开源样本。
**关键指标/资源**：
- 评测/性能：官方未公布标准化基准通过率，「Guardian 默认放行所有已允许端点、需开发者显式配护栏」为厂商自述口径，具体拦截效果待核实
- 代码/论文：eWeek 报道（2026-11-27，eWeek Staff）；Together AI 官方公告（11-25，经 6 个月内部测试后以 npm 库开源）

### 2. Microsoft Research 实证研究：编码 Agent 的补丁为何更大——额外行主要是测试而非冗余代码（arXiv 2611.34875 | 2026-11-25，48h 观察项）

**事件概述**：Microsoft Research 预印本《How Much Do Coding Agents Over-Edit, and Why?》提出 DRA（Delta Residue Attribution）方法：重放 Agent 轨迹、把最终补丁的每个代码块回溯到写入它的步骤、逐块回退并重跑测试以判定该块是否必要；在 7,660 条已解决的 GitHub Copilot CLI 轨迹（覆盖 18 个前沿模型，SWE-bench Verified 6,728 条 + DeepSWE 932 条）上，用同一口径同时评估 Agent 补丁与开发者补丁。
**技术与工程价值**：
- **核心机制**：DRA 用「可执行测试」而非人工判定来归因补丁必要性，直接回答「Agent 多写的行到底是过度编辑还是必要补充」这一评测盲区。
- **实际影响**：结果修正了「Agent 补丁更大=过度编辑」的直觉——SWE-bench Verified 上额外行的 61% 是测试、13% 是文档，Agent 代码块必要率 88.7% 甚至高于开发者的 86.4%；对 AI Coding 评测与代码评审工具设计提供了「补丁构成 + 必要性」的可复现口径。
**关键指标/资源**：
- 评测/性能：额外编辑 61% 为测试、13% 为文档（SWE-bench Verified）；agent 代码块必要率 88.7% vs 开发者 86.4%（均为论文自述口径）
- 代码/论文：[arXiv:2611.34875](https://arxiv.org/abs/2611.34875)（Aakash Goel, Benjamin Steenhoek, Yu Hu，提交于 2026-11-25）

### 3. Einsia AI 开源 RoboUniverse-10K：首个 10K 级可交互物理仿真 RL 环境套件（PRNewswire | 2026-11-25，48h 观察项）

**事件概述**：Einsia AI 于 11-25 以新加坡 PRNewswire 通稿发布 RoboUniverse-10K——面向具身/Agent 机器人训练的开源 10,807 个可交互物理仿真环境（单臂 Franka 与双臂 AgileX 抓取），由真实操作视频构建、在 Isaac Sim 内以自动化检查对齐物理现实，并配套 500 任务验证基准；项目同时开源 RoboUniverse-35B-A3B SFT 模型与论文/代码，与清华、北大等研究者合作。
**技术与工程价值**：
- **核心机制**：把「可验证 + 物理对齐」作为一等公民，把大规模 RL 训练环境从「手工搭场景」变成「可批量生成、可自动验收」的工程资产；held-out 评估与「具身 coding-agent post-training」定位，将 RL 环境与 Agent 后训练打通。
- **实际影响**：对具身智能（世界模型/RL 环境规模化）是基础设施级开源样本——RoboUniverse-35B-A3B 在 RoboUniverse-Verified 零样本成功率从 0.8% 提升到 21.2% 的自述数据，给出「环境规模→成功率」的可复现参照。
**关键指标/资源**：
- 评测/性能：10,807 环境 / 500 任务基准；SFT 模型 RoboUniverse-35B-A3B 零样本 0.8%→21.2%（厂商自述）；第三方称 GPT-6.2 Astra 在该 500-task 基准达 85.8%（待核实）
- 代码/论文：[PRNewswire 通稿（2026-11-25）](https://www.prnewswire.com/news-releases/einsia-ai-open-source-robouniverse-10k-the-first-10k-scale-rl-environment-suite-for-agential-robotics-302950545.html)、[项目主页 lab.einsia.ai/robo-universe](https://lab.einsia.ai/robo-universe/)、HuggingFace 数据集 Einsia/RoboUniverse-10K
