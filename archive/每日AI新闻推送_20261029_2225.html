1. Mistral 开放 Large 4「Le Chonk」权重：1T 参数 MoE 原生多模态 + 混合推理，agentic coding 与网络安全自述领先 （Mistral 官方博客 | 2026-10-29 BJ 20:00）

事件概述

Mistral 把 10 月初公开预览的旗舰 Large 4（代号 Le Chonk）权重正式开放：1 万亿参数 MoE（仓库名 Mistral-Large-4-1T-A52B 推断约 52B 激活，正文仅确认 1T）、原生多模态、hybrid instruct-and-reasoning 混合架构，提供 Low/Medium/High 三档推理强度（High 为默认）；同场披露网络安全特化变体（渗透测试/漏洞评估/红队优化），仅面向 Orange Cyberdefense 等受审企业设计伙伴开放。官方博客 published 2026-10-29T12:00:07Z（北京 20:00）、modified 14:22:31Z；HN 获 39 分（14:13Z 提交）。许可为「Mistral Ecosystem Open-Weight license」——修改版 MIT：可自由使用/修改/微调/商用，唯一条件是 MaaS 转售方需单独商用授权（非 Apache 2.0）。

技术与工程价值

  • 核心机制：1T 级稀疏 MoE + 原生多模态 + instruct/reasoning 单模型混合（三档推理避免双模型维护）；公开预览后 3 周专项 RL 带来全线爬升（Terminal-Bench 4.0 28→41.4、BrowseComp 75→84.5、B3 Agent Security 93.3→97.1、恶意网络安全请求拒绝率 95.3→96.6）；欧洲自有基础设施从头训练（主权叙事），官方定位为「新一代特化 Mistral 模型的基座」。安全变体受控分发的做法与前沿实验室「受限开放」先例同向（第 115 跑 Gemini 4 Carbon Fairwind Program 同款）。
  • 实际影响：开源阵营在 agentic coding 获得 1T 档新旗舰——自述 FrontierCode 2.0 19.7% 微弱领先 DeepSeek V4.1 Flash（19.3）与 GLM-5.3（17.8），AA Coding Agent Index 48%（High）与 GLM-5.3 持平但每任务 tokens 少 47%（性价比叙事）；对照 Artificial Analysis 独立口径（其 Carbon 文章，首发在窗外、此处仅作第三方背景），闭源前沿 Opus 5.5 (max) 62、Gemini 4 Carbon 59——开源第一梯队与闭源前沿仍有约 11–14 分差距。修改版 MIT 许可把「开放权重」与「MaaS 商用墙」明确切分，延续欧洲阵营对开放许可模式的表态；$0.70/$0.07(cached)/$2.10 每百万 tokens 定价 + vLLM/SGLang 自托管支持，直接服务企业私有化部署需求。
