### 1. Argus 开源：MIT 协议智能体安全运营平台，「只提议、不执行」的 Agent 治理架构落地（GitHub thomasunise/argus | 2026-10-25，仓库创建于北京 00:12）

**事件概述**：
独立开发者 Thomas Unise 发布并开源 Argus——一个自托管、MIT 许可的智能体安全运营（agentic SecOps）平台，直指「攻击者以 AI 机器速度渗透、人类 SOC 跟不上」的威胁模型：用 AI 智能体完成检测、调查与响应，但所有变更动作必须经过统一的审批代理（action broker）执行。

**技术与工程价值**：
- **核心机制**：① 证据图（evidence graph）汇总 AWS / Azure / GCP / Kubernetes / GitHub / Okta / Microsoft Entra / 端点 / 网络等 13 类数据源，先于攻击者暴露攻击路径；② 检测面面向 AI 时代行为：身份群（identity swarms）、高速侦察、权限提升、意外公开暴露、泄露密钥与 rogue workload，并布设假 LLM 凭证、诱饵 MCP 服务器、植入式提示注入等「针对自动化攻击者的陷阱」；③ 治理架构是核心设计：AI 智能体只读调查、只能 `propose_action`，任何动作（人发起 / 智能体建议 / playbook 触发）统一流经单一 broker，强制审批 + dry-run + 回滚；自主响应与自主渗透测试默认关闭、需部署级开关 + 按租户 opt-in；playbook 先跑影子模式；自主动作仅限可逆操作、定时无人确认即自动回滚、按租户与 playbook 限速、高风险动作双人审批、全局 kill switch；④ 内置攻击模拟器在隔离沙箱重放 8 类智能体攻击场景（不触真实系统），自主渗透模式可链式调度 Nuclei / ZAP / Trivy 且每步前复查 scope；⑤ AI 网关统一代理 OpenAI / Anthropic 流量（中心持钥、模型白名单、数据防泄漏规则、预算、提示注入标记），shadow-AI 发现员工私自使用的 AI 工具；⑥ 可接 Claude / OpenAI / 本地 Ollama，也可在无 AI 配置下以确定性逻辑兜底。
- **实际影响**：把「Agent 安全层」从口号变成可部署的开源工程——「智能体只提议不执行 + 单一 broker + 不可篡改审计链（hash-linked + HMAC 签名）」是与本期另一线索（Anthropic 10-22 subagent 精简建议、Perplexity 技能市场）共振的 agent 治理工程化收敛；对自建 agent 平台的团队，其 AI 网关与审批 broker 是可直接借鉴的参考实现。

**关键指标/资源**：
- 评测/性能：无第三方基准（项目自述数据）；Hacker News 27 分登上首页（第三方可观测）；仓库上线约 11 小时获 59 stars（第三方可观测）
- 代码/论文：https://github.com/thomasunise/argus （MIT；Docker / Helm / Terraform 部署；CISA KEV 优先级排序；SOC 2 / ISO 27001 / NIST 800-171 控制映射）
