### 1. SpaceX 以 600 亿美元收购 Cursor 母公司 Anysphere（腾讯新闻/科技日报 | 2026-08-14/18）

**事件概述**：
SpaceX 确认收购 AI 编程 IDE 公司 Cursor 的母公司 Anysphere，交易金额约 600 亿美元。这是 2026 年 AI Coding 赛道最大规模并购，标志 AI 编程工具进入「平台化整合」阶段。

**技术与工程价值**：
- **核心机制**：Cursor 采用 VS Code 分支架构，将 AI 深度嵌入编辑器；此次收购后，xAI 与 Cursor 在模型中立性上的关系引发关注。
- **实际影响**：600 亿估值较 Cursor 此前融资估值增长数倍，反映头部 AI 基础设施对编程工作流的战略卡位；同时，SpaceX 旗下 xAI 的 Grok 模型与 Cursor 的集成路径成为后续焦点。

**关键指标/资源**：
- 估值：600 亿美元（交易金额）
- 代码/论文：Cursor（https://cursor.sh），Anysphere 融资历史可查
- 竞争格局：同期 Claude Code 环比增速跌至 5.2%，Codex 环比增 20.8%

**标签**：`#AI Coding` `#并购` `#Cursor`

### 2. Claude Code 增长神话破灭，用户大规模转向 Codex（新智元/界面新闻 | 2026-08-20）

**事件概述**：

**关键指标/资源**：
- 数据：Claude Code ARR 环比 5.2% vs Codex 环比 20.8%（来源：新智元 8/20）
- 待核实：水印合规强制范围（API/CLI/Extension 全覆盖？）/额度延期具体条款

### 3. 镜智格物落地上海张江，自进化 AI 系统产业化迈出关键一步（腾讯新闻 | 2026-08-20）

**关键指标/资源**：
- 融资状态：已落地张江，商业化实质推进中

### 4. General Intuition 开源 MIRA：多玩家实时交互世界模型（将门创投/arXiv | 2026-08-20）

**事件概述**：
General Intuition 与 Kyutai 等机构联合开源 MIRA 框架，基于冻结 DINOv3 特征的表示自编码器构建语义紧凑潜空间，实现多玩家实时交互式世界模型。

**技术与工程价值**：
- **核心机制**：输入四名玩家的历史视角与动作流，联合预测四个玩家未来画面；采用扩散强制训练策略与实时自回归推演解耦，10 Hz 潜变量更新 + 20 FPS 视频输出；因果时空 Transformer 融合多玩家动作流与历史上下文。
- **实际影响**：在 10,000 小时《火箭联盟》多人数据集上实现分钟级至小时级长时连贯推演；解决单玩家世界模型「物体融合失效」问题——多视角输入为目标物体提供连续空间位置约束，防止表征错误合并。

**关键指标/资源**：
- 性能：gFID 10.7（潜空间）vs 81.0（像素空间），提升近一个数量级
- 代码：https://github.com/mira-wm/mira
- 论文：https://arxiv.org/abs/2607.05352
- 项目主页：https://mira-wm.com

**标签**：`#世界模型` `#多智能体` `#开源`
