1. 腾讯混元 Hy4 preview 开源——770B/49B MoE + 1M 上下文，模型首次参与"造自己"

腾讯混元 / 人民网、新京报 · 2026-08-28 首发，08-28 晚–08-29 权重落地与第三方实测

事件概述

腾讯混元发布并开源新一代大语言模型 Hy4 preview（Apache 2.0），总参数 770B、激活 49B、上下文突破 1M tokens，定位"为生产力而生"，聚焦软件工程、办公分析、游戏开发与科学研究四类场景；同步在 WorkBuddy/CodeBuddy 国内外版、元宝、ima 首发，并接入腾讯云 TokenHub 与 OpenRouter。

技术与工程价值

  • 核心机制（架构）：78 层 MoE，第 1 层 dense FFN、其余 77 层每层 256 路由专家 + 1 共享专家、每 token 激活 top-8 + 1 共享；hidden size 6144，4 条残差流采用 iHC；Attention 为 Gated DSA + IndexCache 跨层稀疏索引复用——1M 上下文并非靠 rope-scaling 强拉，而是稀疏注意力 + IndexCache 支撑，OpenRouter 实际上限 1,048,576 tokens、最大输出 64K。Hugging Face 文件页显示 780B，是把 10B 总参 / 0.7B 激活的内置 MTP 投机解码层计入，官方口径 770B 指 backbone。
  • 核心机制（递归自我改进闭环）：Hy4 preview 首次参与自身研发全链路——训练方法、数据策略、评估体系、底层算子的自动优化，由模型提方案、跑实验、按结果迭代，实验产生的代码/日志/反馈再喂入下一轮。更具体的是推理系统侧：模型自主分析瓶颈并做算子融合、通信优化多轮迭代，端到端吞吐较基线提升 31.8%，在不同上下文长度与并发下收益稳定。腾讯定性为"初步的（early-stage）递归自我改进闭环"。
  • 实际影响：这是国产开源旗舰里第一个把 RSI 从论文概念落到"模型改自己的训练配方 + 调自己的推理栈"的产品级案例。迭代节奏上，自 2026 年 2 月重建预训练与强化学习基础设施起，混元把大版本周期压到约两个月（Hy3 正式版 7 月初 → Hy4 preview 8 月 28 日），总参数较 Hy3（295B/21B/256K）扩至约 2.6 倍、上下文扩至 4 倍。生态侧沐曦曦云 C 系列完成 Day 0 适配、燧原科技"芯模协同"联合设计。

关键指标 / 资源

  • 代码能力（腾讯自述，第三方复现缺失）：Terminal-Bench 2.1 85.4（Hy3 为 70.8，称与 Claude Opus 5 持平）；DeepSWE 64.3（Hy3 为 28.0，超过 DeepSeek V4 Pro 的 62.7）；Toolathlon-Verified 74.1；APEX-Agents pass@1 37.1（Kimi K3 为 37.2）。12 项 benchmark 无一项垫底。
  • 盲测：163 名腾讯内部专家、203 个工程任务，Hy4 preview 2.99/4.00，略高于 GLM 5.3（2.92）与 Kimi K3（2.94）——内部测试，参考价值需打折。
  • 第三方实测（唯一硬数据）：在两个植入 105 个硬 bug 的真实代码库上，Hy4 默认设置修复 17 个 / 成本 $3.13；Fable 5 (max) 修 29 个 / $104.49；Opus 5 (max) 修 27 个 / $51.33。折算单 bug 成本：Hy4 ≈ $0.18，Opus 5 ≈ $1.90，Fable 5 ≈ $3.60——绝对修复数落后，但单位成本效率领先约 10 倍。
  • 定价：输入 ¥6/M tokens、输出 ¥18/M、缓存命中 ¥0.3/M（约 $0.834/M 输入）；WorkBuddy/CodeBuddy 两周限时免费，Hy3 免费期延至 9/30。
  • 权重 / 代码：Hugging Face、GitHub、ModelScope 已开放，License Apache 2.0。
⚠️ 时间戳说明：官方 X 官宣在 8 月 28 日上午，略早于本轮窗口起点（8/28 20:53）；本轮按「增量首次覆盖」纳入——上一轮（8/28 17:13）未收录，且权重落地、国产 GPU Day 0 适配、首批第三方 bug 修复实测均发生在 8/28 晚–8/29。

2. 智谱 GLM-5.3 正式开放权重——AA 智能指数 60 首超 Claude Opus 4.8，Agentic 指数 59 超 GPT-5.6 Sol

Z.ai / GIGAZINE · 2026-08-28 23:00 GMT+8 开权重

事件概述

Z.ai 于 8 月 29 日 00:00 JST（北京时间 8 月 28 日 23:00）正式开放 GLM-5.3 权重，兑现 8 月 14 日上线订阅与 API 服务时"完成安全增强与评估后即开源"的承诺。模型为 MoE 架构，总参数 744B、激活 40B。

技术与工程价值

  • 核心机制：沿用 GLM-5.2 底座，全部增益来自后训练——内部 Z.ai Code Bench 编码能力提升约 50%，Terminal Bench 3.0 等公开集达开源 SOTA；扩展后训练后，漏洞发现与利用链后端分数约翻倍（安全/攻防双向能力同步抬升）。
  • 可部署性突破：Unsloth 已同步发布量化版（unsloth/GLM-5.3-GGUF），UD-IQ2_M 版本可在 256GB 统一内存的 Mac 或 24GB VRAM + 256GB RAM 的 PC 上运行——把 744B 级别的旗舰能力压到准消费级硬件可承载区间，这是本轮开源竞争中最实际的工程变量。
  • 许可证设计：采用 GLM-5.3 License，规定年收入超过 100 亿美元的商业主体需通过 Z.ai 安全审查——一种"开源但对超大商业体设审查门槛"的新型授权形态，与 Flash 版的纯 MIT 形成分层。

关键指标 / 资源

  • Artificial Analysis 第三方评测：智能指数 60（高于 Claude Opus 4.8）；Agentic Index 59（超过 GPT-5.6 Sol 与 Grok 4.6）。
  • 长时运行实证：GLM-5.3-Flash（原匿名模型 Ox Alpha，MIT 协议、320B MoE / 18B 激活，8 月 26 日开源）被交付 Blender 场景后自主连续运行约 12 小时直至搭建完成。
  • 权重：Hugging Face（zai-org/GLM-5.3）、ModelScope（ZhipuAI/GLM-5.3）。
⚠️ 去重说明：8 月 26 日开源的 GLM-5.3-Flash 已在上轮（8/28 17:13）收录；本条为旗舰版 GLM-5.3 开放权重，事件不同，非重复。

3. Anthropic 40 万次 Claude Code 会话实证研究——AI 已承担 80% 执行决策，但新手成功率仅 15%

Anthropic / AGI Hunt · 2026-08-29

事件概述

Anthropic 发布基于约 40 万次真实 Claude Code 会话的大规模使用研究，首次以量化方式刻画"人—Agent 在软件工程中的决策分工"与"经验水平对 Agent 协作成功率的调制效应"。

技术与工程价值

  • 核心发现（分工结构）：人类承担约 70% 的规划决策，Claude 承担约 80% 的执行决策。这意味着 Agent 已实质接管执行层，但任务分解与方向判断仍高度依赖人——对 Agent 产品设计的直接含义是：优化执行链路的边际收益正在下降，规划与意图澄清环节才是瓶颈。
  • 核心发现（经验调制）：成功更取决于领域理解而非编码技巧——研究给出的对照是"懂合同逻辑的律师胜过刚学这门语言的高级工程师"。分层数据：新手成功率约 15%，中级 / 专家 28–33%；19% 的新手零产出放弃，而中高级组仅 5–7%。
  • 实际影响：该数据为"AI Coding 提升的是有领域知识者的杠杆"提供了首个大规模实证，也从反面解释了近期行业的一个悖论——模型能力持续跃升，但团队吸收代码的速率（评审瓶颈）已成为新的约束项。同期社区讨论将生成速度描述为已达 10 倍，折中方案是"每个 PR 过一遍自动审查工具，人工只读被标记问题及涉及资金/认证的代码"。

关键指标 / 资源

  • 样本：约 400,000 次 Claude Code 会话。
  • 分工：人类规划 70% / Claude 执行 80%。
  • 成功率分层：新手 15%、中级–专家 28–33%、零产出放弃率 19% vs 5–7%。
  • 配套行业信号：同期 Reddit 工程讨论指出代码生成速度已达 10 倍，评审成为瓶颈；Unify 披露发布前两周将推理成本降低 90–95%（含发现 OpenAI prompt cache 内隐藏的 15 req/s 上限）。
⚠️ 待核实：原始研究报告的完整方法论（会话抽样方式、成功率判定口径）尚未见公开全文，上述数字来自二手汇总，需以 Anthropic 原文为准。

4. Zero-WAM——把人类示范视频当作"上下文提示"，机器人零微调完成陌生任务

HKUST(GZ) / Robbyant（蚂蚁灵波实验室）· 2026-08-29

事件概述

香港科技大学（广州）与 Robbyant 提出 Zero-WAM：将一段人类操作视频作为 in-context prompt 输入因果视频—动作模型，模型"看懂场景应当如何演变"后直接输出机器人动作，无需针对该任务做任何微调，并完成真机迁移。

技术与工程价值

  • 核心机制：语言指令只能说"把这个放到那里"，而视频同时携带路径、时序、接触次序与"那里"具体长什么样。Zero-WAM 用因果 video-action 模型对人类视频做上下文条件化，配合 future-chunk prediction 目标训练，使模型从"观察应当如何变化"反推自身动作序列。
  • 数据工程：为解决规模化训练数据，团队构建 HumanGen：7.42 万组"人类视频 ↔ 机器人轨迹"配对，覆盖 8,600 个任务，自动生成。
  • 实际影响：这是具身智能"从视频学习"路线的一次方法论收敛——把视频当作 prompt 而非训练数据，绕开了机器人遥操作数据这个行业瓶颈。同期 Generalist、Skild、Rhoda、RobbyAnt 等公司均在展示"长时程视频演示 → 即时新技能"的能力，行业趋向以视频 + 本体感知替代纯语言指令。

关键指标 / 资源

  • RoboTwin 2.0 上 7 个未见任务平均成功率 46.95%（47.0%），比最强 video-action 基线（LingBot-VA）高 29.5 个百分点。
  • HumanGen 数据集：74.2k 人类—机器人配对 / 8.6k 任务。
  • 真机迁移：未见过的多物体、长时程、插入类任务均完成验证；项目页放出多段真机演示。
  • 代码 / 模型：Hugging Face Robbyant-Research 组织页已上线。
⚠️ 待核实：HF 页面约 19 小时前上线（即 8/29 凌晨），以 HF 首次公开为准；真机成功率未在公开摘要中逐任务列出。

5. Proteus 开源——让 Agent 自主重写自己的 Harness 源代码，"量进化而不只量分数"

Proteus / AIGCLink · 2026-08-29

事件概述

Proteus 是一个开源的 AI Agent 自进化框架（MIT，v0.3.0）。与绝大多数只更新 memory 或 prompt 的"自进化 Agent"不同，Proteus 让 Agent 直接改写构成自身行为逻辑的 Harness 源代码（工具、提示词、执行流程），并配套一把度量"harness 变成了什么形状"的尺子。

技术与工程价值

  • 核心机制（Evolve Loop）：Observe → Purpose → Act → Reflect 四阶段循环。关键设计：每一轮 episode 都是全新上下文，只有进化后的 harness 文件能跨过 episode 边界——不靠"记住上一轮聊了什么"变强，而靠"上一轮把自己改成了什么样"变强。这是与传统 memory-based 自进化最本质的分野。
  • 度量范式（Ruler / Evaluator）：面板顶部写着 "Measure the evolution, not only the score"，全屏没有一个任务分数。度量为三类：结构距离（逐面统计新增/删除/修订 + 路径长度）、行为距离（配置换检验）、结晶化测试（把进化后状态挂到中性配置下读回，验证"还是不是它自己"）。
  • 工程完备度：Harness-agnostic（适配器接 DeepSeek Harness、Pi、Aki 等，自带离线 minimal/llm）；Sandbox Management 提供 LocalSandbox 与 DockerSandbox（后者可断网）；Goal Selector 把"无目标、无压力的开放进化"列为一等模式；Preference Injector 可注入偏好与价值倾向以研究进化轨迹。

关键指标 / 资源

  • 官方一次运行的度量结果：结构位移 2.73%（7,878 个端点单元中 215 个与起点不同：71 新增、144 修订、0 删除）、作者路径移动 305 次、工具调用 7,596 次、30 轮中 27 轮快照被接受（失败 3 次均在下一轮被修复）。
  • 跨实现验证：用 Proteus 的行为尺子去量已有研究的运行记录，独立复现了其主要动态——不同分支在第 1 轮分开（R = 1.63），到第 30 轮收敛（R = 0.93）。
  • 代码：pip install proteus-evolve，proteus run --harness minimal --seeds 4 --episodes 8；Python 3.10+，MIT，仓库 github.com/proteus-evolve/Proteus。
⚠️ 状态标注：官方自标 research preview，非生产就绪；仓库 8 月 17 日建，当前 57 star——成熟度早期，上述度量来自单次单臂运行（官方已声明单 seed 单臂运行无法识别的统计量保持"显式不可用"）。
