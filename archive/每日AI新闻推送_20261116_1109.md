### 3. Datasette 1.0a43 发布：流式输出渲染器与两个安全修复，0.65.6 稳定分支同步回移（GitHub Release | 2026-11-15）

**事件概述**：
Datasette 1.0 alpha 线发布第 43 版：CSV/TSV 输出改为流式渲染器实现、新增单行 JSON 格式与首页/库页卡片式表格，并修复两个安全漏洞；稳定分支 0.65.6 同晚回移数据库越权下载修复。

**首发时间**：
2026-11-15 23:18:17 UTC（0.65.6）与 23:20:27 UTC（1.0a43），GitHub Release `published_at` 取证；Simon Willison 博客同步发布（聚合器源条目时刻与 release 秒级一致）；11-16 07:20 BJ。

**技术与工程价值**：
- **核心机制**：安全修复一：`/-/queries` 页 `?owner_id=` 过滤器会将该 owner 的私有 stored SQL 查询（含 SQL 正文）返回给任意 actor（含匿名用户），波及 1.0a31–1.0a42；修复二：以 `add_database(db, name=..., route=...)` 注册且 route 与 name 不一致的数据库，`/<route>.db` 可绕过 `view-database-download`/`view-database` 权限校验下载整库，现改按数据库名校验。流式渲染：CSV/TSV 重构为 streaming renderer，长结果集不再全量缓冲后输出。
- **实际影响**：运行受影响 alpha 版本（a31–a42）的生产部署需立即升级；一周一版的 1.0 alpha 节奏延续（a42 为 11-08）。
- **适用限制**：均为 Datasette 1.0 alpha 线与 0.65 稳定分支的补丁性更新，功能细节以 release notes 为准。

**关键指标/资源**：
- 代码/许可：https://github.com/simonw/datasette （Apache-2.0）
