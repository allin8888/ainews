## 一、DeepSeek Harness v0.1 开发者预览版发布：一切皆插件，MIT 开源

- **事件**：8/13 晚，DeepSeek 发布首款 Agent 产品 Harness v0.1 开发者预览，同步以 MIT 协议开源。底层基于 Cordis 插件系统，模型 / 工具 / 技能 / 会话 / 沙箱 / 存储 / 循环 / 调度 / UI 全部由插件组合，可替换、可重组；提供标准 / PTC（程序化工具调用）/ 极简 / 创造四种运行模式；append-only 会话日志 + Trajectory 视图支持恢复 / 分叉 / 检索 / 回放。启动命令：`npx @deepseek-ai/dsh web`。
- **为何值得关注**：DeepSeek 不再只卖"可被调用的模型"，而是下场争夺模型之上的开发者入口，直接对标 Codex / Claude Code。MIT + "一切皆插件"把模型降格为技术栈中可替换的一环，延续本系列「去模型化 → 接入层 → 运行时标准化」主线，并给国产模型厂提供了一个开源 Harness 范本（V4-Flash 公测时的 Code Agent 评测即用的极简模式）。
- **来源**：DeepSeek Harness 团队公告（腾讯新闻转载）/ X @deepseek_ai；<https://news.qq.com/rain/a/20260813A0DOWY00>

## 二、三星 System LSI 用 Claude Code 把 SoC 验证从 30+ 天压到 2 天

- **事件**：8/13 每日经济新闻报道，三星 System LSI 今年 5 月引入 Claude Code，定制 SoC 验证周期由 30 余天缩至 2 天、效率提升约 15 倍，PDK 适配迭代压缩超 95%。
- **为何值得关注**：这是 Coding Agent 在硬核芯片验证场景的最强企业级实证之一——验证是典型的「长上下文 + 强约束 + 高合规」任务。但报道同时指出模型存在"擅改代码"缺陷、仍需人工复核，呼应本系列长期警示：能力增长必须与权限收敛同步。
- **来源**：每日经济新闻（经 vibe coding 日报转述）；<https://view.inews.qq.com/a/20260813A05ZDP00>

## 三、Claude Code 团队揭秘上下文工程原语：Hooks 是唯一可扩展插件抽象

- **事件**：8/13 InfoQ 整理 Anthropic Claude Code 团队在 NDC Copenhagen 的演讲：上下文窗口一年未扩容仍是瓶颈；Hooks 是唯一真正可扩展的插件抽象；2026 年团队重心从"把信息输入模型"转向"把信息从模型输出给用户"。
- **为何值得关注**：把"上下文工程"从玄学落到具体原语——当模型上下文长度见顶，胜负手转向工具 / 钩子编排与输出侧治理。与 #1 DeepSeek Harness 的"一切皆插件"思路同源，印证 Agent 框架的竞争焦点已彻底从模型能力下沉到运行时与编排层。
- **来源**：InfoQ（经 vibe coding 日报转述）；<https://view.inews.qq.com/a/20260813A08L5700>
