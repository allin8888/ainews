### 1. Anthropic 发布 Claude Haiku 5.5：运行成本较上代降约 75%，首款可调推理强度的 Haiku（Anthropic 官方博文 / Reuters | 2026-10-07）

**事件概述**：
Anthropic 于 10-07 发布 Claude Haiku 5.5，系 Haiku 家族第三款 5.5 模型（继 Opus 5.5、Sonnet 5.5 后），官方称其为迄今最快、最便宜、能力最强的 Haiku 系列小型模型；平均运行成本较 Haiku 4.5 低约 75%。这是首款支持**可调节推理强度（effort）**的 Haiku，并可作为 Opus 5.5 / Sonnet 5.5 的「子智能体」用于编码、computer use、知识工作等高频任务。

**技术与工程价值**：
- **核心机制**：引入 effort 旋钮（成本/智能权衡），与 Opus/Sonnet 5.5 一致；首款带窄范围高危网络安全请求内置防护的 Haiku（允许更广的防御性任务，但仍阻断渗透测试等攻击性用法）；定价分层——提示词 ≤100k token 时输入/输出 $0.10/$0.50 per M，>100k 时升至 $0.50/$2.50。同步将 Sonnet 5.5 缓存读取价减半至 $0.10/M，使多数 agentic 任务成本再降约 20%。
- **实际影响**：把「高频、低成本、低延迟子智能体」路线正式产品化——在 agent 编排中，用 Haiku 5.5 承担分类/摘要/提取/子任务，Opus/Sonnet 承担重活，单位任务成本大幅下降。OSWorld 从 15.7%→72.4%、Terminal-Bench 4.0 从 0→39.2% 显示小模型在 coding / computer-use 上的能力跃升，直接压低长链路 agent 的 token 经济学。

**关键指标/资源**：
- 评测/性能（**Anthropic 官方自述，官方 harness，缺第三方复现，待核实**）：OSWorld 72.4%（vs 4.5 的 15.7%）；Terminal-Bench 4.0 39.2%（vs 0）；GDPval-AA 1620（上代 2 倍+）。
- 定价：$0.10/$0.50 per M（≤100k token）；Sonnet 5.5 缓存读取降至 $0.10/M。
- 代码/论文：Anthropic 官方博文与 Haiku 5.5 System Card；Release Notes（releasebot.io/updates/anthropic）。

### 3. OpenAI 在 GitHub 发布 openai/math：722 份由内部模型生成的数学手稿（OpenAI GitHub / 上海证券报·网易 | 2026-10-07）

**事件概述**：
OpenAI 于 10-07 在 GitHub 发布 722 份数学手稿（组织为 372 个「成果族」），覆盖数论、代数几何、实分析、组合、理论计算机、数学物理、PDE 等方向，含米尔恩理性猜想与代数特化、准黎曼假设、希尔伯特第十问题等，全部由一个**尚未发布的内部前沿模型**生成。

**技术与工程价值**：
- **核心机制**：流程为向模型提出约 4000 个问题，平均每个结果耗费约 3 小时 ChatGPT Pro 思维计算；输出汇总为成果族与论文并设定显著性水平，仅保留 judged significant 的 372 族公开。OpenAI 披露：绝大多数结果来自「**单一提示词交给单一 AI agent**」（部分问题需多次尝试），即一次性批量生成数百个证明族。仓库附带 10 个结果的推理过程摘要、基于 Pro 时长估算的计算量、尝试问题数统计。
- **实际影响**：这是 RSI / 自主研究主线的最新坐标——AI 不再只是辅助写代码/检索，而是直接产出成体系数学成果；与 MetaRSI-v1 / AIDE² / RRSI 等「改进研发流程」路线互补，本次是「AI 作为研究产出主体」的极端样本。但学界质疑强烈：仅 162/722（约 22%）有 Lean 形式化主结果，OpenAI 自己承认「部分未形式化结果可能有问题」；MIT Andrew Sutherland 称在模型发布前「单提示词单 agent」说法无法验证，呼吁「拿出证据」。

**关键指标/资源**：
- 评测/性能（**OpenAI 自述 + 社区核验缺口，待核实**）：722 手稿 / 372 成果族 / ~4000 问题 / 平均 3 小时 Pro 思维 / 162 份 Lean 形式化（约 22%）。
- 代码/论文：GitHub `openai/math`；AGMAI（普林斯顿高等研究院）数学与人工智能咨询组声明（仅作咨询角色，不代表对结果影响的评判）。

**标签**：`#RSI` `#自主研究` `#数学AI` `#形式化验证`
