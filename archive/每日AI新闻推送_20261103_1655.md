### 1. Exo：把优化循环折叠进任务执行的 agent 运行时自我改进架构——在岗学习中同时修订 harness 与策略，模型成本对 Codex 降 12–53%（arXiv 2611.00463 · Tue-03 批次 | 2026-11-03 BJ 13:00 公告）

**事件概述**：
Krentsel、Sylvia Ratnasamy、Ion Stoica、Martin Casado、Ankur Goyal 等发布 Exo——一个支持「在岗安全学习」的 agent 运行时架构：把优化循环折叠进任务执行本身，允许 agent 在持续工作过程中同时修订自己的 harness（经可检视的代码变更）与后续策略；由最小「受保护机制层」保存执行历史并管辖策略激活，使 harness 演化不破坏安全边界。论文 v1 提交于 10-30（周末提交顺延），随 arXiv Tue-03 批次公开（公告 2026-11-03 05:00 UTC = 北京 13:00，窗口内）。**本条同时补全第 124 跑待核实项**：当时仅有 Arena X 转述且误归因为「Google Research」，本跑以 arXiv 元数据确证作者归属并取回全部基准数字。

**技术与工程价值**：
- **核心机制**：与「离线跑数据集 + 代价高昂的重复执行」的自动 harness 优化路线不同，Exo 在任务执行中就地完成「发现失败 → 提议修改 → 受保护激活」闭环；受保护机制层只做两件事（保执行历史、管策略激活），把对 agent 行为的干预压缩到最小面。这把 RSI 从「模型自我改进」下沉到「运行时基础设施自我改进」——harness 以可检视代码形式演化，天然可审计。
- **实际影响**：长时程开放世界目标下，Exo 相对 Codex 与 Pi 独立运行降模型成本 12–53%、迁移运行降 45–82%，任务完成率持平；同等起始策略下若不可编辑策略则无此收益（消融对照），验证收益来自「策略可演化」而非单纯调度。

**关键指标/资源**：
- 评测/性能：held-out 模型成本在 AppWorld 与 SREGym 降 35–61%（正确率相当）；AppWorld 平均任务耗时 -13%、SREGym 中位诊断耗时 -35%；Continual Learning Bench 编码任务含学习在内的模型成本 -14% 且两个策略解决全部 issue（自述，未见第三方复现）。

### 4. Archon Robotics 发布 Anchor 1：人形全身操作控制器 + 分级基准，真实世界追踪误差较全基线降 30–80%（arXiv 2611.00193 · Tue-03 批次 | 2026-11-03 BJ 13:00 公告）

Archon Robotics（25 人署名，含 Yu Qiao、Hongyang Li 等）发布 Anchor 1——面向「精准且稳定的人形全身操作」的全身控制器，并配套覆盖多样协调需求的基准。方法三件套：① 校准稀疏运动参考——保留任务相关的人体运动结构、免在线关节空间重定向，为精准控制留出运动学自由度；② 离线策展「机器人运动 × 校准稀疏参考」配对分布，把训练分布塑形至稳定、物理合理的全身协调；③ 显式误差反馈与运动编码解耦——提升控制精度的同时支持灵活指令接口。v1 提交于 10-30，随 Tue-03 批次公开（北京 11-03 13:00，窗口内）。

### 5. Auriga 技术报告：任务无关具身 agent harness 零样本关闭 RoboDojo 68.3% 规划-执行鸿沟（arXiv 2611.01112 · Tue-03 批次 | 2026-11-03 BJ 13:00 公告）

**事件概述**：
Auriga 团队（21 人署名，Chang Xu 组）量化了具身 VLM 的规划-执行鸿沟：在 RoboDojo 上，GPT-6 Astra 在参考控制接口下操作成功率仅 22.5%，移除手臂执行环节即升至 76.2%——差距不在「会不会想」而在「能不能动」。Auriga 作为任务无关 harness 零样本（无目标任务试跑、无重置）关闭该鸿沟的 68.3%：模型在显式任务信念上做全部任务决策，经直接工具调用或合成多步 Python 程序行动；harness 提供校准 3D 测量、指端参考双臂控制与通往机器人的单一准入网关；运动前模型在仿真暂停态检视视觉轨迹预览。v1 提交于 10-31，随 Tue-03 批次公开（北京 11-03 13:00，窗口内）。

### 6. WorldSketch：VLM 不再生成动作、转而「搭建世界模型」——自改进运动学世界模型实现零样本移动操作（arXiv 2611.00513 · Tue-03 批次 | 2026-11-03 BJ 13:00 公告）

**事件概述**：
WorldSketch（Jiaming Wang）提出 agentic robotics 新范式：VLM 不编排预定义技能、也不直接生成动作，而是作为 agent 主动查询感知工具，搭建并可视化校验一个「最小运动学世界模型」——只捕获任务相关物体、交互几何与可能运动；几何规划器随后在该模型上联合优化接触与全身运动。世界模型本身可自改进：执行反馈核验结果、更新不确定假设，使 agent 能力随部署累积。随 Tue-03 批次公开（北京 11-03 13:00，窗口内）。
