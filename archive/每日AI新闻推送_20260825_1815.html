  • 实际影响：6000 条样本换 14.6pp 的 SWE-bench 跃升，数据效率比规模更重要

关键指标

  • GitHub Star：1.76 万

JetBrains Junie Local：免费本地 AI Coding Agent，跑在 Mac 上
2026-08-25 | DEV Community

事件概述

JetBrains 发布 Junie Local，一款完全本地运行的 AI 编程智能体，无需 Token、无需订阅、代码不外传。使用 Qwen3.6-27B 4-bit 量化模型，需 Apple M5 Mac + 64GB RAM。安装只需一条命令 /local，约 20GB 下载后自动启动本地服务器。

技术与工程价值

  • 核心机制：Prefill 优化（MLX-VLM 8-bit 指令集补丁，M5 比 M4 快 40%）、KV-cache 复用、投机解码（n-gram 匹配）
  • 实际影响：解决本地 AI Coding Agent 三大痛点——设置摩擦、模型选择、质量不足

关键指标

  • 模型：Qwen3.6-27B（4-bit 量化）
  • 硬件要求：Apple M5 + 64GB RAM
  • Prefill 速度：约 650 token/s（M5 裸机）
  • 价格：完全免费，无注册、无订阅
#AI Coding #本地部署 #开源

  • 实际影响：改写 AI 工厂"每兆瓦产出"与"每百万 token 利润"经济账，低延迟推理成为 Agent 编程等场景的关键竞争点

关键指标

  • 每兆瓦吞吐：+30x vs GB300 NVL72
  • 每百万 token 成本：-35x
  • 架构：七芯（Vera CPU + Groq 3 LPU + BlueField-4）
