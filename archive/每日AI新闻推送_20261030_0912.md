### 3. LangChain 发布 Managed Deep Agents v0.10：声明式浏览器使用与异步子智能体（公开 beta）（LangChain 官方博客 | 2026-10-30 BJ 00:54）

**事件概述**：
LangChain 托管智能体平台 Managed Deep Agents 发布 v0.10 双核心能力：① Browser Use——在项目根目录声明 `browser.py`（`define_browser(scope=..., idle_ttl_seconds=600)`）即注入浏览器沙箱四工具（snapshot 读取无障碍树、run 导航交互、screenshot、handoff 登录移交）；② Async Subagents——子智能体标 `async: True` 后在自己线程后台运行，经 async task tools 启动/检查/取消，结果以主动通知回传（忙碌时插入模型调用间隙、空闲时以新 run 唤醒、审批挂起时保留待复）。首发时刻经页面 schema.org datePublished 钉住：2026-10-29T16:54:00Z（北京 10-30 00:54），官方表述「available in public beta today」。

**技术与工程价值**：
- **核心机制**：浏览器会话隔离与登录态设计——默认每对话一个浏览器、跨轮次复用但不继承其他线程 cookies；`scope="user"` 下同一用户全部对话共享登录态；遇登录墙/2FA 走 `browser_handoff(reason)`：Slack/Studio 推出链接由真人接管远程浏览器操作后交还，期间密码不进入模型消息与 traces，handoff 链接 15 分钟过期。异步子智能体与主代理共享 sandbox（可读已写文件），LangSmith 中显示为主 run 之下子 run；配套 `runtime.thread` 线程溯源、Slack 原生 Stop、channel handlers（实验性）、`resolveUser` 身份映射等周边；breaking changes：MCP 配置迁移至 `tools/mcp.ts|.py`。
- **实际影响**：托管 agent 平台补齐「网页操作」与「并行子任务」两块最高频能力，浏览器 human-in-the-loop 移交与凭据隔离给出了可复制的合规设计；与 openclaw、mastra（本跑窗口内高频提交）等开源 agent 框架的托管化竞争加剧。v0.9 已加入 schedules、per-run configuration、Slack reactions。

**关键指标/资源**：
- 评测/性能：无性能基准数字（平台发布文）；浏览器默认空闲 TTL 600 秒、handoff 链接 15 分钟过期；文中引述 DataDome 报告称 9 月 agentic browser 请求跳升 4.7 倍（第三方安全厂商口径，转述）。
- 代码/文档：官方博客 https://www.langchain.com/blog/managed-deep-agents-browser-use-and-asynchronous-subagents ；起步：`uvx --from managed-deepagents mda init` → `uv run mda deploy`（public beta，未提及 GA 时间表）。
