①OpenClaw 2.0 发布：项目史上最大更新 （OpenClaw Foundation | 2026-08-31）

事件概述：停更近7周后，OpenClaw 于8月31日发布 v2026.8.1（代号 2.0），官方称"意外地发布了史上最大版本"。由 933 名贡献者（其中 569 人为首次贡献）合并超过 1.6 万个 PR，覆盖安装流程、浏览器 UI、消息系统、记忆机制、安全权限及共享会话全链路。

③Claude Code Opus 5 Auto Mode 模块伪装攻击攻破：60–80% 成功率 （Johann Rehberger @wunderwuzzi23 | 2026-09-01）

事件概述：安全研究员 Johann Rehberger 于9月1日公开实战攻击报告：针对最新版 Claude Code（Opus 5 模型 Auto 模式），通过构造恶意网站摘要请求，诱导 Agent 使用 curl 下载 ZIP 归档，进而利用 Python 模块伪装（module-shadowing）加载攻击者控制的 struct.py，最终实现远程代码执行（RCE）。小样本实验中攻击成功率达 60–80%，而 Anthropic 委托第三方评估显示的 Auto 模式提示注入成功率为 0.00%——两者形成尖锐反差。

技术与工程价值

  • 核心机制：攻击链为"网站摘要→WebFetch失败→Agent自主改用curl→解压ZIP→运行自定义Python解码器→导入base64时触发恶意struct.py→RCE"。关键洞察在于：即使 Agent 拒绝直接运行攻击者二进制文件，其自主编写解码器的行为反而成为攻击载体；单步看似合理的决策累积为完整系统接管。
  • 实际影响：揭示 Auto 模式（8月中旬起成为默认）在"读取不受信任外部内容并按内容行事"场景下的根本性脆弱——纯 Prompt 层防护无法覆盖模型自主绕路行为；对依赖 Agent 处理邮件附件、第三方仓库 README、网页摘要的生产环境构成直接威胁。

关键指标 / 资源

  • 攻击成功率：60–80%（小样本，针对性攻击链）
  • Anthropic 官方评估：Auto Mode 提示注入成功率 0.00%（标准测试集）
  • 已负责任披露至 Anthropic
  • 原始报告：X @wunderwuzzi23 / cyberwire.com 同日播客报道

④智谱发布 2026 中报：API 收入同比增 2736%，GLM-5.3 开源权重落地 （智谱 Z.ai | 2026-08-31）

事件概述：智谱（2513.HK）8月31日发布上市以来首份中期业绩：上半年收入 9.54 亿元（同比 +399.7%，已超 2025 全年），净亏损 20.72 亿元（同比收窄 12.1%）。结构性变化更引人注目——开放平台及 API 业务收入 8.25 亿元（同比 +2736%），占总收入比例从 15.2% 跃升至 86.5%；同期单位 Token 推理成本较年初下降 80%，已实现十万卡级国产芯片规模化低成本推理。同日 GLM-5.3 开源权重在 Hugging Face 正式上传（BF16/FP8 双版本，约 770GB），许可协议含年营收超 100 亿美元企业需经 Z.ai 安全审查条款。

技术与工程价值

关键指标 / 资源

  • 收入：9.54 亿元（+399.7% YoY），API 收入 8.25 亿元（+2736%）
  • API 平均定价：+101%（量价齐升），单位 Token 成本：-80%

⑤Google Research 提出 SKILL.state：长程 Agent 会话 Token 用量降低 94% （Google Research | 2026-09-01）

事件概述：Google Research 于9月1日发布 SKILL.state 架构论文，针对长程 Agent 会话中上下文不断膨胀导致的延迟恶化与 context poisoning 问题，提出用显式、可变执行状态替代追加式对话历史的运行时方案。每个步骤仅向模型提供三样东西：不可变的技能规范、当前结构化状态、最新观测值；中间推理结果一旦产生有效状态更新即被丢弃。实验显示累计 Token 消耗降低 94%，任务准确率提升。

技术与工程价值

  • 核心机制：将 Agent 记忆从"数据库式追加历史"转为"文件格式式显式状态"，支持持久化、版本控制与跨模型迁移；与 ByteDance 同期发布的 Chain-of-Experience 论文形成对照——后者主张保留"混乱的历史尝试记录"优于"整洁的摘要记忆"，两者在记忆管理哲学上呈现分歧。
  • 实际影响：SKILL.state 为长程 Coding Agent、自动化工作流等场景提供了可落地的效率优化路径；架构无关设计允许移植至现有 skill runtime；配合 Google 同期发布的 Gemini 3.6 Flash Managed Agents（hooks/triggers 支持），Agent 工程化基础设施进一步完善。

关键指标 / 资源

  • Token 降低：94%（累计会话）
  • 核心创新：显式可变执行状态替代追加式历史
  • 架构：与现有 skill runtime 兼容
  • 关联研究：ByteDance Chain-of-Experience（保留混乱历史更优）/ Tencent ContextPilot（自适应软压缩）
