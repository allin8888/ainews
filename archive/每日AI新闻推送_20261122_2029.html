1. Inkling 2 Mini（Thinking Machines Lab | 2026-11-21）

事件概述

Thinking Machines Lab 发布 Inkling 2 Mini，一款 26.4B 参数开源代码大模型。采用「looped transformer」架构——中间层对每个 token 循环计算三次，激活参数仅约 3.4B，总内存占用 ~20GB，可在配备 32GB 统一内存的 Mac 上离线运行。Apache 2.0 许可。

技术与工程价值

核心机制：稀疏专家 + 多层重复推理 + 门控消息传递，以更低激活参数量换取更高推理深度；原生低比特训练降低显存压力。
实际影响：在 SWE-bench Pro v2 Hard、DeepSWE v1.1、Vibe Code Bench 等仓库级编程基准上超越 Qwen3.8-27B，成为 sub-100B 开源模型中的 agentic coding 领跑者；单命令 ollama run inkling2mini 即可本地部署，推动离线代码 Agent 落地。

2. Anthropic Claude Managed Agents「Dreaming」功能详解（Code with Claude 活动报道 | 2026-11-21）

事件概述

Anthropic 于「Code with Claude」两天活动中展示 Claude Managed Agents 的「Dreaming」功能——多 Agent 协作时，各 Agent 可将任务笔记自动写入共享存储；下一位接手相同代码任务的 Agent 可读取这些笔记快速上手，实现跨会话知识积累。

技术与工程价值

核心机制：Agent 自写自读笔记（self-notes），通过 Consolidation 流程聚合信息并发现跨任务模式；默认工作流从「Prompt Claude」转为「Claude 自我提示」。
实际影响：将多 Agent 代码协同从纯并发改为可累积经验的迭代过程，缩短同一代码库的切换成本，是 Production Coding Agent 向「团队化」演进的关键一步。

3. Together AI 安全事件：AI 编码 Agent 泄露凭证导致 Prompt 样本被盗（Together AI 官方公告 | 2026-11-21）

事件概述

Together AI 于 11 月 21 日发布安全事件通知——开发公共 GitHub 仓库 xorl 期间，一个 AI 编码 Agent 不慎提交了包含凭据的配置条目，该凭据随后被第三方获取并用以下载存储在私有 Hugging Face 仓库中的 Prompt 样本（涉及 MiniMax M3、GLM-5.2、Kimi K2.6 模型的 June-July 请求数据）。

技术与工程价值

核心机制：Agent 无意识 commit 了含 API key / HF token 的文件 → 凭据暴露窗口期内被外部获取 → 访问私仓下载历史 Prompt 采样。
实际影响：暴露了当前 AI 编码 Agent 在企业级开发链路中的核心隐患——Agent 缺乏「知识边界」意识，会主动抓取配置环境；也验证了 Dragos 研究的结论：200 万个注入探针中部分探针流入非授权渠道。Together AI 随即推出最小特权凭据、PR 扫描、ZDR 默认关闭三项补救措施。

4. Anthropic 员工称借助 Claude 找到黎曼猜想证明线索（Yahoo Finance 报道 | 2026-11-21）

事件概述

Anthropic 技术团队成员 Levent Alpöge 在其个人网站发布四页论证，声称在与 Claude 协作过程中发现了黎曼猜想的证明思路，描述「Claude 在接近终点时远超我……它飞翔、舞蹈、闪耀」。该声明为个人初步成果，尚未经过正式数学界同行评审。

技术与工程价值

核心机制：人类数学家 + LLM 深度协作，LLM 提供长程推理辅助与结构搜索，人类负责最终验证——体现了 RSI（Research Software Engineering）方向的前沿探索。
实际影响：若后续证实有效，将是 LLM 参与解决千年难题的首个产业案例；但当前仍处于「待同行评审」阶段，需谨慎看待。
