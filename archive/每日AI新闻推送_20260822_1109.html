1 OpenAI 全面开源 Codex Harness，Agent 运行时成为新战场
格隆汇 / OpenAI 官方博客 | 2026-08-21

OpenAI 宣布将驱动 Codex App、CLI 与 IDE 扩展的底层执行框架 Codex Harness 以 Apache-2.0 协议全面开源，仓库 github.com/openai/codex 截至当日已累计约 10.7 万 Star、1.6 万 Fork。

核心机制

  • 开源三层接口：codex exec（CI/脚本）、Codex SDK（TypeScript/Python 编程式调用）、app-server（持久会话/事件流/人工审批，JSON-RPC 协议）
  • Harness 负责上下文维护、工具调用、沙箱执行、权限审批等"脏活"，不做推理

实际影响

  • 仅 Harness 侧调整即让 GPT-5.6 Sol 在 ARC-AGI-3 上得分从 13.3% 升至 38.3%，输出 Token 减少约六倍
  • 落地案例：Thrive Holdings 税务申报流程（7000 份申报表，准备时间 -33%）；思科云控制平台自然语言 App Builder

关键指标

  • 10.7 万 GitHub Star / 1.6 万 Fork
  • ARC-AGI-3：13.3% → 38.3%（仅 Harness 调整）

2 DeepSeek Harness 一周三更，把 Claude Code 与 Codex 收编为子代理
新京报 / 数据猿 | 2026-08-19–21

DeepSeek Harness 于 8 月 13 日开放 MIT 协议开发者预览后，一周内完成三次版本迭代（RC.7 → RC.8 → 0.1.0），将 Claude Code 和 Codex 正式纳入插件式子代理体系。

核心机制

  • v0.1.0-rc.8 新增 DeepSeek-V4-Flash-Vision-Exp 多模态选项，支持原生图片请求与图文混合输入
  • Profile Bundle 机制：Claude Code/Codex 作为可按需安装的子代理加载
  • reportDelivery 唤醒：子代理完成任务后主动回传唤醒父任务，不再依赖轮询
  • 工具层视觉：对无视觉模型，通过 OCR/颜色统计/像素扫描将图片转成结构化信息

实际影响

  • 开发者可在单一框架内灵活切换不同模型和工具链，根据任务类型自动选择最优 Agent 执行
  • 发布 24 小时内收获超 200 颗 GitHub Star

3 Generalist AI 发布 GEN-1.5 机器人基础模型，被类比为"具身智能的 GPT-3 时刻"
新智元 / 东方财富 | 2026-08-20

硅谷 Generalist AI 发布新一代机器人基础模型 GEN-1.5，仅需看 3-12 秒人类演示即可零代码执行新任务，10 项操作 one-shot 平均成功率 59%（少样本微调后提升至 83%），李飞飞、英伟达等参投。

核心机制

  • 物理提示（Physical Prompting）：将感知运动示例放入上下文窗口，类比 LLM 的 Prompt Engineering
  • 单次示范学习：3-12 秒演示 → 几秒内学会新任务
  • 物理提示串联：将不同示范串联为更长行为序列
  • 梯度下降少样本自适应：1-5 分钟数据 / 10-50 次演示 → 1-10 个梯度步骤微调

策略涌现

  • 用簸箕代替刷子把积木铲进碗里（训练数据中未见该工具组合）
  • 自发切换双手拧瓶盖 / 用另一只手拨掉粘在指尖的乐高积木

关键指标

  • one-shot 平均成功率 59% / few-shot 83%
  • 30 秒记忆窗口 / 100Hz 动作轨迹生成频率
  • 多模态 + 本体感知 + 传感器融合架构
