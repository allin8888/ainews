1NVIDIA AVO 智能体在 ARC-AGI-3 取得 100% 满分

来源：NVIDIA 官方博客 | 2026-08-21
NVIDIA 通用编程智能体 AVO 在 ARC-AGI-3 交互式推理基准测试中取得 100.00 RHAE 满分，完成全部 25 个环境、183 个关卡，仅用 6624 步环境动作。同一模型 Claude Opus 5 裸跑仅得分约 30%，AVO 通过持久记忆与监督器架构实现 3 倍性能跃升。

技术与工程价值

  • 核心机制：AVO 采用两层架构——主 Agent 负责探索与优化，监督器在搜索停滞时介入重定向；持久记忆跨迭代保留推理状态与评估结果
  • 实际影响：证明"框架层优化"可释放模型 70% 的潜力，调编排架构比换模型更具性价比
  • 主战场验证：AVO 在 GPU 算子优化任务中连续自主运行 7 天，探索超 500 个方向，提交内核比 cuDNN 快 3.5%

关键指标/资源

  • 评测/性能：ARC-AGI-3 RHAE 100.00（满分），6624 步动作（较 VISTA 少 12%）
  • 代码/论文：NVIDIA Developer Blog、TechCrunch 深度解读
  • 同基准历史：2026 年 4 月最佳模型得分 <1%，人类平均约 80%

2OpenAI 开源 Codex Harness，争夺 Agent 运行时标准

来源：OpenAI 官方博客 | 2026-08-19
OpenAI 将驱动 Codex App、CLI 和 IDE 插件的底层执行框架 Codex Harness 以 Apache-2.0 协议完全开源，开源组件包括 codex exec、Codex SDK 和 App Server，仓库 Star 数已突破 10.7 万。

技术与工程价值

  • 核心机制：Harness 负责管理对话状态、调度工具调用、执行沙箱隔离和审批策略；通过保留推理痕迹 + 上下文压缩优化，GPT-5.6 Sol 在 ARC-AGI-3 上得分从 13.3% 升至 38.3%，Token 消耗降低 6 倍
  • 实际影响：将"怎么管模型"的工业级答案公之于众，三层接口覆盖从一次性任务到产品级 Agent 的全谱系
  • 竞争信号：与 DeepSeek Harness 形成"Agent 运行时开源占位战"

关键指标/资源

  • 评测/性能：ARC-AGI-3 13.3% → 38.3%（仅改 Harness），Token 消耗 ×1/6
  • 代码/论文：GitHub openai/codex（Apache-2.0，107k+ Star，16k+ Fork）
  • 集成方式：任意 OpenAI 兼容端点可接入（DeepSeek/Kimi/GLM 等）

5DeepSeek V4-Flash-Vision-Exp 多模态实验模型上线，视觉基准超越 Opus 4.8

来源：DeepSeek 官方博客 | 2026-08-21
DeepSeek 发布实验性多模态视觉模型 DeepSeek-V4-Flash-Vision-Exp，在 V4-Flash（284B MoE，激活 13B 参数）基础上扩展图文混合输入能力，在 ALE 和 ZeroBench 两项视觉基准测试中超越 Anthropic Opus 4.8；端侧部署技术同步开源。

  • 实际影响：国产开源模型在多模态 Agent 场景实现性能突破，降低开发者接入视觉能力的成本门槛
  • 生态扩展：DeepSeek Harness 本周内一周三更，将 Claude Code 与 Codex 收编为子代理

关键指标/资源

  • 评测/性能：ALE、ZeroBench 视觉基准超越 Opus 4.8；Chartography 64.3（Opus 4.8 为 65.0）
  • 代码/论文：DeepSeek API 文档、GitHub deepseek-ai/harness
  • 价格：与 V4-Flash 一致，千张图约 1 元
