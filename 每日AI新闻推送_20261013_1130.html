1 Meta 发布 Muse Wonder / Muse Wonder Full 前沿模型：Active Memory + Active Focus 面向长程 Agent 任务Meta | 2026-10-12 美东

事件概述

Meta Superintelligence Labs（Alexandr Wang 团队）发布 Muse Wonder 与 Muse Wonder Full 两款前沿模型，主打跨会话记忆保持与多步骤目标持续推进，正式重返与 OpenAI / Anthropic 的前沿模型竞争。

技术与工程价值
  • 核心机制：Active Memory 让模型跨对话携带并主动检索用户关键上下文；Active Focus 让模型在困难目标前自动尝试替代路径、从错误中恢复、在关键动作前与用户确认。1M token 上下文，多模态输入，输出为文本。
  • 实际影响：Meta 在 14 个月研发周期内将综合智能指数从 Muse Spark 1.3 的 48 分推至 Muse Wonder Full 的 56 分（AA v4.3），六周提升 8 分；「个人超级智能」产品路线正式落地商业化。
关键指标/资源
  • 评测/性能（自述数据，未见第三方复现）：SWE-Marathon Muse Wonder Full 57.5% vs Claude Opus 5.5 46.3% vs GPT-6 Astra 42.5%；DeepSWE 1.1 Full 79.0 vs Opus 74.2；Harvey Legal 13.1 vs Opus 4.2。Artificial Analysis 独立评分：Full 56 / 标准 52（Opus 5.5 为 58）。
  • 定价：API 输入 $4/M、输出 $20/M（与 Opus 5.5 同价位）；Full 版仅通过 Muse Code 订阅（$50/$200/月）。
  • 独立基准冲突：AA 综合分低于 Meta 自述长程编码优势；第三方实测 3D 生成与图像-HTML 任务表现明显落后（见待核实）。

事件概述

Ola-Sem 正式开源版本 UniWAM（Unified World-Action Model）将语义理解、未来视觉预测与动作生成纳入统一架构，首次系统揭示人类-机器人联合预训练的 Scaling 趋势，代码与权重全面开源。

技术与工程价值
  • 核心机制：三组件统一架构——Physical Reasoner（Qwen3-VL-2B）+ World Generator（Wan2.2-TI2V-5B）+ Action Predictor，通过联合多模态注意力交互；引入「物理语言」作为共享监督；历史条件流匹配减少生成步数；未来视觉噪声增强降低对精确预测的依赖。
  • 实际影响：首次在 10,000+ 小时数据上验证人机联合预训练 Scaling 趋势；真机实验（AgileX Piper 双臂平台）验证长程任务执行能力；为具身基础模型规模化训练提供方法论支撑。
关键指标/资源
  • 评测/性能：LIBERO 99.2% / LIBERO-Plus 92.6% / RoboTwin 2.0 C2R 68.32%（C2C→C2R 仅降 6.82pt）；真机 4 类任务平均成功率 67.5%、指令跟随率 82.5%；长程桌面整理 5.0/6（vs π₀.₅ 4.8 / Motus 3.2）。

事件概述

跨维智能（DexForce）发布 UNITAS（A 3D-Native World Action Model for Embodied Manipulation），主张「只有让模型原生理解三维物理世界，世界模型才真正接近世界本身」，探索为 Physical AI 建立统一三维表示空间的新路径。

技术与工程价值
  • 核心机制：突破传统 VLA/WAM 以二维图像 token 为桥梁的范式，直接让模型在三维物理空间中联合建模观察、行动与世界变化；引入「动作流」（Action Flow）与「场景流」（Scene Flow）两个互补量，在同一坐标系下联合学习。
  • 实际影响：将「策略模型」与「世界模型」两个独立问题统一为可解释的三维物理交互建模，是 3D 原生物理 AI 架构的代表性探索；中国团队在 3D 具身世界模型方向的持续输出。

4 清华 VeriLoop E2 开源：VGR 循证收敛递归机制让模型无法自证成功清华 SGR 机器人实验室 | 2026-10-12

事件概述

清华大学深圳国际研究生院智能机器人实验室开源 VeriLoop E2（27B 后训练模型，基于 Qwen3.8-27B，Apache-2.0，原生 262K 上下文），核心创新是 VGR（VeriLoop-Governed Recurrence）机制——将「模型提案」与「外部验证」严格分离，候选状态只有在保护证据坐标无退化且至少一项严格改进时才原子提交，否则完整回滚，模型不能自证成功。

技术与工程价值
  • 核心机制：VGR 将任务求解建模为候选状态转移：模型作为 proposer 生成候选潜变量位移，固定 decoder 物化为输出，外部 verifier 在固定合同下返回受保护证据秩；弱支配且至少一坐标严格改进才提交；配合 14 条 Golden Rules 工程契约约束长周期任务的可审计性。
  • 实际影响：为「可验证智能」提供工程范式——在软件工程与科学研究中防止模型用局部优化掩盖全局错误；将 RSI 循环的安全性从「信任模型」转向「验证证据」。
关键指标/资源
  • 评测/性能（自述数据）：SWE-bench Pro 76.2% / Terminal-Bench 2.1 88.8% / DeepSWE v1.1 64.6%；AIME 2026 98.3% / GPQA Diamond 93.9%；黎曼 ζ 临界线零点比例下界 67.350003708785593%（严格有限维证书）。
  • 代码/权重：Apache 2.0，vLLM 0.17.0 OpenAI 兼容接口；HF / ModelScope 已上架。

5 智谱开源 GLM-Legal：基于 GLM-5.3-Flash 的法律智能体全通过率 19.2%智谱 Z.ai | 2026-10-12

事件概述

智谱发布 GLM-Legal，基于轻量级 GLM-5.3-Flash 基座，通过法律领域中期训练与高效后训练强化专业能力，覆盖合同审查、证据分析与合规流程，API 已开放申请并将接入其桌面智能体平台 AutoClaw。

技术与工程价值
  • 核心机制：轻量基座（GLM-5.3-Flash）+ 领域中期训练 + 高效后训练三层架构，以远低于全量前沿模型的参数规模实现法律专业能力，显著降低垂直 Agent 部署成本。
  • 实际影响：法律 Agent 领域首次出现「轻量基座 + 第三方验证」完整开源方案——结果由第三方评测机构 Vals 独立验证（Harvey LAB 全通过率 19.2%，较基座提升 12.5pt），与决策模型浪潮（OpenAI/Perplexity/Cloudflare/微软四方竞争）形成对标。
关键指标/资源
  • 评测/性能（Vals 独立验证）：Harvey 法律智能体基准（24 个执业领域）全通过率 19.2%（基座 6.7%）；LegalBench 与中文 PLawBench 与顶级闭源模型持平。
  • 代码/API：API 申请已开放；接入 AutoClaw 桌面平台；完整模型规格待核实。
