DeepSeek 开源 V4 系列首款多模态模型：DeepSeek-V4-Flash-Vision-Exp

DeepSeek · 2026-08-31 · Hugging Face MIT 许可
事件概述

8月31日上午，DeepSeek 在 Hugging Face 以 MIT 许可协议开放了 V4 系列首款实验性多模态模型 DeepSeek-V4-Flash-Vision-Exp（总参数约 305B，每 token 仅激活 13B，激活率 4.6%）。该模型在 V4-Flash 纯文本架构基础上续训视觉模块，原生支持图片输入（JPEG/PNG/GIF/WebP），同时完整保留文本推理与 Agent 能力。

技术与工程价值
  • 核心机制：在已有高性能纯文本 Flash 模型基础上"续训"出视觉能力，最大限度保留原有文本 Agent 能力；开源内容除模型权重外，还包括视觉编码器、Aligner、DFlash Attention、MoE、Hyper-Connections 与 DSpark 最小化 PyTorch 推理实现。
  • 实际影响：标志着 DeepSeek 产品线正式从"文本推理"向"视觉 Agent"延伸——模型能将图片作为 Agent 工作流程的一部分（如制作 PPT、读取修改网页、生成带动态效果的前端页面），使开源社区能以极低门槛部署多模态 Agent。
关键指标/资源
  • ApexBench：36.5（Opus 4.8 为 39.4）；ZeroBench：35.0（反超 Opus 4.8 的 34.0）；Agents' Last Exam：27.3（超 Opus 4.8 的 25.7）
  • Terminal Bench 2.1：83.9；DeepSWE：59.3（反超 Opus 4.8 的 58.0）
  • Hugging Face：deepseek-ai/DeepSeek-V4-Flash-Vision-Exp，MIT 许可；API 已于 8月21日上线
  • 部署门槛：128GB 内存即可运行，支持 vLLM/SGLang/Transformers/Docker Model Runner

NVIDIA 拟 129 亿美元收购 Hugging Face：直取开源 AI 生态核心入口

The Information / 钛媒体 · 2026-08-30/31 · 尚未正式公告
事件概述

据 The Information 及钛媒体等多方报道，英伟达已同意以约 129 亿美元收购开源 AI 模型与开发者平台 Hugging Face，交易价格相当于其 1.5 亿美元年化收入的 86 倍。若完成，这将是云/GPU 厂商历史上最大单笔收购之一。9月1日，黄仁勋同步宣布与联发科深化合作（35 亿美元可转债），一周内累计承诺投资超 140 亿美元。

技术与工程价值
  • 核心机制：Hugging Face 托管超过 303 万个开源模型、近 100 万个数据集、1300 万开发者活动数据，是 Llama/Qwen/DeepSeek 等主流开源模型的首要分发渠道。英伟达收购的直接意图是掌控开源模型的"默认优化/默认部署/默认推理"入口。
  • 实际影响：这是英伟达从"卖 GPU"向"掌控开源 AI 分发链路"的战略跃迁——此前 OpenAI、Anthropic 等大厂均在尝试自研芯片以降低对英伟达的依赖，而 Hugging Face 的开源生态锁定是反制这一趋势的关键抓手。Hugging Face 年初曾拒绝英伟达 5 亿美元参股，九个月后以 129 亿美元整体出售。
关键指标/资源
  • 交易规模：129 亿美元（86 倍市销率）；Hugging Face 年化收入 1.5 亿美元
  • 状态：尚未正式公告，可能面临反垄断监管审查
  • 同日动态：Hugging Face 发布 399 美元"机器鸭"Microduck（物理 AI 训练机，24小时售出 260 万美元）

Meta Muse Code 正式版发布：跨会话消息 + 工作流引擎，订阅制全面落地

Meta AI / explainx.ai · 2026-09-01
事件概述

9月1日凌晨，Meta 宣布旗下 AI 编程工具 Muse Code 正式脱离 Beta，推出跨会话消息传递（Inter-session Messaging）、多智能体工作流引擎（Workflow）、SDK 开发者预览版及三档订阅套餐。扎克伯格在 X 官宣："Muse Code is out of beta and now built to handle bigger, more complex engineering tasks." 模型底座仍为 Muse Spark 1.2（与 Beta 期相同），重点升级在 harness 层。

技术与工程价值
  • 核心机制：跨会话消息通过 Unix Socket 在本地进程间传输，不经过网络；Workflow 模式允许用户调度大量子智能体协同处理复杂工程任务（设置强度为 ultra 时自动触发）；Rewind 功能支持回退至历史安全节点并需用户二次确认。
  • 实际影响：Meta 成为继 OpenAI（Codex）、Anthropic（Claude Code）、Cursor 之后第四家推出 dedicated terminal coding agent 的头部闭源实验室，但此次升级重点在编排而非模型能力——Coding Agent 竞争已从"谁的模型更强"转向"谁的 harness/记忆/协作基础设施更扎实"。
关键指标/资源
  • 订阅方案：Everyday Usage $5/月 / High Usage $15/月 / Power Usage $50/月
  • 安装方式：curl -fsSL https://dev.meta.ai/install.sh | bash（macOS/Linux）
  • 模型：Muse Spark 1.2（未更新），基准数据沿用 Beta 期 Terminal-Bench 2.1 / DeepSWE 1.1

清华 AIR 与域变换发布 Zeva：具身 In-Context Causal Learning，冻结模型越用越强

清华 AIR / 量子位 · 2026-09-01
事件概述

9月1日，清华AIR（智能产业研究院）与域变换 AI 联合发布 Zeva——首个实现 In-Context Causal Learning（ICCL）的具身世界动作模型（WAM）。Zeva 的核心突破在于：模型参数完全不更新（zero gradient update），仅通过上下文记忆机制从交互经验中持续学习；在真实化学实验室中累计成功率从 Evolve 1 的 26% 单调提升至 Evolve 4 的 73%；一次人类演示即可让模型"学会"新操作。

技术与工程价值
  • 核心机制：将传统"梯度更新权重"的学习范式转为"扩充因果上下文"——每个环境步提取视觉状态、动作编码、状态变化三类信号，递归编码为 Causal Interaction State；双时标因果记忆（BIT 保当前尝试连贯性、PIM 跨尝试累积可复用经验）；决策时检索与当前任务阶段匹配的交互证据，构造 Causal Prompt 注入冻结的 Cosmos3 动作生成模型。
  • 实际影响：为具身智能开辟了一条独立于参数规模的 scaling 路径——交互次数越多、因果上下文越丰富，模型对当前物理域的辨识越准；一次人类演示即可完成 one-shot warm-up（Place Beaker 最高提升 20pp，Pour Water 提升 15pp），大幅降低部署成本。
关键指标/资源
  • RoboCasa365-Atomic5 平均成功率：76.8%；ChemLab-Evo Pick Up Test Tube 65%→100%、Place Beaker 25%→70%、Pour Water 30%→80%
  • 论文：arXiv（2026-09-01 提交）；项目主页：https://air-embodied-brain.github.io/Zeva/
  • 对比基线：优于 ViTAL、Fast-WAM、Cosmos3-Nano 等开源 WAM

欧盟将 ChatGPT 指定为 VLOSE 纳入 DSA 最严监管：首个 AI 产品直面 6% 全球营收罚款风险

欧盟委员会 / Euronews · 2026-08-31
事件概述

8月31日，欧盟委员会依据《数字服务法》（DSA）正式将 ChatGPT 指定为"超大型在线搜索引擎"（VLOSE），Reddit 和 Roblox 同日获 "超大型在线平台"（VLOP）指定。ChatGPT 在欧盟申报月活达 1.591 亿（远超 4500 万门槛），系首个以对话式 AI 产品身份被纳入 DSA 最严监管梯队的服务。三家须在 2027 年 1 月前完成系统性风险评估与合规整改，违规最高可处全球年营业额 6% 罚款。

技术与工程价值
  • 核心机制：DSA 对"在线搜索引擎"的定义为纯功能性描述（允许用户输入查询、检索全网内容并以任意格式返回结果），欧委会将 ChatGPT 的"联网检索+来源呈现"功能段映射到搜索引擎定义，而非针对其生成式输出本身。
  • 实际影响：这是欧盟首次将 DSA 的适用范围延伸至生成式 AI 产品，为后续 AI 产品的监管定性树立先例；OpenAI 2026 年上半年 ChatGPT 广告业务已达 10 亿美元 ARR，此时叠加 DSA 合规义务将显著增加运营复杂度。
关键指标/资源
  • 合规期限：2027 年 1 月（收到通知后 4 个月）
  • 违规上限：全球年营业额 6%（DSA 第 74 条）
  • 附加义务：年度系统性风险评估、独立审计、监管机构数据访问、透明度报告
  • 同批指定：Reddit（5720 万月活）/ Roblox（4800 万月活）为 VLOP
