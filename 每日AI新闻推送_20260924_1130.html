1. OpenAI 与 Anthropic 同日「双响」发布：GPT-6 Sol/Luna 价格腰斩 + Claude Opus 5.5 成本降 40% （OpenAI / Anthropic 官方博客 | 2026-09-22 美东，窗口内为第二信源密集期）

事件概述

9 月 22 日美东约 90 分钟内，OpenAI 上线 GPT-6 Sol（$2/M 输入、$10/M 输出）与 GPT-6 Luna（$0.10/M 输入、$0.50/M 输出），均比 GPT-5.6 促销价降 50% 且为永久定价；同日 Anthropic 上线 Claude Opus 5.5（$4/M 输入、$20/M 输出，较 Opus 5 降 20%，缓存读取 $0.20/M 较前代降 60%），官方口径「大多数任务表现与 Fable 5.1 相当、典型工作负载成本降 40%」。9 月 23 日（窗口内），Codex CLI 0.156.1 将 Sol/Luna 加入模型选择器、Claude Code 2.1.280 将 Pro/Team 默认 Opus 从 Sonnet 切至 Opus 5.5。

技术与工程价值

  • 核心机制：OpenAI 将 Astra 训练方法论下沉至更快更便宜的 Sol/Luna，缓存与推理效率改进使价格腰斩；Opus 5.5 主打「效率型编码」——长程代码迁移/审计 token 消耗更少（HAProxy C→Rust 重写 9.5h vs Fable 5.1 的 12h、成本降 51%），输出速度较 Opus 5 快 30%+。两家不约而同把「更便宜」作为核心卖点，标志竞争从「能力上限之争」转向「能力×成本×速度×规模化效率」。
  • 实际影响：Luna 输入 $0.10/M 宣告高频低复杂度场景 API 红利期结束；Opus 5.5 缓存读取 $0.20/M 与 Fable 5.1 同档，长程 Agent 成本结构被重定价。开源模型（MiMo-V2.6、Kimi K3）的低价竞争倒逼海外厂商走性价比路线——「定速前沿」叙事与商业化节奏首次正面碰撞。

关键指标/资源

  • 评测/性能：GPT-6 Sol AutomationBench xhigh 33.2%（超低档 Astra 30.3%，单任务成本约为 Opus 5 的 9%）；Luna 高推理档较 5.6 Luna +5.4 分、成本降 58%；Opus 5.5 SWE-bench Pro 89.9% / Terminal-Bench 4.0 66.4%（xhigh）/ FrontierCode 1.1 Main 54.4%（均为发布方自述，待核实）
  • 代码/论文：OpenAI 官方博客（9/22 美东）；Anthropic 官方 anthropic.com/claude-opus-5-5（9/22 美东）；窗口内增量：Codex CLI 0.156.1 / Claude Code 2.1.280（AI/TLDR 9/23 跟踪）

2. 小米开源 MiMo-V2.6 系列 + HySparse2 架构公开：RL 算力扩展路径验证，百万 token prefill 砍至 1/5 （小米 MiMo / 罗福莉 / arXiv | 2026-09-22 北京时间首发，9/23 窗口内为 HySparse2 arXiv 在线 + MiMo Desktop 正式版）

事件概述

小米 MiMo 团队于 9 月 22 日发布并全面开源 MiMo-V2.6 系列（Pro 旗舰 + Flash 高效推理 + Pro-UltraSpeed 超高速变体），AA 综合智能指数 46 分，超越 Kimi K3 与 Qwen3.8 Max，登顶全球开源权重模型第一；Pro 单任务成本 $0.13，约为海外同档模型的 1/20–1/60。9 月 23 日（窗口内），负责人罗福莉公开 MiMo-V3 核心架构 HySparse2 并挂出 arXiv:2609.26368：两级 KV 共享（KV 桥接 + KV 复用）+ token 级稀疏选择 + 强制近期窗口，在 1M token 上下文中 prefill FLOPs 较 Hybrid SWA 降低 5.02 倍、KV cache 缩小 4.5 倍。

技术与工程价值

  • 核心机制：① RL 算力扩展的 RSI 路径——6 天 Live RL 训练（约 75 万条轨迹、成本 ~347 万美元），大 Batch 全异步架构（单步 1,568 样本 / 1M 上下文 / 2.7–3.7B token）+ 多任务 Harness 混合 + 更大 Grader 算力（组内相对比较形成自我改进闭环），冻结 MoE Router 抑制漂移 + 四层 Reward Hacking 防线。② HySparse2 架构——YOCO 式 self/cross-decoder 拆分 + 全注意力层间 KV 桥接 + 块内稀疏层 KV 复用 + token 级 top-k 选择 + 强制近期 128 token 窗口；prefill 节点仅需部署前 25 层（权重砍半）。
  • 实际影响：国产开源模型首次以「RL 算力扩展」而非「堆参数」实现智能代际跃升（参数规模不变、DeepSWE v1.1 提升 14–17 分）；HySparse2 将 Agent 推理成本拆解为可量化工程账目，与 MiMo-V2.6 的「智能-成本帕累托前沿」形成完整叙事。MiMo Desktop 客户端 + UltraSpeed（20× 输出速度）在 9/23 窗口内完成正式版发布，补齐「模型 + Agent 生态 + 端侧交付」全链路。

关键指标/资源

  • 评测/性能：AA Intelligence Index 46 分（开源第一，自述榜单口径）；DeepSWE v1.1 Flash 65.68 / Pro 72.57；SWE-bench Verified 61.1→66.2；HySparse2 1M token：prefill FLOPs -5.02× / KV 2.69GB（-4.5×）/ RULER-v2@256k 58.45（论文自述，待核实）
  • 代码/论文：mimo.xiaomi.com/mimo-v2-6（9/22 官方发布）；arXiv:2609.26368（HySparse2，9/23 在线）；HuggingFace: XiaomiMiMo/mimo-v26（权重 + 技术报告 + 7k RL 任务环境 + verl 训练框架 + mini-harnesses）

3. Google Intrinsic 在 ROSCon 2026 开源 Intrinsic Core 生产级机器人软件栈（Apache 2.0） （Intrinsic / GitHub | 2026-09-22 ROSCon 多伦多）

事件概述

9 月 22 日 ROSCon 2026（多伦多，9/22–24）上，Google 旗下机器人软件公司 Intrinsic 将其生产部署中实际使用的机器人核心软件栈 Intrinsic Core 以 Apache 2.0 协议开源。核心组件：Intrinsic Control（硬件无关实时控制框架，支持运动中传感器驱动的轨迹中途调整）、基于 NVIDIA FoundationPose 的 6-DoF 位姿估计（免刚性夹具）、自动运动规划（碰撞避让路径生成）、抓取规划（实时传感反馈自适应）、Gazebo 仿真服务、自动相机标定与预配置 ROS 2 驱动。同步发布 Open Machine Tending Solution（OMTS）——CNC 上下料的开源参考设计，支持 FANUC 与 Universal Robots 硬件。

技术与工程价值

  • 核心机制：与 ZDTaichu（第 65 跑）/ Open-RAIL（第 65 跑）的「模型侧开源」不同，Intrinsic Core 是控制 + 感知 + 规划三层一体的工程栈开源——Intrinsic CTO Brian Gerkey 明确「这不是丢代码给你玩，是我们自己软件栈的核心」。硬件无关控制层意味着切换机器人臂/夹爪/传感器无需重写驱动；Apache 2.0（非 copyleft）允许企业在其上构建专有产品而不必公开修改。
  • 实际影响：机器人感知/规划/控制层长期由各集成商自建，Intrinsic Core 将「生产级 + 开源 + 参考设计」三合一首次标准化；OMTS 瞄准「美欧数万家机加工车间自动化率仅 8%」的市场。战略层面，这是 Google「物理 AI 生态 Android 路线」的具身智能版本，与 NVIDIA Isaac ROS / 高通 Dragonwing 形成三层竞争。

关键指标/资源

  • 评测/性能：Intrinsic AI for Industry Challenge 中两个团队在柔性线缆插入任务上达成 100% 成功率（Intrinsic 自述，待核实）；OMTS 支持 FANUC/UR 硬件（官方口径）
  • 代码/论文：github.com/GoogleRobotics/intrinsic（Apache 2.0，9/22 ROSCon 发布）；Intrinsic 官方博客；The Robot Report / SiliconANGLE / GismoLand 跟踪

4. Cognex 5 亿美元收购 RealSense + 高通收购 PickNik：机器人感知与操控软件层 48 小时双并购 （Cognex 8-K / Qualcomm 官方 | 2026-09-22 / 09-23）

事件概述

48 小时内两笔机器人软件/感知并购先后落地：① 9/22（SEC 8-K 披露） Cognex 以 5 亿美元全现金收购 Intel 系深度相机公司 RealSense（另含 ~50M 股票激励），进军机器人感知/Physical AI；交易预计 2026 Q4 完成，RealSense 面部生物识别业务独立拆分。② 9/23 高通宣布收购 PickNik（MoveIt 开源机器人操控框架维护方），交易条款未披露，MoveIt 1/2 承诺保持开源，将与 Dragonwing 机器人平台与 Arduino 深度整合。

技术与工程价值

  • 核心机制：两笔交易形成「感知层（Cognex×RealSense：3D 深度相机 + 实时感知流）→ 操控层（高通×PickNik：MoveIt 运动规划 + 逆运动学 + 抓取）」的上下游覆盖——芯片/相机厂商通过收购软件层把「从传感器到轨迹生成」的完整链路纳入自有生态。RealSense 深度相机是 ROS 机器人应用的事实标准输入源；MoveIt 是 ROS 操控领域使用最广的开源框架。
  • 实际影响：Physical AI 基建竞争从「模型能力」下沉至「感知硬件 + 操控软件 + 端侧算力」全栈——Google Intrinsic（开源控制栈）、NVIDIA（Isaac ROS + Jetson Thor）、高通（Dragonwing + MoveIt）、Cognex（RealSense 深度相机）四方在同一周争夺机器人开发生态；开源社区成为各厂商的「获客入口」而非「交付终点」。

关键指标/资源

  • 评测/性能：RealSense 2026 年营收预计 $80–90M（+50% YoY，公司自述，待核实）；Cognex 预计 2027 年贡献 >$100M 收入（VDC Strategy 估算）；高通收购条款未披露
  • 代码/论文：Cognex SEC 8-K（9/22）；Qualcomm 官方公告（9/23）；The Robot Report / VDC Strategy / Biometric Update 跟踪

5. Boston Dynamics 在 HMGMA 正式启用 RMAC：Atlas 人形机器人在真实产线开始训练 （Boston Dynamics 官方 | 2026-09-21 美东，9/22–24 窗口内为集中报道与文档片预告）

事件概述

9 月 21 日（美东周一），Boston Dynamics 宣布在 Hyundai Motor Group Metaplant America（HMGMA，佐治亚州）正式启用 RMAC（Robotics Metaplant Application Center）——Atlas 人形机器人测试与训练中心，6 月试点后转入全面运营。Atlas 在复刻真实产线的环境中学习物流准备与零部件排序任务；Hyundai 计划未来数年在全球现代/起亚工厂部署约 25,000 台 Atlas，并新建美国工厂（年产能 30,000 台）；Atlas 2028 年进入 HMGMA 实际产线（零部件排序），2030 年扩展到组件装配。9 月 23 日（窗口内），Hyundai × Boston Dynamics × Bloomberg 联合制作的纪录片《The Robotics Race: At the Forefront》确认 9/30 上线。

技术与工程价值

  • 核心机制：RMAC 的核心价值不在单台机器人，而在训练数据飞轮 + 产线级验证闭环——Atlas 在「与真实工位 1:1 复刻」的环境中学习排序/装配，通过性能验证后再部署到实际产线；2027 年 RMAC 扩容 10× 并扩展到非汽车行业，同时在 HMGMA 场内新建 30,000 台/年产能的工厂，形成「训练→验证→量产→多行业推广」的完整路径。
  • 实际影响：这是人形机器人从技术演示到工业部署的关键过渡节点——不同于 Figure/Tesla Optimus 的「实验室→家庭/工厂」路线，Atlas 选择「工厂内训练中心→工厂内产线→多厂扩展」的渐进路径；2030 年组件装配目标意味着从「排序/搬运」到「力控精密操作」的能力跃迁。
