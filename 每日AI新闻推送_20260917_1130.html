1Google Dream-RSI：AI Agent 通过"做梦"实现递归自我改进，162 倍算力节省 Google / DeepMind / UMD / UVA | arXiv:2609.14858 | 2026-09-16

Google、Google DeepMind、马里兰大学与弗吉尼亚大学联合发布 Dream-RSI（Recursive Self-Improvement through Evolving Worlds），提出不改动模型权重、只进化 Agent 探索策略的 RSI 路线。核心机制：将 Agent 历史搜索记录存为"发现树"，以此树作为"重放模拟器"，让策略 Agent 在零执行成本下测试成千上万种探索策略，只将最优策略部署回真实世界，形成闭环。
技术与工程价值
  • 核心机制：三阶段闭环——①在线探索：当前策略引导冻结模型（Gemini 3.1 Pro / 3.7 Flash）真实执行，完整记录工作区快照、生成代码、评估诊断与得分；②构建重放模拟器池：所有发现树进历史数据库；③"做梦"策略改进：策略开发 Agent 批量生成候选 Python 策略，直接在历史树上重放评估（不跑一行代码、不调一次模型），胜出的策略部署回真实探索。数学上保证新策略不会弱于旧策略。
  • 实际影响：将 Agent 搜索成本与模型参数量解耦，小模型（Gemini 3.7 Flash）同样受益。论文同时发现反直觉结论：将历史经验总结为"高层原则"注入 Prompt 反而使探索效果显著更差——空洞原则会转化为认知偏见，过度约束搜索空间，扼杀多样性。
关键指标 / 资源
  • Lasso 正则化路径：317 次调用 vs SimpleTES 51,200 代（约 162 倍节省）；GPU Kernel VGG16/LayerNorm：同等性能所需生成次数降至 1/2.43 与 1/1.79；ConvDiv/ConvMax：同等预算下性能分别提升 2.09× 与 1.44×（均为论文自述数据，未见第三方复现）
  • 代码/论文：arXiv:2609.14858（9/16 提交）| dream-rsi.com | GitHub: zhengkid/Dream-RSI
  • 一作 Tong Zheng（马里兰 UMD 博士生，2026 暑期 Google Student Researcher）；17 人作者团；Logan Kilpatrick 此前已透露"Google 看到 RSI 早期迹象"

2紫东太初开源 ZDTaichu5.0-9B：9B 参数在 9 项空间基准拿下 8 项同档位第一，同步开放数据生产管线 中科院自动化所 / 武汉AI院 | GitHub/HuggingFace | 2026-09-15

9 月 15 日，中国科学院自动化研究所联合武汉人工智能研究院开源面向物理世界的通用多模态大模型 ZDTaichu5.0-9B，约 9B 参数（语言主干 Qwen3.5-9B + 视觉编码器 C-RADIOv4-H），在九大国际空间理解基准的 10B 以下档位中取得 8 项第一，并同步开放完整的空间多模态数据生产管线方案，是业内首个"权重 + 数据管线"双开放的具身多模态模型。
技术与工程价值
  • 核心机制：自适应循环推理（Adaptive Loop Inference）——内置熵门控机制，先做标准前向计算，由熵评估当前 token 不确定度：确定性高直接输出，高不确定性节点在模型内部重复执行部分层块、迭代调整隐层表征（全程不调用外部工具），配套阻尼更新、双重停止判据与状态回滚防止发散。"看题下菜"式设计在复杂空间任务上提升精度的同时不显著推高 Token 推理成本。
  • 实际影响：9B 参数在 10B 档位空间具身能力最强，且通用能力不降级（AI2D 91.48、AIME 2026 89.2、LiveCodeBench v6 73.4）。Apache-2.0 协议 + 数据管线全开放，机器人/科研团队可直接用自己的行业数据继续训练，降低空间具身智能落地门槛。
关键指标 / 资源
  • MindCube-tiny 78.27（vs Gemini 3 Pro 70.87、Grok 4 63.56）；ViewSpatial 62.50；AI2D 91.48；WeMath 75.9；OCRBench 85.5；IFEval 93.7；AIME 2026 89.2（均为官方自述数据，未见第三方独立复现）
  • 代码/论文：GitHub: Taichu-AI/ZDTaichu5.0-9B（Apache-2.0）| HuggingFace: TaichuAI/ZDTaichu5.0-9B | 项目主页: taichu-ai.github.io/ZDTaichu5.0-9B
  • 榜单限定 10B 以下同参数组；通用能力层面 Gemini 3 Pro 等大模型仍领先；演示视频由官方发布

3中国移动开源 Open-RAIL：行业首个连接 VLA/WAM 模型与机器人本体的通用工程底座 中国移动 | 2026-09-16

9 月 16 日，中国移动宣布向全球开源 Open-RAIL——行业内首个连接 VLA（视觉-语言-动作）/ WAM（世界-动作模型）模型与机器人本体的通用工程底座。核心目标：打破不同机器人硬件（关节定义、通信协议、坐标系方向）之间的壁垒，让模型推理、真机执行、数据回流、模型迭代在同一个底座内闭环运转。
技术与工程价值
  • 核心机制：轻量级硬件抽象层——将控制、状态读取、动作执行统一标准化；新机器人只需实现底层适配并注册，上层逻辑完全复用；模型侧统一接入约定，新模型仅需实现标准推理接口即可接入。端边云灵活部署：代码零改动，端侧算力不再是限制。
  • 实际影响：已适配 4 款异构机器人、支持 10 个主流 VLA/WAM 模型；新模型接入最低仅需 50–100 行代码；关节加速度标准差从 10+ rad/s² 降至 0.1 rad/s²（动作平滑度提升两个数量级，自述数据）；每次真实运行自动积累训练数据，格式开箱即用，消除数据采集的额外成本。
关键指标 / 资源
  • 动作平滑度（关节加速度标准差）10+ rad/s² → 0.1 rad/s²（自述数据，未见第三方复现）；新机器人接入周期从"以周计"压缩至"以小时计"；新模型接入 50–100 行代码
  • 代码/论文：Open-RAIL 项目主页: cmcc-tao.github.io/open-rail/（9/16 开源）
  • 具身智能工程瓶颈——模型能力（大脑）与硬件控制（手脚）之间的适配成本；Open-RAIL 将"机器人换型"这一工程痛点标准化

4Cognition Devin 接入 macOS：云端 Mac VM 自主开发并测试 iOS 应用 Cognition 官方博客 | 2026-09-16

9 月 16 日，Cognition 宣布 Devin Cloud 支持 macOS 工作区，将自主编程流程扩展到 iPhone、iPad 和 Mac 原生应用开发。Devin 现在可在云端使用 Xcode 和 iOS Simulator，从复现 Bug、修改代码到在应用内验证修复结果，全流程自动化，并自动发送 TestFlight 链接到 Slack。
技术与工程价值
  • 核心机制：基于 AWS EC2 Mac 裸金属主机 + 苹果 Virtualization.framework 运行；虚拟机内置持久化快照、网络访问规则；任务开始前自动完成 Xcode 安装、Simulator 预热与系统索引；测试时 Devin 同时读取辅助功能树（Accessibility Tree）与屏幕截图，用结构化控件完成按钮操作，检查界面与状态变化。
  • 实际影响：这是主流 Coding Agent 首次完整支持原生 iOS/macOS 应用开发闭环（复现 → 修改 → 运行 → 验证 → TestFlight 交付）；结合 Cognition 同日发布的 SWE-2 模型（9/12，已入历史），Devin 的"代码能力 + 平台覆盖"双线推进正在重塑移动原生开发的人力边界。
关键指标 / 资源
  • SWE-2 FrontierCode 1.1 Main 50.0%（9/12 发布，已入历史报告）；macOS 工作区无公开 benchmark（产品功能发布）；iOS 应用自动化测试成功率（待核实）

5字节 Seed / TokenWave 等发布 ASPIRE、S³Gym、HarnessDev 三项 RSI 新基准：从"会做题"到"能自进化" 字节跳动 Seed | Blog | 2026-09-15~16

字节跳动 Seed 团队与 TokenWave 等机构在 Self-Developing Agents 项目中发布三项专门衡量 Agent 自我进化能力的基准：ASPIRE（从模糊目标中找学习方向）、S³Gym（从经验中学习）、HarnessDev（Harness 改进能否保留）。三者共同覆盖完整 RSI 闭环的三个关键断点，填补当前"半环 RSI"（有外部 Golden Verifier）与"完整闭环 RSI"之间的评测空白。
技术与工程价值
  • 核心机制：ASPIRE：Agent 只能看到自然语言描述的能力方向（如"提高数学推理能力"），学习材料、更新方法、验证方式全部自主决定；S³Gym：测试 Agent 能否从成功/失败经验中提取可复用技能；HarnessDev：检验 Agent 对执行框架的改进能否保留并跨任务泛化，而非过拟合特定 benchmark。三者共同定义"从模糊目标中找到正确方向"这一完整 RSI 的核心能力边界。
  • 实际影响：当前 80%+ 的 Agent 系统停留在 L1/L2 级（执行自主 + 策略自主，参考 RSI L1-L5 分类学），缺乏"经验自主"（L3）与"环境适应"（L4）的标准化评测；三项基准的发布为"自进化 Agent"提供了可复现、可量化的竞争标尺，预计将成为下一个 Agent 评测赛道的核心参考。
关键指标 / 资源
  • 三项基准本身（评测工具发布，无模型跑分数据）；当前 Agent 系统 L1/L2 占比 >80%（RSI 调研 491 篇论文统计）
  • 代码/论文：ASPIRE arXiv:2608.31111 | 项目主页: self-developing-agents.github.io（S³Gym / HarnessDev 博客）
  • 与 Dream-RSI（9/16，本期第 1 条）同日形成"基准 + 方法"双发布，RSI 评测基建正在加速成形
