1. GVS5H「Gorilla vs. 5 Humans」：零训练账本式自编排让 27B 开源权重在 LiveCodeBench Hard 上追平 Claude Fable 5

第一来源：GitHub slee-persis/GVS5H + Hacker News｜仓库首发 2026-08-26、论文最后更新 09-23；窗口内触发事件为北京时间 10-25 11:56 登 HN 首页（175 分 / 63 评论）

事件概述

第三方研究者开源 GVS5H——一种免训练的「账本式零样本自编排」（ledger-based zero-shot self-orchestration）harness：让同一个模型的多个全新实例自行拆解问题，并通过一个存放 plan / notes / 当前解法的共享文件系统协调，以五实例规模在 100 道最新困难 LiveCodeBench 题目上把开源权重的 pass@1 推到接近甚至超过 Claude Fable 5 单次调用的水平。仓库 8 月 26 日创建、论文与图表最后更新 9 月 23 日（首发在窗口外）；窗口内的实质事件是其登 HN 首页并引发对基准有效性的集中质疑。

技术与工程价值

  • 核心机制：① 无编排者、无训练——协调逻辑写在提示与共享「账本」文件里，实例间靠文件系统读写交接状态，规避中心 orchestrator 的上下文与吞吐天花板；② 11 个开源 / 闭源权重同批测试，pinned backend 上最高提升 25.6 个百分点，作者明确写出负结果「部分模型无提升甚至变差」；③ 两个成本档位：托管侧 Qwen3.8 Flash Next 编排后 pass@1 93.0%（Fable 5 单次调用 90.4%，成本约其 9%）；本地自托管侧 Qwen3.8-27B 从单次 66.8% → 92.4%；④ 转录分析把增益归因于「问题分解 + 持久化上下文」，即推理时组织结构而非思考预算；⑤ 代码 MIT、论文与运行数据 CC BY 4.0，附可复现命令（--engine multiagent / single 对照）。
  • 实际影响：为「inference-time compute 的第二条腿」提供可复现开源参照，直接支撑自托管成本论证——9% 成本追平前沿编码模型若成立，会把「本地 27B + 编排」变成中小团队可选项。窗口内的社区审查同样有价值：指出生效依据的 LiveCodeBench 更新版（1,055 题）近乎确定存在训练污染、未与 Astra / GPT-6.1 Sol / Fable 5.1 / Opus 5.5 对照、也未做「harness 加持后的对手机位」对照（作者自陈 Opus 5 用旧脚手架单次经 OpenRouter，口径不可比）。与此前 Agentic Shortcutting 基准利用率 82.4% 的可信度危机一脉相承：结论方向可用，绝对分数不可引用。

关键指标/资源

  • 评测/性能：pass@1 93.0%（Qwen3.8 Flash Next，编排）vs 90.4%（Claude Fable 5，单次调用）；本地 Qwen3.8-27B 66.8% → 92.4%；11 模型 / 100 题、pinned backend 最高 +25.6 pt；托管成本约为 Fable 5 的 9%（全部为作者自述数据，未见第三方复现，且存在基准污染与对照组缺失问题）

2. xAI 把 Agent 推向真实世界动作面：Grok Bot 0.77 支持代打电话、通话纪要与支付账户连接

第一来源：官方 X @elonmusk｜2026-10-25 北京 22:31 / 22:35（snowflake 解码核验）

事件概述

埃隆·马斯克在 X 宣布 Grok @Bot 现在可以代用户致电个人或商家、代为提出请求、记录通话内容并把摘要回送用户；其引用内容为 Grok Bot 0.77 版本说明，同时包含 Mac 端消息通道接入、加入 Tailscale 私有网络、连接支付账户，以及 Bot 分享邀请需 Premium / Ultra 等条目。

技术与工程价值

  • 核心机制：① 语音外呼闭环——拨号 / 等待 / 按键（IVR）/ 转接四类呼叫动作 + 实时转录 + 结构化纪要回送，等于把电话网络当成 Agent 的一个标准工具；② 与已上线的手机原生 App 授权（日历、提醒、通讯录、短信、位置、家庭，逐 App 授权）及邮箱、专属手机号拼出完整的「身份 + 动作」面；③ Tailscale 私网接入是本版本最具工程含义的一项：Agent 从「只能访问公网 API」升级到「可触达内网服务」，同时把支付账户纳入可授权动作集。
  • 实际影响：Agent 能力边界从「读数据 / 写代码」推进到「打电话、付款、进内网」三类真实世界高价值动作；风险面同向放大——不可逆外呼（对第三方构成骚扰 / 社会工程）、支付授权链路、私网接入后的横向移动面。与 Anthropic 千级并行子代理 + 爆炸半径 containment 属同一周的对偶推进。

关键指标/资源

  • 评测/性能：xAI 未公布该版本任何量化基准（自述能力清单，未见第三方复现）；背景值——SpaceX 管理层 10-20 财报电话会称 Grok Bot 周付费用户约 80 万、月内翻倍（第三方转述口径，待核实）
